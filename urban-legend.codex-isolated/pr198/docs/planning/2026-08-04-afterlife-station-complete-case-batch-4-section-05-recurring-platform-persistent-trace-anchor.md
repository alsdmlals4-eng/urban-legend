# 저승역 완전 사건 설계 — Section 05

책임 Decision:

상태:

`APPROVED_PRODUCT_DECISION / GRILLME_BATCH_4_5_OF_10 / PENDING_BATCH_MERGE`

`NOT_AUTHORIZED / NOT_RUN`

## 1. 패턴의 역할

`[회귀 승강장]`은 저승역의 두 번째 대표 회수 패턴이다.

첫 대표 패턴 `[무정차 환송]`이 구출 단계에서 보관한 공식 승차권을 전투 파훼 수단으로 사용했다면, 이 패턴은 Decision 2에서 확인한 다음 지식을 사용한다.

> 위치는 초기화되지만 시간·기록·흔적은 유지된다.

승차권을 파훼 수단으로 사용하지 않는다. 공식 검표 흔적은 지속 흔적 후보 중 하나일 뿐이며 필수 선행 조건이 아니다.

## 2. 가변 전조 구조

패턴은 `N ≥ 2`, `N-1개의 전조`, 최종 턴 사전 대응 계약을 따른다.

최종 발현 전에 다음 조건을 만족해야 한다.

- 최소 2개의 초기화 주기
- 최소 2종의 독립적인 지속 흔적
- 각 흔적의 타임스탬프와 좌표
- 초기화마다 사라지는 허상과 계속 남는 흔적의 대비

단일 전조 하나만 보고 정답 좌표를 알 수 없게 한다. 복수 초기화 주기의 기록을 교차 비교해야 한다.

## 3. 첫 사건의 3턴 예시

### 1턴 전조

플레이어의 평상 행동 전에 요원·괴이 허상·승강장 표지가 진입점 배치로 되돌아간다.

그러나 다음은 유지된다.

- 전투 턴과 시계의 타임스탬프
- 이전 행동의 연속 로그
- 전장에 놓인 소지품 위치
- 초기화 직전 기록한 요원 로그의 좌표

```text
위치는 초기화
+ 시간·기록·흔적은 유지
→ 플레이어 평상 행동
→ 괴이 평상 행동
```

### 2턴 전조

플레이어의 행동이 먼저 해결된 뒤 승강장 표지와 괴이 허상이 다시 초기화된다.

새로 나타난 허상 좌표는 이전 주기와 달라지지만, 다음 흔적은 같은 구역에 누적된다.

- 소지품 위치
- 공식 검표 흔적
- 연속 녹음의 시간 지점
- 요원 로그의 좌표
- 누적된 잔향 자국

공식 검표 흔적은 `[무정차 환송]`을 먼저 파훼했을 때만 추가되는 선택적 근거다. 검표 흔적이 없더라도 다른 독립 흔적 둘 이상으로 해결할 수 있다.

### 최종 턴

여러 개의 괴이 허상이 서로 다른 좌표에 겹쳐 나타나며 전체 위치 초기화를 준비한다.

```text
대응 선택
→ 전체 위치 초기화 발현
→ 결과 산출
→ 평상 진행
```

플레이어는 발현 전에 어떤 흔적 조합이 실제 잔향 좌표를 가리키는지 확정해야 한다.

## 4. 지속 흔적의 교차 비교

### 소지품 위치

초기화 전에 내려놓은 물건은 같은 좌표에 남는다. 단독으로는 우연한 위치일 수 있으므로 다른 기록과 함께 사용한다.

### 공식 검표 흔적

공식 승차권을 제시한 개찰기 흔적은 위치 초기화 뒤에도 유지된다. 선택적 근거이며 필수 근거가 아니다.

### 연속 녹음의 시간 지점

초기화 순간에도 녹음이 끊기지 않는다. 특정 시간 지점에서 반복되는 잡음과 좌표 로그를 연결할 수 있다.

### 요원 로그의 좌표

요원이 각 초기화 직전에 기록한 괴이 반응 좌표가 시간 순서대로 남는다.

### 누적된 잔향 자국

허상의 위치는 매번 달라지지만 실제 잔향 주변의 자국은 사라지지 않고 농도와 형태가 누적된다.

플레이어는 복수 초기화 주기에서 다음을 교차 비교한다.

```text
지속 시간 일치
+ 좌표 중첩
+ 서로 다른 출처의 흔적
= 실제 잔향 좌표
```

단일 빛나는 오브젝트가 정답을 알려 주지 않는다.

## 5. 정확한 대응

최종 턴에 플레이어가 `지속 흔적 고정`을 선택하고, 복수 기록이 겹치는 좌표를 지정한다.

```text
지속 흔적 고정
→ 실제 잔향 좌표 확인
→ 잔향 고정
→ 전체 위치 초기화 실패
→ [파훼]
→ 잔향 노출
→ 괴이 [취약]
```

- 잔향은 다음 유효 공격·연결 절단·회수 행동의 대상으로 노출된다.
- 정확한 고정은 초기화 현상을 일시적으로 막지만 사건을 자동 종료하지 않는다.
- 매뉴얼이 실제 잔향을 자동 표시하지 않는다.
- 정답 좌표를 자동 선택하지 않는다.
- 플레이어가 기록을 비교하고 좌표를 직접 지정한다.

## 6. 다른 대응의 결정적 결과

### 초기화된 괴이 허상 공격

- 빗나감
- 괴이 반격
- 실제 잔향은 노출되지 않음

### 방어

- 초기화 피해 감소
- 전체 초기화는 완전히 취소되지 않음
- `[취약]은 발생하지 않는다`

### 이미 사라진 흔적 선택

- 잘못된 좌표 고정
- 위치 초기화
- 해당 흔적이 비지속성이라는 관찰 로그 추가

### 흔적이 충분히 쌓이기 전 조기 고정

- 행동만 소비
- 파훼 효과 없음
- 즉시 사망이나 영구 소프트락은 발생하지 않음

이 결과들은 숨겨진 확률로 달라지지 않는다. 같은 전조·기록·선택은 같은 결과를 반환한다.

## 7. 접근성·기록 표현

- 모든 초기화 주기에 타임스탬프를 표시한다.
- 흔적에는 절대 좌표와 상대 위치 설명을 함께 제공한다.
- 전투 기록창에 주기별 텍스트 로그를 남긴다.
- 잔향 자국의 형태 설명과 농도 변화를 텍스트로 제공한다.
- 연속 녹음은 음성 외에 문자 기록과 재생 시간을 제공한다.
- 화면 효과만으로 판별하지 않는다.
- 음향만으로 판별하지 않는다.
- 접근성 기능은 정답 좌표를 자동 추천하거나 후보를 순위화하지 않는다.

## 8. 적대적 검토 Guardrail

- 승차권 제시를 다시 정답으로 사용하지 않는다.
- 공식 검표 흔적이 없는 전투 순서에서도 해결 가능해야 한다.
- 단일 흔적 하나만 누르면 파훼되는 숨은그림찾기로 축소하지 않는다.
- 허상 위치의 시각적 밝기나 색상으로 정답을 암시하지 않는다.
- 매뉴얼이나 접근성 기능이 실제 잔향을 자동 표시하지 않는다.
- 방어·허상 공격과 정확한 잔향 고정에 같은 보상을 주지 않는다.
- 조기 시도는 낭비가 있지만 즉사·영구 실패로 처리하지 않는다.
