## 설계 요약

괴이 매뉴얼의 슬롯은 세션 중 자동 채점되지 않는다. 플레이어는 `단서 [기록]`을 확인하고 획득한 후보를 임의 배치하며, 조사 종료 전에는 이전 페이지를 자유롭게 수정한다.

```text
기록 확인
→ 임의 후보 배치
→ 페이지 진행
→ 이전 페이지 자유 수정
→ 최종 진입 확인
→ 구출·회수에서 현상 관찰
→ 사건 결과 확정
→ 세션 종료 후 정답 공개
```

## 편집 상태

| 상태 | 페이지 수정 | 키워드 재사용 | 정답 공개 |
|---|---|---|---|
| 조사 중 | 가능 | 가능 | 없음 |
| 최종 진입 확인 전 | 가능 | 가능 | 없음 |
| 구출·회수 실행 중 | 읽기 전용 | 기존 참조 유지 | 없음 |
| 조사 후퇴 | 다시 가능 | 가능 | 없음 |
| 사건 결과 확정 후 | 제출본 보존 | 비교용 | 슬롯별 공개 |

페이지 완료는 다음 페이지 해금일 뿐 잠금이 아니다.

## 증거 모델

키워드는 소모 카드가 아니라 비소모 증거 참조다.

- 정규 키워드: 단일 출처와 단서 [기록]
- 사용: page/slot 사용 위치 목록
- 변조 후보: 원본 ID와 변경 변수
- 여러 위치 사용: 동일 객체를 참조
- 정오: 세션 중 숨김

## 실행 검증

구출·회수는 정답표가 아니라 실험 환경이다.

- 결과는 관찰 가능한 현상
- 성공·실패가 후보 하나의 정답 라벨을 직접 제공하지 않음
- 실패 관찰은 기록과 위험 사례로 누적
- 같은 상태 반복은 같은 결과
- 후퇴 수정 시 위험 이력 유지

## 결과 보고서

사건 결과 확정 뒤 다음을 비교한다.

1. 최종 진입 제출본
2. 공식 규칙
3. 슬롯별 정확·부분·오답·미해결
4. 단서 [기록] 근거
5. 변조 원본·변경 변수
6. 구출·회수 결과
7. 일반 클리어와 S 랭크 차이

## Decision 2 교정

세션 중 `확인 규칙` 표시를 제거한다. 검증은 구조·근거·상충·실행 준비도만 보여 주며 정답 여부는 결과 보고서에서만 공개한다.
