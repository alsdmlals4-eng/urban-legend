## 1. 승인 결정

사용자는 대화에서 통합 설계 작성본을 최종 승인하고 PR #58의 병합을 요청했다. 이에 따라 대상 설계는 후속 정본 갱신 및 구현 계획 수립의 기준 설계로 승인한다.

## 2. 승인 범위

다음 상위 제품 방향을 승인한다.

- 권나래를 직접 육성하는 1년 4분기 캠페인
- 텍스트 노벨을 전체 서사와 화면 경험의 기본 문법으로 사용
- 규칙 추리, 조작형 미니게임, 턴제 회수 전투 유지
- 핵심 사건 내부에 조사·검증·회수 전투를 통합
- 권나래 직접 조작과 동료 최대 2명의 자동 보조 스킬
- 기관 교육 및 괴이 연구를 통한 공용 보조 스킬 획득
- 기본 장비와 연구 모듈 강화
- 실패 전진, 분기 정산, 연도 결산, 다음 연도 계승
- 연말 결과를 최종 엔딩이 아닌 해당 연도의 중간 결산으로 처리

이 승인은 코드 구현이나 저장 Schema 변경을 자동 허가하지 않는다. 다음 작업은 별도 계획과 검토를 거친다.

1. `PROJECT_CORE`, GDD, 현재 상태, 로드맵의 정본 갱신 계획 작성
2. 기존 CORE-MVP-001과 신규 상위 루프의 마이그레이션 경계 확정
3. 육성 수직절편의 데이터·UI·테스트·커밋 단위 구현 계획 작성
4. 구현 계획 사용자 승인
5. 승인된 범위만 TDD로 구현
