## 1. 질문과 권장안

앞으로 중요한 질문이나 작업 방향을 제안할 때 내부 취향만으로 결론내리지 않는다.

1. 현재 프로젝트 구조와 정본을 먼저 확인한다.
2. 관련된 벤치마킹 자료와 현업 비교 사례를 조사한다.
3. 프로젝트에 그대로 맞지 않는 관행은 분리한다.
4. 최소 2개 접근의 장단점과 실패 가능성을 비교한다.
5. 프로젝트 제약에 맞는 권장안을 제시한다.
6. 출처·확인일·적용 여부를 기록한다.

벤치마킹은 권위가 아니라 비교 근거다. 대형 스튜디오·상용 엔진·SaaS 관행이라도 현재 팀 규모, Godot 구조, 이미 승인된 정본과 맞지 않으면 채택하지 않는다.

## 2. 승인 배치

- 승인 10건을 최대 10건, 즉 `최대 10건`의 배치 크기로 둔다.
- 일반 배치는 승인 후보를 누적하고 배치 종료 시 정본·GitHub·Google Sheet를 검증한다.
- 다음 조건에서는 10건을 채우지 않아도 조기 체크포인트를 연다.
  - 고위험 충돌이 발견됨
  - 세션 종료가 임박하거나 실제로 종료됨
  - 정본 영향이 커서 후속 결정의 전제가 바뀜
  - 저장·경제·보상·캠페인·데이터 손실 위험이 있음
  - 외부 API·엔진 버전·법적 또는 보안 전제가 바뀜
- 조기 체크포인트는 승인 수를 임의로 늘리기 위한 예외가 아니다. 위험을 격리하고 다음 작업의 전제를 재확인하기 위한 중단점이다.

## 3. 작업별 TDD

모든 작업은 TDD 또는 그 작업 성격에 맞는 테스트 우선 계약으로 시작한다.

### 실행형 변경

코드·Schema·JSON·워크플로·자동화·저장 이관처럼 실행 결과가 있는 변경은 다음 순서를 강제한다.

1. 수용 조건을 자동 테스트로 작성한다.
2. RED를 실행해 의도한 이유로 실패하는지 확인한다.
3. 실패를 통과시키는 최소 구현을 작성한다.
4. GREEN을 확인한다.
5. 중복·결합·이름·경계만 리팩터한다.
6. focused 테스트와 전체 회귀를 실행한다.
7. exact HEAD·명령·결과를 기록한다.

테스트를 먼저 썼다는 사실만으로 TDD가 성립하지 않는다. RED가 이미 통과하거나 무관한 이유로 실패하면 테스트 또는 전제를 바로잡는다.

### 비실행형 작업

조사·기획·문서·아트 방향처럼 직접 실행할 코드가 없는 비실행형 작업에는 가짜 단위 테스트를 만들지 않는다. 대신 먼저 검증 가능한 수용 계약을 작성한다.

- 필수 질문과 비교 축
- 반드시 포함할 출처·Decision ID·상태
- 금지되는 누락·왜곡·충돌
- 정본과 Sheet의 일치 조건
- 완료 판정을 위한 체크리스트 또는 문서 계약 테스트

문서가 자동 검증 가능한 경우 RED/GREEN 문서 계약 테스트를 사용한다. 자동화할 수 없는 부분은 명시적 체크리스트와 적대적 검토 증거를 남긴다.

## 4. 현업 비교 기록

현업 비교에는 다음을 구분한다.

- 업계 공통 원칙
- 도구·엔진별 구현 관행
- 현재 프로젝트에 채택한 부분
- 현재 프로젝트에서 기각한 부분
- 후속 Human QA가 필요한 가정

추천은 `왜 이 프로젝트에 맞는가`를 설명해야 하며, 유명 사례를 단순 모방하지 않는다.

## 5. 정본 동기화

승인된 주요 결정은 동일 Decision ID로 다음을 동기화한다.

- GitHub 권위 Decision
- 관련 Design Spec·Plan·Audit
- Draft PR 설명과 exact HEAD 증거
- 연결된 Google Sheet 작업·결정·감사·변경이력

정본 영향이 큰 변경은 동기화가 끝나기 전 다음 구현 단계로 넘어가지 않는다.

## 6. 승인 경계

다음 승인은 서로 대체하지 않는다.

- 방향 승인
- 작성 문서 승인
- 구현 계획 승인
- 구현 승인
- Human QA 승인
- PR 병합 승인

문서 승인만으로 게임 코드 실행이나 PR 병합을 허가하지 않는다.

## 7. 적대적 검토 기준

각 체크포인트에서 최소한 다음을 확인한다.

- 정본과 구현 계약이 서로 다른 말을 하는가
- 벤치마크가 프로젝트 맥락을 압도했는가
- 테스트가 실제 위험 대신 문자열 존재만 검증하는가
- 저장·보상·캠페인 상태가 소급 변경되는가
- 승인 범위가 조용히 확대됐는가
- 실행하지 않은 Runtime·Human QA를 완료로 표시했는가
