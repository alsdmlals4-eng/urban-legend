# D-2026-08-11-CASE01-RECORDS-TAB-ARCHIVE-IA

> 상태: `USER_APPROVED_RECORDS_ARCHIVE_IA / PLANNING_ONLY / IMPLEMENTATION_NOT_AUTHORIZED`
> 승인 시각: 2026-08-11 KST
> 적용 범위: CASE-01 조사 디바이스 `[기록]` 탭 정보 구조·표시 원칙
> Human/UI 검증: `NOT_RUN`

## 1. 승인 결정

`[기록]` 탭은 사건 자료를 다시 읽고 비교하는 **단일 조사 아카이브**로 구성한다.

기본 3열 구조는 다음을 기준으로 한다.

```text
[기록 분류·목록] | [기록 상세 본문] | [기록 메타·연결 정보]
```

분류 최소 집합:

- 전체
- 현장 기록
- 증거
- 증언
- 통신·방송 기록

## 2. 기록 상세 정보 구조

기록 상세는 필요에 따라 다음 필드를 사용한다.

- 기록 제목
- 시간·출처
- 기록 상황
- 본문 또는 텍스트 기록
- 확인된 내용
- 획득 장소
- 획득 시점
- 관련 인물
- 관련 장소
- 이미 획득한 관련 키워드

모든 필드를 매 기록에 강제하지 않고 자료 유형에 필요한 것만 표시한다.

## 3. 음성·방송 자료 처리

제품에는 조사 기록 재열람을 위한 실제 음성 파일, 재생 버튼, 음성 파형 UI를 넣지 않는다.

통화·녹취·방송 등 원래 음성 기반인 자료도 다음처럼 **텍스트 중심 기록**으로 제공한다.

```text
기록 상황 → 확인된 내용 → 필요한 경우 짧은 발췌 → 출처·시간
```

이 Decision은 사건 연출 전체의 오디오 사용을 금지하는 것이 아니라, `[기록]` 탭의 조사 자료 재열람 계약에서 실제 음성 파일 재생을 사용하지 않는다는 뜻이다.

## 4. 추리 공정성·연결 규칙

- 관련 키워드는 플레이어가 이미 획득한 것만 표시한다.
- 기록 중요도·정답성·추천도·슬롯 적합도를 표시하지 않는다.
- `이 기록이 정답` 또는 특정 슬롯에 넣으라는 추천을 제공하지 않는다.
- `[괴이 매뉴얼에서 보기]` 같은 **비정답성 위치 이동 링크**는 허용한다.
- 링크로 매뉴얼에 이동했다가 돌아오면 기존 기록 선택과 스크롤 문맥을 보존한다.

## 5. 목록 상태

기록 목록에서 허용하는 최소 상태는 다음과 같다.

- `NEW`
- 미열람/열람
- 현재 선택

정답성, 핵심도, 추천순, 위험도 같은 추리 결과를 대신하는 분류는 기본 목록 상태로 사용하지 않는다.

## 6. 루메 연계

기존 `D-2026-08-11-LUME-INTEGRATED-COMPANION-NO-LOG-TAB`을 따른다.

- `[기록]` 우측 하단에 compact 루메를 기본 표시할 수 있다.
- 루메는 현재 기록에 대한 짧은 반응·기능 안내·이미 획득한 정보 재확인만 제공한다.
- 미획득 단서·정답 후보·추천 이동·정답 슬롯을 암시하지 않는다.

## 7. 상태 보존

기존 조사 디바이스 상태 보존 계약을 따른다.

- 다른 탭으로 이동해도 선택한 기록·목록 위치·본문 스크롤을 보존한다.
- 탭 전환 자체는 저장·판정·시간 경과·조사 진행을 발생시키지 않는다.
- 도메인 상태가 실제로 변경되어 기록이 추가되거나 접근 조건이 달라진 경우에만 필요한 목록·상세를 갱신한다.

## 8. 구현 경계

이 Decision은 정보 구조와 UX 계약만 승인한다.

아직 승인하지 않는 항목:

- Godot Scene/Control/GDScript 변경
- 구체적인 JSON/Resource Schema
- 기록 정렬·검색의 최종 세부 기능
- 최종 픽셀 크기·폰트·간격
- 제품 자산 승격

실제 구현은 CASE-01 조사 UI 분리 명세 완료와 별도 구현 계획/TDD 게이트 뒤에 진행한다.
