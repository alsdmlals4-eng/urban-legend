## 결정

괴이 사건은 플레이어가 조사문을 채워 **괴이 매뉴얼을 완성해 가는 구조**로 제작한다.

사건 제작자는 조사 장면부터 순서대로 쓰지 않고 다음 공식으로 결론에서 조사 경험을 역설계한다.

```text
괴이의 실제 규칙
→ 완성 괴이 매뉴얼
→ 2~3장의 완성 조사문
→ 장당 3~5개의 정답 키워드 슬롯
→ 정답을 뒷받침하는 원시 단서
→ 단서를 얻는 장면과 플레이어 행동
→ 그럴듯한 오답 가설
→ 오답을 수정하는 후속 반증 단서
→ 피해자 구출·회수 전투에서 규칙 검증
→ 공식 규칙·위험 사례·미해결 기록
```

이 공식을 프로젝트 작업구조 `docs/workflows/INVESTIGATION_CASE_AUTHORING_WORKFLOW.md`와 기존 등록 스킬 `urban-legend-investigation-case-authoring`에 반영한다. 같은 책임을 가진 새 스킬을 중복 생성하지 않는다.

## 1. 조사문 분량

- 사건당 조사문은 기본 `2~3장`이다.
- 각 장은 `3~5개`의 키워드 슬롯을 가진다.
- 짧은 사건은 2장, 표준·핵심 사건은 3장을 권장한다.
- 장은 발생 조건, 피해자 연결·금지 행동, 구출 절차·회수 전투 대응을 사건 특성에 따라 나눈다.
- 문장 빈칸의 수·품사·길이만으로 정답을 과도하게 누설하지 않는다.
- 완성문은 사건 기록으로 자연스럽게 읽히며 현장에서 실행 가능한 규칙을 표현한다.

## 2. 혼합형 단서·키워드 파이프라인

모든 단서를 즉시 완성 키워드로 지급하지 않고, 모든 단서를 조합 문제로 만들지도 않는다.

```text
명확한 직접 물증·명시적 증언
→ 즉시 사건 키워드

불완전한 현상·간접 증언·상충 기록
→ 원시 관찰 기록
→ 비교·모순 지적·논리 연결
→ 정제 키워드 또는 추론 키워드
```

키워드는 다음 세 층을 구분한다.

1. `원시 관찰 기록`: 플레이어가 직접 확인한 해석 전 사실
2. `사건 키워드`: 관찰을 사건 문맥에 맞게 정리한 조사문용 표현
3. `추론 키워드`: 둘 이상의 기록을 연결해 얻은 관계·규칙

## 3. 단서 출처 계약

모든 조사문용 키워드는 최소한 다음 정보를 보존한다.

- 출처
- 획득 행동
- 선행 조건
- 표시 문구
- 의미 주장
- 사용 조사문 장·슬롯
- 지지·반박하는 괴이 매뉴얼 의미 슬롯
- 신뢰 상태
- 놓쳤을 때의 대체 경로

플레이어가 키워드를 읽었을 때 `어디서 무엇을 했고 왜 얻었는지` 기억할 수 있어야 한다.

## 4. 흥미로운 키워드 원칙

키워드는 일반 명사보다 작은 사건을 담은 표현으로 작성한다.

```text
손자국
→ 안에서 바깥으로 밀려난 젖은 손자국

반사상
→ 본체보다 0.8초 먼저 고개를 든 반사상

안내방송
→ 전원이 꺼진 뒤 재생된 안내방송
```

좋은 키워드는 다음을 만족한다.

- 발견 장면이 떠오른다.
- 하나의 관찰 가능한 사실을 주장한다.
- 출처가 분명하다.
- 시간·대상·원인·행동·결과 관계를 만들 수 있다.
- 정답 전체나 대응 절차를 직접 말하지 않는다.

## 5. 키워드 예산

3장 표준 사건은 약 `18~24개`의 관리 키워드를 권장한다.

```text
정답 키워드                 9~12개
의미 있는 보조 키워드        4~6개
그럴듯한 오답 후보           3~5개
복수 단서 연결 추론 키워드   2~4개
```

획득 방식은 직접 관찰·증언 약 50%, 비교·모순 약 30%, 복수 단서 연결 추론 약 20%를 제작 시작점으로 사용한다. 이 수치는 구현 고정값이 아니라 사건 제작과 Human QA에서 조정할 기준이다.

## 6. 단간론파·역전검사 참고 경계

### 단간론파에서 참고

- 조사 중 확보한 단서가 이후 판단에 실제로 사용된다는 명확성
- 단서명이 발견 장면과 모순 지점을 기억하게 하는 방식
- 중요한 증언에서 물증과 발언의 충돌을 직접 지적하는 플레이 행동

다음은 적용하지 않는다.

- 모든 대화를 논쟁 전투로 만드는 구조
- 단서 하나를 제시하면 즉시 정답 문장이 완성되는 구조
- 사건 해결을 단일 반박 성공으로 축소하는 구조

### 역전검사에서 참고

- 현장 조사·증언·기록에서 얻은 두 정보를 논리적으로 연결해 새 추론이나 조사 경로를 여는 방식
- 단서 획득 → 단서 연결 → 새 단서 생성의 진행감

다음은 적용하지 않는다.

- 의미가 자명한 두 카드만 반복해서 합치는 형식 절차
- 근거 없이 인물의 감정·의도를 찍게 하는 연결
- 논리 연결이 피해자 구출과 회수 전투를 자동 해결하는 구조

## 7. 자연스러운 획득 장면

사건 제작자는 다음 방식을 섞는다.

- 현장 관찰이 세부 조사 지점을 연다.
- 증언과 물증의 모순을 제시해 숨겨진 진술을 얻는다.
- 시간표·CCTV·음향·출입 기록을 비교한다.
- 서로 떨어진 사실을 논리 연결해 추론 키워드를 만든다.
- 안전 절차 아래 제한적 위험 실험으로 규칙을 확인한다.
- 구출·회수 전투 결과를 새 관찰과 위험 사례로 환류한다.

위험 실험은 핵심 진행의 유일한 정답 경로로 강제하지 않는다.

## 8. 그럴듯한 오답

오답은 무관한 쓰레기 카드가 아니라 현재 증거만으로는 합리적인 가설이어야 한다.

각 오답에는 다음이 필요하다.

- 처음에 그럴듯한 이유
- 지지하는 관찰 또는 증언
- 수정하게 하는 후속 반증 단서
- 틀린 채 실행했을 때 남는 위험 사례

정답과 무관한 카드 수를 늘려 난도를 만드는 방식은 사용하지 않는다.

## 9. 사건 제작 산출물

사건 하나는 다음 패키지를 제출한다.

1. 사건 목적과 핵심 조사 질문
2. 실제 규칙 5개 의미 슬롯
3. 완성 괴이 매뉴얼
4. 2~3장 완성 조사문과 장당 3~5개 슬롯
5. 정답·보조·그럴듯한 오답·추론 키워드 표
6. 원시 단서와 출처·획득 행동·대체 경로
7. 조사 장면 흐름과 해금 조건
8. 후속 반증 단서와 가설 상태 전이
9. 피해자 구출·회수 전투 참조 규칙
10. 공식 규칙·위험 사례·미해결 기록
11. 정상·실패·경계 QA 행렬
12. 미확정과 사람 검증 항목

## 12. 적대적 검토

### 방지하는 실패

- 조사 장면을 먼저 쓰고 마지막에 정답을 끼워 맞추는 문제
- 모든 클릭이 완성 키워드를 지급하는 정답 배급
- 모든 단서를 두 카드 결합으로 만드는 반복 절차
- 키워드가 일반 명사라 발견 장면과 출처가 기억나지 않는 문제
- 무관한 쓰레기 오답으로 난도만 높이는 문제
- 조사문을 완성하면 구출·회수 전투가 자동 해결되는 문제
- 핵심 단서 하나를 놓치면 사건 전체가 막히는 문제
- 새 스킬을 중복 생성해 라우팅 책임이 갈라지는 문제

### 남은 미확정

- 사건별 정확한 총 키워드 수
- 장별 슬롯 수를 달리하는 기준
- 비교·연결 UI와 키워드 정제 표시 방식
- 조사 장면별 행동 비용과 일정 시스템 연결
- 위험 실험의 피해자 보호·랭크 비용
- 키워드 탐색·정렬·접근성 UX
- 실제 플레이어가 추론으로 느끼는지 빈칸 맞추기로 느끼는지
