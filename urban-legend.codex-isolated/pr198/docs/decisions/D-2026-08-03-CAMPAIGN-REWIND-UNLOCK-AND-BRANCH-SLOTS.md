## 결정

캠페인 되감기는 첫 번째 1년차 캠페인을 어떤 결과로든 완료한 뒤 조건 없이 해금한다. 첫 플레이 도중에는 사용할 수 없으며, S 랭크·특정 엔딩·특정 난이도·유료 상품을 해금 조건으로 요구하지 않는다.

되감기에는 횟수 제한과 게임 내 재화 비용을 두지 않는다. 선택 지점 이후의 캠페인을 새 정본 결과에 맞춰 다시 플레이해야 하는 시간이 자연스러운 비용이 된다.

최대 3개의 캠페인 분기 슬롯을 제공한다. 첫 번째로 완료한 1년차 캠페인은 자동으로 보호된 보관 기록을 만들며, 플레이어가 명시적으로 삭제하거나 덮어쓰기 승인하기 전까지 캠페인 되감기로 교체되지 않는다.

## 해금 계약

```text
첫 1년차 캠페인 완료
→ 연도 결산 생성
→ 최초 완료 캠페인 보호
→ 캠페인 되감기와 분기 슬롯 해금
```

- 기관 강제 봉쇄·낮은 사건 랭크·미해결 책임이 포함돼도 1년차를 끝까지 완료했다면 해금한다.
- 첫 플레이에서는 사건 내 체크포인트·출동 재개·결과 확정 Gate만 사용한다.
- 캠페인 되감기는 첫 완료 뒤 다른 서사 결과를 탐색하는 메타 기능이다.

## 비용과 제한

- 횟수 제한 없음
- 게임 내 재화 소모 없음
- S 랭크·업적·특정 엔딩 요구 없음
- 유료 상품이나 상위판 독점 금지
- 특정 난이도 완료 요구 없음
- 실제 비용은 선택 사건 이후의 캠페인을 다시 진행하는 플레이 시간

## 캠페인 분기 슬롯

최대 3개 분기를 보관한다.

```text
분기 1 — 최초 완료 캠페인
분기 2 — 과거 사건에서 되감은 새 캠페인
분기 3 — 다른 선택 지점에서 되감은 대안 캠페인
```

분기마다 별도로 보존한다.

- 사건별 캠페인 정본
- 피해자 상태와 후유증
- 동료·기관·외부 세력 관계
- 지식·관계/기관·현장 결과 패킷
- 분기 활성 결과
- 연도 결산과 남은 책임
- 현재 진행 지점

모든 분기에서 공유한다.

- 최고 숙련 랭크
- 축별 최고 기록
- 업적
- 칭호·코스메틱
- 추가 비필수 기록 열람

## 최초 완료 캠페인 보호

첫 번째 1년차 완료 시 보호된 보관 기록을 자동 생성한다.

- 되감기 실행만으로 덮어쓰지 않는다.
- 최초 연도 결산과 피해·관계·책임을 다시 열람할 수 있다.
- 삭제 또는 덮어쓰기는 별도 명시적 재확인을 요구한다.
- 숙련 기록과는 다른 캠페인 정본 기록으로 표시한다.

## 되감기 실행 흐름

```text
되감을 사건 선택
→ 폐기될 이후 사건·후일담·관계·책임 표시
→ 새 분기 슬롯 또는 덮어쓸 슬롯 선택
→ 현재 캠페인 자동 백업
→ 선택 사건부터 새 정본으로 재진행
```

슬롯이 가득 찼다면 덮어쓸 캠페인의 다음 정보를 비교해서 보여준다.

- 진행 연도와 분기
- 핵심 사건 종결 상태
- 주요 피해자 상태
- 핵심 동료·기관 관계
- 남은 책임
- 마지막 저장 시각

## 보호 규칙

1. 캠페인 되감기는 첫 1년차 완료 후 해금한다.
2. 첫 플레이 도중에는 사용할 수 없다.
3. 해금에 S 랭크·특정 엔딩·유료판·특정 난이도를 요구하지 않는다.
4. 되감기 횟수와 게임 내 재화 비용을 두지 않는다.
5. 최대 3개의 캠페인 분기 슬롯을 제공한다.
6. 최초 완료 캠페인은 자동으로 보호한다.
7. 되감기 전에 폐기될 이후 진행과 유지될 숙련 기록을 구체적으로 표시한다.
8. 되감기 시작 시 현재 캠페인을 새 슬롯 또는 선택 슬롯에 백업한다.
9. 슬롯 삭제·덮어쓰기는 명시적 재확인을 요구한다.
10. 숙련 기록·업적·비필수 보상은 캠페인 분기와 무관하게 공유한다.
11. 서로 다른 캠페인 분기의 피해자·관계·결과 패킷·연도 결산을 혼합하지 않는다.
12. 클라우드 동기화나 저장 충돌 시 보호 캠페인을 자동 삭제하지 않는다.
13. 되감기 대상의 정확한 단위는 후속 Decision에서 확정한다.

## 적대적 검토

### 방지하는 실패

- 첫 플레이부터 불리한 결과를 즉시 되돌리는 것이 최적 전략이 됨
- 이야기 탐색을 위해 재화를 아끼거나 파밍해야 함
- 되감기권 미사용 불안과 소비 압박 발생
- S 랭크·특정 엔딩이 서사 탐색 기능의 입장권이 됨
- 단일 저장 덮어쓰기로 장시간 캠페인과 최초 결산을 잃음
- 무제한 분기 저장으로 저장 UI·클라우드 동기화·QA 범위가 폭발함
- 서로 다른 분기의 피해자·관계·책임 데이터가 섞임

### 남은 미확정

- 캠페인 되감기의 정확한 대상 단위
- 사건 시작·주요 결정 지점 중 어떤 지점으로 돌아갈지
- 분기 슬롯 UX와 보호 캠페인 삭제 정책의 세부 문구
- 자동·수동 저장 슬롯 및 클라우드 충돌 복구 정책
- 접근성 완화 사용 시 최고 랭크·업적 처리
- 최고 랭크·업적·숙련 보상 범위
