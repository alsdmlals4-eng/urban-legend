## 1. 메인 콘텐츠 권위

괴이기록국의 메인 콘텐츠는 일정 편성 자체가 아니라 다음 사건 플레이 루프다.

```text
괴이 사건 진입
→ 텍스트 노벨 조사
→ 키워드 획득·괴이 매뉴얼 구성
→ 피해자 구출 미니게임
→ 턴제 회수 전투
→ 안정화·봉쇄·잔향 회수
→ 결과·기록·환류
```

간결 표현:

> 추리해서 피해자를 구출하고, 이해한 규칙으로 싸워 괴이를 회수한다.

세 단계는 서로 대체할 수 없다.

1. 조사: 괴이 규칙과 피해자 구출·전투 대응 정보를 알아낸다.
2. 피해자 구출: 조사 규칙을 적용해 피해자를 현상에서 분리한다.
3. 회수 전투: 괴이의 공격을 버티며 제압·안정화·봉쇄·잔향 회수를 수행한다.

## 2. 조사 시스템

조사는 텍스트 노벨의 `상황 설명 → 조건 표시 선택지 → 결과 문장 → 키워드 획득`으로 진행한다.

- 선택지는 일반·능력·태그·판정·지원 조건을 사전에 표시한다.
- 키워드는 괴이 매뉴얼의 발생 조건·피해 연결·금지 행동·구출 절차·전투 대응을 구성한다.
- 후보·확인·위험 사례·미해결 상태를 구분한다.
- 능력·태그·판정은 객관적 진실을 바꾸지 않고 조사 비용·위험·우회 경로·정보량을 바꾼다.

동료·기록관·능력치는 정답을 대신 말하지 않는다.

## 3. 피해자 구출 미니게임

미니게임은 조사에서 파악한 규칙을 적용해 피해자를 직접 구출하는 독립 단계다.

- 피해자의 위치·상태·연결·행동 정상화
- 금지 행동 회피와 안전 행동 적용
- 피해자를 괴이 현상·매개체에서 분리
- 성공·부분 실패·지연 상태를 회수 전투로 전달

미니게임은 조사 내부의 추가 추리 퍼즐도 아니고 회수 전투 자체도 아니다. 성공해도 전투를 자동 해결하지 않는다.

## 4. 회수 시스템 — 턴제 전투

회수는 괴이와 맞서는 명확한 전투 시스템이다.

기본 행동군:

```text
보호
관찰
대응
공격
장비
봉쇄
후퇴
```

- 보호: 요원·동료·피해자의 피해와 상태 이상 방지
- 관찰: 다음 행동·대상·조건·전조 판독
- 대응: 사건 고유 규칙을 이용한 회피·차단·역이용
- 공격: 현현체·매개체·침식 연결 약화와 행동 중단
- 장비: 분석·방호·회복·봉쇄 수단 사용
- 봉쇄: 조건을 충족한 괴이를 안정화하고 잔향 회수
- 후퇴: 출동 실패·불완전 종결·후속 책임으로 전환

공격은 실제 전술 행동이지만 괴이 HP를 0으로 만드는 것만으로 기본 승리할 수 없다.

```text
피해자 구출 또는 보호
+ 규칙 관찰
+ 사건 고유 대응
+ 현현체·매개체 약화
+ 봉쇄 조건
= 안정화·잔향 회수
```

## 5. 일정·육성의 역할

일정, 동료, 장비, 연구, 관계, 기관 지원은 메인 콘텐츠를 대체하지 않는다.

이들은 다음을 담당하는 지원·준비·환류 계층이다.

- 사건 진입 전에 위험과 선택 폭 조정
- 조사 가능한 질문·경로·실패 여유 확장
- 피해자 보호·전투 대응·복구 조건 지원
- 사건 결과를 다음 사건 준비에 반영
- 권나래의 장기 성장과 관계 변화 표현

따라서 다음 표현과 구현은 금지한다.

- 일정 편성이 게임의 메인 콘텐츠라고 설명
- 자동 일정 결과만으로 핵심 사건 해결
- 사건 플레이보다 일정 소비가 기본 경험을 지배
- 일정·능력치가 조사·구출·전투 정답을 대신함

## 6. 계층 구조

```text
메인 콘텐츠
- 괴이 사건
  - 텍스트 노벨 조사
  - 키워드 기반 괴이 매뉴얼
  - 피해자 구출 미니게임
  - 턴제 회수 전투
  - 결과 기록

지원 계층
- 일정·육성
- 동료·관계
- 장비·연구
- 기관·보급
- 저장·복귀
```

지원 계층은 사건 경험을 더 깊고 다양하게 만들기 위해 존재한다. 지원 계층이 비대해져 사건 코어를 가리면 범위 오류로 판정한다.

## 7. 분기 캠페인 적용

각 분기의 핵심 괴담 1개는 반드시 완전한 다음 경험을 제공한다.

```text
조사
→ 피해자 구출
→ 회수 전투
→ 안정화·현재 사건 종결
```

분기 사이의 일정·육성은 다음 핵심 사건을 준비하고 이전 사건 결과를 환류하는 연결부다. 일정만 진행하고 핵심 괴담을 자동 처리하는 분기는 허용하지 않는다.

## 8. 기존 코어와의 관계

기존 프로젝트 코어의 인과는 다음 화면 구조로 구체화된다.

```text
관측·가설
→ 텍스트 노벨 조사·괴이 매뉴얼

위험 검증·피해 분리
→ 피해자 구출 미니게임

전조·대응·제압·포획
→ 턴제 회수 전투

공식 규칙·위험 사례
→ 결과 기록과 다음 사건 환류
```

연도제·일정 시스템은 이 인과의 앞뒤에 연결되는 지원 구조이며, 이를 대체하거나 상위 권위로 덮어쓰지 않는다.
