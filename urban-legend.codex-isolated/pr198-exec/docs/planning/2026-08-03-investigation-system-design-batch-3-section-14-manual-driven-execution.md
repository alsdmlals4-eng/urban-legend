## 14.1 목적

조사에서 완성한 괴이 매뉴얼이 문서 퍼즐로 끝나지 않고 피해자 구출 미니게임과 회수 전투의 판단 규칙으로 이어지게 한다.

```text
정상 키워드 획득
→ 정상 키워드에서 파생한 [변조] 후보 혼입
→ 조사 기억·원본 출처·매뉴얼 문맥으로 판별
→ 괴이 매뉴얼 완성
→ 피해자 구출 절차 수행
→ 회수 전조 해석
→ 정확한 발현 턴에 대응
→ [파훼]·[취약]
→ 잔향 회수
```

## 14.2 변조 후보 구조

`[변조]`는 독립 단서가 아니다. 기존 정상 키워드의 핵심 변수 하나를 바꾼 후보다.

```yaml
normal_keyword:
  keyword_id: K-02
  display_text: 세 번째 빗소리 직후
  source_ref: AUDIO-WAVEFORM-01
  acquisition_action: 휴대전화 원본 파형 확인

mutated_candidate:
  candidate_id: M-K02-01
  source_keyword_ref: K-02
  mutation_type: count_shift
  original_value: 세 번째
  altered_value: 네 번째
  display_text: 네 번째 빗소리 직후
  independent_source_ref: null
  independent_acquisition_action: null
```

위 구조는 Design 권장안이며 최종 Schema는 Design Spec에서 확정한다.

### 허용 변조

- 횟수
- 시점·지연
- 행동 순서
- 방향·범위
- 주체·대상
- 재질·도구
- 금지/허용 조건
- 파훼 행동
- 취약 조건

한 후보에서는 변수 하나만 바꾼다.

## 14.3 후보 표시와 검증

플레이어는 정상 후보와 변조 후보를 같은 빈칸 후보군에서 본다. 처음부터 `[변조]` 표식을 표시하지 않는다.

판별 근거:

```text
조사 장면의 기억
+ 정상 키워드의 원본 출처
+ 다른 매뉴얼 슬롯과의 일관성
```

별도 가짜 증언·가짜 영상·가짜 획득 장면을 필수 제작하지 않는다. 변조의 목적은 후보 검증이며 독립 조사 파이프라인 증설이 아니다.

## 14.4 피해자 구출 미니게임

구출 절차 매뉴얼은 다음 실행 변수를 제공한다.

| 변수 | 예시 |
|---|---|
| 차단 대상 | 피해자와 반사상의 시야 |
| 도구·환경 | 불투명 차폐막 |
| 금지 행동 | 피해자의 이름을 부르지 않음 |
| 반복 횟수 | 외부 식별음 두 번 |
| 제한 시간 | 네 번째 빗소리 전 |
| 안전 지점 | 마른 바닥 |

미니게임은 매뉴얼을 열람할 수 있게 하지만 자동으로 올바른 도구·경로·타이밍을 선택하지 않는다.

## 14.5 회수 전투의 가변 전조 패턴

패턴 길이는 사건마다 다르며 최소 2턴이다.

```text
N ≥ 2
전조 횟수 = N - 1
```

### 턴 계약

```text
첫 턴: [전조] → 선택 → 평상 진행
중간 턴: 선택 → [전조] → 평상 진행
마지막 턴: 대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행
```

- 첫 턴 전조는 패턴 시작만 알린다.
- 중간 턴의 후속 전조는 플레이어 선택 처리 뒤 보인다.
- 마지막 전조 턴에도 평상 전투를 진행한다.
- 패턴 준비 완료 상태를 표시하지 않는다.
- 다음 턴 발현 경고를 자동으로 띄우지 않는다.
- 마지막 턴에는 대응 선택 전 패턴을 공개하지 않는다.
- 플레이어가 매뉴얼을 근거로 대응을 먼저 결정한다.
- 4턴은 예시일 뿐 고정값이 아니다.

## 14.6 결과 판정

### 정확한 대응

```text
대응 선택
→ 패턴 발현
→ 대응 조건 일치
→ [파훼]
→ 괴이 행동 무효·역이용
→ [취약]
→ 유효 공격·연결 절단·잔향 노출
→ 평상 진행
```

### 부분 대응

방어처럼 피해를 줄이는 행동은 생존에 도움을 줄 수 있지만 파훼·취약을 발생시키지 않는다.

### 실패 대응

공격 지속, 잘못된 방향 이동, 잘못된 도구 사용은 강한 피해나 자원 손실을 일으킬 수 있다. 결과 산출 뒤 평상 전투로 돌아간다.

### 조기 대응

전조가 충분히 누적되기 전에 파훼 행동을 사용하면 행동·자원만 소비하고 파훼하지 못한다. 조기 대응은 최적 행동이 아니지만 치명적인 함정으로 만들지 않는다.

## 14.7 회수 매뉴얼 필수 정보

각 패턴은 다음을 기록한다.

1. 전조 종류
2. 전조 횟수 또는 순서
3. 발현 시점
4. 발현 방향·범위·대상
5. 올바른 대응
6. 파훼 효과
7. 취약 지속 또는 소비 조건

예시:

> 종소리가 세 번 들린 다음 턴 정면 휩쓸기가 발현한다. 발현 턴에 정면에서 벗어나면 파훼되며, 괴이는 다음 유효 공격까지 취약해진다.

## 14.8 사건 제작 QA

- 정상 키워드는 실제 획득 장면과 출처가 있는가?
- 변조 후보가 정상 키워드와 파생 관계를 가지는가?
- 변조 후보가 변수 하나만 바꾸는가?
- 변조 후보 때문에 별도 가짜 획득 장면을 불필요하게 추가하지 않았는가?
- 구출 매뉴얼 키워드가 미니게임 행동을 실제로 결정하는가?
- 회수 매뉴얼이 전조·발현 턴·대응·취약을 모두 기록하는가?
- 첫 전조가 선택 전에 표시되는가?
- 후속 전조가 중간 턴 선택 뒤 표시되는가?
- 마지막 턴에 플레이어가 먼저 대응을 고르는가?
- 패턴 준비 완료·발현 경고가 매뉴얼 판단을 대체하지 않는가?
- 2턴·3턴·4턴 이상 패턴을 모두 표현할 수 있는가?
- 정확한 대응만 파훼·취약을 만드는가?
- 매뉴얼이 행동을 자동 수행하지 않는가?

- 전조 접근성 표현
- 변조 후보 수와 난이도 곡선
