## 결정

괴이 기록국의 사건 진행은 다음 고정된 핵심 흐름을 사용한다.

```text
빈칸이 많은 괴이 매뉴얼을 보유한 채 사건 시작
→ 조사 행동으로 후보 키워드 획득
→ 획득한 정상 키워드에서 파생된 [변조] 후보가 후보 풀에 개입
→ 1장부터 괴이 매뉴얼 페이지를 순서대로 채움
→ 현재 페이지의 모든 빈칸을 채우면 다음 페이지 진행
→ 최종장의 모든 빈칸을 채우면 조사 페이즈 종료
→ 피해자 구출 미니게임
→ 회수 페이즈(턴제 전투)
→ 일반 클리어 또는 사건별 종결
→ 필요 시 기록 복기·정밀화
```

조사 페이즈 종료 Gate는 **정답 확인 Gate가 아니라 구조적 페이지 완료 Gate**다. 모든 빈칸에 후보가 배치되어 실행 가능한 문장으로 읽혀야 하지만, 모든 키워드가 옳거나 확인됐다는 뜻이 아니다. 완성된 페이지에는 근거가 부족한 후보나 플레이어가 판별하지 못한 `[변조] 후보가 포함될 수 있다`.

## 1. 사건 시작 상태

- 플레이어는 처음부터 사건 전용 `빈칸이 많은 괴이 매뉴얼`을 보유한다.
- 페이지 수, 문장 골격, 빈칸 위치는 보이지만 정답·미획득 키워드·변조 여부는 보이지 않는다.
- 조사의 목적은 별도 보고서를 나중에 만드는 것이 아니라 이 매뉴얼을 실제 구출·회수에 사용할 수 있도록 채우는 것이다.

## 2. 조사와 후보 획득

- 조사 행동은 출처가 있는 정상 `후보 키워드`를 획득한다.
- `[변조] 후보`는 정상 후보의 횟수·시간·순서·방향·대상·재질·조건 등 변수 하나를 바꿔 후보 풀에 개입한다.
- 변조 후보는 별도 가짜 조사 장면이나 독립 출처를 요구하지 않는다.
- 플레이어는 조사 기억, 원본 출처, 다른 매뉴얼 문장과의 일관성으로 변조 여부를 판단한다.

## 3. 페이지 순차 완료

- 기본 진행은 `1장 → 2장 → … → 최종장` 순서다.
- 현재 페이지의 모든 빈칸을 채우면 다음 페이지가 진행 가능해진다.
- `페이지 완료`의 최소 의미는 `빈칸 없음 + 문장 의미 구조 성립`이다.
- 페이지 완료는 해당 페이지의 모든 후보가 진실·확인 규칙임을 보증하지 않는다.
- 최종장을 채우기 전에는 획득한 근거와 후보를 재검토할 수 있다.
- 과거 페이지의 최종 편집 허용 범위와 잠금 UX는 Design Spec/Human QA에서 확정한다.

## 4. 조사 종료 Gate

조사 페이즈 종료 조건:

1. 모든 매뉴얼 페이지가 진행 순서상 완료됐다.
2. 최종장의 모든 빈칸이 채워졌다.
3. 각 문장이 구조적으로 읽히며 저장 가능한 의미 관계를 가진다.
4. 시스템 수준의 불가능 구조가 없다.

조사 종료를 막는 조건:

- 하나 이상의 빈칸이 비어 있음
- 키워드 연결이 문장 구조상 성립하지 않음
- 필수 페이지가 해금되지 않음
- 저장할 수 없는 중복·순환·손상 상태

조사 종료를 막지 않는 조건:

- 후보의 진실성이 아직 완전히 확인되지 않음
- 근거가 약한 후보가 존재함
- 플레이어가 `[변조]` 후보를 정상 후보로 오인함
- 선택적 미스터리가 남아 있음

즉 `모든 빈칸을 채움`과 `모든 규칙을 정확히 확인함`을 분리한다.

## 5. Decision 6 교정

Decision 6의 `현장 진입 가능`은 더 이상 일부 빈칸이 남은 매뉴얼로 조사 페이즈를 조기 종료하는 상태를 뜻하지 않는다.

교정된 정의:

```text
현장 진입 가능 = 조사 종료 Gate 통과 + 실행 가능 상태
```

필수:

- 모든 페이지와 모든 빈칸 완료
- 금지 행동·구출 절차·회수 전투 대응이 구조적으로 실행 가능한 문장
- 확인된 정상 증거와 정면 충돌하는 치명적 상충이 시스템에 의해 이미 판명된 경우 없음

허용:

- 근거가 약한 후보
- 아직 확인되지 않은 발생 조건·피해자 연결
- 미판별 `[변조]` 후보
- 비치명적 상충과 선택적 미스터리

따라서 불완전할 수 있는 것은 **매뉴얼의 확실성**이지 **페이지의 빈칸 상태**가 아니다.

## 6. 피해자 구출 위험도

구출 미니게임은 다음 단계형 위험도를 사용한다.

```text
안정 → 불안정 → 위험 → 임계 → 명확히 예고된 비가역 결과
```

### 안정

구출 시작 상태. 매뉴얼을 열람하고 절차를 수행한다.

### 불안정

첫 실패 또는 경미한 절차 오류로 진입한다. 즉시 피해자 상실이나 사건 재시작은 발생하지 않는다.

### 위험

반복 실패나 중요한 금지 위반으로 피해자 연결이 심해진다. 선택 가능한 회복 수단과 남은 기회를 명확히 보여 준다.

### 임계

다음 중대한 실패가 비가역 결과로 이어질 수 있음을 구체적으로 경고한다. 숨겨진 확률로 갑자기 피해자를 잃지 않는다.

### 비가역 결과

부상, 연결 심화, 구출 등급 저하, 사건별 서사적 손실 등이다. 기본 캠페인에서 전체 세이브 재시작을 기본 비용으로 사용하지 않는다. 영구 사망 수준의 규칙은 기록 재현용 선택 도전에서만 별도 검토한다.

## 7. 실패 피드백

첫 실패와 후속 실패는 다음을 수행한다.

- 위험도 한 단계 상승 또는 사건별 명시된 상태 변화
- 괴이 반응·피해자 변화·환경 변화 제공
- `새로운 관찰 증거` 또는 위험 사례 기록
- 잘못된 대상·횟수·순서·도구 중 정확히 무엇이 정답인지 직접 공개하지 않음
- 매뉴얼을 자동 수정하지 않음

실패는 학습 가능한 현상이어야 하지만 정답 근접도 힌트가 되어서는 안 된다.

## 8. 의미 있는 재시도

`동일 매뉴얼·도구·경로·순서`와 동일한 상황 상태를 그대로 반복하면 같은 결과를 반환한다. 단순 전수 대입을 막기 위해 새 시도로 인정받으려면 하나 이상의 `실질적 변경`이 필요하다.

실질적 변경 예:

- 행동 순서 변경
- 도구·배치·경로 변경
- 횟수·타이밍 변경
- 긴급 안정화 자원 사용
- 새 관찰 결과를 근거로 다른 대응 선택
- 구출을 중단하고 조사 페이즈로 후퇴해 매뉴얼 수정 또는 추가 근거 확보

후퇴 분기는 정상적인 전진 흐름의 기본 단계가 아니라 실패 회복용 예외 분기다. 후퇴 시 피해자 위험도와 발생한 위험 사례는 삭제하지 않는다.

## 9. 임계 단계 선택

임계 상태에서는 최소 다음 선택군을 제공한다.

- 구출 중단 후 추가 조사
- 제한 자원을 사용한 긴급 안정화
- 위험을 감수한 최종 시도

비가역 결과의 종류와 원인은 사건 규칙 안에서 사전에 예고 가능해야 한다. `숨겨진 확률`과 무작위 즉사는 사용하지 않는다.

## 10. 비용이 없는 정보 접근

다음 행동은 시간·턴·자원·위험도를 증가시키지 않는다.

- `매뉴얼 열람`
- 일시정지
- 이전 전조·대사·관찰 기록 재생
- 스크린리더
- 입력 보조
- 설명 반복
- 기타 `접근성` 기능

접근성 사용 여부는 일반 클리어·S 랭크 감점 대상이 아니다.

## 11. 회수 페이즈 연결

피해자 구출에 성공하면 완성된 매뉴얼을 유지한 채 회수 페이즈로 넘어간다.

- 회수 페이즈는 평상 턴제 전투와 매뉴얼 기반 전조·대응·파훼·취약을 결합한다.
- 구출 중 얻은 관찰·위험 사례는 회수 전투의 정답을 자동 공개하지 않는다.
- 구출 실패로 발견한 규칙이 회수 패턴과 연결될 수는 있지만, 사건 제작 단계에서 근거 관계를 명시해야 한다.

## 12. 적대적 검토

### 페이지 완성과 정답 확인을 동일시하는 문제

모든 후보를 완전 확인해야만 최종장을 닫을 수 있다면 조사 진행이 막히고 실행 검증의 의미가 사라진다. 페이지 완료는 빈칸 없음과 구조 성립, 정밀 확인은 일반/S 랭크 판정으로 분리한다.

### 빈칸이 남은 채 구출로 넘어가는 문제

매뉴얼 작성이 핵심 재미가 아니라 선택적 힌트로 약화된다. 모든 페이지·모든 빈칸 완료를 조사 종료 Gate로 고정한다.

### 실패 즉시 피해자 상실 문제

실험·추론보다 정답 암기와 세이브 로드를 보상한다. 첫 실패는 관찰 증거와 위험 상승으로 처리한다.

### 무제한 재시도 문제

모든 선택지를 순서대로 시험하는 것이 최적이 된다. 동일 의미 상태는 캐시하고 실질적 변경만 새 시도로 인정한다.

### 위험도가 숨은 확률인 문제

공정하게 예측할 수 없고 매뉴얼 지식이 무력화된다. 단계와 비가역 결과를 명시적으로 예고한다.

## 13. 적용 경계

현재 확정하는 것은 핵심 콘텐츠 흐름, 페이지 완료 Gate, 피해자 위험도와 재시도 원칙이다.

아직 확정하지 않는 항목:

- 페이지 잠금·이전 페이지 편집 UX
- 위험도별 정확한 수치와 허용 실패 횟수
- 사건별 비가역 결과 종류
- 긴급 안정화 자원 비용
- 조사 후퇴의 화면 전환과 저장 처리
- 피해자 영구 사망 도전 규칙
- 실제 코드·Scene·Schema·UI·저장 마이그레이션

상세 구현은 Design Spec과 별도 승인 후 Codex 단계에서 수행한다.
