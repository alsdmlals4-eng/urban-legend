## Section 13 — 사건 역설계 공식과 단서·키워드 파이프라인

### 13.1 핵심 구조

사건은 괴이 매뉴얼의 완성 규칙에서 조사 장면으로 역설계한다.

```text
괴이의 실제 규칙
→ 완성 괴이 매뉴얼
→ 2~3장 조사문
→ 장당 3~5개 정답 슬롯
→ 원시 단서
→ 획득 행동과 장면
→ 그럴듯한 오답
→ 후속 반증
→ 피해자 구출·회수 전투 검증
→ 공식 규칙·위험 사례·미해결 기록
```

### 13.2 조사문 구조

- 짧은 사건: 2장 × 3~4개 슬롯
- 표준 사건: 3장 × 3~5개 슬롯
- 핵심 사건: 3장 × 4~5개 슬롯과 복수 가설·상충 증거
- 장별 완성문은 기록 문장으로 자연스럽게 읽힌다.
- 빈칸의 수·품사·길이만으로 정답을 과도하게 노출하지 않는다.

### 13.3 혼합형 획득

```text
직접 물증·명시적 증언
→ 즉시 사건 키워드

불완전한 현상·간접 증언·상충 기록
→ 원시 관찰 기록
→ 비교·모순·논리 연결
→ 정제 키워드 또는 추론 키워드
```

모든 클릭이 완성 키워드를 주지 않고, 모든 단서를 두 카드 결합으로 만들지 않는다.

### 13.4 키워드 품질

키워드는 장면을 기억하게 하는 구체적 사실이어야 한다.

```text
손자국 → 안에서 바깥으로 밀려난 젖은 손자국
반사상 → 본체보다 0.8초 먼저 고개를 든 반사상
안내방송 → 전원이 꺼진 뒤 재생된 안내방송
```

각 키워드는 출처, 획득 행동, 선행 조건, 의미 주장, 사용 슬롯, 신뢰 상태, 대체 경로를 보존한다.

### 13.5 키워드 예산

3장 표준 사건의 시작 기준:

- 정답 9~12개
- 보조 4~6개
- 그럴듯한 오답 3~5개
- 추론 키워드 2~4개
- 총 관리 약 18~24개

직접 관찰·증언 약 50%, 비교·모순 약 30%, 복수 단서 연결 약 20%를 권장 시작점으로 사용한다. 구현 고정값은 아니다.

### 13.6 벤치마크 변환

- 단간론파: 단서가 나중 판단에 실제로 사용되는 명확성과 기억 가능한 단서명을 참고한다.
- 역전검사: 떨어진 정보를 연결해 새 추론·조사 경로를 여는 진행감을 참고한다.
- 모든 대화를 논쟁 전투로 만들거나, 자명한 두 카드 결합을 반복하거나, 단일 반박으로 사건을 끝내는 방식은 적용하지 않는다.
- 괴이기록국에서는 단서가 괴이 매뉴얼, 피해자 구출, 회수 전투의 판단으로 이어져야 한다.

### 13.7 사건 제작 패키지

사건 하나는 실제 규칙, 완성 매뉴얼, 조사문, 키워드 표, 원시 단서, 획득 장면, 오답·반증 흐름, 구출·전투 참조, 기록 전이, QA 행렬을 하나의 패키지로 제출한다.

상세 제작 절차와 Fairness review는 `docs/workflows/INVESTIGATION_CASE_AUTHORING_WORKFLOW.md`가 책임진다.

### 13.8 적대적 보호

- 조사 장면을 먼저 쓰고 정답을 끼워 맞추지 않는다.
- 일반 명사·무관한 쓰레기 오답으로 난도를 만들지 않는다.
- 핵심 단서에는 재확인 또는 대체 경로를 둔다.
- 추론 키워드는 원시 단서 사이의 관계가 사건 안에서 검증 가능해야 한다.
- 조사문 완성이 구출·회수 전투를 자동 실행하지 않는다.
- 프로젝트 스킬은 기존 등록 스킬을 확장하며 중복 스킬을 만들지 않는다.
