## 결정

괴이 매뉴얼은 다음 다섯 개의 공통 의미 슬롯으로 구성한다.

1. 발생 조건
2. 피해자 연결
3. 금지 행동
4. 구출 절차
5. 회수 전투 대응

플레이어는 조사에서 실제로 획득한 사건 키워드와 공통 관계자를 이용해 규칙을 구성한다. 자유 메모는 제공하지만 시스템 판정·진행 조건·자동 번역의 입력으로 사용하지 않는다.

사용자가 제시한 TRPG 《둘이서 수사》식 번호 키워드 문장 조립은 **증거를 읽을 수 있는 추론문으로 정리하는 중간 계층**으로 채택한다. 다만 완성 문장 자체를 최종 규칙 판정의 원본으로 사용하지 않는다.

```text
상황·증거 확인
→ 사건 키워드 획득
→ 번호 슬롯이 있는 추론문에 키워드 배치
→ 추론문이 주장하는 의미 관계 확인
→ 하나 이상의 괴이 매뉴얼 의미 슬롯에 근거로 연결
→ 후보·근거 확보·확인·위험 사례·미해결 상태 갱신
→ 구출·회수 전투에서 규칙을 직접 적용
```

## 2단 구조

### 1단계 — 증거 추론문

증거와 증언을 다음과 같은 읽을 수 있는 문장 단위로 정리한다.

```text
진열장에는 「한 번 열렸던 흔적」이 남아 있다.
보석은 공개 전날까지 「관계자만 출입 가능한 공간」에 있었다.
따라서 도난 시점은 「공개 전날부터 발견 시점 사이」로 좁혀진다.
마지막 출입자는 『박물관의 청소부』다.
```

이 계층의 목적은 다음과 같다.

- 흩어진 증거를 인과·시간·대상 관계로 읽게 한다.
- 조사 로그와 정답 입력을 하나의 세계관 문서 경험으로 연결한다.
- 플레이어가 어떤 근거로 가설을 세웠는지 보존한다.
- 부분적으로 맞은 추론과 잘못된 추론을 개별 단위로 관리한다.

### 2단계 — 괴이 매뉴얼 의미 슬롯

추론문은 하나 이상의 의미 슬롯을 지지하거나 반박한다.

예시:

```text
[발생 조건]
세 번째 빗소리 + 이후 + 반사상이 선행

[피해자 연결]
젖은 손자국 + 전이 + 우산 소유자

[금지 행동]
반사상을 직접 따라가기 + 금지

[구출 절차]
우산 격리 + 피해자 호위 + 분리한 뒤

[회수 전투 대응]
반사 차단 + 대상 전환 직후 + 봉쇄 우선
```

문장 표면형이 아니라 내부 의미 구조가 규칙의 원본이다. 하나의 추론문은 여러 슬롯의 근거가 될 수 있고, 한 슬롯은 여러 추론문과 증거를 요구할 수 있다.

## 키워드와 관계자

### 사건 키워드

사건 키워드는 조사에서 실제로 획득하며 출처를 보존한다.

- 현장 흔적
- 피해자·목격자 증언
- 기록·문서
- 음향·영상·감각 정보
- 반복·누락·모순
- 대응 실험 결과
- 실패와 위험 사례

각 키워드는 최소한 다음 정보를 가진다.

```text
keyword_id
표시 문구
의미 태그
획득 출처
획득 시점
연결 가능한 증거
현재 신뢰 상태
```

### 공통 관계자

관계자는 사건의 정답 단어가 아니라 의미 관계를 표현하는 공통 도구다.

- 이전 / 이후
- 동시에
- 때문에 / 따라서
- 반복될 때
- 대상이 되면
- 분리한 뒤
- 금지
- 유지
- 대체
- 우선
- 예외

언어별 문장은 관계자의 의미를 각 언어에 맞게 렌더링한다. 한국어 조사·어순이나 특정 문장 틀을 규칙 데이터로 저장하지 않는다.

## 슬롯 상태

각 의미 슬롯은 독립적으로 다음 상태를 가진다.

- 미작성
- 후보 규칙
- 근거 확보
- 확인 규칙
- 위험 사례
- 미해결

상태는 정답 단어를 즉시 공개하지 않는다. 구체적인 검증 시점·피드백 강도·힌트 수준은 후속 Decision으로 분리한다.

## 자유 메모

자유 메모는 플레이어 개인의 추론 보조 수단이다.

- 진행 판정에 사용하지 않는다.
- 정답으로 파싱하지 않는다.
- LLM 판정을 사용하지 않는다.
- 자동 번역·검증·QA 범위에 포함하지 않는다.
- 저장과 편집은 지원하되 삭제해도 게임 상태가 변하지 않는다.

## 일반 클리어와 숙련

- 일반 클리어에는 사건을 안전하게 종결할 수 있는 최소 실행 가능 매뉴얼을 요구한다.
- 모든 슬롯의 완전한 규명이나 모든 반증을 일반 클리어에 강제하지 않는다.
- S 랭크·특수 업적은 더 많은 확인 규칙, 반증, 위험 사례 정리, 기록 완성도를 요구할 수 있다.
- 구출·회수 전투는 올바른 슬롯을 참조하지만 자동 해결되지 않는다. 플레이어가 대상·순서·타이밍을 직접 판단하고 수행한다.

## 적대적 보호 규칙

1. 획득하지 않은 사건 키워드는 선택 목록에 표시하지 않는다.
2. 문장 빈칸의 형태만으로 정답의 품사·개수·순서를 과도하게 암시하지 않는다.
3. 시스템은 의미상 불가능한 조합만 차단하고, 그럴듯하지만 틀린 가설은 작성할 수 있게 한다.
4. 틀린 후보도 즉시 삭제하지 않고 반증·위험 사례·추론 이력으로 보존할 수 있다.
5. 키워드를 모든 슬롯에 무차별 대입하는 행동이 최적 풀이가 되지 않게 검증 피드백을 단계적으로 제공한다.
6. 하나의 거대한 정답 문장보다 증거 추론문과 의미 슬롯을 분리해 부분 진척을 제공한다.
7. 문법·표면 문장과 규칙 엔진을 분리해 현지화가 게임 로직을 변경하지 않게 한다.
8. 조사 매뉴얼이 정답을 자동 실행하지 않으며 구출·전투의 판단과 조작을 대체하지 않는다.
9. 카드 수·정렬·검색·접근성 탐색 부담은 후속 UX Spec과 사람 검증 전까지 `NOT_VALIDATED`다.
10. 구현·사람 검증·POC·Production은 별도 승인 전까지 열지 않는다.

## 벤치마크 적용 경계

- 《The Case of the Golden Idol》: 제한된 문구 조립과 부분 퍼즐의 진행감은 적용하되, 문장 틀이 정답을 노출하는 문제는 의미 슬롯 분리로 완화한다.
- 《Return of the Obra Dinn》: 세계관 내부 문서와 구조화된 추론은 적용하되, 언어 문법에 규칙을 의존하지 않는다.
- 《The Roottrees are Dead》: 공통 입력 구조 안에서 사건별 관계를 추론하는 원칙을 적용한다.
- TRPG 《둘이서 수사》: 번호 키워드가 들어간 읽을 수 있는 추론문을 적용하되, 최종 규칙 판정은 언어 중립 의미 구조가 담당한다.

벤치마크의 UI나 문장을 복제하지 않고 괴이기록국의 조사→구출→회수 전투 루프에 맞게 변환한다.

## 남은 미확정

- 후보 가설을 언제 검증하며 어떤 강도로 피드백할지
- 잘못된 가설의 비용과 위험 사례 전환 조건
- 사건별 키워드 수·동시 보유량·정렬·필터 UX
- 상충 증거와 뒤늦은 증거가 기존 추론을 무효화하는 방식
- 한 슬롯의 최소 규칙과 정밀 규칙을 데이터로 표현하는 방식
- 추론문 템플릿의 사건별 제작량과 QA 행렬
- 키보드·컨트롤러·스크린리더 접근성
- 실제 플레이어가 추론한다고 느끼는지, 빈칸 맞추기로 느끼는지에 대한 사람 검증
