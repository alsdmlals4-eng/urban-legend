## 10. 최종 판정

자동·렌더·사람·접근성 결과를 하나의 평균 점수로 합치지 않는다.

```yaml
build_commit: NOT_RUN
automated_contracts: NOT_RUN
godot_runtime: NOT_RUN
render_720p: NOT_RUN
render_1080p: NOT_RUN
keyboard_path: NOT_RUN

causal_recap: HUMAN_NOT_RUN
long_session_usability: HUMAN_NOT_RUN
audio_fallback: NOT_RUN
motion_fallback: NOT_RUN
disabled_user_validation: HUMAN_NOT_RUN
product_decision: RETEST_REQUIRED
```

### 허용 판정

- `KEEP`: 통과 근거가 있고 변경 불필요
- `AMPLIFY`: 핵심 경험을 강화할 가치가 있음
- `CHANGE`: 동일 코어를 유지하며 UX 수정 필요
- `REMOVE`: 플레이어 가치보다 혼란·비용이 큼
- `RETEST`: 증거 부족 또는 수정 후 재검증 필요
- `DEFER`: 현재 Vertical Slice 밖

### 완료 금지

다음 중 하나라도 남으면 `POC_PASSED`, `annual loop passed`, 제작 확대를 선언하지 않는다.

- 신규 플레이어 6명 미완료
- 핵심 이해도 5/6 미달
- 인과 복기 5/6 미달
- 치명적 입력·가독성 Finding 미해결
- 45분 장시간 사용성 미실행
- 자동·렌더와 사람 테스트 commit 불일치

실제 장애 사용자 검증을 실행하지 않았다면 접근성 사용자 상태는 `HUMAN_NOT_RUN`으로 유지한다.
