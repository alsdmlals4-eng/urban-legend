## 목적

정상 클리어에는 현재 사건의 완전한 복기를 제공하고, 실패·승인 철수에는 실제 현장에서 검증된 범위만 공개해 실패 학습과 미스터리 보존을 동시에 달성한다.

## 결과별 공개 흐름

```text
정상 클리어
→ 다섯 의미 슬롯 전체 정답 자동 공개
→ 슬롯별 정답 비교
→ answer_viewed
→ 비정본 재현 / 재현 숙련 등급

실패·승인 철수
→ 검증된 슬롯·직접 관찰된 현상·실패 행동·위험 사례 공개
→ 미검증 슬롯은 숨김
→ partial_truth_revealed
→ 정답 비공개 후속 재조사
   또는 공식 정답 전체 공개 명시적 선택
→ 사전 경고
→ answer_viewed로 전환
→ 비정본 재현 / 재현 숙련 등급
```

## 정상 클리어 보고서

정상 클리어 결과 보고서에서 현재 사건의 `전체 정답 자동 공개`를 수행한다.

- `다섯 의미 슬롯`의 공식 답
- 최종 제출 키워드와 `슬롯별 정답 비교`
- 정확·부분 일치·오답·미해결
- 단서 [기록]·원본 출처
- `[변조]` 원본과 변경 변수
- 핵심 오답 가설과 반증
- 구출·회수 결과·위험 사례
- 일반 클리어와 최초 조사 S 랭크 차이

전체 답이 실제 표시되면 `answer_viewed`가 된다. `다음 사건의 미획득 증거나 정답은 공개하지 않는다`.

## 실패·승인 철수 제한 보고서

자동 공개:

- `검증된 슬롯`
- `직접 관찰된 현상`
- `실패를 일으킨 행동`·순서·조건·상충
- 피해자 반응·환경 변화·전조·파훼 실패
- `위험 사례`
- 획득 기록과 출처

자동 비공개:

- 미검증 슬롯의 공식 답
- 미획득 증거·조사 장면
- 틀린 슬롯의 정확한 교체 답
- 추천 후보·성공 확률·`정답 근접도`

`미검증 슬롯은 숨김`으로 표시하며 길이·색·아이콘·정렬·후보 수로 답을 누설하지 않는다.

검증된 슬롯은 제출 여부가 아니라 재현 가능한 현상, 복수 출처, 구출·회수 결과, 기록된 실패 인과로 판단한다. 부분 검증이면 확인된 관계까지만 공개한다.

## 전체 정답 공개 선택

실패·승인 철수 보고서에서 `공식 정답 전체 공개`를 선택할 수 있다.

- 플레이어의 `명시적 선택`
- 기본·자동·시간 초과 선택 금지
- `사전 경고`와 취소 제공
- 현재 사건 전체 답을 표시하는 순간 `answer_viewed로 전환`
- 이후 `비정본 재현`과 `재현 숙련 등급`
- `최초 조사 정본을 덮어쓰지 않는다`

경고는 최초 결과 불변, 이후 재현 분류, 최초 조사 S 불가를 명시한다.

## partial_truth_revealed와 후속 재조사

제한 보고서만 본 상태는 `partial_truth_revealed`이며 `answer_viewed로 전환하지 않는다`.

`정답 비공개 후속 재조사`에서는:

- 기존 단서·검증된 슬롯·위험 사례 유지
- `최초 실패와 위험 사례를 보존`
- 최초 등급·피해자 상태·세력 반응 재작성 금지
- 후속 해결은 `후속 결과를 추가 기록`
- `최초 조사 S 랭크를 덮어쓰지 않는다`
- 후속 정상 클리어 시 전체 정답 자동 공개와 answer_viewed 전환

상태:

```text
first_run
partial_truth_revealed
reinvestigation
answer_viewed
replay_mastery
```

## 안전·접근성·보상

숨겨진 답과 무관하게 다음 `필수 안전 정보`를 제공한다.

- 확인된 즉시 위험·금지 행동
- 다음 시도의 임계 조건
- `명확히 예고된 비가역 결과`
- 현재 위험도·피해자 상태·사용 자원

`접근성 기능`은 `동일한 경고와 선택`을 제공하며 전체 공개를 자동 선택하지 않는다. `전체 정답 공개를 강제하지 않는다`.

- `정답 공개 자체에 보상 없음`
- 공개 여부로 성장 재화·필수 보상 지급 금지
- `유료화·시간 잠금 금지`
- 제한 보고서·전체 공개로 보상 횟수 초기화 금지

## 제작 체크리스트

사건별로 다음을 작성한다.

1. 정상 클리어 전체 공개표
2. 실패 직접 관찰과 검증 슬롯
3. 승인 철수 관찰과 미검증 슬롯
4. 필수 안전 정보
5. 전체 공개 경고 문구
6. 후속 재조사 경로와 추가 결과
7. 누설 방지 QA
8. 접근성 등가 표현

## 적대적 검토

- 철수가 전체 답 자동 획득 수단이 되지 않는가?
- 실패 원인을 학습할 관찰 근거는 충분한가?
- 제출 후보를 검증된 슬롯으로 오인하지 않는가?
- 숨김 UI가 답을 역산하게 하지 않는가?
- 전체 공개가 명시적·취소 가능한 선택인가?
- 후속 재조사가 최초 실패와 피해 결과를 지우지 않는가?
- 최초 S 랭크 세탁을 막는가?
- 필수 안전 정보와 접근성을 스포일러 명목으로 숨기지 않는가?
- 전체 공개가 보상·유료화·시간 잠금과 분리되는가?

## 적용 경계

정확한 판정 Schema, 저장 상태, 보고서 UI, 경고 UX, 후속 재조사 분기, 프로필 공유와 Human QA는 구현 승인 뒤 별도 Design Spec에서 정한다. 현재 게임 코드·Scene·사건 데이터·자산·이미지·애니메이션·HX는 변경하지 않는다.
