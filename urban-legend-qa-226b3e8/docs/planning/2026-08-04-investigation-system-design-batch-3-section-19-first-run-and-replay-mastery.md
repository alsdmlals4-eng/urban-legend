# Section 19 — 최초 조사 정본과 기록 재현 숙련 분리

> Decision: `D-2026-08-04-INVESTIGATION-FIRST-RUN-CANON-AND-REPLAY-MASTERY-SEPARATION`
> 상태: `APPROVED_DESIGN_SECTION / PENDING_BATCH_MERGE`
> Grill Me: `GRILLME_BATCH_3 / 9_OF_10`
> 구현: `NOT_AUTHORIZED`
> 사람 검증: `NOT_RUN`

## 목적

정답을 보기 전 수행한 최초 조사의 추론·실패·피해자 결과를 캠페인 정본으로 보존하면서도, 정답 공개 후 사건을 다시 플레이해 완성된 절차를 연습하고 숙련 성취를 얻을 수 있게 한다.

## 상태 모델

```text
first_run
= 공식 정답 미공개
+ 최초 조사 세션 진행 중 또는 최초 사건 결과 확정

answer_viewed
= 해당 프로필·저장 이력에서 공식 사건 답 공개

replay_mastery
= answer_viewed 이후의 비정본 기록 재현
```

## 최초 조사 소유권

최초 조사 기록만 다음을 확정한다.

- 최초 조사 등급과 최초 조사 S 랭크
- 캠페인 정본
- 피해자 상태
- 사건 위험 사례·미해결 상태
- 세력 반응과 후속 사건 반영
- 기본 성장 보상 1회

정답 공개 후 재현은 이 값을 덮어쓰지 않는다.

## 기록 재현

- 정답 공개 후 동일 사건을 자유롭게 다시 플레이할 수 있다.
- 결과는 `비정본 재현`으로 표시한다.
- 최초 조사와 별도의 `재현 숙련 등급`을 계산한다.
- 완성 매뉴얼, 구출 안전성, 회수 파훼, 선택 도전 등을 평가할 수 있다.
- 최초 조사 S 랭크·캠페인 정본·피해자 상태·세력 반응은 변경하지 않는다.

## 보상 경계

허용:

- 사건당 1회의 도감·기록 완성
- 선택적 외형 보상·칭호·재현 도장
- 전투력과 필수 성장에 영향을 주지 않는 성취

금지:

- 성장 재화·경험치·장비의 반복 파밍
- 최초 조사 보상의 중복 지급
- 재현 숙련을 캠페인 진행 필수 Gate로 사용
- 재현 S를 최초 조사 S와 동일 통계로 합산

## 정답 공개 전 재개

정답 보고서가 열리기 전 체크포인트 재개·조사 후퇴·저장 로드는 같은 최초 조사 세션이다. 공식 답이 공개되지 않았다면 `answer_viewed`로 전환하지 않는다.

접근성 기능, 일시정지, 기록 재생, 입력 보조는 최초 조사 자격에 영향을 주지 않는다.

## 표시 예시

```text
최초 조사
등급: A
정본 결과: 피해자 부상 / 잔향 회수
기본 보상: 지급 완료

기록 재현
상태: answer_viewed / 비정본 재현
재현 숙련: S
선택 기록 보상: 사건당 1회
```

## Fairness Gate

- 최초 실패와 위험 사례를 재현으로 삭제하지 않는가?
- 재현 결과가 캠페인 정본을 덮어쓰지 않는가?
- 최초 조사 S와 재현 숙련 S를 혼동하지 않는가?
- 재현 보상이 경제 파밍을 만들지 않는가?
- 정답 공개 전 체크포인트 재개를 answer_viewed로 오판하지 않는가?
- 접근성 기능을 스포일러나 치트로 취급하지 않는가?
- 외부 공략 열람 여부를 시스템이 판정한다고 주장하지 않는가?

## 적용 경계

정확한 저장 Schema, 프로필 간 spoiler 공유, 새 게임+, 기록 비교 UI, 재현 숙련 산식과 보상 수치는 Design Spec·Human QA·구현 승인 후 확정한다.
