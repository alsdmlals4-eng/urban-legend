## 1. 승인 구조

각 분기 핵심 괴담은 서로 다른 전용 **피해자 구출 미니게임**을 사용한다.

```text
텍스트 노벨 조사
→ 키워드 획득·괴이 매뉴얼 구성
→ 피해자 구출 미니게임
→ 턴제 회수 전투
```

미니게임은 조사에서 알아낸 괴이 규칙을 적용해 피해자를 현상에서 분리하는 짧은 조작 절차다. 규칙 추리 자체나 회수 전투를 대체하지 않으며, 일정 화면의 부가 활동도 아니다.

## 2. 핵심 역할

피해자 구출 미니게임은 다음을 담당한다.

- 조사에서 확인한 구출 조건·금지 행동·안전 행동 적용
- 피해자의 위치·상태·연결·행동 정상화
- 피해자를 괴이 현상이나 매개체에서 분리
- 성공·부분 실패·지연 결과를 회수 전투 시작 상태로 전달

미니게임 성공이 사건을 자동 해결하거나 회수 전투를 삭제해서는 안 된다.

## 3. 초간단 조작 계약

각 미니게임은 다음 제한을 목표로 한다.

- 설명을 읽고 30초 안에 핵심 조작을 이해
- 핵심 입력 종류 1~2개
- 별도 튜토리얼 스테이지 없이 첫 시도 가능
- 기본 플레이 1~3분
- 실패 이유 즉시 표시
- 빠른 재시도 또는 실패 전진
- 반사 신경보다 조사 지식 적용 우선
- 접근성 대체 입력과 시간 압박 완화 지원

이 수치는 Design 목표이며 사람 플레이 검증 전에는 달성 판정을 내리지 않는다.

## 4. 분기별 대표 피해자 구출 문법

### 봄 — 순서·경로 복원

- 공식 기록과 종료 신호를 기준으로 안전 경로를 복원한다.
- 피해자를 올바른 순서와 시점에 현상 밖으로 이동시킨다.

### 여름 — 대상·역할 배치

- 피해자·도구·동료·위험 표식의 역할을 분리한다.
- 반사 차단·매개체 격리·피해자 호위 역할을 배치한다.

### 가을 — 보호 범위·반환 대상 조절

- 피해 확산을 막는 범위와 먼저 구출할 피해자를 선택한다.
- 결과와 대가를 선택 전에 표시하며 숨은 선악 정답을 두지 않는다.

### 겨울 — 기록 비교·복구 순서

- 확인 사실·충돌 기록·보존할 공백·위험한 복구를 분류한다.
- 다른 사람을 기록에서 밀어내지 않는 순서로 피해자를 복구한다.

구체 입력·UI·난이도·장면은 후속 사건 Spec에서 확정한다.

## 5. 공통 인지 문법

미니게임은 서로 달라도 다음을 공통으로 표시한다.

1. 구출 대상과 현재 상태
2. 조사에서 확보한 구출 규칙
3. 선택 가능한 입력
4. 위험·금지 행동 예고
5. 즉시 결과와 이유
6. 회수 전투로 전달되는 상태

## 6. 실패 전진

- 성공: 피해자 안전 확보·안정된 전투 시작
- 부분 실패: 피해자 후유증·괴이 고착·추가 보호 목표
- 지연: 피해자가 전투 현장에 남아 전투 중 재구출 또는 보호 필요
- 반복 오판: 명확한 위험 사례와 더 어려운 시작 조건

첫 실패는 학습 정보와 복구 기회를 제공한다. 반복 실패는 실제 비용으로 이어질 수 있다.

## 7. 금지 구조

- 미니게임을 조사 단계의 별도 규칙 추리 퍼즐로 취급
- 미니게임을 회수 전투 자체로 취급
- 설명을 외워야 하는 복잡한 조작
- 여러 버튼 조합·정밀 액션·긴 튜토리얼
- 조사 결과와 무관한 순수 반사 신경 판정
- 실패 이유를 숨기는 시행착오
- 미니게임 성공이 조사 오류를 자동 정답 처리
- 미니게임 성공이 회수 전투를 자동 승리 처리
- 한 미니게임을 이름과 스킨만 바꿔 네 번 반복
- 각 미니게임이 별도 장르 수준의 독립 시스템이 되는 범위 팽창
- 일정 편성·훈련 반복을 핵심 미니게임으로 취급

- 실패 이유 이해와 재시도 피로
