## 결정

괴이 매뉴얼은 조사문 완성용 정답표가 아니라 **조사·피해자 구출·회수 전투를 관통하는 실행 규칙**이다.

정상 키워드는 실제 조사 행동으로 획득한다. `[변조]` 키워드는 별도 단서나 획득 장면을 추가하지 않고, 이미 획득한 기존 정상 키워드의 핵심 변수 하나를 괴이가 바꿔 같은 슬롯의 후보로 삽입한다.

```text
정상 키워드 획득
→ 괴이가 핵심 변수 하나를 변조
→ 정상·변조 후보가 같은 슬롯에 표시
→ 플레이어가 조사 기억·원본 출처·매뉴얼 문맥으로 판별
→ 올바른 괴이 매뉴얼 완성
→ 구출 미니게임과 회수 전투에서 직접 사용
```

## 1. 변조 키워드 계약

### 정상 키워드

- 현장 관찰, 증언, 기록, 실험, 비교 또는 추론으로 실제 획득한다.
- 출처와 획득 행동을 보존한다.
- 플레이어가 당시 장면을 기억할 수 있는 구체적 표현을 사용한다.

예:

```text
세 번째 빗소리 직후
출처: 휴대전화 원본 파형 확인
```

### `[변조]` 키워드

- 기존 정상 키워드에서 파생한다.
- 횟수, 시간, 순서, 방향, 대상, 재질, 조건, 주체 중 **변수 하나만** 바꾼다.
- 별도 획득·생성 경로를 만들지 않는다.
- 플레이어 화면에서는 처음부터 `[변조]`라고 표시하지 않는다.
- 정상 키워드의 원본 출처는 그대로 남기되 변조 후보에는 독립 출처를 부여하지 않는다.

예:

```text
정상: 세 번째 빗소리 직후
변조: 네 번째 빗소리 직후
변조 변수: 횟수 3 → 4
```

### 판별 근거

플레이어는 다음 세 가지를 사용해 올바른 키워드를 선택한다.

```text
직접 조사하면서 본 기억
+ 정상 키워드의 원본 출처
+ 완성 중인 괴이 매뉴얼의 다른 규칙
```

변조 판별을 위해 별도 장면이나 추가 가짜 기록을 의무 제작하지 않는다. 작업량과 정보 피로를 늘리는 독립 가짜 단서 파이프라인은 사용하지 않는다.

## 2. 후보 키워드 구성

- 핵심 슬롯에는 정상 후보와 1~2개의 변조 후보를 함께 둘 수 있다.
- 모든 정상 키워드에 변조 짝을 만들지는 않는다.
- 전조 횟수·순서·발현 시점·대응 행동처럼 실행 결과에 직접 영향을 주는 슬롯에서 우선 사용한다.
- 두 변수 이상을 한 번에 바꿔 원본과의 대응 관계를 흐리지 않는다.
- 완전히 무관한 거짓 카드는 `[변조]`로 취급하지 않는다.
- 사실이지만 매뉴얼 슬롯에 쓰이지 않는 보조 키워드는 변조와 분리한다.

## 3. 피해자 구출 미니게임 연결

완성된 구출 절차 슬롯은 피해자 구출 미니게임의 행동 규칙이 된다.

매뉴얼은 다음을 알려 줄 수 있다.

- 차단해야 할 시야·소리·연결 대상
- 사용해야 할 도구 또는 환경 조건
- 금지 행동
- 행동 순서
- 반복 횟수
- 제한 시간 또는 안전 지점

플레이어는 매뉴얼을 열람해 행동을 선택하지만 위치 배치, 경로 선택, 타이밍 수행은 직접 한다. 매뉴얼 완성이 구출을 자동 해결하지 않는다.

예:

```text
피해자와 반사상의 시야를 끊는다.
우산 바깥의 식별음을 두 번 들려준다.
네 번째 빗소리 전에 마른 바닥으로 이동시킨다.
```

## 4. 회수 전투 전조 패턴

회수 페이즈는 평소 턴제 전투를 진행하다가 여러 턴에 걸친 `[전조]`를 통해 패턴을 예고한다.

패턴 길이는 고정 4턴이 아니다.

```text
N ≥ 2
전조 횟수 = N - 1
마지막 N턴 = 대응 선택 후 패턴 발현
```

### 공통 턴 순서

```text
첫 턴: [전조] → 선택 → 평상 진행
중간 턴: 선택 → [전조] → 평상 진행
마지막 턴: 대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행
```

- 첫 턴에는 패턴 시작을 알리기 위해 `[전조]`를 선택 전에 표시한다.
- 두 번째 턴부터 마지막 전 턴까지는 플레이어가 먼저 평상 행동을 고른 뒤 후속 `[전조]`를 보여 준다.
- 마지막 전조가 나온 턴에도 평상 전투를 진행한다.
- `패턴 준비 완료` 상태를 표시하지 않는다.
- `다음 턴 패턴 발현`을 시스템이 자동 안내하지 않는다.
- 마지막 턴에도 패턴을 먼저 보여 주지 않는다.
- 플레이어가 완성된 매뉴얼과 누적 전조를 기억해 먼저 대응 행동을 선택한다.
- 선택 확정 뒤 패턴을 발현하고 상호작용 결과를 계산한다.
- 4턴은 설명용 예시일 뿐이며 실제 패턴은 최소 2턴 이상에서 사건별로 달라질 수 있다.

## 5. 파훼·취약 결과

정확한 발현 턴에 올바른 대응을 선택하면:

```text
[파훼]
→ 괴이의 패턴 행동 무효 또는 역이용
→ 플레이어 피해 방지
→ 괴이 [취약]
→ 유효 공격·연결 절단·잔향 노출 기회
→ 이후 평상 진행
```

부분 대응은 피해를 줄일 수 있으나 `[파훼]`와 `[취약]`을 만들지 않는다.

잘못된 대응은 강한 피해, 자세 붕괴, 자원 손실 또는 불리한 상태를 발생시킬 수 있다. 결과 이후 전투는 평상 턴 흐름으로 돌아간다.

전조가 아직 충분히 누적되지 않은 턴에 조기 대응하면 행동과 자원을 소비하지만 패턴은 파훼되지 않는다. 다만 조기 대응을 치명적 함정으로 만들지는 않는다.

## 6. 회수 매뉴얼 필수 키워드

회수 전투 대응 슬롯은 패턴마다 다음을 정의한다.

1. 전조의 종류
2. 전조 횟수 또는 순서
3. 발현 시점
4. 발현 방향·범위·대상
5. 올바른 대응 행동
6. 파훼 성공 효과
7. 취약 상태의 지속 또는 소비 조건

예:

```text
종소리가 세 번 들린 다음 턴 정면 휩쓸기가 발현한다.
발현 턴에 정면에서 벗어나면 파훼되고 괴이는 다음 유효 공격까지 취약해진다.
```

## 7. 핵심 재미 연결

```text
조사에서 정상 키워드 획득
→ 괴이가 변수를 바꾼 변조 후보 삽입
→ 조사 기억과 매뉴얼 문맥으로 정답 선택
→ 괴이 매뉴얼 완성
→ 구출 절차를 미니게임에서 수행
→ 회수 전조를 매뉴얼로 해석
→ 정확한 발현 턴에 대응 선택
→ [파훼]·[취약]
→ 유효 공격·연결 절단·잔향 회수
```

매뉴얼의 핵심 키워드는 문장 완성에서 끝나지 않는다. 구출 행동, 전조 해석, 발현 시점, 파훼 행동, 취약 조건 중 최소 하나를 실제 플레이에서 결정해야 한다.

## 8. 적대적 검토

### 모든 정보를 의심하게 되는 문제

진짜 조사 단서는 서로 일관된 규칙을 가리킨다. 가짜 후보는 괴이가 정상 키워드의 변수를 바꾼 `[변조]`에 한정한다.

### 작업량 폭증

변조 후보마다 별도 장면·출처·증언을 만들지 않는다. 정상 키워드와의 파생 관계만 관리한다.

### 전조 UI가 매뉴얼을 대체하는 문제

패턴 준비 완료나 발현 예고를 자동 표시하지 않는다. 첫 전조는 시작만 알리고, 정확한 발현 턴과 대응은 매뉴얼을 읽은 플레이어가 판단한다.

### 고정 턴 암기 문제

패턴은 가변 `N ≥ 2` 구조다. 2턴·3턴·4턴 이상의 패턴을 섞고, 횟수뿐 아니라 순서·방향·대상·지연 조건도 사용한다.

### 긴 대기와 행동 낭비

중간 턴에는 평상 전투를 계속할 수 있다. 조기 대응은 자원 손실이 있으나 치명적이지 않으며, 정확한 대응에는 명확한 파훼·취약 보상을 준다.

## 9. 적용 경계

현재 확정하는 것은 제품 설계와 사건 제작 계약이다.

다음은 아직 확정하지 않는다.

- 전투 행동력·자원 수치
- 패턴별 정확한 피해량
- 취약 지속 시간과 중첩 규칙
- 전조가 동시에 겹칠 때 우선순위
- UI 표시 형식과 접근성 옵션
- 실제 사건 데이터·전투 코드·미니게임 구현

상세 Schema·UI·저장·전투 구현은 별도 Design Spec과 승인 전 시작하지 않는다.
