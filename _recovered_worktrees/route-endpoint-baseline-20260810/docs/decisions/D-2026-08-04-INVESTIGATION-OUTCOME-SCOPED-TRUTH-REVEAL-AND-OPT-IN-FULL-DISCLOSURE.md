## 결정

사건 결과 보고서의 공식 정답 공개 범위를 **종결 결과와 현장 검증 범위**에 따라 다르게 처리한다.

```text
정상 클리어
→ 현재 사건 다섯 의미 슬롯 전체 정답 자동 공개
→ 슬롯별 정답 비교
→ answer_viewed
→ 이후 비정본 재현 / 재현 숙련 등급

실패 또는 승인 철수
→ 현장에서 검증된 슬롯과 직접 관찰된 위험 원인만 공개
→ 미검증 슬롯은 숨김
→ partial_truth_revealed
→ 정답 비공개 후속 재조사 가능
→ 또는 플레이어가 공식 정답 전체 공개를 명시적 선택
→ 사전 경고
→ answer_viewed로 전환
→ 이후 비정본 재현 / 재현 숙련 등급
```

실패 원인을 학습할 최소한의 근거는 제공하되, 실패·승인 철수만으로 모든 정답을 자동 공개해 철수를 정답 확인 수단으로 최적화하지 않는다.

## 1. 결과 유형

결과 보고서는 최소 다음 결과 유형을 구분한다.

- `정상 클리어`: 피해자 구출과 잔향 회수 또는 승인된 동등 종결에 성공
- `실패`: 예고된 비가역 결과, 회수 실패, 피해자 상실 등 사건 실패 조건 확정
- `승인 철수`: 조직 절차에 따라 현장을 포기하거나 후속 재조사를 선택한 종결

결과 유형은 최초 조사 등급·캠페인 정본·피해자 상태·세력 반응을 먼저 확정한다. 정답 공개 범위가 그 결과를 소급 변경하지 않는다.

## 2. 정상 클리어 — 전체 정답 자동 공개

`정상 클리어` 결과 보고서에서는 현재 사건의 `전체 정답 자동 공개`를 수행한다.

공개 범위:

- `다섯 의미 슬롯`의 공식 정답
- 최종 진입 시 제출한 키워드와 `슬롯별 정답 비교`
- 정확 / 부분 일치 / 오답 / 미해결
- 판단을 뒷받침하는 단서 [기록]과 원본 출처
- 사용한 `[변조]` 후보의 원본과 변경 변수
- 핵심 오답 가설과 반증
- 구출·회수 결과와 위험 사례
- 일반 클리어·최초 조사 S 랭크의 차이

정상 클리어 보고서에서 전체 정답이 실제 표시되면 해당 사건은 `answer_viewed`가 된다. 이후 시도는 Decision 9에 따라 `비정본 재현`이며 별도 `재현 숙련 등급`으로 기록한다.

`다음 사건의 미획득 증거나 정답은 공개하지 않는다`.

## 3. 실패·승인 철수 — 결과 범위 제한 공개

`실패`와 `승인 철수`의 기본 보고서는 전체 답안지가 아니다.

자동 공개하는 항목:

- 현장 결과로 `검증된 슬롯`
- 구출·회수에서 `직접 관찰된 현상`
- `실패를 일으킨 행동`, 순서, 조건 또는 상충 관계
- 피해자 반응·환경 변화·전조·파훼 실패 등 관찰 기록
- 새로 발생한 `위험 사례`
- 획득한 단서 [기록]과 출처
- 아직 확인되지 않은 쟁점의 범주

자동 공개하지 않는 항목:

- 현장에서 검증되지 않은 슬롯의 공식 정답
- 미획득 단서와 숨겨진 조사 장면
- 정답 후보 추천
- 틀린 슬롯의 정확한 교체 답
- 숨긴 슬롯의 `정답 근접도`
- 정답 적합도·성공 확률·추천 순위

`미검증 슬롯은 숨김` 상태로 표시한다. 단순 공백의 길이, 정렬, 색상, 아이콘, 후보 개수 차이로 정답을 역산할 수 없게 한다.

### 검증된 슬롯의 기준

검증은 플레이어가 제출했다는 이유만으로 성립하지 않는다. 다음 중 하나 이상의 현장 근거가 있어야 한다.

- 해당 규칙에 대응한 행동 뒤 재현 가능한 현상이 발생
- 독립된 원본 출처 둘 이상이 같은 관계를 지지
- 구출·회수 결과가 특정 조건·순서·대상을 직접 확인
- 실패 원인 분석에서 인과 관계가 관찰 기록으로 남음

부분 검증이면 확인된 관계까지만 공개하고 나머지 변수는 숨긴다. 시스템은 추측을 공식 정답으로 승격하지 않는다.

## 4. 공식 정답 전체 공개 — 플레이어 선택

실패·승인 철수 보고서에는 `공식 정답 전체 공개` 선택을 제공한다.

- 전체 공개는 플레이어의 `명시적 선택`이어야 한다.
- 기본 포커스·자동 진행·시간 초과로 선택하지 않는다.
- 선택 전 `사전 경고`를 표시한다.
- 경고 뒤 취소하고 정답 비공개 상태를 유지할 수 있다.
- 전체 공개를 선택하면 현재 사건의 다섯 의미 슬롯과 근거를 모두 보여 준다.
- 실제 전체 정답이 표시되는 시점에 `answer_viewed로 전환`한다.

사전 경고는 다음 영향을 명확히 설명한다.

```text
- 아직 숨겨진 공식 정답이 공개됩니다.
- 최초 조사 기록·캠페인 정본·피해자 상태·세력 반응은 바뀌지 않습니다.
- 이후 시도는 비정본 재현으로 기록됩니다.
- 이후에는 최초 조사 S가 아니라 재현 숙련 등급을 획득합니다.
```

전체 공개 뒤에도 `최초 조사 정본을 덮어쓰지 않는다`. 최초 실패·승인 철수·위험 사례·피해자 결과는 보존한다.

## 5. 정답 비공개 후속 재조사

실패·승인 철수의 제한 보고서만 본 상태는 `partial_truth_revealed`다.

- 제한 보고서 열람만으로 `answer_viewed로 전환하지 않는다`.
- 플레이어는 `정답 비공개 후속 재조사`를 선택할 수 있다.
- 후속 재조사는 기존 단서, 검증된 슬롯, 위험 사례를 가진 채 미검증 슬롯을 다시 조사한다.
- `최초 실패와 위험 사례를 보존`한다.
- 최초 조사 등급·피해자 상태·세력 반응을 지우거나 다시 굴리지 않는다.
- 후속 해결은 최초 결과를 덮어쓰는 시간 역행이 아니라 `후속 결과를 추가 기록`하는 사건 연속성이다.
- `최초 조사 S 랭크를 덮어쓰지 않는다`.
- 후속 재조사로 정상 클리어하면 그 후속 종결과 날짜를 추가하고, 정상 클리어 보고서에서 전체 정답을 공개해 answer_viewed로 전환한다.

후속 재조사는 정답이 공개된 `replay_mastery`와 구분한다.

```text
first_run
→ failure 또는 approved_withdrawal
→ partial_truth_revealed
→ reinvestigation
→ 후속 결과 추가 기록

partial_truth_revealed
→ opt_in_full_disclosure
→ answer_viewed
→ replay_mastery
```

## 6. 상태 계약

권장 의미 상태:

```text
first_run                # 공식 정답 미공개 최초 조사
partial_truth_revealed   # 실패·철수 뒤 검증 범위만 공개
reinvestigation          # 정답 비공개 후속 재조사
answer_viewed             # 현재 사건 공식 전체 답 공개 이력 있음
replay_mastery            # 정답 공개 후 비정본 기록 재현
```

상태 전환 원칙:

- 정상 클리어 보고서의 전체 답 표시 → `answer_viewed`
- 실패·철수 제한 보고서 표시 → `partial_truth_revealed`, answer_viewed 아님
- 공식 정답 전체 공개 확인 → `answer_viewed`
- 접근성·일시정지·저장·메뉴 이탈 → 공개 상태 변경 없음
- 외부 공략을 봤는지 시스템이 추측해 상태를 변경하지 않음

## 7. 필수 안전 정보

정답을 숨긴다는 이유로 플레이어 안전과 공정성을 숨기지 않는다.

반드시 공개하는 `필수 안전 정보`:

- 이미 확인된 즉시 위험과 금지 행동
- 다음 시도 전에 알아야 할 예고된 임계 조건
- `명확히 예고된 비가역 결과`
- 사용한 자원·위험도·피해자 상태
- 같은 행동을 반복하면 같은 위험이 재현된다는 사실

필수 안전 정보는 정답 키워드 전체를 자동 작성하지 않고도 행동 수준으로 전달한다. 미공개 정답을 이유로 무작위 즉사나 회복 불가능한 함정을 만들지 않는다.

## 8. 접근성·선택 공정성

- 스크린리더, 입력 보조, 반복 설명, 기록 재생 등 `접근성 기능`은 `동일한 경고와 선택`을 제공한다.
- 접근성 기능 사용으로 전체 정답 공개가 자동 선택되지 않는다.
- 감각 방식에 따라 공개되는 정보량과 공개 시점을 다르게 하지 않는다.
- 제한 보고서를 이해하기 위한 텍스트·구조·아이콘 대체 정보를 제공한다.
- 플레이어에게 `전체 정답 공개를 강제하지 않는다`.
- 전체 공개를 거절해도 핵심 캠페인 진행·저장·종료를 막지 않는다.

## 9. 보상·상업화 경계

- `정답 공개 자체에 보상 없음`.
- 전체 정답을 보거나 보지 않았다는 사실만으로 성장 자원·전력·필수 아이템을 지급하지 않는다.
- 전체 공개를 보상 광고, 유료 결제, 재화 소모, 대기 시간과 연결하지 않는다.
- `유료화·시간 잠금 금지`.
- 제한 보고서를 유지한다고 기본 보상을 추가 파밍할 수 없다.
- 전체 공개 선택이 최초 결과·기본 보상·재현 보상 횟수를 초기화하지 않는다.

## 10. 사건 제작 요구사항

사건 작가는 실제 규칙을 작성할 때 결과 보고서 공개 표도 함께 만든다.

| 항목 | 정의 |
|---|---|
| 정상 클리어 공개 | 다섯 슬롯 전체와 근거 |
| 실패 직접 관찰 | 어떤 행동·조건·현상이 확인되는가 |
| 승인 철수 관찰 | 무엇을 안전하게 확인했고 무엇이 미검증인가 |
| 검증된 슬롯 | 공개 가능한 관계와 변수 범위 |
| 숨길 슬롯 | 미검증 공식 답과 미획득 단서 |
| 필수 안전 정보 | 재도전 전에 반드시 알려야 할 위험 |
| 전체 공개 경고 | answer_viewed·비정본 재현 전환 설명 |
| 후속 재조사 | 남은 조사 경로와 후속 결과 기록 방식 |

실패 장면을 먼저 쓰고 정답 공개를 끼워 맞추지 않는다. 각 실패·철수 결과가 무엇을 실제로 검증하는지 실제 규칙에서 역설계한다.

## 11. 적대적 보호 규칙

- 일부러 철수해 전체 답을 자동 획득하는 최적 전략을 만들지 않는다.
- 실패 원인을 전혀 설명하지 않아 같은 실수를 맹목 반복하게 만들지 않는다.
- 후보를 제출했다는 이유만으로 검증된 슬롯으로 처리하지 않는다.
- 숨긴 슬롯의 길이·색·정렬·후보 수로 답을 누설하지 않는다.
- 전체 공개를 기본 선택·자동 선택·보상 선택으로 유도하지 않는다.
- 전체 공개 선택을 되돌려 answer_viewed 이력을 지우지 않는다.
- 후속 재조사가 최초 실패·피해자 결과·위험 사례를 삭제하지 않는다.
- 후속 성공으로 최초 조사 S 랭크를 세탁하지 않는다.
- 필수 안전 정보와 접근성 정보를 스포일러 보호 명목으로 숨기지 않는다.
- 전체 공개를 유료화하거나 시간 잠금하지 않는다.
- 다음 사건의 미획득 증거나 정답을 현재 보고서에서 공개하지 않는다.

## 12. 미확정

- 검증된 슬롯의 세부 판정 Schema
- partial_truth_revealed·reinvestigation 저장 구조
- 후속 사건 결과가 조직 평가에 반영되는 세부 규칙
- 제한 보고서·전체 공개 경고·기록 비교 UI
- 캠페인 최종 종결 시 남은 미공개 사건 답의 일괄 공개 여부
- Human QA에서 실패 설명량과 재조사 동기의 균형
