# Urban Legend Investigation Case Authoring

괴이는 처치 대상이 아니다. 플레이어가 **관찰 가능한 전조를 읽고, 가설을 세우며, 근거를 확보해, 스스로 대응을 선택**하도록 설계한다.

## Read first

`AGENTS.md` → `docs/CURRENT_STATUS.md` → `docs/planning/PROJECT_DIRECTION.md` → `docs/GAME_DESIGN_DOCUMENT.md` → `docs/MINIGAME_SYSTEM_SPEC.md`(해당 시) → `docs/workflows/INVESTIGATION_CASE_AUTHORING_WORKFLOW.md` → 대상 `data/episodes/*`와 관련 테스트.

## Required formula

```text
괴이의 실제 규칙
→ 완성 괴이 매뉴얼
→ 2~3장의 완성 조사문
→ 장당 3~5개의 정답 키워드
→ 원시 단서와 획득 장면
→ 그럴듯한 오답 가설과 후속 반증
→ 피해자 구출·회수 전투 적용
→ 공식 규칙·위험 사례·미해결 기록
```

조사 장면부터 쓰고 정답을 끼워 맞추지 않는다. 결론에서 조사 경험으로 역설계한다.

## Clue and keyword contract

- 명확한 물증·증언은 `즉시 사건 키워드`로 획득할 수 있다.
- 불완전한 현상·간접 증언·상충 기록은 `원시 관찰 기록 → 비교·모순·논리 연결 → 정제 키워드`로 발전시킨다.
- 키워드는 `원시 관찰 기록 / 사건 키워드 / 추론 키워드`를 구분한다.
- 모든 키워드는 출처, 획득 행동, 선행 조건, 의미 주장, 사용 슬롯, 신뢰 상태, 대체 경로를 가진다.
- 좋은 키워드는 일반 명사가 아니라 발견 장면이 떠오르는 구체적 사실이다.
- 그럴듯한 오답은 무관한 쓰레기 정보가 아니라 후속 근거로 반증 가능한 초기 가설이다.

## Case contract

| 요소 | 반드시 정의할 내용 |
|---|---|
| 현상과 금기 | 반복 규칙, 발동 조건, 플레이어가 볼 수 있는 전조 |
| 조사문 | 2~3장, 장당 3~5개 슬롯, 자연스러운 완성문 |
| 가설 | 처음에는 비교 가능한 후보와 각 후보의 지지·반증 근거 |
| 단서 | 출처·획득 행동·해석·사용 슬롯·놓쳤을 때 대체 경로 |
| 대응 | 피해자 구출과 회수 전투의 대상·순서·타이밍·위험 |
| 실패 | 위험 사례, 비용·학습, 재시도 또는 다른 근거 탐색 경로 |
| 매뉴얼 | 발생 조건·피해자 연결·금지 행동·구출 절차·회수 전투 대응 |

## Authoring rules

- `상황 설명 → 플레이어 행동 → 짧은 결과 → 기록 변화`의 리듬을 유지한다.
- 모든 클릭이 완성 키워드를 주지 않으며, 모든 단서를 두 카드 조합으로 만들지도 않는다.
- 핵심 대응은 요원·아카·장비·자동행동이 대신 고르거나 숨은 정답을 알려 주지 않는다.
- 맞는 대응이어도 필요한 근거가 부족하면 공식 규칙으로 자동 승격하지 않는다.
- 실패는 진행을 막지 않되 위험 사례와 배제 근거를 남긴다.
- 미니게임은 조사 마지막 규칙 검증이며 안정화·잔향 회수 전체를 대체하지 않는다.
- 기존 사건 ID·저장 스키마·저승역 외 직접 대응 흐름을 불필요하게 바꾸지 않는다.

## Fairness review

1. 첫 선택 전에 읽을 수 있는 전조가 있는가?
2. 정답 키워드는 실제 조사 행동과 출처를 갖는가?
3. 원시 관찰 기록에서 정제 키워드로 가는 해석이 비약하지 않는가?
4. 두 가설 이상이 처음에는 그럴듯하고 후속 근거로 구분되는가?
5. 완성문이 자연스럽고 빈칸 형태가 정답을 과도하게 누설하지 않는가?
6. 핵심 단서를 놓쳐도 공정한 대체 경로가 있는가?
7. 외부 지식·운·숨은 수치가 아니라 사건 내부 증거로 결정되는가?
8. 조사문이 피해자 구출과 회수 전투의 실제 판단에 사용되는가?
9. 실패가 다음 방향을 주되 정답을 자동 작성하지 않는가?
10. 공식 매뉴얼과 결과 화면이 같은 기록 상태를 소비하는가?

## Output

사건 목적, 실제 규칙 5슬롯, 완성 괴이 매뉴얼, 2~3장 조사문, 정답·보조·그럴듯한 오답·추론 키워드 표, 원시 단서·획득 장면, 가설·반증 흐름, 피해자 구출·회수 전투 참조, 위험 사례·매뉴얼 전이, 정상·실패·경계 QA, 미확정을 분리한다.

## Failure conditions

- 괴이를 HP·공격·처치 중심의 전투 적으로 바꾼다.
- 자동 보조가 플레이어의 가설·대응 선택을 대체한다.
- 키워드에 출처·획득 행동·사용 슬롯이 없다.
- 맞는 문장 하나만 강요하면서 근거 확인과 반증을 생략한다.
- 위험 사례를 삭제하거나 같은 실패를 중복 기록한다.
