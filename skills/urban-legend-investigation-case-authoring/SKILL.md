# Urban Legend Investigation Case Authoring

괴이는 단순 처치 대상이 아니다. 플레이어가 **관찰 가능한 전조를 읽고, 가설을 세우며, 근거를 확보해, 괴이 매뉴얼을 완성하고, 현장에서 스스로 대응을 선택**하도록 설계한다.

## Required formula

```text
괴이의 실제 규칙
→ 완성 괴이 매뉴얼
→ 2~3장의 완성 조사문
→ 장당 3~5개의 정답 키워드
→ 원시 단서와 획득 장면
→ 정상 키워드에서 파생한 [변조] 후보
→ 그럴듯한 오답 가설과 후속 반증
→ 피해자 구출 미니게임 적용
→ 회수 전투의 전조·대응·파훼·취약 적용
→ 공식 규칙·방해 기록·위험 사례·미해결 기록
```

조사 장면부터 쓰고 정답을 끼워 맞추지 않는다. 결론에서 조사 경험으로 역설계한다.

## Clue and keyword contract

- 명확한 물증·증언은 `즉시 사건 키워드`로 획득할 수 있다.
- 불완전한 현상·간접 증언·상충 기록은 `원시 관찰 기록 → 비교·모순·논리 연결 → 정제 키워드`로 발전시킨다.
- 키워드는 `원시 관찰 기록 / 사건 키워드 / 추론 키워드`를 구분한다.
- 정상 키워드는 출처, 획득 행동, 선행 조건, 의미 주장, 사용 슬롯, 신뢰 상태, 대체 경로를 가진다.
- 좋은 키워드는 일반 명사가 아니라 발견 장면이 떠오르는 구체적 사실이다.
- 그럴듯한 오답은 무관한 쓰레기 정보가 아니라 후속 근거로 반증 가능한 초기 가설이다.

## Mutated candidate contract

- `[변조]` 후보는 **기존 정상 키워드**에서 파생한다.
- 횟수·시간·순서·방향·대상·주체·재질·조건 중 **변수 하나**만 바꾼다.
- 변조 후보마다 별도 획득·생성 경로를 만들지 않는다.
- 변조 후보에 독립 출처·독립 조사 장면을 부여하지 않는다.
- 플레이어는 `조사 기억 + 정상 키워드의 원본 출처 + 완성 중인 괴이 매뉴얼`로 판별한다.
- 모든 정상 키워드에 변조 짝을 만들지 않는다.
- 실행 결과에 직접 영향을 주는 시간·횟수·순서·대응·취약 슬롯에서 우선 사용한다.
- 완전히 무관한 카드나 사실인 보조 키워드를 `[변조]`로 분류하지 않는다.

예:

```text
정상: 세 번째 빗소리 직후
변조: 네 번째 빗소리 직후
변수: 횟수 3 → 4
```

## Case contract

| 요소 | 반드시 정의할 내용 |
|---|---|
| 현상과 금기 | 반복 규칙, 발동 조건, 플레이어가 볼 수 있는 전조 |
| 조사문 | 2~3장, 장당 3~5개 슬롯, 자연스러운 완성문 |
| 가설 | 처음에는 비교 가능한 후보와 각 후보의 지지·반증 근거 |
| 단서 | 출처·획득 행동·해석·사용 슬롯·놓쳤을 때 대체 경로 |
| 변조 | 정상 키워드 참조, 변경 변수, 변조 표시문, 독립 출처 없음 |
| 구출 | 피해자 구출 미니게임의 대상·도구·순서·횟수·제한 시간 |
| 회수 | 전조 종류·횟수/순서·발현 시점·대응·파훼·취약 |
| 실패 | 위험 사례, 비용·학습, 재시도 또는 다른 근거 탐색 경로 |
| 매뉴얼 | 발생 조건·피해자 연결·금지 행동·구출 절차·회수 전투 대응 |

## Manual-driven rescue contract

- 완성된 구출 절차를 피해자 구출 미니게임에서 실제로 열람·사용한다.
- 매뉴얼은 차단 대상, 도구, 금지 행동, 순서, 반복 횟수, 제한 시간, 안전 지점을 알려 줄 수 있다.
- 플레이어가 도구 배치, 경로, 타이밍, 행동 선택을 직접 수행한다.
- 매뉴얼을 완성했다고 구출을 자동 해결하지 않는다.

## Recovery telegraph contract

회수 전투 패턴은 가변 길이를 사용한다.

```text
N ≥ 2
전조 횟수 = N - 1
첫 턴: [전조] → 선택 → 평상 진행
중간 턴: 선택 → [전조] → 평상 진행
마지막 턴: 대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행
```

- 최소 2턴이며 4턴은 예시일 뿐 고정값이 아니다.
- 첫 턴에는 패턴 시작을 알리기 위해 `[전조]`를 선택 전에 표시한다.
- 중간 턴에는 플레이어가 먼저 행동을 고른 뒤 후속 `[전조]`를 표시한다.
- 마지막 전조 턴에도 평상 전투를 진행한다.
- 패턴 준비 완료 상태를 표시하지 않는다.
- 다음 턴 발현을 시스템이 자동 안내하지 않는다.
- 마지막 턴에도 패턴을 먼저 보여 주지 않는다.
- 플레이어가 완성 매뉴얼을 근거로 대응 선택을 먼저 확정한 뒤 패턴 발현과 결과 산출을 처리한다.
- 정확한 대응만 `[파훼]`와 `[취약]`을 발생시킨다.
- 부분 대응은 피해를 줄일 수 있으나 취약을 만들지 않는다.
- 조기 대응은 행동·자원을 소비하지만 파훼하지 못하며 치명적 함정으로 만들지 않는다.

## Authoring rules

- `상황 설명 → 플레이어 행동 → 짧은 결과 → 기록 변화`의 리듬을 유지한다.
- 모든 클릭이 완성 키워드를 주지 않으며, 모든 단서를 두 카드 조합으로 만들지도 않는다.
- 핵심 대응은 요원·아카·장비·자동행동이 대신 고르거나 숨은 정답을 알려 주지 않는다.
- 맞는 대응이어도 필요한 근거가 부족하면 공식 규칙으로 자동 승격하지 않는다.
- 실패는 진행을 막지 않되 위험 사례와 배제 근거를 남긴다.
- 미니게임은 조사 마지막 규칙 검증이며 안정화·잔향 회수 전체를 대체하지 않는다.
- 매뉴얼의 핵심 키워드는 구출 행동, 전조 해석, 발현 시점, 파훼 행동, 취약 조건 중 최소 하나를 실제 플레이에서 결정한다.
- 기존 사건 ID·저장 스키마·저승역 외 직접 대응 흐름을 불필요하게 바꾸지 않는다.

## Fairness review

1. 첫 선택 전에 읽을 수 있는 전조가 있는가?
2. 정답 키워드는 실제 조사 행동과 출처를 갖는가?
3. 원시 관찰 기록에서 정제 키워드로 가는 해석이 비약하지 않는가?
4. 두 가설 이상이 처음에는 그럴듯하고 후속 근거로 구분되는가?
5. `[변조]` 후보가 기존 정상 키워드의 변수 하나만 바꾸는가?
6. 변조 후보 때문에 별도 가짜 획득 장면을 불필요하게 만들지 않았는가?
7. 완성문이 자연스럽고 빈칸 형태가 정답을 과도하게 누설하지 않는가?
8. 핵심 단서를 놓쳐도 공정한 대체 경로가 있는가?
9. 조사문이 피해자 구출 미니게임과 회수 전투의 실제 판단에 사용되는가?
10. 첫 턴 전조·중간 턴 후속 전조·마지막 턴 선대응 순서가 지켜지는가?
11. 패턴 준비 완료·발현 안내가 매뉴얼 판단을 대신하지 않는가?
12. 최소 2턴의 가변 패턴을 표현할 수 있는가?
13. 정확한 대응만 파훼·취약을 만드는가?
14. 실패가 다음 방향을 주되 정답을 자동 작성하지 않는가?
15. 공식 매뉴얼과 결과 화면이 같은 기록 상태를 소비하는가?

## Output

사건 목적, 실제 규칙 5슬롯, 완성 괴이 매뉴얼, 2~3장 조사문, 정상·보조·그럴듯한 오답·추론·변조 후보 표, 원시 단서·획득 장면, 가설·반증 흐름, 피해자 구출 미니게임 절차, 회수 전조·대응·파훼·취약 규칙, 위험 사례·매뉴얼 전이, 정상·실패·경계 QA, 미확정을 분리한다.

## Failure conditions

- 괴이를 HP·공격·처치 중심의 단순 전투 적으로 바꾼다.
- 자동 보조가 플레이어의 가설·대응 선택을 대체한다.
- 정상 키워드에 출처·획득 행동·사용 슬롯이 없다.
- 변조 후보마다 독립 가짜 단서·획득 장면을 추가한다.
- 맞는 문장 하나만 강요하면서 조사 기억과 출처 확인을 생략한다.
- 패턴 발현 전에 준비 완료·정답 대응을 자동 표시한다.
- 마지막 턴에 패턴을 먼저 공개한 뒤 선택하게 한다.
- 4턴을 고정값으로 사용한다.
- 위험 사례를 삭제하거나 같은 실패를 중복 기록한다.
