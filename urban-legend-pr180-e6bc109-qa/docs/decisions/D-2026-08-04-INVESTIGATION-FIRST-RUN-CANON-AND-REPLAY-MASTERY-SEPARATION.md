# D-2026-08-04-INVESTIGATION-FIRST-RUN-CANON-AND-REPLAY-MASTERY-SEPARATION

> 상태: `APPROVED_PRODUCT_DECISION / PENDING_BATCH_MERGE`
> 승인일: 2026-08-04
> 승인 시각: 2026-08-04 07:26 KST
> Grill Me: `GRILLME_BATCH_3 / 9_OF_10`
> 범위: 최초 조사 등급·캠페인 정본·정답 공개 후 기록 재현·보상 경계
> 구현: `NOT_AUTHORIZED`
> 사람 검증: `NOT_RUN`

## 결정

괴이 사건은 **정답 비공개 상태에서 처음 확정된 결과**와 **정답 공개 후 기록 재현**을 별도 기록으로 관리한다.

```text
정답 비공개 상태의 최초 조사 세션
→ 최초 사건 결과 확정
→ 최초 조사 기록·캠페인 정본·기본 성장 보상 확정
→ 사건 결과 보고서와 정답 공개
→ answer_viewed
→ 정답 공개 후 기록 재현
→ 비정본 재현 결과와 재현 숙련 등급 기록
```

최초 조사에서 발생한 불완전한 판단과 위험 사례를 지워 버리지 않으면서도, 플레이어가 완성된 매뉴얼·구출·회수 절차를 다시 연습하고 정밀하게 재현할 수 있게 한다.

## 1. 최초 조사 기록

`최초 조사 기록`은 다음 조건에서 생성한다.

- 해당 사건의 공식 정답 보고서가 아직 열리지 않은 `정답 비공개 상태`
- 성공·실패·승인된 철수 등 `최초 사건 결과 확정`
- 사건 결과가 확정되기 전의 저장·로드·일시정지·메뉴 이탈은 별도 최초 조사로 계산하지 않음

최초 조사 기록이 소유하는 값:

- `최초 조사 등급`
- `최초 조사 S 랭크`
- 피해자 생존·부상·상실 등 `피해자 상태`
- 사건 안정화·위험 사례·미해결 상태
- 조직·인물·`세력 반응`
- 후속 사건과 캠페인에 반영되는 `캠페인 정본`
- 최초 결과에 따른 `기본 성장 보상`
- 최초 조사 보고서와 사용한 최종 괴이 매뉴얼

`기본 성장 보상`은 사건당 1회 지급한다. 최초 조사 결과가 완벽하지 않아도, 정답을 본 뒤 반복 플레이해 기본 성장 보상을 증식시키지 않는다.

## 2. 최초 조사 S 랭크

`최초 조사 S 랭크`는 정답을 보기 전에 다음을 달성한 경우에만 기록한다.

- 정답 비공개 상태에서 사건을 해결
- 다섯 의미 슬롯이 공식 규칙과 일치
- 핵심 증거와 출처가 연결
- 핵심 `[변조]`와 오답 가설을 적절히 판별
- 피해자 구출과 회수 대응의 정밀 조건 충족

정답 공개 후 기록 재현에서 완벽한 결과를 내더라도 **최초 조사 S 랭크를 덮어쓰지 않는다**. 대신 별도의 재현 숙련 등급을 제공한다.

최초 조사 등급이 낮더라도 캠페인 진행을 봉쇄하지 않는다. 이미 승인된 일반 클리어·승인된 종결 조건을 만족하면 다음 콘텐츠로 진행할 수 있다.

## 3. 정답 공개 후 기록 재현

사건 결과 보고서의 공식 답을 연 뒤 해당 사건의 spoiler 상태는 `answer_viewed`가 된다.

그 이후의 플레이는 `정답 공개 후 기록 재현`으로 분류한다.

- 화면과 저장 기록에 `비정본 재현`임을 명확히 표시한다.
- 최초 조사와 동일한 조사·매뉴얼·구출·회수 콘텐츠를 다시 수행할 수 있다.
- 정답 매뉴얼을 그대로 따라도 허용한다.
- 다양한 도구·경로·팀 구성·전투 대응을 실험할 수 있다.
- 재현 결과는 별도 `replay_mastery` 기록에 저장한다.
- 최초 조사 결과와 같은 화면에서 비교할 수 있지만 두 기록을 합치거나 혼동시키지 않는다.

기록 재현은 다음을 변경하지 않는다.

- `최초 조사 S 랭크를 덮어쓰지 않는다`
- `캠페인 정본을 덮어쓰지 않는다`
- `피해자 상태를 덮어쓰지 않는다`
- `세력 반응을 덮어쓰지 않는다`
- 최초 사건의 위험 사례·미해결 기록을 삭제하지 않는다
- 이미 지급된 성장 자원과 필수 보상을 다시 지급하지 않는다

## 4. 재현 숙련 등급

기록 재현에는 최초 조사 등급과 구분되는 `재현 숙련 등급`을 둔다.

평가할 수 있는 요소:

- 완성 괴이 매뉴얼의 정확도
- 피해자 구출의 절차 정확도·안전성·시간
- 회수 전투의 전조 판별·파훼·취약 활용
- 선택한 도구·경로·팀 구성의 정밀도
- 선택적 도전 조건

표시 원칙:

```text
최초 조사 등급: A
최초 조사 정본: 피해자 부상 / 잔향 회수
재현 숙련 등급: S
상태: answer_viewed / 비정본 재현
```

재현 숙련 S는 숙련 성취이지만 최초 조사 S와 동일한 명칭·아이콘·통계로 합치지 않는다.

## 5. 재현 보상 경계

정답 공개 후 재현 보상은 `반복 파밍 불가`를 기본으로 한다.

허용 가능:

- `도감·기록 완성`
- 사건별 재현 도장·칭호
- `선택적 외형 보상`
- 전투력·필수 성장에 영향을 주지 않는 장식·기록 보상
- 사건당 1회 획득 가능한 재현 숙련 보상

금지:

- `중복 성장 보상 금지`
- 경험치·재화·장비·전력의 무제한 반복 파밍
- 캠페인 정본·피해자 상태·세력 반응을 보상 조건으로 재작성
- 정답 공개 후 재현 S를 최초 조사 S처럼 표시
- 재현 숙련을 `캠페인 진행 필수 조건으로 사용하지 않는다`

재현 보상은 **전투력·필수 성장에 영향을 주지 않는** 선택적 성취가 원칙이다. 정확한 화장품·칭호·도감 보상 수치는 Human QA와 후속 보상 Spec에서 정한다.

## 6. 정답 공개 전 재시도

`정답 보고서가 열리기 전`의 재시도는 정답 공개 후 기록 재현이 아니다.

- 기존 체크포인트에서 `체크포인트 재개`
- 실패 회복으로 조사 페이즈에 후퇴
- 저장·로드 후 같은 사건을 계속 진행
- 임계 결과 직전 승인된 안전 재개

이들은 `같은 최초 조사 세션`의 연속으로 취급한다. 정답이나 공식 보고서를 열지 않았다면 `answer_viewed로 전환하지 않는다`.

사건 결과를 확정한 뒤 공식 정답 보고서를 열지 않고 새 게임을 시작하는 특수 UX는 후속 Design Spec에서 정하되, 정답 공개 이력을 우회해 최초 조사 보상을 반복 획득하는 경로는 만들지 않는다.

## 7. 접근성과 공정성

- 스크린리더, 입력 보조, 일시정지, 기록 재생, 텍스트 반복, 난이도 보조 등 `접근성 기능`은 최초 조사 자격을 박탈하지 않는다.
- 접근성 기능 사용을 `answer_viewed`로 기록하지 않는다.
- 접근성 기능은 `최초 조사 자격을 박탈하지 않는다`.
- 정답 공개 시점과 정보량은 입력·감각 방식과 무관하게 동일하다.
- 재현 숙련 등급도 접근성 등가 입력에 불이익을 주지 않는다.

## 8. 스포일러 상태와 데이터 의미

권장 상태:

```text
first_run        # 공식 정답 미공개 최초 조사
answer_viewed    # 현재 사건 공식 답 공개 이력 있음
replay_mastery   # 정답 공개 후 비정본 기록 재현
```

시스템은 `시스템 내부 공개 이력`만 기록한다.

- 결과 보고서 또는 공식 답을 실제로 열었는가
- 시스템이 정답 매뉴얼을 공개했는가
- 해당 프로필·저장 데이터에 공개 이력이 있는가

시스템은 `외부 공략 열람 여부를 판정하지 않는다`. 외부 영상·공략·다른 사람의 설명을 봤는지 추측해 처벌하거나 최초 조사 자격을 임의로 박탈하지 않는다.

UI는 `최초 조사와 기록 재현을 한 화면에서 혼동시키지 않는다`. 정확한 Schema·프로필 공유·클라우드 저장 규칙은 구현 승인 후 정의한다.

## 9. 적대적 보호 규칙

- 정답을 본 뒤 최초 조사 결과를 지워 완벽한 정본으로 교체하지 않는다.
- 최초 실패·피해자 상태·위험 사례를 기록 재현으로 삭제하지 않는다.
- 재현 숙련 보상을 반복 경제 파밍으로 만들지 않는다.
- 최초 조사 S와 재현 숙련 S를 통계·업적에서 혼합하지 않는다.
- 재현 숙련을 필수 진행 Gate로 만들지 않는다.
- 정답 보고서가 열리기 전 재개를 부당하게 answer_viewed로 표시하지 않는다.
- 접근성 기능을 스포일러·치트·보상 감점으로 취급하지 않는다.
- 외부 공략 사용 여부를 시스템이 정확히 판정할 수 있다고 주장하지 않는다.

## 10. 미확정

- 최초 조사 실패·철수 시 공개할 정답 범위
- 캠페인 정본을 별도 비정본 분기에서 체험하는 UX
- 재현 숙련 등급의 세부 평가식
- 선택적 외형 보상과 도감 보상의 종류·수량
- 프로필 간 answer_viewed 공유 범위
- 클라우드 저장·새 게임+에서의 spoiler 상태
- 기록 비교 화면과 통계 표시
- Human QA 난이도·보상 적정성
