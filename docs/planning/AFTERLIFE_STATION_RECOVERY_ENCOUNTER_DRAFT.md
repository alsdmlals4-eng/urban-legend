# 저승역 Validation Cut 회수 encounter 초안

> 상태: `DRAFT_REQUIRES_REVIEW`
> 추적: Issue #121 / Draft PR #122
> 선행 Benchmark Gate: `REUSED`
> 선행 설계:
> - `AFTERLIFE_STATION_HYPOTHESIS_DESIGN_V2.md`
> - `AFTERLIFE_STATION_TIMELINE_EVIDENCE_DRAFT.md`
> 대상: Validation Cut 35~50분
> 구현 권한: `NONE`

## 1. 목적

Validation Cut의 회수 단계에서 사건 전체 가설을 반복하지 않고 다음을 검증한다.

- 조사·가설 보드에서 만든 안전 운용 규칙을 새 전조에 적용하는가
- 전조의 대상·시점·조건을 읽고 중립적인 행동을 고르는가
- 올바른 행동과 공식 추론 검증을 구분하는가
- 오대응이 원인·위험 사례·다음 질문을 남기는가

## 2. Validation 범위

회수 패턴 네 개 중 두 개를 고정 사용한다.

1. 존재하지 않는 종착 안내
2. 검은 승차권의 승객 각인

선정 이유:

- 첫 패턴은 노선 복원에서 검증한 안전 운용 규칙을 즉시 재사용한다.
- 두 번째 패턴은 남은 원인 질문과 검은 승차권의 매개 역할을 분리해 보여준다.
- 시선 유도와 선로 경계 붕괴는 Showcase Cut 또는 후속 회수 테스트로 보류한다.

## 3. 공통 회수 흐름

```text
전조 제시
→ 현재 패턴 분류
→ 관련 기록 확인
→ 중립 행동 선택
→ 현장 결과
→ 추론 검증 또는 미검증 기록
→ 다음 패턴 또는 잔향 회수
```

사건 수준 후보 네 개를 다시 제시하지 않는다.

## 4. 패턴 1 — 존재하지 않는 종착 안내

### 전조

> 스피커가 같은 승강장 이름을 세 번 반복한다. 반복될 때마다 전광판의 글자가 한 칸씩 사라진다.

### 현재 질문

> 지금 표시되는 목적지를 현실 경로 기준으로 신뢰할 수 있는가?

### 사용 가능한 기록

- 방송 원본의 목적지 공백
- 기기별 목적지 불일치
- 공식 운행 기준
- 노선 복원 검증 기록

### 패턴 분류

권장 분류:

- 개인화된 목적지 유도
- 공식 식별 정보와 불일치

오인 후보:

- 실제 숨은 종착역 개방
- 단순 전광판 고장

### 중립 행동

행동 문구는 근거를 포함하지 않는다.

1. 안내 신호를 차단한다.
2. 표시된 승강장으로 이동한다.
3. 방송에 현재 목적지를 응답한다.

정답 행동: 안내 신호 차단

### 행동 성공

- 목적지 유도 신호 차단
- 안정화 진행
- 현실 경로 유지

### 추론 검증

다음을 모두 만족하면 `RULE_APPLIED_AND_VERIFIED` 후보:

- 개인화된 목적지를 현실 기준으로 신뢰할 수 없다고 분류
- 공식 운행 기준 또는 노선 복원 기록을 근거로 연결
- 안내 신호 차단 행동 선택

행동만 맞고 근거가 부족하면:

- 현장 결과: 성공
- 기록 결과: `ACTION_SUCCESS / REASONING_UNVERIFIED`

### 오대응

표시된 승강장 이동:

- 이동 경로 잠김
- 위험 증가
- 위험 사례: 개인화된 목적지를 실제 노선으로 취급함

방송 응답:

- 현재 위치·이름 정보가 방송에 반영됨
- 다음 패턴의 승객 각인 위험 증가 후보
- 위험 사례: 괴이 신호에 개인 정보를 제공함

첫 오대응은 즉시 패배를 만들지 않는다.

## 5. 패턴 2 — 검은 승차권의 승객 각인

### 전조

> 검은 승차권의 천공 자국이 번지며 가장 가까운 요원의 이름과 비슷한 획을 만든다.

### 현재 질문

> 검은 승차권은 지금 무엇을 하려는가?

### 사용 가능한 기록

- 검은 승차권 각인
- 피해자 음성 메모와 최초 접촉 시각
- 승객 등록 현상 관측
- 패턴 1 결과

### 패턴 분류

권장 분류:

- 접촉 대상을 새 승객으로 고정
- 개인 인식을 물리 매개에 각인

중요 경계:

- 이 패턴은 승차권이 사건 최초 원인임을 증명하지 않는다.
- 시간순 기록은 개인 목적지 청취가 접촉보다 먼저였음을 보여줄 수 있다.
- 승차권의 현장 역할은 `원인`이 아니라 `고정·각인 매개` 후보로 기록한다.

### 중립 행동

1. 승차권과의 접촉을 차단한다.
2. 승차권을 개찰한다.
3. 대표 요원이 승차권을 소지한다.

정답 행동: 접촉 차단

### 행동 성공

- 신규 승객 각인 중단
- 안정화 진행
- 검은 승차권의 매개 역할 관측 강화

### 추론 검증

다음을 모두 만족하면 `PATTERN_ROLE_VERIFIED` 후보:

- 승차권이 접촉 대상을 고정·등록한다고 분류
- 검은 승차권 각인 기록을 연결
- 시간순 기록과 충돌하지 않게 최초 원인과 현장 역할을 구분
- 접촉 차단 행동 선택

행동만 맞고 승차권을 최초 원인으로 잘못 확정하면:

- 현장 결과: 성공
- 기록 결과: `ACTION_SUCCESS / CAUSAL_REASONING_CONTRADICTED`

### 오대응

개찰:

- 목적지 표식이 개찰 행동을 한 요원에게 옮겨감
- 위험·정신 부담 증가
- 위험 사례: 매개체를 정보 장치로 오인함

직접 소지:

- 대표 요원이 신규 승객으로 각인됨
- 보호 행동 또는 동료 지원으로 다음 기회 제공
- 즉시 영구 이탈·강제 중상 금지

## 6. 잔향 회수 진입

두 패턴 뒤 다음을 확인한다.

### 현장 조건

- 안정화 기준 충족
- 최소 한 패턴에서 올바른 현장 대응
- 포획·회수 경로 유지

### 지식 조건

- 안전 운용 규칙 검증 상태
- 검은 승차권의 현장 역할 검증 상태
- 최초 원인 가설 검증 또는 미해결 상태

### 가능한 결과 조합

| 현장 | 지식 | 결과 방향 |
|---|---|---|
| 성공 | 검증됨 | 높은 해결 등급 후보 |
| 성공 | 원인 미해결 | 구조·회수 가능, 공식 원인 기록 보류 |
| 부분 성공 | 위험 사례 있음 | 불완전 안정화·후유증·연구 질문 |
| 실패 | 일부 지식 확보 | 후퇴 또는 불완전 종료, 위험 사례 보존 |

정확한 temporary / standard / complete 매핑은 별도 결과 계약에서 확정한다.

## 7. UI 정보 위계

### 상단

- 현재 전조
- 대상·시점·조건 중 관측된 태그
- 현재 안정화·위험 상태

### 중앙

- 패턴 분류 후보
- 관련 기록 바로가기
- 중립 행동 3개

### 하단 기록

- 선택한 분류
- 선택한 근거
- 실행 행동
- 직전 결과
- 검증 상태

금지:

- 정답 행동 강조색
- 가장 긴 행동 문구에 근거 포함
- 자동 예측 성공을 정답 표시로 사용
- 패턴마다 사건 원인 가설 네 개 재표시

## 8. 동료 지원 경계

### 허용

- 첫 오대응 피해 완화
- 기록 원문 빠른 복귀
- 이미 관측한 전조 태그 표시 시간 연장
- 접촉 차단 실패 시 한 번의 재대응 기회

### 금지

- 정답 행동 자동 선택
- 미관측 패턴명 공개
- 최초 원인 가설 확정
- 잘못된 행동을 성공 처리

## 9. 저장·재진입

현재 구현 사실인 대응 뒤 자동 저장을 기획 baseline으로 우선 유지한다.

검수 조건:

- 동일 저장 재진입으로 패턴·예측·지원 결과 재추첨 금지
- 직전 패턴 결과와 선택 근거 복원
- 이미 적용된 피해·보상 중복 금지
- 회수 가능 상태 중복 실행 금지

자동 저장 정책 자체의 변경은 별도 사용자 결정으로 남긴다.

## 10. Validation 테스트

테스터 과제:

1. 패턴 1에서 개인화된 목적지 유도를 분류한다.
2. 근거를 확인하고 중립 행동을 고른다.
3. 행동 성공과 추론 검증 결과를 읽는다.
4. 패턴 2에서 승차권의 현장 역할을 분류한다.
5. 최초 원인과 각인 매개 역할을 구분한다.
6. 잔향 회수 가능 상태와 남은 미해결 질문을 설명한다.

성공 기준:

- 두 패턴의 차이를 설명한다.
- 행동 문구만 보고 정답을 고르지 않는다.
- 노선 복원 규칙을 패턴 1에 재사용한다.
- 승차권이 최초 원인이 아닐 수 있어도 접촉 차단은 필요하다고 설명한다.
- 현장 성공과 공식 원인 검증을 구분한다.

실패 기준:

- 패턴 1에서 전광판 목적지를 그대로 따름
- 패턴 2에서 승차권을 정보 확인 도구로만 인식
- 시간순 기록을 무시하고 승차권을 최초 원인으로 확정
- 동료 예측을 정답으로 인식
- 두 패턴에서 같은 추론을 반복한다고 느낌

## 11. 미결정 항목

1. 안정화 진행 수치와 회수 기준
2. 패턴 1 오대응이 패턴 2 위험에 미치는 정확한 영향
3. 패턴별 분류 후보 문구
4. 자동 예측 UI를 숨길지 보조 정보로 유지할지
5. 원인 미검증 상태의 해결 등급 상한
6. 회수 결과의 연구·장비 환류 1개
