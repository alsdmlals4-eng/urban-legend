# 저승역 완전 사건 설계 — Section 09

## 사건 결과·등급·후속 재조사

책임 Decision:

`D-2026-08-04-AFTERLIFE-STATION-OUTCOME-GRADE-AND-REINVESTIGATION`

상태:

`APPROVED_PRODUCT_DECISION / GRILLME_BATCH_4_9_OF_10 / PENDING_BATCH_MERGE`

## 1. 독립 결과 축

저승역 사건은 다음 결과를 독립적으로 기록한다.

- `victim_rescued`: 피해자 구출 성공 여부
- `residue_recovered`: 잔향 회수 성공 여부
- `manual_precision`: 최종 매뉴얼 정확도·근거 완성도
- `risk_cases`: 예방 가능 위험 사례와 불가피한 시연 기록
- `truth_state`: 정답 공개 범위

구출 성공이 회수 성공을 자동 보장하지 않고, 회수 성공이 매뉴얼 전체 정답을 자동 확인하지 않는다.

## 2. 일반 클리어

일반 클리어에는 다음이 모두 필요하다.

1. 피해자 구출 성공
2. 잔향 회수 성공
3. 금지 행동·구출 절차·회수 대응의 실행 핵심에 치명적 상충 없음
4. 실제 실행 결과가 최소 근거로 남음

발생 조건이나 피해자 연계의 비치명적 미해결은 위험 사례·미해결 기록으로 남을 수 있다. 실행 성공만으로 모든 슬롯을 자동 확인하지 않는다.

## 3. S 랭크

S 랭크는 정답을 본 뒤의 완벽 재현이 아니라 최초 조사에서의 정밀 매뉴얼 성취다.

필수 조건:

- 필수 슬롯 전부 확인
- 모든 필수 주장에 추적 가능한 단서 `[기록]` 연결
- 핵심 `[변조]` 후보 반증·분류
- 제시된 대표 회수 패턴마다 전조를 읽고 정확한 파훼 성공
- 구출에서 올바른 승차권·열차·하차 역을 첫 유효 실행에 선택
- 명확히 예고된 뒤 반복한 예방 가능한 위험 사례 없음
- 핵심 기록 누락 없음

다음은 감점하지 않는다.

- 접근성 기능 사용은 감점하지 않는다.
- 검증 요청 횟수는 감점하지 않는다.
- 입력 보조·일시정지·스크린리더 사용
- 첫 10분의 통제된 첫 초기화 시연은 S 랭크 감점 대상이 아니다.

감점 대상은 예고 뒤 반복한 예방 가능한 위험이다.

## 4. 승인 철수

### 피해자 구출 후 회수 중단

- 결과: 승인 철수
- 피해자: 구조됨
- 괴이: 미회수
- 캠페인: 재출현 위험과 후속 임무 생성
- 보고서: 검증된 범위만 공개

### 구출 전 철수

- 피해자: 미해결 또는 위험 상태 유지
- 사건: 일반 클리어 아님
- 후속 재조사 가능

승인 철수는 무조건 실패나 게임오버가 아니다. 그러나 일반 클리어·S 랭크로 기록하지 않는다.

## 5. 실패와 정답 공개

실패·승인 철수는 `partial_truth_revealed` 상태가 된다.

자동 공개:

- 플레이 중 직접 검증된 슬롯
- 실패를 일으킨 행동과 상충 관계
- 관찰된 위험 사례
- 실제 사용한 후보 키워드

숨김 유지:

- 현장에서 검증하지 못한 슬롯의 공식 정답
- 아직 획득하지 않은 핵심 기록
- 후속 패턴의 정답 대응

플레이어가 결과 보고서에서 `공식 정답 공개`를 선택하면 경고 후 `answer_viewed`가 된다.

## 6. 최초 조사 정본과 후속 플레이

- 최초 조사 결과는 최초 조사 정본으로 보존한다.
- 후속 재조사 성공은 최초 실패·피해자 상태·세력 반응·위험 사례를 덮어쓰지 않는다.
- 후속 해결 결과를 별도 기록으로 추가한다.
- `answer_viewed` 이전 후속 재조사는 최초 조사 자격을 유지할 수 있다.
- `answer_viewed` 이후 도전은 비정본 기록 재현이다.
- 기록 재현은 별도 재현 숙련 등급을 사용한다.
- 반복 성장 재화 파밍은 허용하지 않는다.

## 7. 대표 결과 행렬

| 피해자 | 잔향 | 결과 |
|---|---|---|
| 구출 | 회수 | 일반 클리어 또는 S 랭크 후보 |
| 구출 | 미회수 | 승인 철수·후속 회수 임무 |
| 미구출 | 회수 | 비정상 결과·피해자 위험 사례, 일반 클리어 아님 |
| 미구출 | 미회수 | 실패·후속 재조사 |

`미구출 + 회수`가 보상 최적 전략이 되지 않게 피해자 보호를 핵심 결과로 유지한다.

## 8. 범위 경계
