# 저승역 완전 사건 설계 — Section 04

## `[무정차 환송]`과 공식 승차권 파훼

책임 Decision:

`D-2026-08-04-AFTERLIFE-STATION-NONSTOP-FAREWELL-TICKET-COUNTER`

상태:

`APPROVED_PRODUCT_DECISION / GRILLME_BATCH_4_4_OF_10 / PENDING_BATCH_MERGE`

구현·Human QA:

`NOT_AUTHORIZED / NOT_RUN`

## 1. 패턴의 역할

`[무정차 환송]`은 저승역의 첫 대표 회수 패턴이다. 구출 미니게임에서 회수하고 끝까지 보관한 공식 승차권이 전투에서 실제 파훼 수단이 되면서, 조사·구출·회수 전투가 하나의 지식 루프로 연결된다.

모든 회수 전투 패턴을 승차권으로 해결하지 않는다. 이 패턴은 사건 지식을 전투 판단으로 전환하는 첫 사례다.

## 2. 가변 전조 구조

패턴 길이는 고정하지 않는다. 모든 회수 패턴은 `N ≥ 2`이며 발현 전에 `N-1개의 전조`를 제공한다.

- 1턴 전조는 플레이어의 평상 행동 전에 나타난다.
- 2턴부터 N-1턴까지는 플레이어의 행동이 먼저 해결된 뒤 후속 전조가 나타난다.
- 최종 N턴은 `대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행` 순서다.
- `패턴 준비 완료`, `다음 턴 발현` 같은 메타 경고는 표시하지 않는다.

## 3. 첫 사건의 3턴 예시

### 1턴 전조

플레이어의 평상 행동 전에 목적지 없는 전광판에 투영된 역명이 떠오르고 잘못된 노선색이 점등된다.

```text
목적지 없는 전광판
+ 잘못된 노선색
→ 플레이어 평상 행동
→ 괴이 평상 행동
```

### 2턴 전조

플레이어의 행동이 먼저 해결된 뒤 전광판의 역 코드와 노선 문양이 차례로 변조된다. 선로 진동과 무정차 열차 접근 기록이 추가된다.

```text
플레이어 평상 행동
→ 역 코드 변조
→ 노선 문양 변조
→ 선로 진동
→ 무정차 열차 접근 기록
→ 괴이 평상 행동
```

### 3턴 발현

```text
대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행
```

열차가 나타난 뒤 반응하는 것이 아니라, 전조를 읽고 열차 진입 전에 대응을 확정해야 한다.

## 4. 정확한 대응

플레이어는 구출 단계에서 끝까지 보관한 공식 승차권을 최종 턴에 개찰기에 제시한다.

```text
공식 승차권 제시
→ 노선색·노선명·역 코드 대조
→ 투영 노선 무효화
→ 무정차 열차 패턴 취소
→ [파훼]
→ 괴이 [취약]
→ 유효 공격 기회
```

- 승차권은 소모되지 않는다.
- 공식 검표 흔적이 추가된다.
- 검표 흔적은 사건 보고서와 회수 결과에 남는다.
- `[취약]`은 다음 유효 공격 또는 연결 절단·잔향 노출 기회를 만든다.

## 5. 다른 대응의 결정적 결과

### 방어

- 피해 감소
- 패턴은 완전히 취소되지 않음
- [취약]은 발생하지 않는다

### 공격

- 무정차 열차 진입을 막지 못함
- 강한 피해
- [취약]은 발생하지 않는다

### 잘못된 승차권

- 노선 불일치가 전광판·검표 로그에 표시됨
- 위치 초기화 효과
- 공식 승차권 파훼 실패

### 너무 일찍 승차권 제시

- 행동이나 자원만 소비
- 파훼 효과 없음
- 승차권은 사라지지 않지만 해당 턴의 이득은 없음

이 결과들은 숨겨진 확률로 바뀌지 않는다. 같은 전조와 같은 선택에는 같은 결과를 반환한다.

## 6. 전조의 접근성·추적 가능성

전조는 하나의 감각이나 색상만으로 판별하지 않는다.

- 목적지 없는 전광판: 화면 텍스트와 로그 제공
- 잘못된 노선색: 노선명·문양·텍스트 표기를 함께 제공
- 역 코드: 숫자·문자 코드와 음성 안내를 함께 제공
- 노선 문양: 형태 설명과 텍스트 라벨 제공
- 선로 진동: 화면 흔들림 외에 진동 상태 로그 제공
- 무정차 열차 접근 기록: 거리·방향·접근 단계가 텍스트 로그에 남음

색상만으로 정답을 판별하지 않으며 음향만으로 발현 시점을 알아야 하는 구조도 금지한다.

## 7. 적대적 검토 Guardrail

- `방송 세 번 후 방어` 같은 사건 비고유 카운트 퍼즐로 축소하지 않는다.
- 열차가 나타난 뒤 정답 버튼이 강조되는 반응형 QTE로 만들지 않는다.
- 공식 승차권을 파괴하거나 소모품으로 처리하지 않는다.
- 승차권을 너무 일찍 사용해도 즉시 사망시키지 않는다.
- 방어가 파훼와 동일한 보상을 주지 않는다.
- 공격만으로 패턴을 무시하고 취약을 만들 수 없게 한다.
- 잘못된 승차권 결과를 숨겨진 확률로 처리하지 않는다.
- 모든 후속 회수 패턴을 승차권 제시로 반복하지 않는다.
