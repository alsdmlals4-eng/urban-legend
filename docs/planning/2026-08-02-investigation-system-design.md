# 조사 시스템 Design

> 상태: `SECTIONS_1_TO_5_APPROVED / GRILLME_BATCH_2_5_OF_10`
> 갱신일: 2026-08-03
> Base: `9.4.3`
> 구현: `NOT_AUTHORIZED`
> 사람 검증: `NOT_RUN`

## 목적

텍스트 노벨 조사, 능력·태그·판정, 키워드 획득, 괴이 매뉴얼 구성, 사건 랭크와 재도전 동기를 하나의 공정한 시스템으로 구체화한다.

조사는 다음 메인 콘텐츠 흐름의 첫 단계다.

```text
상황 설명
→ 조건이 표시된 선택지
→ 결과 문장
→ 키워드 획득
→ 괴이 매뉴얼 구성
→ 피해자 구출 미니게임
→ 회수 전투
```

## Grill Me·작업 운영 방식

향후 Grill Me 질문과 주요 작업 제안은 관련 게임·현업 사례를 조사하고, 그대로 모방하지 않고 괴이기록국의 코어·제작 범위·UX에 맞춰 비교한다.

```text
현재 정본 확인
→ 벤치마킹
→ 적용점/비적용점 분리
→ 현업 제작 관점 비교
→ 적대적 검토
→ 선택지와 권장안
→ 사용자 승인
→ GitHub·Sheet 동일 Decision ID 동기화
```

이 운영 방식은 제품 Decision 수에 별도로 포함하지 않는다.

## Section 1 — 핵심 진실 접근과 랭크 게이트

상태: `APPROVED`

책임 Decision:

- `D-2026-08-02-INVESTIGATION-CORE-TRUTH-AND-RANK-GATING`

### 승인 계약

- 일반 클리어에 필요한 필수 핵심 키워드는 특정 능력·태그·확률 판정 없이도 얻을 수 있다.
- 필수 핵심 키워드마다 최소 한 개의 비판정 또는 확정 우회 경로를 둔다.
- 능력·태그·판정은 시간·피로·위험·추가 근거·오답 조기 배제·구출 및 전투 정보 우위를 바꾼다.
- 최고 랭크·업적은 사건별 요구 능력·태그 보유 또는 지정 판정 성공을 포함할 수 있다.
- 최고 랭크 조건을 충족하지 못해도 일반 클리어와 캠페인 진행은 보장한다.
- 업적·완전 달성을 원하는 플레이어가 준비를 바꿔 재도전하도록 설계한다.

### 플레이 목표 분리

```text
첫 플레이 목표
괴이 규칙을 논리적으로 이해하고 피해자를 구출해 사건을 종결한다.

재도전 목표
다른 육성·능력·태그 준비로 더 많은 근거와 더 안전한 결과를 확보하고 최고 랭크·업적을 달성한다.
```

## Section 2 — 최고 랭크 조건 공개 방식

상태: `APPROVED`

책임 Decision:

- `D-2026-08-02-INVESTIGATION-RANK-CONDITION-DISCLOSURE`

### 출동 전 공개

- 최고 랭크에 필요한 능력·태그 이름
- 요구 수치 또는 충족 여부
- 완전 조사·피해 최소화·정밀 안정화·매뉴얼 완성 같은 넓은 목표 범주
- 현재 준비로 최고 랭크 달성이 가능한지 여부
- 조건이 없어도 일반 사건 종결이 가능하다는 안내

### 출동 전 숨김

- 정확한 사용 지점
- 정답 키워드와 괴이 규칙
- 피해자의 구체 위험
- 최적 행동 순서
- 봉쇄 해법

### 조사 중

능력·태그 선택지는 요구 조건과 잠긴 이유를 표시한다. 잠긴 선택지를 사용하지 못해도 필수 진실로 가는 비판정 또는 확정 우회 경로를 유지한다.

### 첫 클리어 후

- 달성·미달 조건
- 필요한 능력·태그·수치
- 놓친 심층 조사 범주
- 피해자 보호·매뉴얼·구출·전투의 미달 항목
- 재도전 준비 단서

상세 숙련 체크리스트를 해금하되 정답 규칙이나 최적 행동 순서를 직접 알려주지 않는다. 첫 플레이에서도 조건을 갖췄다면 최고 랭크를 달성할 수 있다. 완전 비공개 업적은 최고 랭크 조건에 포함하지 않는다.

## Section 3 — 다축 사건 보고서와 관문형 종합 랭크

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-INCIDENT-MULTIAXIS-GATED-RANKING`

### 네 평가축

| 평가축 | 평가 내용 |
|---|---|
| 조사 정확도 | 필수 규칙 규명, 오답 반증, 심층 근거, 객관적 진실과 일치하는 괴이 매뉴얼 |
| 피해자 보호 | 구출 여부, 부상·공포·오염·후유증, 추가 피해와 보호 약속 |
| 현장 통제 | 규칙 대응, 부수 피해, 안정화·봉쇄·잔향 회수, 철수·기관 강제 봉쇄 |
| 기록 완성도 | 공식 규칙, 위험 사례, 미해결 항목, 재출현 대응과 후속 책임 |

### 관문형 산출

```text
일반 클리어
= 네 축 모두 최소 종결 기준 충족

상위 랭크
= 네 축 각각의 상위 기준 충족

최고 랭크
= 네 축 모두 최고 기준 충족
+ 사건별 숙련 조건 충족
+ 사전 공개된 요구 능력·태그 또는 지정 판정 성공
+ 치명적 실패 없음
```

단순 점수 합산이나 평균을 사용하지 않는다. 한 축의 최고 성과가 다른 축의 치명적 실패를 상쇄하지 못한다.

### 랭크 상한

다음과 같은 결과는 사건별로 종합 랭크 상한을 만든다.

- 피해자 사망·회복 불능
- 핵심 괴이 규칙 오판
- 기관 강제 봉쇄
- 중대한 현장 확산
- 사건별로 사전에 정의한 치명적 보호 실패

상한의 정확한 값은 사건 Spec에서 정의한다.

### 시간과 특수 업적

- 시간은 공통 핵심 평가축에서 제외한다.
- 사건 규칙과 직접 관련된 경우에만 시간 제한을 숙련 목표나 업적으로 사용한다.
- 특수 업적은 종합 랭크와 별도로 운용할 수 있다.
- 모든 특수 업적을 최고 랭크 필수 조건으로 묶지 않는다.

### 결과 화면 원칙

플레이어에게 불투명한 총점보다 다음을 먼저 보여준다.

- 네 축의 판정
- 종합 랭크
- 랭크 상한을 만든 결과
- 최고 랭크 미달 이유
- 재도전 시 개선 가능한 축
- 필요한 능력·태그와 준비 단서

낮은 랭크도 유효한 사건 결과이며 캠페인 진행을 막지 않는다. 연도 결산은 사건 랭크 평균이 아니라 조사 성향·보호 원칙·기관 위치·남은 책임의 복합 기록을 유지한다.

## Section 4 — 랭크 단계와 공식 명칭

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-INCIDENT-RANK-STAGES-AND-LABELS`

### 종합 랭크

정상 종결된 사건은 문자 랭크와 기록국식 공식 명칭을 함께 표시한다.

| 랭크 | 공식 명칭 | 의미 |
|---|---|---|
| C | 조건부 대응 | 일반 클리어 최소 관문 충족 |
| B | 적정 대응 | 주요 목표 안정적 달성 |
| A | 우수 대응 | 네 축에서 높은 수준의 결과 달성 |
| S | 정밀 대응 | 네 축 최고 관문·숙련 조건·사전 공개 준비 조건 모두 충족 |

최고 랭크의 정식 표기는 `S — 정밀 대응`이다. `S+`, `SS`, `SSS`는 사용하지 않는다.

### 축별 평가

네 평가축은 문자 랭크를 반복하지 않고 다음 공통 용어를 사용한다.

```text
미달 → 충족 → 우수 → 정밀
```

### 사건 종결 상태 분리

사건 종결 상태와 플레이 성과를 별도 항목으로 표시한다.

```text
사건 종결 상태
안정화

현장 종합 평가
A — 우수 대응
```

다음 결과에는 종합 랭크를 부여하지 않는다.

- 출동 실패
- 정상 종결 전 철수
- 기관 강제 봉쇄
- 사건 Spec에서 정의한 정상 종결 실패

해당 경우에도 네 축의 실제 결과, 확보 기록, 실패 이유와 남은 책임은 사건 보고서에 보존한다.

## Section 5 — 캠페인 정본과 숙련 재도전 분리

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-INCIDENT-REPLAY-CANON-AND-MASTERY-RECORDS`

### 기록 재현

첫 클리어 뒤 일반 재도전은 기록 재현으로 처리한다.

```text
기록 재현
→ 최고 종합 랭크·축별 최고 기록 갱신
→ 업적·칭호·코스메틱·추가 기록 열람 해금
→ 캠페인 정본 유지
```

기록 재현은 피해자 상태·관계·기관 변화·다음 분기 활성 결과·연도 결산을 바꾸지 않는다.

### 이중 기록

```text
캠페인 정본 기록
정식 사건 결과·피해자 상태·관계·분기 환류·연도 결산 책임

숙련 기록
최고 종합 랭크·축별 최고 평가·업적·비필수 보상
```

결과 화면과 사건 선택 화면은 두 기록을 명확히 구분한다.

### 캠페인 되감기

실제 서사 결과를 바꾸려면 별도 캠페인 되감기를 명시적으로 선택한다.

```text
과거 사건으로 되감기
→ 해당 사건 이후 캠페인 진행 폐기
→ 해당 사건을 다시 확정
→ 새 정본 결과를 기준으로 이후 분기 재진행
```

과거 사건 하나만 바꾸고 이후 분기를 그대로 유지하는 부분 덮어쓰기는 금지한다. 숙련 기록·업적·비필수 보상은 되감기 뒤에도 유지한다.

- 판정 모델
