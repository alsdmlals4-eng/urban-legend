## 목적

텍스트 노벨 조사, 능력·태그·판정, 키워드 획득, 괴이 매뉴얼, 사건 랭크, 재도전과 접근성 계약을 하나의 공정한 시스템으로 구체화한다.

```text
상황 설명
→ 조건이 표시된 선택지
→ 결과 문장
→ 키워드 획득
→ 괴이 매뉴얼 구성
→ 피해자 구출 미니게임
→ 회수 전투
→ 사건 결과 보고서와 정본 확정
```

## Grill Me·작업 운영 방식

```text
현재 정본 확인
→ 게임·현업 사례 벤치마킹
→ 적용점/비적용점 분리
→ 제작비·UX·밸런스·재플레이 관점 비교
→ 적대적 검토
→ 선택지와 권장안
→ 사용자 승인
→ GitHub·Sheet 동일 Decision ID 동기화
```

이 운영 방식은 제품 Decision 수에 별도로 포함하지 않는다.

## Section 1 — 핵심 진실 접근과 랭크 게이트

상태: `APPROVED`

책임 Decision:

- `D-2026-08-02-INVESTIGATION-CORE-TRUTH-AND-RANK-GATING`

### 계약

- 일반 클리어에 필요한 필수 핵심 키워드마다 최소 한 개의 비판정 또는 확정 우회 경로를 둔다.
- 능력·태그·판정은 시간·피로·위험·추가 근거·오답 조기 배제·구출 및 전투 정보 우위를 바꾼다.
- 최고 랭크와 일부 업적은 사건별 요구 능력·태그 또는 지정 판정 성공을 포함할 수 있다.
- 최고 랭크 조건이 없어도 일반 클리어와 다음 분기 진행은 보장한다.
- 첫 플레이는 사건 이해와 종결, 재도전은 더 완전한 구출·기록·회수를 목표로 한다.

## Section 2 — 최고 랭크 조건 공개 방식

상태: `APPROVED`

책임 Decision:

- `D-2026-08-02-INVESTIGATION-RANK-CONDITION-DISCLOSURE`

### 출동 전 공개

- 필요한 능력·태그 이름과 요구 수치
- 현재 준비로 최고 랭크가 가능한지
- 완전 조사·피해 최소화·정밀 안정화·매뉴얼 완성 같은 목표 범주
- 조건이 없어도 일반 사건 종결은 가능하다는 안내

### 출동 전 비공개

- 정확한 사용 지점
- 정답 키워드와 괴이 규칙
- 피해자의 구체 위험
- 최적 행동 순서와 봉쇄 해법

### 첫 클리어 후

- 달성·미달 조건과 필요한 준비
- 놓친 심층 조사 범주
- 피해자 보호·기록·구출·전투의 미달 항목
- 재도전 단서와 상세 숙련 체크리스트

완전 비공개 업적은 최고 랭크 조건에 포함하지 않는다. 첫 플레이에서도 준비 조건을 갖췄다면 최고 랭크를 달성할 수 있다.

## Section 3 — 다축 사건 보고서와 관문형 종합 랭크

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-INCIDENT-MULTIAXIS-GATED-RANKING`

### 네 평가축

| 평가축 | 평가 내용 |
|---|---|
| 조사 정확도 | 필수 규칙 규명, 오답 반증, 심층 근거, 객관적 진실과 일치하는 매뉴얼 |
| 피해자 보호 | 구출 여부, 부상·공포·오염·후유증, 추가 피해와 보호 약속 |
| 현장 통제 | 규칙 대응, 부수 피해, 안정화·봉쇄·잔향 회수 |
| 기록 완성도 | 공식 규칙, 위험 사례, 미해결 항목, 재출현 대응과 후속 책임 |

### 관문형 산출

```text
일반 클리어
= 네 축 모두 최소 종결 기준 충족

상위 랭크
= 네 축 각각의 상위 기준 충족

S — 정밀 대응
= 네 축 모두 최고 기준
+ 사건별 숙련 조건
+ 사전 공개된 준비 조건
+ 치명적 실패 없음
```

단순 점수 합산과 평균은 사용하지 않는다. 피해자 사망·회복 불능, 핵심 규칙 오판, 기관 강제 봉쇄, 중대한 현장 확산 등은 다른 축의 성과로 상쇄할 수 없으며 사건별 랭크 상한을 만든다.

시간은 공통 핵심 평가축에서 제외한다. 사건 규칙과 직접 관련된 경우에만 별도 숙련 목표나 선택 업적으로 사용한다.

## Section 4 — 랭크 단계와 공식 명칭

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-INCIDENT-RANK-STAGES-AND-LABELS`

| 종합 랭크 | 공식 명칭 | 의미 |
|---|---|---|
| C | 조건부 대응 | 일반 클리어 최소 관문 충족 |
| B | 적정 대응 | 주요 목표 안정적 달성 |
| A | 우수 대응 | 네 축에서 높은 수준의 결과 달성 |
| S | 정밀 대응 | 네 축 최고 관문과 숙련·준비 조건 충족 |

- `S+`, `SS`, `SSS`는 사용하지 않는다.
- 축별 평가는 `미달 → 충족 → 우수 → 정밀`로 통일한다.
- 사건 종결 상태와 수행 랭크를 별도 표시한다.
- 출동 실패·정상 종결 전 철수·기관 강제 봉쇄에는 종합 랭크를 부여하지 않는다.
- 랭크가 없어도 확보한 기록, 실패 이유와 남은 책임은 보존한다.

## Section 5 — 캠페인 정본과 숙련 재도전 분리

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-INCIDENT-REPLAY-CANON-AND-MASTERY-RECORDS`

### 기록 재현

```text
기록 재현
→ 최고 종합 랭크·축별 최고 기록 갱신
→ 업적·칭호·코스메틱·추가 기록 열람 해금
→ 캠페인 정본 유지
```

### 이중 기록

```text
캠페인 정본 기록
사건 결과·피해자 상태·관계·분기 환류·연도 결산 책임

숙련 기록
최고 랭크·축별 최고 평가·업적·비필수 보상
```

실제 서사 결과를 변경하려면 별도 `캠페인 되감기`를 사용한다. 되감은 사건 이후의 캠페인 진행은 폐기하고 다시 진행하며, 과거 사건만 바꾸고 이후 결과를 유지하는 부분 덮어쓰기는 금지한다.

## Section 6 — 체크포인트·즉시 재시도·정본 확정 Gate

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-INCIDENT-CHECKPOINT-RETRY-AND-CANON-CONFIRMATION`

### 조사

- 선택 확정 전에는 취소할 수 있다.
- 결과와 키워드·시간·피로·위험 변화가 반영되면 선택은 확정된다.
- 결과 확인 뒤 선택 단위 자유 되감기는 제공하지 않는다.
- 조사 장면 또는 소단락 시작 체크포인트와 읽은 텍스트 빠른 넘김을 제공한다.

### 피해자 구출

- 첫 실패는 즉시 재시도할 수 있다.
- 핵심 조작과 실패 원인을 다시 안내한다.
- 반복 실패 시 일반 클리어를 막지 않는 접근성 대체 또는 완화 기능을 제공한다.
- 구출 재시도는 확정된 조사 결과를 되돌리지 않는다.

### 회수 전투

- 전투 시작 체크포인트를 제공한다.
- 전투 패배 시 전투 시작부터 재시도할 수 있다.
- 턴 단위 자유 되감기는 기본 제공하지 않는다.
- 중대한 행동은 실행 전에 대상·소비·예상 결과를 확인하게 한다.

### 사건 결과 확정

```text
회수 전투 종료
→ 사건 결과 보고서
→ 결과 확정 또는 사건당 1회 출동 재개
→ 결과 확정 시 캠페인 정본 저장
```

최소 자동 저장 지점은 조사 소단락 시작, 조사 결과 반영 뒤, 피해자 구출 시작, 전투 시작, 결과 보고서 직전, 결과 확정 직후다.

## Section 7 — 캠페인 되감기 해금과 분기 슬롯

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-CAMPAIGN-REWIND-UNLOCK-AND-BRANCH-SLOTS`

```text
첫 1년차 캠페인 완료
→ 연도 결산 생성
→ 최초 완료 캠페인 보호
→ 캠페인 되감기와 분기 슬롯 해금
```

- 첫 플레이 도중에는 사용할 수 없다.
- 기관 강제 봉쇄·낮은 랭크·미해결 책임이 포함돼도 1년차를 완료하면 해금한다.
- S 랭크·특정 엔딩·난이도·유료 상품을 조건으로 요구하지 않는다.
- 횟수 제한과 게임 내 재화 비용은 없다.
- 선택 사건 이후를 다시 진행하는 플레이 시간이 자연스러운 비용이다.
- 최대 3개의 캠페인 분기를 보관한다.
- 최초 완료 캠페인은 자동 보호한다.
- 피해자·관계·결과 패킷·연도 결산은 분기별로 분리한다.
- 최고 숙련 기록·업적·칭호·코스메틱·비필수 기록 열람은 모든 분기에서 공유한다.
- 되감기 전에 폐기 범위를 표시하고 슬롯 삭제·덮어쓰기는 재확인한다.

## Section 8 — 캠페인 되감기 정본 앵커

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-CAMPAIGN-REWIND-CANON-ANCHOR-SCOPE`

지속 결과를 남기는 사건마다 출동 준비 확정 직전의 `정본 앵커`를 하나 둔다.

```text
사건 수락과 기본 정보 공개
→ 출동 팀·장비·지원 선택
→ 출동 준비 확정 직전 정본 앵커
→ 조사
→ 피해자 구출
→ 회수 전투
→ 결과 확정
```

- 조사·구출·전투 중간 지점으로 직접 캠페인 되감기하지 않는다.
- 사건 당시의 능력·태그·동료 관계·장비·소비품·기관 지원·사건 이전 결과를 복원한다.
- 당시 보유 범위 안에서 출동 준비를 다시 구성할 수 있다.
- 이후 분기의 성장·장비·관계를 과거에 소급 반입하지 않는다.
- 캠페인 정본을 바꾸려면 조사부터 결과 확정까지 사건 전체를 재진행한다.
- 읽은 텍스트와 비상호작용 연출은 빠르게 넘길 수 있다.
- 현재 성장 상태로 S 랭크·업적을 노리는 목적은 기록 재현이 담당한다.
- 지속 결과를 쓰지 않는 짧은 장면에는 정본 앵커를 만들지 않는다.
- 중간 스냅숏의 유리한 상태만 조합하는 혼합 정본을 금지한다.

## Section 9 — 접근성 등가성과 숙련 관문

상태: `APPROVED`

책임 Decision:

- `D-2026-08-03-ACCESSIBILITY-EQUIVALENCE-AND-MASTERY-GATES`

### 판단 기준

접근성 기능은 사용 여부가 아니라 **평가 대상인 판단을 플레이어가 직접 수행하는지**를 기준으로 랭크와 업적에 반영한다.

### 표현·정보 접근 기능

예: 화면 낭독, 자막·비언어 소리 표시, 글자·아이콘 확대, 고대비·색각 옵션, 진동·섬광 조절, 키 재배치.

처리:

```text
일반 클리어 영향 없음
C/B/A/S 랭크 영향 없음
업적 영향 없음
```

### 입력·시간 등가 기능

예: 연타를 길게 누르기로 전환, 유지/토글 전환, 입력 시간 확대, 게임 속도 조절, 대상 선택 보조, 미니게임 입력 단순화.

플레이어가 규칙을 이해하고 대상과 대응을 직접 선택한다면 모든 랭크와 업적에 중립이다. 괴이기록국의 숙련은 입력 속도가 아니라 관찰·추리·보호·대응·기록으로 평가한다.

### 판단·해법 자동 해결 기능

예: 정답 키워드 공개, 올바른 선택지 자동 강조, 구출 자동 완료, 전투 대응 자동 선택, 봉쇄 순서 자동 실행.

- 일반 클리어와 핵심 서사는 차단하지 않는다.
- 자동 해결과 관계없는 평가축은 정상 평가한다.
- 자동 해결이 대신한 숙련 관문은 직접 충족한 것으로 처리하지 않는다.
- 가능한 경우 같은 판단을 검증하는 접근성 등가 과제로 대체한다.
- 등가 과제를 완료하면 해당 관문과 S 랭크·관련 업적을 충족할 수 있다.

예:

```text
빠른 타이밍 입력
→ 제한 시간 없는 순서 선택형 대체
→ 같은 규칙 이해 검증
→ S 랭크 가능
```

```text
정답 키워드 자동 공개
→ 조사 추론을 시스템이 대신함
→ 조사 정확도 정밀 관문 미충족
→ 다른 평가축과 일반 클리어는 정상 처리
```

### 필수 제작 원칙

> S 랭크에 필요한 모든 핵심 행동에는 접근 가능한 등가 수행 방식이 최소 하나 존재해야 한다.

동일한 판단을 검증하는 등가 수행 방식을 만들 수 없는 운동·감각 과제는 S 랭크 필수 조건에서 제거한다.

### 보호 규칙

- 접근성 프리셋 사용 자체를 경고·감점·낙인 표시하지 않는다.
- 장애 증명이나 의료 정보 입력을 요구하지 않는다.
- 자동 해결 하나 때문에 관계없는 평가축을 무효화하지 않는다.
- 기능 사용 전에 랭크·업적 영향 여부를 명확히 표시한다.
- 접근성 기능을 사용하지 않는 플레이에 우월 칭호를 주지 않는다.
- 무보조·시간 단축 도전은 종합 랭크가 아닌 선택 업적으로만 운용할 수 있다.
- 등가성과 사용성은 장애 당사자·접근성 컨설턴트 검증 전까지 `NOT_VALIDATED`다.
