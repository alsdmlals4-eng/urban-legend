## 목적

텍스트 노벨 조사, 능력·태그·판정, 키워드 획득, 괴이 매뉴얼 구성, 사건 랭크와 재도전 동기를 하나의 공정한 시스템으로 구체화한다.

조사는 다음 메인 콘텐츠 흐름의 첫 단계다.

```text
상황 설명
→ 조건이 표시된 선택지
→ 결과 문장
→ 키워드 획득
→ 괴이 매뉴얼 구성
→ 피해자 구출 미니게임
→ 회수 전투
```

## Grill Me·작업 운영 방식

향후 Grill Me 질문과 주요 작업 제안은 관련 게임·현업 사례를 조사하고, 그대로 모방하지 않고 괴이기록국의 코어·제작 범위·UX에 맞춰 비교한다.

```text
현재 정본 확인
→ 벤치마킹
→ 적용점/비적용점 분리
→ 현업 제작 관점 비교
→ 적대적 검토
→ 선택지와 권장안
→ 사용자 승인
→ GitHub·Sheet 동일 Decision ID 동기화
```

이 운영 방식은 제품 Decision 수에 별도로 포함하지 않는다.

## Section 1 — 핵심 진실 접근과 랭크 게이트

상태: `APPROVED`

책임 Decision:

- `D-2026-08-02-INVESTIGATION-CORE-TRUTH-AND-RANK-GATING`

### 승인 계약

- 일반 클리어에 필요한 필수 핵심 키워드는 특정 능력·태그·확률 판정 없이도 얻을 수 있다.
- 필수 핵심 키워드마다 최소 한 개의 비판정 또는 확정 우회 경로를 둔다.
- 능력·태그·판정은 시간·피로·위험·추가 근거·오답 조기 배제·구출 및 전투 정보 우위를 바꾼다.
- 최고 랭크·업적은 사건별 요구 능력·태그 보유 또는 지정 판정 성공을 포함할 수 있다.
- 최고 랭크 조건을 충족하지 못해도 일반 클리어와 캠페인 진행은 보장한다.
- 업적·완전 달성을 원하는 플레이어가 준비를 바꿔 재도전하도록 설계한다.

### 플레이 목표 분리

```text
첫 플레이 목표
괴이 규칙을 논리적으로 이해하고 피해자를 구출해 사건을 종결한다.

재도전 목표
다른 육성·능력·태그 준비로 더 많은 근거와 더 안전한 결과를 확보하고 최고 랭크·업적을 달성한다.
```

## Section 2 — 최고 랭크 조건 공개 방식

상태: `APPROVED`

책임 Decision:

- `D-2026-08-02-INVESTIGATION-RANK-CONDITION-DISCLOSURE`

### 출동 전 공개

- 최고 랭크에 필요한 능력·태그 이름
- 요구 수치 또는 충족 여부
- 완전 조사·피해 최소화·정밀 안정화·매뉴얼 완성 같은 넓은 목표 범주
- 현재 준비로 최고 랭크 달성이 가능한지 여부
- 조건이 없어도 일반 사건 종결이 가능하다는 안내

### 출동 전 숨김

- 정확한 사용 지점
- 정답 키워드와 괴이 규칙
- 피해자의 구체 위험
- 최적 행동 순서
- 봉쇄 해법

### 조사 중

능력·태그 선택지는 요구 조건과 잠긴 이유를 표시한다. 잠긴 선택지를 사용하지 못해도 필수 진실로 가는 비판정 또는 확정 우회 경로를 유지한다.

### 첫 클리어 후

- 달성·미달 조건
- 필요한 능력·태그·수치
- 놓친 심층 조사 범주
- 피해자 보호·매뉴얼·구출·전투의 미달 항목
- 재도전 준비 단서

상세 숙련 체크리스트를 해금하되 정답 규칙이나 최적 행동 순서를 직접 알려주지 않는다. 첫 플레이에서도 조건을 갖췄다면 최고 랭크를 달성할 수 있다. 완전 비공개 업적은 최고 랭크 조건에 포함하지 않는다.
