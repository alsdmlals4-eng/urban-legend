## 목적

텍스트 노벨 조사, 능력·태그·판정, 키워드 획득, 괴이 매뉴얼 구성, 사건 랭크와 재도전 동기를 하나의 공정한 시스템으로 구체화한다.

조사는 다음 메인 콘텐츠 흐름의 첫 단계다.

```text
상황 설명
→ 조건이 표시된 선택지
→ 결과 문장
→ 키워드 획득
→ 괴이 매뉴얼 구성
→ 피해자 구출 미니게임
→ 회수 전투
```

## Section 1 — 핵심 진실 접근과 랭크 게이트

상태: `APPROVED`

책임 Decision:

- `D-2026-08-02-INVESTIGATION-CORE-TRUTH-AND-RANK-GATING`

### 승인 계약

- 일반 클리어에 필요한 필수 핵심 키워드는 특정 능력·태그·확률 판정 없이도 얻을 수 있다.
- 필수 핵심 키워드마다 최소 한 개의 비판정 또는 확정 우회 경로를 둔다.
- 능력·태그·판정은 시간·피로·위험·추가 근거·오답 조기 배제·구출 및 전투 정보 우위를 바꾼다.
- 최고 랭크·업적은 사건별 요구 능력·태그 보유 또는 지정 판정 성공을 포함할 수 있다.
- 최고 랭크 조건을 충족하지 못해도 일반 클리어와 캠페인 진행은 보장한다.
- 업적·완전 달성을 원하는 플레이어가 준비를 바꿔 재도전하도록 설계한다.

### 플레이 목표 분리

```text
첫 플레이 목표
괴이 규칙을 논리적으로 이해하고 피해자를 구출해 사건을 종결한다.

재도전 목표
다른 육성·능력·태그 준비로 더 많은 근거와 더 안전한 결과를 확보하고 최고 랭크·업적을 달성한다.
```
