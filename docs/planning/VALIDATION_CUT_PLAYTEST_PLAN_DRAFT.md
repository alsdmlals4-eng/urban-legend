# 저승역 Validation Cut 플레이테스트 계획 초안

> 상태: `DRAFT_REQUIRES_REVIEW`
> 추적: Issue #121 / Draft PR #122
> 선행 Benchmark Gate: `REUSED`
> 대상 빌드: `NOT_YET_IMPLEMENTED`
> 구현 권한: `NONE`

## 1. 목적

35~50분 Validation Cut이 다음 핵심 연결을 전달하는지 검증한다.

```text
준비 선택
→ 조사·기록
→ 가설·반증
→ 안전 운용 규칙 적용
→ 회수 전조 대응
→ 결과·매뉴얼·다음 준비 환류
```

정답률만 측정하지 않는다. 플레이어의 사고 과정, 근거 수정, 실패 귀인, 인과 설명을 함께 기록한다.

## 2. 참가자 구성

최소 6명 권장:

- 추리·비주얼노벨 경험이 적은 참가자 3명
- 추리·비주얼노벨 경험자 3명

가능하면 반복 사용자와 완전 신규 사용자를 구분한다.

이번 단계에서는 통계적 유의성보다 심각한 이해 실패와 반복 마찰을 찾는다.

## 3. 진행 원칙

- 진행자는 정답·조사 위치·UI 조작법을 먼저 설명하지 않는다.
- 참가자가 60초 이상 같은 화면에서 행동하지 못할 때만 최소 개입을 기록한다.
- 첫 시도와 개입 후 시도를 분리한다.
- 플레이 중 발화 유도는 최소화하고 구간 종료 뒤 이유를 묻는다.
- 오류·소프트락·접근성 문제는 즉시 중단 사유로 기록한다.

## 4. 세션 구간

### 구간 A — 첫 10분

과제:

- 콜드 오픈의 모순 확인
- 아카의 사실·추정 구분 이해
- 조사 우선순위 선택
- 제한된 준비 결정 1회

행동 지표:

- 첫 모순 발견 시간
- 아카를 정답 제공자로 인식하는지
- 준비 선택 수정 횟수
- 준비 결과 미리보기 확인 여부

질문:

- 지금 플레이어의 역할은 무엇인가
- 방금 선택이 현장에서 무엇을 바꿀 것 같은가

성공:

- `기록을 조사해 규칙을 판단하는 요원`이라고 설명
- 준비가 정답이 아니라 접근·안전·정보 표현을 바꾼다고 예상

### 구간 B — 조사·가설 보드

과제:

- 기록 5~7개 조사
- 후보 네 개에 지지·반박·미해결 연결
- 숨은 단일 종착역설 제거
- 기기 오염설 제거
- 남은 두 후보 차이 설명
- 시간순 기록 비교

행동 지표:

- 첫 제거까지 시간
- 잘못 연결했다 수정한 횟수
- 원문 복귀 사용 횟수
- 시스템 제안을 그대로 수용한 횟수
- 제거 이유 설명률

질문:

- 왜 이 후보를 제거했는가
- 남은 두 후보는 무엇이 다른가
- 어떤 기록이 최종 구분에 필요했는가

성공:

- 제거를 관측 근거로 설명
- 공백 투사와 승차권 지정의 인과 차이 설명
- 시간순 비교가 필요한 이유 설명

### 구간 C — 노선 복원

과제:

- 공식 식별 정보를 사용해 안전 경로 복원
- 개인화된 목적지 표기 배제
- 성공 뒤 무엇이 검증됐는지 설명

행동 지표:

- 기록 패널 재확인 횟수
- 경로 수정 횟수
- 개인 목적지를 경로 기준으로 사용한 횟수
- 키보드·포인터 경로 완주 여부

질문:

- 무엇을 검증했는가
- 사건의 최초 원인까지 확정했는가

성공:

- 안전 운용 규칙을 검증했다고 설명
- 원인 가설은 별도라고 구분

### 구간 D — 회수 encounter

과제:

1. 존재하지 않는 종착 안내 분류·대응
2. 검은 승차권 승객 각인 분류·대응
3. 현장 성공과 추론 검증 결과 확인
4. 잔향 회수 가능 상태 확인

행동 지표:

- 전조 읽기 시간
- 관련 기록 확인 횟수
- 행동 문구 길이에 의존한 선택 여부
- 동료 예측을 정답으로 인식한 횟수
- 같은 추론 반복 피로 발언

질문:

- 두 패턴은 무엇이 다른가
- 승차권은 최초 원인인가, 현장 매개인가
- 행동은 성공했지만 추론이 미검증일 수 있는가

성공:

- 두 패턴의 역할 차이 설명
- 시간순 기록과 충돌하지 않게 승차권 역할 설명
- 현장 결과와 지식 결과 구분

### 구간 E — 결과·환류

과제:

- 현장·피해자·규칙·회수 결과 확인
- 공식 규칙과 위험 사례 확인
- 연구·장비 후보 확인
- 다음 준비 변화 설명

행동 지표:

- 결과 화면 재확인 위치
- 원인·결과 혼동
- 다음 행동 선택 시간

질문:

- 왜 이 결과 등급이 나왔는가
- 무엇을 배웠는가
- 다음에는 무엇을 다르게 준비할 것인가

성공:

- 결과 원인을 준비·조사·행동·추론과 연결
- 폐주파수 필터 후보가 정답 제공이 아니라 비교 보조임을 설명

## 5. 진행자 개입 코드

| 코드 | 개입 |
|---|---|
| I0 | 개입 없음 |
| I1 | 현재 목표 위치만 재안내 |
| I2 | 입력 방법만 안내 |
| I3 | 읽을 기록 범주 안내 |
| I4 | 판단 질문 재진술 |
| I5 | 정답·관계·행동 직접 안내 |

I5가 발생한 구간은 첫 시도 성공으로 계산하지 않는다.

## 6. 중단 기준

즉시 중단·기록:

- 진행 소프트락
- 저장·복귀로 상태 중복 또는 손실
- 비관측 규칙으로 비가역 피해
- 점멸·모션·음향으로 플레이 지속 곤란
- 키보드 또는 포인터 경로 진행 불가
- 핵심 텍스트 잘림·읽기 불가
- 동료·아카가 정답을 자동 실행

구간 중단:

- 5분 이상 같은 판단을 진전 없이 반복
- 참가자가 목표를 설명하지 못하고 I4 이상 개입 필요
- 같은 추론을 세 단계에서 반복한다고 명확히 보고

## 7. 판정

구간별 판정:

- `KEEP`: 핵심 목적 달성, 경미한 수정만 필요
- `AMPLIFY`: 강한 반응이 있어 더 강조할 가치 있음
- `CHANGE`: 구조·문구·정보 위계 수정 필요
- `RETEST`: 수정 뒤 같은 과제로 재검증
- `HOLD`: 코어 침해·불공정·소프트락·심각한 혼동

Showcase 진입 조건:

- 모든 P1 구간에 `HOLD` 없음
- 첫 10분, 가설 보드, 노선 복원, 회수, 결과 환류가 모두 `KEEP` 또는 `AMPLIFY`
- 신규 사용자 다수가 전체 인과를 설명
- 사용자 별도 승인
