## 1. 설계 목표

저승역 조사에서 플레이어가 다음 질문을 직접 판단하게 한다.

> 같은 안내방송을 들은 사람들이 서로 다른 목적지를 기억하는 이유는 무엇이며, 현실 승강장으로 돌아오기 위해 어떤 기준을 신뢰해야 하는가?

가설 보드는 정답을 자동 완성하지 않는다. 플레이어는 관측 기록을 이용해 네 후보 중 명백히 반증되는 두 후보를 제거하고, 남은 두 후보의 차이를 마지막 현장 기록으로 검증한다.

## 2. 사실·해석 경계

### 현재 데이터에서 확인된 관측 사실

| 관측명 | 현재 데이터의 사실 | 해석 제한 |
|---|---|---|
| 방송 원본의 공백 | 안내방송 원본에는 객관적인 목적지명이 남아 있지 않다. | 공백을 무엇이 채우는지는 아직 확정하지 않는다. |
| 동시 목적지 불일치 | 같은 시각의 기억·전광판·기기 기록이 서로 다른 목적지를 표시한다. | 어느 하나가 진짜 목적지라고 단정하지 않는다. |
| 공식 운행 기록 | 막차 이후 추가 운행은 없고 정상 역명·노선 식별음·운행 종료 시각이 남아 있다. | 공식 기록이 현실 기준이라는 가설은 세울 수 있으나 아직 현장 검증 전이다. |
| 검은 승차권의 변화 | 검은 승차권에 개인 목적지와 유사한 획이 번지고 접촉 대상을 새 승객으로 기록하려 한다. | 승차권이 원인인지 결과를 물리화하는 매개인지 구분되지 않는다. |
| 00:00 고정 | 피해자의 마지막 문자 도착 예정 시각이 00:00으로 고정된다. | 시간 고정이 원인인지 반복 현상의 결과인지 확정하지 않는다. |

### 현재 빠진 관측 사실

최종 두 후보를 공정하게 구분하려면 사건의 인과 순서를 보여주는 기록 한 개가 필요하다.

권장 최소안:

> **승차권 접촉 전 목적지 기억 기록** — 피해자가 검은 승차권을 접촉하기 전에 이미 개인 목적지를 들었다는 시간순 기록.

대체 가능안:

- 승차권을 소지하지 않은 관측자의 개인 목적지 청취 기록
- 방송 노출 뒤 승차권 획이 생성됐음을 보여주는 관제·CCTV 기록

이 기록은 새 시스템이 아니라 기존 문자·현장 로그·관제 기록 형식으로 제공한다.

## 3. 후보 가설 4개

## 가설 A — 공백 투사설

> 방송의 목적지 공백을 청자의 기억과 귀환 욕구가 각자 채운다. 전광판과 검은 승차권은 그 개인 인식을 물리적으로 반영하며, 현실 경로는 공식 운행 식별 정보로만 고정할 수 있다.

- 현재 판정: `CORRECT_CANDIDATE`
- 지지 가능 근거:
  - 방송 원본의 목적지 공백
  - 같은 시각의 목적지 불일치
  - 공식 운행 기록
  - 승차권 접촉 전 개인 목적지 기억 기록
- 미해결:
  - 검은 승차권이 개인 인식을 어떻게 물리화하는가
  - 00:00 고정이 반복 시작 시점인지 결과 표식인지
- 행동 예측:
  - 개인 목적지 문구를 따르지 않는다.
  - 공식 식별음·노선 번호·종료 시각을 현실 기준으로 사용한다.

## 가설 B — 검은 승차권 지정설

> 검은 승차권이 접촉자를 새 승객으로 등록하고 개인 목적지를 지정한다. 방송과 전광판은 승차권이 만든 목적지를 뒤늦게 전달한다.

- 현재 판정: `PLAUSIBLE_FINAL_CANDIDATE`
- 지지 가능 근거:
  - 승차권의 개인 목적지 획
  - 접촉 대상을 새 승객으로 기록하려는 현상
- 반박 가능 근거:
  - 승차권 접촉 전에 이미 개인 목적지가 들렸다는 시간순 기록
  - 승차권 미소지자에게도 동일 현상이 발생한 통제 기록
- 미해결:
  - 승차권이 괴이 핵이라는 사실과 목적지 발생의 최초 원인이 같은가
- 행동 예측:
  - 승차권 접촉을 차단한다.
  - 공식 기록은 보조 안전 기준으로 사용한다.

## 가설 C — 숨은 단일 종착역설

> 공식 노선도에서 지워진 하나의 종착역이 실제로 존재하며, 승객과 기기의 서로 다른 표기는 노선 간섭으로 생긴 오차다.

- 현재 판정: `ELIMINATE_FIRST`
- 초기 지지처럼 보이는 근거:
  - 존재하지 않는 종착지 표기
  - 막차 이후의 반복 안내
- 반증 근거:
  - 같은 시각에 목적지가 하나가 아니라 서로 다르게 표시됨
  - 막차 이후 추가 운행이 없고 공식 식별 기록이 일관됨
  - 방송 원본 자체에는 숨은 역명이 남아 있지 않음
- 제거 문장:
  - `하나의 객관적 종착지가 존재한다면 같은 시각의 기록들이 같은 목적지를 가리켜야 하지만, 관측 결과는 서로 다르고 공식 운행에도 추가 노선이 없다.`

## 가설 D — 전광판 전염설

> 고장 난 전광판이 존재하지 않는 목적지를 생성하고, 그 문구가 방송·승객 기억·승차권으로 전염된다.

- 현재 판정: `ELIMINATE_SECOND`
- 초기 지지처럼 보이는 근거:
  - 전광판에 지도에 없는 목적지가 나타남
  - 전광판이 꺼질 때 표기가 변함
- 반증 근거:
  - 방송 원본의 목적지 구간은 전광판 문구와 무관하게 비어 있음
  - 목적지 변화가 전광판뿐 아니라 기억과 검은 승차권에도 독립적으로 남음
  - 서로 다른 기기·목격 기록이 같은 문구로 수렴하지 않음
- 제거 문장:
  - `전광판이 단일 오염원이라면 다른 기록이 같은 문구로 전염되어야 하지만, 관측된 목적지는 매체와 사람마다 다르며 방송 원본에는 전광판의 목적지가 없다.`

## 4. 4→2 제거 순서

### 첫 번째 제거 — 숨은 단일 종착역설

필수 근거:

1. 동시 목적지 불일치
2. 공식 운행 기록

플레이어 행동:

- 두 근거를 가설 C에 `반박`으로 연결한다.
- 시스템은 `제거 가능`만 표시한다.
- 플레이어가 제거를 확정하면 제거 문장을 기록한다.

실패 방지:

- 근거 하나만 연결하면 `반박은 있으나 단일 종착역을 완전히 배제하기 부족함`으로 표시한다.
- 공식 기록을 얻지 못한 상태에서는 후보를 강제로 제거하지 않는다.

### 두 번째 제거 — 전광판 전염설

필수 근거:

1. 방송 원본의 공백
2. 검은 승차권 또는 개인 기억의 독립 변화

플레이어 행동:

- 전광판 외 매체에서도 서로 다른 목적지가 발생했음을 연결한다.
- 전광판이 현상 표현 매체일 수는 있어도 최초 원인이라는 주장은 반증한다.

실패 방지:

- 전광판 관측만 확보한 경우 가설 D는 `미해결`로 남는다.
- 시스템은 방송·승차권 조사 위치를 정답 위치가 아니라 `추가 확인 질문`으로 안내한다.

## 5. 최종 두 후보 구분

남는 후보:

1. 공백 투사설
2. 검은 승차권 지정설

### 공통으로 예측하는 것

- 개인 목적지를 그대로 따르면 위험하다.
- 공식 운행 식별 정보가 현실 경로 고정에 유효하다.
- 검은 승차권 접촉은 차단해야 한다.

따라서 **노선 복원 미니게임의 성공만으로 두 후보의 원인을 구분할 수 없다.** 미니게임은 안전 경로의 운용 규칙을 검증할 뿐, 개인 목적지가 최초로 생긴 원인을 확정하지 않는다.

### 최종 구분 근거

필수 최소 근거:

- 승차권 접촉 전 개인 목적지 기억 기록

판정:

| 선택 | 근거 상태 | 결과 |
|---|---|---|
| 공백 투사설 | 시간순 기록 포함 | `OFFICIAL_RULE_VERIFIED` 후보 |
| 공백 투사설 | 시간순 기록 없음 | `OPERATIONAL_RULE_CONFIRMED / CAUSE_UNRESOLVED` |
| 승차권 지정설 | 승차권 접촉 전 기록 존재 | `CONTRADICTED` |
| 승차권 지정설 | 시간순 기록 없음 | `UNRESOLVED`, 오답 확정 금지 |

## 6. 단계별 책임 분리

## 사건 가설 보드

책임:

- 개인 목적지 현상의 원인 후보를 비교한다.
- 숨은 종착역·전광판 단독 원인을 제거한다.
- 공백 투사와 승차권 지정 사이의 미해결 질문을 만든다.

출력:

- 제거 후보 2개와 제거 이유
- 최종 후보 2개
- 필요한 추가 관측 질문
- 안전 운용 규칙 초안: `개인 목적지를 신뢰하지 않고 공식 식별 정보를 사용한다.`

## 노선 복원 미니게임

책임:

- 공식 식별 정보로 현실 경로를 복원하는 운용 규칙을 직접 적용한다.
- 사건 원인의 최종 정답을 대신 확정하지 않는다.

입력:

- 공식 노선 식별 정보
- 방송 종료 식별음
- 배제된 개인 목적지 표기

출력:

- 안전 경로 검증 기록
- 잘못된 경로의 위험 사례
- 회수 단계의 경로 안정도·위험 변화

## 회수 encounter

책임:

- 이미 세운 사건 수준 가설을 매 턴 다시 만들지 않는다.
- 새 전조가 `개인 목적지 유도 / 승객 각인 / 경계 붕괴 / 시선 유도` 중 어떤 현장 패턴인지 판별하고 대응한다.
- 새로운 예외가 나타날 때만 추가 근거를 요구한다.

금지:

- 매 패턴마다 사건 가설 4개를 다시 제시
- 정답 행동 문구에 근거와 결론을 모두 포함
- 올바른 버튼 선택만으로 공식 규칙 검증 처리

## 7. 행동 성공과 추론 검증 분리

현장 행동 결과와 지식 결과를 분리한다.

| 현장 행동 | 가설·근거 | 현장 결과 | 기록 결과 |
|---|---|---|---|
| 올바름 | 검증됨 | 안정화 진행 | 공식 규칙 후보 갱신 |
| 올바름 | 부족·불일치 | 안정화 진행 | `행동 성공 / 추론 미검증` |
| 잘못됨 | 논리 일관 | 피해·위험 증가 | 가설의 반례·위험 사례 추가 |
| 잘못됨 | 근거 부족 | 피해·위험 증가 | 오독 근거와 추가 질문 기록 |

등급 연결은 다음 원칙만 승인 후보로 둔다.

- 원인 미검증 상태에서 우연히 안전 행동을 수행해도 `complete`를 얻지 않는다.
- 공식 규칙 검증 없이 피해자 구조만 성공한 경우 현재 해결 등급 체계 안에서 상한을 별도 검토한다.
- 구체적인 `temporary / standard / complete` 매핑은 기존 threshold·회수 보상과 함께 후속 기획 검수에서 확정한다.

## 8. UI 정보 구조

### 가설 카드

- 가설명
- 한 문장 주장
- 현재 상태: `후보 / 미해결 / 제거 가능 / 제거됨 / 최종 후보`
- 지지·반박·미해결 수
- 제거 이유 또는 남은 질문

### 증거 카드

- 관측 사실
- 출처 위치
- 획득 시점
- 원문 보기
- 플레이어가 선택한 현재 관계

### 관계선

- 지지: 실선 + `지지`
- 반박: 절단선 + `반박`
- 미해결: 점선 + `미해결`
- 색상만으로 구분하지 않는다.

### 제거 확인

제거 버튼을 누르면 다음을 보여준다.

```text
이 후보를 제거하는 관측 근거
→ 근거 1
→ 근거 2
→ 제거 이유 문장
```

정답 여부는 표시하지 않는다. 제거에 필요한 반증 체인이 부족하면 확인 버튼을 비활성화하고 부족한 관계 유형만 안내한다.

## 9. Validation Cut 테스트 과제

테스터는 다음을 수행한다.

1. 기록 5~6개를 읽는다.
2. 네 후보에 지지·반박·미해결 관계를 연결한다.
3. 숨은 단일 종착역설을 제거한다.
4. 전광판 전염설을 제거한다.
5. 남은 두 후보의 차이를 말한다.
6. 어떤 추가 기록이 필요할지 설명한다.
7. 노선 복원 뒤 `안전 경로를 검증한 것`과 `괴이 원인을 확정한 것`의 차이를 설명한다.

### 성공 기준

- 다수 참가자가 제거 후보 2개를 관측 근거로 설명한다.
- 공백 투사설과 승차권 지정설의 차이를 말할 수 있다.
- 시간순 기록이 필요한 이유를 설명한다.
- 미니게임 성공이 사건 원인의 자동 정답이 아님을 이해한다.
- 정답 행동과 공식 규칙 검증을 구분한다.

### 실패 기준

- 가장 길거나 안전해 보이는 문장만 선택한다.
- 시스템 제안을 정답 표시로 오인한다.
- 전광판·방송·승차권의 관측 사실을 같은 정보로 취급한다.
- 근거 없이 후보가 자동 제거된다.
- 미니게임 성공 뒤 가설 보드가 불필요하다고 느낀다.
- 회수 단계에서 같은 사건 추론을 반복한다고 느낀다.

## 10. 미결정 항목

1. 최종 구분용 시간순 기록의 정확한 표현 매체
2. 해당 기록의 조사 위치와 획득 조건
3. 원인 미검증 상태의 해결 등급 상한
4. 가설 관계 연결 입력 방식: 클릭 순차 선택 / 키보드 목록 / 선택형 연결 메뉴
5. 기존 회수 패턴 데이터에 `question`·`hypothesis`를 추가할지, 별도 사건 가설 결과를 참조할지
6. 한세린 `교차 색인`이 활성화될 때 제안할 수 있는 범위

이 항목은 사용자·기획 검수 후 확정하며 Codex 구현으로 넘기지 않는다.
