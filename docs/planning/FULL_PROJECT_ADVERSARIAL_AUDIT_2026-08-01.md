### F-FPA-001 — GitHub 권위 문서가 두 계층으로 갈라짐

영향:

- 동일 질문에 두 개의 정답이 존재한다.
- Codex가 문서 우선순위에 따라 기존 주간·반일 계약을 구현할 수 있다.
- 승인 결정 즉시 정본 동기화 규칙이 GitHub 최상위 책임 원본까지 완결되지 않았다.

보완:

- 별도 `CANON_MIGRATION_BUNDLE`에서 상위 책임 원본·로드맵·테스트 책임을 같은 Decision ID로 갱신한다.
- 병합 전에는 `APPROVED_TARGET / CURRENT_IMPLEMENTATION_LEGACY`를 병기한다.

### F-FPA-006 — 가설 보드·미니게임을 건너뛰고 회수로 진입할 수 있음

현재 조사 화면은 단서 수집률 40% 이상이면 `start_resolution_phase()`를 호출해 `battle_scene`으로 직접 이동한다. 조사 화면의 상단 이동 버튼도 회수 Scene으로 직접 이동할 수 있다.

승인 목표는 사건 가설 보드와 안전 노선 복원을 완료한 뒤 회수 패턴으로 진입하는 구조다.

영향:

- 단서 퍼센트가 의미 추론을 대체한다.
- 미니게임이 조사 규칙의 마지막 검증이라는 프로젝트 불변식이 우회된다.

보완:

- 회수 진입 조건을 퍼센트 단독 조건이 아니라 `가설 제출 상태 + 필수 시간순 증거 상태 + 안전 노선 검증 상태`로 정의한다.
- 개발용 직접 이동은 제품 빌드에서 분리한다.

### F-FPA-007 — 브리핑이 정답 원인군을 과도하게 선행 제시함

보완:

- 브리핑 질문은 `왜 같은 방송을 서로 다르게 기억하는가` 수준으로 중립화한다.
- 공백·기억 투사 관계는 플레이어가 기록을 연결한 뒤 나타나야 한다.

### F-FPA-009 — 회수 화면이 승인된 책임과 다름

현재 회수 화면은 각 패턴마다 `가설 → 근거 → 대응`을 반복한다. Validation overlay는 4개 패턴을 유지하고, 정답 행동 문구 안에 근거와 대응 논리를 함께 적는다.

예:

- 방송 공백과 전광판 차이를 대조해 안내 신호를 차단한다
- 자정 기록을 대조하며 승차권과의 접촉을 차단한다

승인 목표:

```text
패턴 분류
→ 관련 기록
→ 중립 행동
→ 현장 결과 / 추론 결과 분리
```

보완:

- Validation은 `존재하지 않는 종착 안내`, `검은 승차권 승객 각인` 2개만 사용한다.
- 시선 유도와 경계 붕괴는 Showcase 이후로 보류한다.
- 행동 버튼에서 근거 문장을 제거한다.

- 신규 행은 `APPROVED_TARGET_NOT_IMPLEMENTED`로 통일한다.

### F-FPA-017 — SCREEN/SIT 정본과 수정된 비주얼 보드가 없음

기준 화면 7종은 승인됐지만, CURRENT·INFERRED·PROPOSED 화면 명세와 상태 변형, SIT-001~008 시퀀스, 전체 전환도가 없다. 기존 생성 보드는 메인 캐릭터 노출·주간 일정·일상 활동 과설계로 폐기 상태다.

보완:

- 기술 구현보다 SCREEN-01~07 정본을 먼저 작성한다.
- 보드 A 4종과 보드 B 3종을 판독 가능한 크기로 재생성한다.

### F-FPA-018 — 사람 플레이 검증은 여전히 0회

자동·정적 검증은 현재 데이터와 파일 계약의 존재를 확인하지만 다음은 검증하지 않는다.

- 첫 10분 역할 이해
- 텍스트 과밀
- 행동 문구 정답 누설
- 추리 반복감
- 일정 조작 피로
- 결과 환류 이해

`POC_PASSED`, 제작 확대, Showcase 구현은 계속 금지한다.

## 5. P2 Finding — P1 정리 뒤 보완

### F-FPA-019 — Validation에 비핵심 기능이 너무 많이 노출될 위험

현재 본편에는 랜덤 이벤트, 세력 의뢰, 시장 구매, 소모품 자동 사용, 요원 자동 행동, 신뢰도, 일상 에피소드, 런타임 UI 편집 기능이 존재한다.

삭제할 필요는 없지만 Validation Cut에서는 다음만 전면에 둔다.

- 축약 준비 1회
- 텍스트 조사
- 사건 가설
- 안전 노선 복원
- 회수 2패턴
- 결과·환류

나머지는 숨기거나 비활성 상태로 두어 핵심 경험 검증을 방해하지 않게 한다.

### F-FPA-020 — 조사 화면의 수치 과밀

현재 조사 화면은 단서 수집률, 위험도, 괴이 이해도, 피해자 이해도, 정신력, 안정도, 예측률, 팀 보조를 한꺼번에 표시한다.

SCREEN-02에서는 현재 판단에 필요한 정보 3개만 전면에 두고 나머지는 기록 서랍으로 이동하는 것이 적절하다.

### F-FPA-021 — 미니게임 설정의 데이터·런타임 중복

저승역 노선 복원의 제목·설명·규칙·결과 문구가 사건 데이터와 `minigame_scene.gd` 런타임 override에 중복돼 있다.

구현 전에 한 책임 원본을 선택하고 다른 쪽은 호환 fallback으로 제한한다.

### F-FPA-022 — 오래된 Draft PR의 병합 위험

열린 PR 중 #120은 Base v9.3 이관과 Codex Goal을 포함하고, #54·#26은 오래된 main 기준이며 mergeable하지 않다.

- #120은 현재 기획 최종 승인 전 실행 금지 상태를 명시한다.
- #54·#26은 재사용 필요성을 판정한 뒤 닫거나 최신 main에 재작성한다.
- PR #122와 병합 순서를 정하기 전 교차 변경 문서를 비교한다.
