## 1. 아트 브리프 핵심

### 심야 도시철도 현실감

- 형광등, 안전선, 전광판, 개찰기, 노선도 등 익숙한 도시철도 재질과 비율을 유지한다.
- 폐역 유적이나 판타지 지하세계보다 `정상 영업이 끝난 뒤의 현실적인 역`을 기본으로 한다.
- 공포는 현실의 세부가 조금씩 어긋나는 데서 시작한다.

### 개인 기억의 미세한 침입

- 광고판 문구 일부가 피해자의 옛집 주소처럼 보임
- 전광판의 목적지 한 칸만 개인 기억의 역명으로 바뀜
- 타일 반사에 과거 집 복도나 귀가길 색온도가 섞임
- 기억 장면을 완전한 플래시백 공간으로 전환하지 않고 현실 표면에 침투시킨다.

### 공식 교통 정보 문법

현실을 고정하는 정보는 공공 교통 표준처럼 일관되게 표현한다.

- 노선색
- 노선명
- 역 코드
- 방향 화살표
- 문양·천공 패턴
- 운행 시각과 공식 식별음 파형

색상만으로 구분하지 않는다. 모든 색 정보는 노선명·역 코드·문양·텍스트와 중복 제공한다.

### 공간 반복 공포

- 동일 승강장 구도가 반복되지만 시계·소지품·검표 흔적은 누적된다.
- 위치 잔상은 흐릿한 캐릭터 복제보다 좌표 불일치·겹친 표지판·반복된 발자국으로 표현한다.
- 카메라만 흔들어 혼란시키지 않고, 플레이어가 비교 가능한 지속 흔적을 남긴다.

### 현장 기록 문서

괴이 매뉴얼은 낡은 마법서보다 기록국의 현장 기록 문서에 가깝다.

- 조사 사진·파형·타임스탬프·출처 번호
- 빈 슬롯과 후보 키워드 카드
- 사용 위치와 원본 기록 연결선
- 사건 종료 뒤 공식 정답·오답·위험 사례 주석

## 2. 승차권 시각 언어

승차권은 다음 정보를 동시에 표시한다.

- 노선색
- 노선명
- 역 코드
- 노선별 문양
- 천공 패턴
- 출발·하차 역 텍스트

색상만으로 구분하지 않는다. 색각 차이가 있는 플레이어도 노선명·역 코드·문양·텍스트로 같은 판정을 할 수 있어야 한다.

정상 승차권은 현실 교통 인쇄물처럼 안정된 정렬과 잉크를 사용한다. [변조] 후보는 확인 전 정상 후보와 같은 정보 해상도다. 단순히 붉은빛·글리치·불길한 테두리로 정답을 암시하지 않는다.

확인 후에는 다음을 추가한다.

- 방해 기록 도장
- 원본 승차권 참조
- 변경된 변수
- 발견한 단서 `[기록]`

## 3. 후보 키워드와 `[변조]` 표현

- 확인 전 정상·변조 후보의 카드 스타일은 동일하다.
- 카드에는 후보명·원본 출처·획득 맥락만 표시한다.
- 정답 가능성·슬롯 적합도·추천 순위를 시각적으로 암시하지 않는다.
- 확인 후 `[변조]` 라벨보다 `어떤 변수가 어떻게 바뀌었는지`를 우선 표시한다.

## 4. 세 대표 회수 패턴

### `[무정차 환송]`

- 잘못된 노선 전광판
- 목적지 글자가 사라진 빈 칸
- 공식 노선과 맞지 않는 역 코드·문양
- 선로 끝에서 접근하는 무정차 열차의 압력과 로그

### `[회귀 승강장]`

- 지속 흔적과 위치 잔상
- 같은 장소에 겹치는 소지품·발자국·검표 흔적
- 주기별 좌표와 타임스탬프
- 사라지는 허상과 남는 잔향 자국의 대비

### `[목적지 합창]`

- 서로 다른 목적지 자막과 공통 무음 파형
- 대상마다 다른 역명·기억 조각
- 모든 원본에서 같은 타임스탬프의 빈 구간
- 공식 역 식별음이 삽입될 때 개인 자막이 무너지는 연출

세 패턴은 서로 다른 정보 비교를 요구하며 같은 색 맞추기·아이템 제시·좌표 클릭을 반복하지 않는다.

## 5. 피해자와 감정 표현

이하린의 철거된 옛집 기억은 과장된 슬픔 연출보다 사소한 생활 흔적으로 표현한다.

- 벽지 무늬
- 현관 비밀번호 메모
- 이사 상자 라벨
- 익숙한 역 출구 번호
- 마지막으로 챙기지 못한 작은 물건

피해자의 후회를 공포 장식으로만 소비하지 않고, 왜 목적지를 실제로 믿는지 이해할 수 있는 맥락을 제공한다.

## 6. 접근성 정보 언어

- 모든 음성 전조에 자막·발화자·타임스탬프 제공
- 파형 구간에 번호와 텍스트 라벨 제공
- 색상 정보에 노선명·역 코드·문양 병기
- 위치 흔적에 절대 좌표와 상대 위치 설명 제공
- 화면 흔들림·번쩍임 강도 조절 가능성을 후속 Spec 요구사항으로 보존
- 접근성 기능이 정답을 자동 추천하지 않는다.

## 7. 후속 이미지·자산 목록

후속 승인 뒤 제작할 수 있는 아트 목록:

1. 심야 승강장 환경 콘셉트
2. 정상·투영 전광판 비교
3. 이하린 피해자 콘셉트
4. 괴이 매뉴얼 3장 UI 콘셉트
5. 정상·변조 승차권 시트
6. `[무정차 환송]` 키프레임
7. `[회귀 승강장]` 키프레임
8. `[목적지 합창]` 키프레임
9. 결과 보고서와 방해 기록 도장

이미지 생성은 후속 승인이다. 게임 자산 제작은 승인하지 않는다. 코드·Scene·UI 구현은 승인하지 않는다.
