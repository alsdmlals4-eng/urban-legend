## 2. 매뉴얼에서 회수 전투로 이어지는 판단 근거

회수 전투 대응을 별도 정답 슬롯으로 자동 제공하지 않는다. 플레이어가 각 장에서 작성한 규칙과 연결된 단서 `[기록]`을 전투 전조에 다시 적용한다.

| 매뉴얼 장 | 조사에서 확보한 규칙 | 회수 전투에서의 판단 근거 |
|---|---|---|
| 1장 | 개인마다 목적지는 다르지만 원본의 목적지 구간은 비어 있음 | `[목적지 합창]`에서 서로 다른 역명 중 하나를 고르지 않고 공통 무음 구간을 찾음 |
| 2장 | 위치는 초기화되지만 시간·기록·소지품 흔적은 유지됨 | `[회귀 승강장]`에서 복수 주기에 계속 남는 흔적의 교차 좌표를 찾음 |
| 3장 | 공식 기록과 일치하는 승차권·노선·역이 현실 기준임 | `[무정차 환송]`에서 보관한 공식 승차권으로 투영 노선을 무효화함 |

- 매뉴얼은 패턴명·정답 대응·정답 좌표·정답 타이밍을 자동 표시하지 않는다.
- 전투에서 플레이어가 직접 기록을 비교하고 대응을 사전 선택한다.
- 잘못 작성한 매뉴얼도 실행 단계까지 유지될 수 있으며, 관찰 결과로 가설을 검증한다.
- 접근성 기능은 기록을 읽을 수 있게 하지만 대응을 추천하거나 자동 선택하지 않는다.

이 구조로 `조사 → 매뉴얼 가설 → 구출 실행 → 전투 전조 판단 → 결과 검증`의 핵심 재미를 유지한다.

## 3. 페이지 진행 Gate

- 현재 페이지의 모든 빈칸이 채워져야 다음 페이지가 열린다.
- 페이지 완료는 정답 확인이 아니라 작성 완료다.
- 최종장의 모든 빈칸을 채우면 조사 페이즈 종료 확인이 열린다.
- 최종 확인 전에는 1~3장을 자유롭게 수정할 수 있다.
- 구출·회수 진입 후 매뉴얼은 읽기 전용이다.

## 4. 자유 배치와 비소모 증거

획득·해금된 후보라면 어떤 빈 슬롯에도 배치할 수 있다. 시스템은 정답 적합도를 이유로 배치를 막지 않는다.

- 정답·오답·근접도·추천 순위는 표시하지 않는다.
- 슬롯 선택 후 자동 후보 축소를 하지 않는다.
- 키워드는 사용해도 사라지지 않는 비소모 증거 참조다.
- 하나의 키워드를 의미가 맞는 여러 슬롯·페이지에서 참조할 수 있다.
- 출처와 사용 위치를 함께 보존한다.

## 5. `[변조]` 후보 계약

- 모든 `[변조]`는 이미 획득한 정상 후보에서 파생한다.
- 독립 가짜 출처를 만들지 않는다.
- 한 번에 변수 하나만 바꾼다.
- 확인 전에는 정상 후보와 같은 정보 해상도로 표시한다.
- 확인 후에는 원본·변경 변수·사용 위치를 방해 기록으로 남긴다.

## 6. 검색·정렬

허용 검색:

- 후보 이름
- 원본 출처명
- 장소·인물·기록명
- 짧은 획득 맥락

금지 검색·정렬:

- 정답 가능성
- 슬롯 적합도
- 정상·변조 여부
- 추천 순위
- 성공 확률

## 7. 접근성

- 후보 이름·출처·획득 맥락을 텍스트로 제공한다.
- 색상이나 카드 테두리만으로 후보 종류를 암시하지 않는다.
- 키보드·컨트롤러·스크린리더가 동일 정보 해상도를 가진다.
- 접근성 기능이 정답 후보를 자동 추천하지 않는다.
