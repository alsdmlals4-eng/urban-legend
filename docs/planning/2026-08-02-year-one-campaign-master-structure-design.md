## 3. 메인 콘텐츠 권위

상태: `CURRENT_APPROVED_PRODUCT_AUTHORITY`

괴이기록국의 메인 콘텐츠는 일정 편성 자체가 아니라 괴이 사건에 진입해 조사·피해자 구출·회수 전투를 수행하는 경험이다.

```text
괴이 사건 진입
→ 텍스트 노벨 조사
→ 선택지와 키워드 획득
→ 괴이 매뉴얼 후보 규칙 구성
→ 피해자 구출 미니게임
→ 턴제 회수 전투
→ 안정화·봉쇄·잔향 회수
→ 공식 규칙·위험 사례·결과 환류
```

간결한 제품 정의:

> 추리해서 피해자를 구출하고, 이해한 규칙으로 싸워 괴이를 회수한다.

- 조사는 상황 설명·선택지·키워드 획득·규칙 문장 구성을 포함한다.
- 미니게임은 사건 규칙을 적용해 피해자를 구출하는 단계다.
- 회수는 보호·관찰·대응·공격·장비·봉쇄를 사용하는 턴제 전투다.
- 일정·육성·동료·장비·연구·기관은 사건을 준비하고 결과를 되돌리는 지원 계층이다.
- 일정은 사건을 자동 해결하거나 조사·구출·회수의 정답을 대신하지 않는다.
- 분기 사이의 일정은 다음 핵심 괴담을 준비하고 이전 결과를 환류하는 연결부다.

계층 구조:

```text
메인 콘텐츠
- 괴이 사건
  - 텍스트 노벨 조사
  - 키워드 기반 괴이 매뉴얼 구성
  - 피해자 구출 미니게임
  - 턴제 회수 전투
  - 결과 기록

지원 계층
- 일정·육성
- 동료·관계
- 장비·연구
- 기관·보급
- 저장·복귀
```

## 4. Section 1 — 캠페인 목적과 분기당 핵심 사건

상태: `APPROVED`

### 캠페인 중심 질문

> 권나래가 한 해 동안 무엇을 이해하고, 누구의 책임을 선택하며, 어떤 방식으로 괴이를 기록하는 요원이 되었는가?

### 4분기 성장 축

```text
봄 — 배우고 소속된다
→ 여름 — 전문화하고 약속한다
→ 가을 — 가치 충돌의 대가를 치른다
→ 겨울 — 축적한 판단으로 책임을 완수한다
```

### 사건 수

- 봄 핵심 괴담 1개
- 여름 핵심 괴담 1개
- 가을 핵심 괴담 1개
- 겨울 핵심 괴담 1개
- 1년 총 4개 핵심 사건

각 분기의 핵심 괴담은 완전한 `조사 → 피해자 구출 → 회수 전투 → 안정화·종결` 경험을 제공한다.

`제거`의 정본 의미는 완전 소멸이 아니라 `안정화 상태 + 현재 사건 종결`이다. 공식 규칙·위험 사례·잔향·재출현 조건·미해결 질문은 남을 수 있다.

## 5. Section 2 — 분기별 사건 역할과 환류

상태: `APPROVED`

### 승인 접근

> 독립 사건 4개 + 강한 결과 환류 + 약한 공통 미스터리

각 사건은 자체 규칙과 안정화 결말을 가진다. 공통 미스터리는 동일 괴이·동일 범인·동일 흑막이 아니라, 서로 다른 괴이가 왜 기억·기록·대응 절차와 유사하게 상호작용하는지 묻는 상위 질문이다.

### 분기별 역할

| 분기 | 역할 | 플레이어가 증명하는 것 |
|---|---|---|
| 봄 | 기준 사건 | 조사·구출·회수·기록의 기본 인과를 이해했는가 |
| 여름 | 선택 사건 | 어떤 전문성·협업·준비 방식을 자신의 강점으로 삼는가 |
| 가을 | 충돌 사건 | 정확한 규칙을 알아도 가치 충돌 속에서 책임 있는 선택을 하는가 |
| 겨울 | 종합 사건 | 한 해 동안 축적한 기록·관계·연구·실패를 조합하는가 |

### 환류 세 축

1. 지식: 공식 규칙·위험 사례·미해결 질문·연구·재출현 대응법
2. 관계·기관: 동료 신뢰·갈등·기관 평가·외부 협력·민간 책임
3. 현장: 잔향·안정화 수준·재출현 조건·피해 경로·후속 현상

다음 분기는 이전 분기의 최소 두 축을 실제 조건·선택·대가로 사용한다. 겨울 사건은 세 축을 모두 사용한다.

### 실패 전진

실패는 다음 분기를 차단하지 않는다. 불완전 후보 기록, 재출현 위험, 기관 압박, 관계 변화, 위험 사례처럼 다른 시작 조건으로 변환한다.

## 6. Section 3 — 사건 차별화와 분기별 초간단 피해자 구출 미니게임

상태: `APPROVED`

### 승인 접근

> 공통 사건 코어를 유지하되, 각 분기 핵심 괴담은 서로 다른 전용 피해자 구출 미니게임을 사용한다.

공통 사건 코어:

```text
상황 설명과 선택지 조사
→ 키워드 획득
→ 괴이 매뉴얼 후보 규칙 구성
→ 피해자 구출 미니게임
→ 회수 전투
→ 안정화·봉쇄·잔향 회수
→ 공식 규칙·위험 사례 기록
```

미니게임의 공통 목적은 조사에서 파악한 규칙을 적용해 피해자를 괴이 현상에서 분리하고 구출하는 것이다. 별도 아케이드나 일정 화면의 부가 활동이 아니며, 회수 전투를 대체하지 않는다.

### 초간단 조작 계약

- 설명을 읽고 30초 안에 핵심 조작을 이해할 수 있어야 한다.
- 핵심 입력 종류는 1~2개다.
- 별도 튜토리얼 스테이지 없이 첫 시도가 가능하다.
- 기본 플레이 길이는 1~3분을 목표로 한다.
- 실패 이유를 즉시 읽을 수 있다.
- 빠른 재시도 또는 실패 전진이 가능하다.
- 반사 신경보다 조사로 얻은 규칙 적용이 중요하다.
- 접근성 대체 입력과 시간 압박 완화를 지원한다.
- 성공·부분 실패 결과가 회수 전투의 피해자 상태·보호 목표·괴이 고착에 반영된다.

이 수치는 Design 목표이며 사람 플레이 검증 전에는 달성 판정을 내리지 않는다.

### 분기별 대표 구출 문법

| 분기 | 대표 미니게임 문법 | 피해자 구출 기능 |
|---|---|---|
| 봄 | 순서·경로 복원 | 안전 경로를 만들어 피해자를 현상 밖으로 이동 |
| 여름 | 대상·역할 배치 | 사람·도구·보호 역할을 규칙에 맞게 배치 |
| 가을 | 보호·공개 범위 조절 | 피해 확산을 막으며 구출 범위와 대가 선택 |
| 겨울 | 과거 기록 비교·적용 | 과거 절차 중 현재 피해자를 구할 규칙 선별 |

구체 조작·UI·난이도·사건 소재는 후속 사건 Spec에서 확정한다.

### 공통 인지 문법

미니게임은 서로 달라도 다음 표시는 유지한다.

1. 구출 대상과 상태
2. 조사에서 확보한 구출 규칙
3. 선택 가능한 입력
4. 위험 또는 금지 행동 예고
5. 즉시 결과와 이유
6. 회수 전투로 이어지는 결과

## 7. 핵심 게임 화면 표현 기준선

상태: `APPROVED_PROVISIONAL_UX_BASELINE`

책임 Decision: `D-2026-08-02-CORE-GAMEPLAY-SCREEN-PRESENTATION-BASELINE`

### 조사 화면

- 핵심 위계는 `상황 설명 → 선택지`다.
- 선택지는 일반·능력 요구·태그 요구·판정 요구·지원 조건 요구 상태를 사전에 표시한다.
- 선택 결과로 키워드를 획득하고 규칙 문장을 구성한다.
- 플레이어 노출 명칭은 `추리문 진행`이 아니라 **괴이 매뉴얼**이다.
- 괴이 매뉴얼은 후보 규칙·확인된 규칙·위험 사례·미해결 항목을 혼동하지 않게 구분한다.
- 키워드와 매뉴얼 UI는 상황 설명과 선택지를 밀어내지 않는 보조 정보 영역이다.

### 피해자 구출 화면

- 사건 고유의 간단한 조작과 구출 대상·금지 행동·안전 행동을 중심으로 표시한다.
- 구출 성공·부분 실패·지연이 회수 전투의 시작 조건으로 이어진다.

### 회수 전투 화면

- 메인 상단·중앙 전장에는 대상 괴이만 상시 표시한다.
- 아군 전신은 전장에 상시 배치하지 않는다.
- 아군은 하단 초상·상태·스킬 UI로 표현한다.
- 캐릭터는 스킬 사용 시에만 하단에서 짧은 컷인으로 등장한다.
- 기본 행동군은 `보호·관찰·대응·공격·장비·봉쇄`다.
- 공격은 현현체·매개체 약화와 대응·봉쇄 기회를 만들며, 공격만으로 기본 승리할 수 없다.

### UX 가변 범위

현재 이미지는 방향 확인용 콘셉트이며 최종 화면 명세가 아니다. 패널 위치·크기·선택지 수·매뉴얼 표시 방식·컷인 크기와 시간·단축키·반응형 배치·애니메이션은 후속 UX 설계와 사람 검증에서 수정할 수 있다.

## 8. Section 4 — 네 핵심 괴담 선정과 분기 배치

상태: `APPROVED`

책임 Decision: `D-2026-08-02-YEAR-ONE-FOUR-CORE-CASES-AND-QUARTER-PLACEMENT`

| 분기 | 핵심 괴담 | 캠페인 역할 | 대표 피해자 구출 문법 |
|---|---|---|---|
| 봄 | 저승역 | 기준 사건 — 조사·구출·회수·기록의 기본 문법 학습 | 공식 기준을 이용한 순서·경로 복원 |
| 여름 | 비 오는 골목의 빨간 우산 | 선택 사건 — 동료·장비·전문성의 현장 역할과 빈틈 확인 | 반사 차단·우산 격리·피해자 호위 역할 배치 |
| 가을 | 폐주파수 방송국 | 충돌 사건 — 즉시 차단과 피해자 목소리 반환 사이의 책임 선택 | 보호 범위·무음 구간·반환 대상 조절 |
| 겨울 | 기록되지 않은 병동 | 종합 사건 — 한 해의 기록·관계·기관·실패 사례 조합 | 과거 기록 비교·모순 보존·복구 절차 선택 |

### 사건별 핵심 차별성

- 저승역: 개인 욕구가 목적지 공백을 채우는 공간 반복. 객관적 운행 기록과 종료 신호로 안전 경로를 복원한다.
- 빨간 우산: 세 번째 빗소리·선행 반사·귀가 기억·마른 흔적이 사람과 도구의 역할을 뒤섞는다. 대상과 역할을 분리해 구출한다.
- 폐주파수 방송국: 이름에 응답한 목소리를 복사한다. 추가 피해 차단과 기존 피해자 목소리 반환 사이의 책임 충돌을 전면에 둔다.
- 기록되지 않은 병동: 반복 누락된 사람이 기록에 없는 병동으로 이동하고, 성급한 복구는 다른 사람을 기록에서 밀어낸다. 모순을 보존한 복구와 능동적인 회수 전투가 필요하다.

### 약한 공통 미스터리

```text
저승역: 개인의 욕구가 기록의 공백을 채운다.
빨간 우산: 기억이 현실의 경로를 덮어쓴다.
폐주파수 방송국: 응답이 새로운 기록과 목소리를 만든다.
기록되지 않은 병동: 기관 기록이 누가 현실에 남는지에 영향을 준다.
```

공통 질문은 `인간의 기억과 기록·대응 절차가 괴이의 경계와 행동을 바꿀 수 있는가`로 제한한다. 동일 흑막이나 하나의 괴이가 네 사건을 조종했다는 뜻이 아니다.

### 적대적 보호 규칙

- 저승역과 빨간 우산을 동일한 경로 퍼즐로 만들지 않는다.
- 폐주파수 방송국을 무음 구간 맞추기만으로 끝내지 않는다.
- 기록되지 않은 병동을 서류 정리나 행정 문답만으로 만들지 않는다.
- 과거 기록은 비교 근거로 사용하되 현재 사건의 정답을 자동 제공하지 않는다.
- 겨울 성공이 이전 피해·관계 갈등·기관 책임을 자동 삭제하지 않는다.

## 9. Section 5 — 조사·괴이 매뉴얼·피해자 구출·회수 전투 차별화 계약

상태: `APPROVED`

책임 Decision: `D-2026-08-02-YEAR-ONE-CASE-PLAY-DIFFERENTIATION-CONTRACT`

### 승인 접근

> 공통 시스템과 공통 UI·행동군은 유지하고, 각 사건은 조사부터 회수 전투까지 하나의 대표 위협 문법을 일관되게 사용한다.

| 사건 | 대표 위협 문법 |
|---|---|
| 저승역 | 순서와 이동 시점 |
| 비 오는 골목의 빨간 우산 | 대상과 역할의 전이 |
| 폐주파수 방송국 | 응답과 송수신 구간 |
| 기록되지 않은 병동 | 기록 권위와 존재 대체 |

### 공통 조사·괴이 매뉴얼 계약

조사는 `상황 설명 → 조건 표시 선택지 → 결과 문장 → 키워드 획득`으로 진행한다.

괴이 매뉴얼은 다음 문장군을 구성한다.

1. 발생 조건
2. 피해 연결 방식
3. 금지 행동
4. 피해자 구출 절차
5. 회수 전투 대응

키워드는 `후보·확인·위험 사례·미해결` 상태를 구분한다. 능력·태그·판정은 사건의 객관적 진실을 무작위로 바꾸지 않으며 조사 시간·위험도·우회 단서·부분 키워드·검증 비용·지원 기회를 변화시킨다.

### 봄 — 저승역 / 순서

- 조사: 목적지 공백·개인 목적지·공식 노선 번호·종료 식별음·조기 이동·위치 초기화를 분리한다.
- 피해자 구출: 공식 기준으로 안전 경로를 복원한 뒤 안내 종료 후 이동시킨다.
- 회수 전투: 괴이 행동 순서와 종료 시점을 관찰하고 피해자의 강제 이동을 보호하며 공식 번호 고정과 종료 식별음 뒤 봉쇄한다.
- 공격: 스피커 잔향·검은 승차권·현현체 약화에 사용한다.

### 여름 — 비 오는 골목의 빨간 우산 / 전이

- 조사: 세 번째 빗소리·선행 반사·젖은 손자국·마른 발자국·귀가 기억·전이 대상을 분리한다.
- 피해자 구출: 반사 차단·우산 격리·피해자 호위·마른 흔적 감시 역할을 배치한다.
- 회수 전투: 반사상이 예고하는 대상과 이동하는 표식을 관찰하며 보호·격리·대응한다.
- 공격: 우산 현현체와 손자국 연결을 약화한다. 세 번째 박자 오공격은 공격자를 새 전이 대상으로 만들 수 있다.

### 가을 — 폐주파수 방송국 / 응답

- 조사: 빈 호출문·음성 응답·이름 복사·조립된 사연·원본 음성·송수신 동시 무음을 분리한다.
- 피해자 구출: 고정할 무음 구간·반환할 원본 음성·차단할 채널과 보호 범위를 선택한다.
- 책임 충돌: 즉시 전체 차단과 기존 피해자 목소리 반환은 완전 양립하지 않을 수 있으며 결과와 대가를 선택 전에 표시한다.
- 회수 전투: 채널 상태를 관찰하고 음성 응답을 금지하며 비언어 신호·무음 고정·가짜 명령 거부를 사용한다.
- 음성형 스킬 여부는 사용 전에 명확히 표시한다.

### 겨울 — 기록되지 않은 병동 / 기록 권위

- 조사: 반복 누락·기록에 없는 병상·충돌 신원·독립 원본·대체 보호 관계·보존해야 할 공백을 구분한다.
- 과거 세 사건 기록은 비교 근거와 위험 사례이며 현재 규칙의 자동 정답이 아니다.
- 피해자 구출: 확인 사실·충돌 기록·보존할 공백·타인을 밀어내는 위험 복구를 분류하고 복구 순서를 정한다.
- 회수 전투: 괴이가 점유한 문서·단말·환자 팔찌·안내 표지를 관찰하고 독립 사본으로 존재를 보호하며 자동 동기화 중단·충돌 기록 유지·대체 관계 해제를 수행한다.
- 기록 자체를 무차별 파괴하지 않고 현현체와 침식 연결만 공격한다.

### 공통 회수 전투 승리 계약

```text
피해자 구출 또는 보호 상태 확보
+ 대표 규칙 관찰
+ 사건 고유 대응 성공
+ 현현체·매개체 약화
+ 봉쇄 조건 달성
= 안정화·잔향 회수
```

공격 반복만으로 기본 승리할 수 없지만, 공격은 행동 중단·연결 약화·대응 틈 생성·봉쇄 창 유지에 실질적으로 기여한다.

### 실패 전진

| 결과 | 환류 |
|---|---|
| 정밀 성공 | 피해 최소·추가 기록·안정된 잔향 |
| 일반 성공 | 사건 종결·일부 후유증 |
| 부분 성공 | 피해자 후유증·위험 사례·기관 부담 |
| 철수 | 재출현 조건·관계 변화·다음 조사 이점 |
| 반복 오판 | 더 어려운 보호 목표와 명확한 반증 |

팀 전멸이나 핵심 피해자의 회복 불가능 상태에서는 출동 실패가 가능하다. 단, 획득한 위험 사례와 일부 관측 기록은 보존한다.

## 10. 현재 금지 조건

- 서로 영향을 주지 않는 괴담 단편 4개
- 모든 사건이 같은 흑막의 일부인 구조
- 겨울 사건만을 위한 무의미한 복선 수집
- 이전 실패로 겨울 진입이 막히는 소프트락
- 단순 수치 보너스만으로 과거 결정을 표현
- 한 미니게임을 이름과 스킨만 바꿔 네 번 반복
- 사건별 시스템을 완전히 별도 장르로 분리
- 복잡한 버튼 조합·정밀 액션·긴 튜토리얼
- 조사 결과와 무관한 순수 반사 신경 판정
- 능력·태그·판정 결과로 사건의 객관적 진실을 뒤집음
- 구출 미니게임 성공이 회수 전투를 자동 승리 처리
- 조사 화면을 대시보드화해 상황 설명과 선택지를 밀어냄
- 능력·태그·판정 요구와 잠금 이유를 숨김
- `괴이 매뉴얼`의 미확정 후보를 공식 규칙으로 오인하게 표시
- 회수 전투에서 아군 전신을 상시 전장에 배치해 괴이 중심 구도를 훼손
- 컷인으로 괴이 전조·대상·결과를 가리거나 전투를 과도하게 지연
- 관찰·대응 없이 공격 반복만으로 안정화·회수 완료
- 저승역과 빨간 우산을 동일 경로 퍼즐로 구성
- 폐주파수 방송국을 무음 타이밍 맞추기만으로 종결
- 기록되지 않은 병동을 서류 정리 화면만으로 구성
- 과거 기록이 겨울 사건 정답을 자동 제공
- 일정 편성을 메인 콘텐츠로 설명하거나 일정으로 사건을 자동 해결
- 사건 플레이보다 일정 소비가 기본 경험을 지배
- 겨울 성공으로 이전 피해와 책임 자동 삭제
- 괴이 완전 소멸을 모든 사건의 기본 성공 조건으로 사용
