## 3. 메인 콘텐츠 권위

상태: `CURRENT_APPROVED_PRODUCT_AUTHORITY`

괴이기록국의 메인 콘텐츠는 일정 편성 자체가 아니라 괴이 사건에 진입해 조사와 회수를 수행하는 경험이다.

```text
괴이 사건 진입
→ 조사
→ 기록 비교·가설
→ 위험 검증
→ 회수
→ 안정화·사건 종결
→ 결과·기록·환류
```

간결한 제품 정의:

> 메인 콘텐츠 = 괴이 사건에 진입해 `조사`와 `회수`를 진행하는 것.

- 조사는 관측·기록 비교·가설·위험 검증을 포함한다.
- 회수는 전조 해석·대응·안정화·봉쇄·포획 창·잔향 회수를 포함한다.
- 일정·육성·동료·장비·연구·기관은 사건을 준비하고 결과를 되돌리는 지원 계층이다.
- 일정은 사건을 자동 해결하거나 조사·회수의 정답을 대신하지 않는다.
- 분기 사이의 일정은 다음 핵심 괴담을 준비하고 이전 결과를 환류하는 연결부다.

계층 구조:

```text
메인 콘텐츠
- 괴이 사건
  - 조사
  - 추론·검증
  - 회수
  - 결과 기록

지원 계층
- 일정·육성
- 동료·관계
- 장비·연구
- 기관·보급
- 저장·복귀
```

## 4. Section 1 — 캠페인 목적과 분기당 핵심 사건

상태: `APPROVED`

### 캠페인 중심 질문

> 권나래가 한 해 동안 무엇을 이해하고, 누구의 책임을 선택하며, 어떤 방식으로 괴이를 기록하는 요원이 되었는가?

### 4분기 성장 축

```text
봄 — 배우고 소속된다
→ 여름 — 전문화하고 약속한다
→ 가을 — 가치 충돌의 대가를 치른다
→ 겨울 — 축적한 판단으로 책임을 완수한다
```

### 사건 수

- 봄 핵심 괴담 1개
- 여름 핵심 괴담 1개
- 가을 핵심 괴담 1개
- 겨울 핵심 괴담 1개
- 1년 총 4개 핵심 사건

각 분기의 핵심 괴담은 완전한 `조사 → 회수 → 안정화·종결` 경험을 제공한다.

`제거`의 정본 의미는 완전 소멸이 아니라 `안정화 상태 + 현재 사건 종결`이다. 공식 규칙·위험 사례·잔향·재출현 조건·미해결 질문은 남을 수 있다.

## 5. Section 2 — 분기별 사건 역할과 환류

상태: `APPROVED`

### 승인 접근

> 독립 사건 4개 + 강한 결과 환류 + 약한 공통 미스터리

각 사건은 자체 규칙과 안정화 결말을 가진다. 공통 미스터리는 동일 괴이·동일 범인·동일 흑막이 아니라, 서로 다른 괴이가 왜 기억·기록·대응 절차와 유사하게 상호작용하는지 묻는 상위 질문이다.

### 분기별 역할

| 분기 | 역할 | 플레이어가 증명하는 것 |
|---|---|---|
| 봄 | 기준 사건 | 관측·가설·검증·회수·기록의 기본 인과를 이해했는가 |
| 여름 | 선택 사건 | 어떤 전문성·협업·준비 방식을 자신의 강점으로 삼는가 |
| 가을 | 충돌 사건 | 정확한 규칙을 알아도 가치 충돌 속에서 책임 있는 선택을 하는가 |
| 겨울 | 종합 사건 | 한 해 동안 축적한 기록·관계·연구·실패를 조합하는가 |

### 환류 세 축

1. 지식: 공식 규칙·위험 사례·미해결 질문·연구·재출현 대응법
2. 관계·기관: 동료 신뢰·갈등·기관 평가·외부 협력·민간 책임
3. 현장: 잔향·안정화 수준·재출현 조건·피해 경로·후속 현상

다음 분기는 이전 분기의 최소 두 축을 실제 조건·선택·대가로 사용한다. 겨울 사건은 세 축을 모두 사용한다.

### 실패 전진

실패는 다음 분기를 차단하지 않는다. 불완전 후보 기록, 재출현 위험, 기관 압박, 관계 변화, 위험 사례처럼 다른 시작 조건으로 변환한다.

## 6. Section 3 — 사건 차별화와 분기별 초간단 미니게임

상태: `APPROVED`

### 승인 접근

> 공통 사건 코어를 유지하되, 각 분기 핵심 괴담은 서로 다른 전용 미니게임을 사용한다.

공통 사건 코어:

```text
관측
→ 기록 비교
→ 가설 구성
→ 위험 검증
→ 전조 해석
→ 대응
→ 안정화
→ 매뉴얼·위험 사례 기록
```

미니게임은 이 사건 흐름 안에서 조사 또는 회수 기능을 담당한다. 별도 아케이드나 일정 화면의 부가 활동이 아니다.

### 초간단 조작 계약

- 설명을 읽고 30초 안에 핵심 조작을 이해할 수 있어야 한다.
- 핵심 입력 종류는 1~2개다.
- 별도 튜토리얼 스테이지 없이 첫 시도가 가능하다.
- 기본 플레이 길이는 1~3분을 목표로 한다.
- 실패 이유를 즉시 읽을 수 있다.
- 빠른 재시도 또는 복구가 가능하다.
- 반사 신경보다 조사로 얻은 규칙 적용이 중요하다.
- 접근성 대체 입력과 시간 압박 완화를 지원한다.

이 수치는 Design 목표이며 사람 플레이 검증 전에는 달성 판정을 내리지 않는다.

### 분기별 대표 미니게임 문법

| 분기 | 대표 미니게임 문법 | 사건 내 역할 |
|---|---|---|
| 봄 | 순서·경로 복원 | 조사한 시간·금지 행동·안전 경로를 적용 |
| 여름 | 대상·역할 배치 | 동료·도구·보호 대상을 올바른 역할에 배치 |
| 가을 | 보호·공개 범위 조절 | 보호·공개·격리의 대가를 보며 범위를 선택 |
| 겨울 | 과거 기록 비교·적용 | 과거 규칙·위험 사례 중 현재 전조에 맞는 절차를 선별 |

구체 조작·UI·난이도·사건 소재는 후속 사건 Spec에서 확정한다.

### 공통 인지 문법

미니게임은 서로 달라도 다음 표시는 유지한다.

1. 현재 목표
2. 조사에서 확보한 적용 규칙
3. 선택 가능한 입력
4. 위험 또는 실패 예고
5. 즉시 결과와 이유
6. 사건 흐름으로 돌아갈 위치

## 7. 현재 금지 조건

- 서로 영향을 주지 않는 괴담 단편 4개
- 모든 사건이 같은 흑막의 일부인 구조
- 겨울 사건만을 위한 무의미한 복선 수집
- 이전 실패로 겨울 진입이 막히는 소프트락
- 단순 수치 보너스만으로 과거 결정을 표현
- 한 미니게임을 이름과 스킨만 바꿔 네 번 반복
- 복잡한 버튼 조합·정밀 액션·긴 튜토리얼
- 조사 결과와 무관한 순수 반사 신경 판정
- 미니게임 성공이 조사 오류를 자동 정답 처리
- 일정 편성을 메인 콘텐츠로 설명하거나 일정으로 사건을 자동 해결
- 사건 플레이보다 일정 소비가 기본 경험을 지배
- 겨울 성공으로 이전 피해와 책임 자동 삭제
- 괴이 완전 소멸을 모든 사건의 기본 성공 조건으로 사용
