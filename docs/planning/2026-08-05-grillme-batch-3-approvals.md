## 1번 승인 내용 — 규칙 정보 연속성

- 조사·보고: 전체 괴이 매뉴얼 작업공간.
- 피해자 구출·회수 전투: 같은 권위 상태에서 파생된 현행 규칙 스트립.
- 현재 행동 관련 조건·금지 행동·안전 행동 우선 노출.
- 모순·규칙 위반은 관측 근거와 함께 즉시 표시.
- 전체 매뉴얼은 단축키 또는 버튼으로 재열람.
- 정답 자동 공개 금지.
- PC 사이드 패널 기준, 모바일 접이식 카드는 PC 검증 이후.

## 2번 승인 내용 — 같은 규칙, 다른 책임

- 피해자 구출: 피해자 분리·보호, 생존, 분리, 후유증 최소화.
- 회수 전투: 현상 통제, 안정화, 봉쇄, 잔향 회수 또는 승인 철수.
- 구출 결과는 회수의 초기 조건과 보호 의무를 바꾸지만 승패를 대신하지 않는다.
- 구출 성공이 회수 자동 승리 또는 전투 삭제로 이어지지 않는다.
- 구출 실패가 회수 전투를 자동 삭제하거나 무조건 강제 전투로 이어지지 않는다.
- 공격 반복만으로 기본 승리 불가.
- 괴이는 회수 난도를 위해 규칙 자체를 임의로 변경하지 않고 조건 중첩·범위 확대·시간 창구 축소로 압박한다.
- 구출·회수 결과는 독립 기록하며 서로를 소급 삭제하지 않는다.

## 3번 승인 내용 — 공통 구출 문법과 규칙 범위

- 공통 4단계: 피해자·현재 위험 확인→안전/금지 행동 확인→사건별 핵심 조작→구출 결과·회수 인계.
- 핵심 입력 1~2종, 설명 30초, 기본 1~3분을 제작 목표로 하되 사람 검증 전 달성 판정 금지.
- 저승역: 공식 기록·경로·승차권·동행 승하차.
- 빨간 우산 골목: 반사 차단·우산 격리·호위 역할 배치.
- 폐주파수 방송국: 무음 구간·보호 범위·반환 대상 분리.
- 기록되지 않은 병동: 기록 비교·모순 보존·복구 순서.
- 위험 상태는 안정→불안정→위험→임계→비가역 결과로 진행한다.
- 동일 의미 상태는 동일 결과를 내고 재시도에는 실질적 변경이 필요하다.
- 구출 결과 패킷은 생존·분리·후유증·위험·보호 의무·회수 초기 조건을 분리한다.
- 회수 행동은 보호·관찰·대응·공격·장비·봉쇄·후퇴를 포함한다.
- `core_recovered` 단일 결과는 구형 호환 상태이며 최종 제품 계약이 아니다.
- 접근성 대체 입력·시간 압박 완화는 랭크 감점 금지.

## 감사 핵심

- 정본 준비 완료: 공통 권위, 저승역 Canon v2 `rescue_protocol`, `recovery_encounters`, 결과 계약.
- 부분 연결: 저승역 회수 projection은 기존 battle UI에 연결됐으나 구출 패킷·보호 의무·다중 결과는 미연결.
- 구형 구현 충돌: 마지막 단서 미니게임 스펙, route 무제한 재시도, rain 무작위 회피, rhythm 박자 판정, core 단일 회수 종료.
- 우선 누락: 공통 구출 상태기계, 구출 결과 패킷, 회수 다중 결과, 독립 결과 저장·보고, 최신 사건별 adapter.
