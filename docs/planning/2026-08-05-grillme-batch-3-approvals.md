## 1번 승인 내용 — 규칙 정보 연속성

- 조사·보고: 전체 괴이 매뉴얼 작업공간.
- 피해자 구출·회수 전투: 같은 권위 상태에서 파생된 현행 규칙 스트립.
- 현재 행동 관련 조건·금지 행동·안전 행동 우선 노출.
- 모순·규칙 위반은 관측 근거와 함께 즉시 표시.
- 전체 매뉴얼은 단축키 또는 버튼으로 재열람.
- 정답 자동 공개 금지.

## 2번 승인 내용 — 같은 규칙, 다른 책임

- 피해자 구출: 피해자 분리·보호, 생존, 분리, 후유증 최소화.
- 회수 전투: 현상 통제, 안정화, 봉쇄, 잔향 회수 또는 승인 철수.
- 구출 결과는 회수 초기 조건과 보호 의무를 바꾸지만 승패를 대신하지 않는다.
- 공격 반복만으로 기본 승리 불가.
- 구출·회수 결과는 독립 기록한다.

## 3번 승인 내용 — 공통 구출 문법과 규칙 범위

- 공통 4단계: 피해자·현재 위험 확인→안전/금지 행동 확인→사건별 핵심 조작→구출 결과·회수 인계.
- 위험 상태는 안정→불안정→위험→임계→비가역 결과.
- 구출 결과 패킷은 생존·분리·후유증·위험·보호 의무·회수 초기 조건을 분리한다.
- 회수 행동은 보호·관찰·대응·공격·장비·봉쇄·후퇴를 포함한다.
- `core_recovered` 단일 결과는 구형 호환 상태다.

## 4번 승인 내용 — 전조 → 패턴 시스템

```text
1턴: 전조 1 → 선택 → 평상 진행
2턴: 선택 → 전조 2 → 평상 진행
3턴: 선택 → 전조 3 → 평상 진행
4턴: 대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행
```

- 2턴과 3턴의 평상 선택은 새 전조 공개 전에 확정한다.
- 전조 2·3은 이미 확정한 선택을 소급 변경하지 않는다.
- 전조 2는 3턴 이후 판단, 전조 3은 4턴 대응에 사용한다.
- 1~3턴 평상 선택과 4턴 전용 대응 선택을 분리한다.
- 평상 선택은 결과 범위·보호·관찰·봉쇄 준비를 바꿀 수 있지만 패턴 정답을 바꾸지 않는다.
- 세 전조를 누적한 뒤에만 대응 선택이 열린다.
- 패턴은 1턴에 고정되며 대응 결과로 새 규칙이 생성되지 않는다.
- 결과 산출과 평상 진행 뒤 다음 패턴 주기를 시작한다.
- 저장·재개 시 패턴·턴·전조 순서·확정 행동을 복원하며 재추첨하지 않는다.
- 전조는 근거이지 정답 공개가 아니며 매뉴얼 열람은 행동 비용 없음이다.

## 현행 구현 감사

- `battle_scene.gd`는 단일 전조를 즉시 보여주고 곧바로 대응·결과를 산출하므로 `LEGACY_RUNTIME_CONFLICT`다.
- `GameState.select_next_recovery_pattern()`은 완성 패턴 선택만 담당하며 4턴 주기 상태가 없다.
- 현행 Canon v2 projection은 단일 `telegraph` 중심이므로 저작된 전조 1·2·3 Schema가 필요하다.
- 제품 runtime·Scene·JSON·저장 Schema는 이번 승인에서 변경하지 않는다.
