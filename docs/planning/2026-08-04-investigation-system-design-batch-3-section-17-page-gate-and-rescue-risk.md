## 17.1 핵심 플레이 흐름

```text
빈칸이 많은 괴이 매뉴얼 보유
→ 조사로 후보 키워드 획득
→ 정상 후보에서 파생된 [변조] 후보가 후보 풀에 개입
→ 1장부터 페이지를 순서대로 채움
→ 현재 페이지의 모든 빈칸 완료
→ 다음 페이지
→ 최종장의 모든 빈칸 완료
→ 조사 페이즈 종료
→ 피해자 구출 미니게임
→ 회수 페이즈(턴제 전투)
```

이 흐름은 괴이 매뉴얼을 선택적 도감이 아니라 조사·구출·회수를 관통하는 핵심 콘텐츠로 고정한다.

## 17.2 페이지 완료의 의미

페이지 완료는 다음의 구조적 조건이다.

```text
빈칸 없음
+ 문장 의미 구조 성립
+ 저장 가능한 후보 관계
```

페이지 완료는 모든 키워드가 옳거나 확인됐다는 뜻이 아니다. 정상 후보처럼 보이는 `[변조] 후보가 포함될 수 있다`. 플레이어는 완성한 매뉴얼을 실제 구출·전투에 사용해 그 판단을 검증한다.

## 17.3 조사 종료 Gate

조사 종료 Gate는 최종장의 모든 빈칸이 채워질 때 열린다.

- 하나라도 빈칸이 남으면 피해자 구출 미니게임으로 넘어가지 않는다.
- 모든 페이지는 `1장 → 2장 → … → 최종장` 순서로 진행한다.
- 현재 페이지 완료 후 다음 페이지가 진행 가능해진다.
- 이전 페이지 검토·수정 UX는 후속 Spec에서 정하되, 최종장 완료 전에는 조사 기억과 출처를 재검토할 수 있어야 한다.
- 조사 종료 Gate는 진실성 검증이 아니라 실행 가능 상태 진입이다.

## 17.4 Decision 6와의 정합성

Decision 6의 `현장 진입 가능`은 다음으로 교정된다.

```text
현장 진입 가능
= 모든 페이지·모든 빈칸 완료
+ 실행 핵심 문장 구조 성립
+ 이미 판명된 치명적 상충 없음
```

불완전할 수 있는 것은 근거 확실성·후보 진실성·변조 판별 상태다. 빈칸 자체는 남길 수 없다.

## 17.5 피해자 위험도

```text
안정 → 불안정 → 위험 → 임계 → 명확히 예고된 비가역 결과
```

- 첫 실패는 즉시 피해자 상실이 아니다.
- 실패는 위험 상태를 변화시키고 새로운 관찰 증거를 남긴다.
- 정확한 오답 위치나 정답 후보는 공개하지 않는다.
- 임계 상태에서는 다음 중대한 실패의 결과를 명확히 경고한다.
- 숨겨진 확률이나 무작위 즉사를 사용하지 않는다.

## 17.6 재시도 계약

`동일 매뉴얼·도구·경로·순서`와 동일한 상황을 반복하면 같은 결과를 반환한다.

새 시도는 다음 중 하나 이상의 실질적 변경이 있을 때만 성립한다.

- 도구·배치·경로 변경
- 행동 순서·횟수·타이밍 변경
- 긴급 안정화 자원 사용
- 새 관찰 증거를 반영한 대응 변경
- 구출 중단 후 조사 페이즈로 후퇴해 매뉴얼 수정·추가 근거 확보

조사 후퇴는 실패 회복용 예외 분기이며, 위험도와 위험 사례를 초기화하지 않는다.

## 17.7 접근성·열람 보호

다음은 위험도를 증가시키지 않는다.

- 매뉴얼 열람
- 일시정지
- 기록·대사·전조 재생
- 스크린리더
- 입력 보조
- 설명 반복
- 기타 접근성 기능

접근성 사용은 클리어·랭크 불이익이 아니다.

## 17.8 콘텐츠 제작 체크

사건 작가는 다음을 제출한다.

1. 시작 시 표시되는 매뉴얼 페이지와 빈칸
2. 페이지별 정상 후보·보조 후보·[변조] 후보 풀
3. 페이지 진행 순서와 완료 조건
4. 최종장 조사 종료 Gate
5. 피해자 구출 절차와 선택 행동
6. 실패별 관찰 증거·위험도 변화
7. 실질적 변경으로 인정되는 재시도 조건
8. 임계 경고와 비가역 결과
9. 조사 후퇴 분기 여부
10. 회수 페이즈로 전달되는 매뉴얼·위험 사례

## 17.9 적대적 검토

- 매뉴얼 빈칸을 남긴 채 구출로 넘어갈 수 없는가?
- 페이지 완료와 정답 확인을 혼동하지 않는가?
- `[변조]`를 잘못 넣은 상태도 구조적으로 완성될 수 있는가?
- 첫 실패가 즉사·전체 재시작으로 이어지지 않는가?
- 실패가 정답을 직접 알려주지 않으면서 관찰 가능한 변화는 주는가?
- 동일 행동 전수 대입을 실질적 변경 조건이 막는가?
- 임계 결과가 숨은 확률이 아니라 사전 예고되는가?
- 매뉴얼 열람과 접근성 기능이 위험 비용을 만들지 않는가?
- 조사 후퇴가 실패 기록을 삭제하는 리셋 버튼이 되지 않는가?
- 구출 성공 후 같은 매뉴얼이 회수 페이즈 전조 해석에 이어지는가?

## 17.10 적용 경계

이 Section은 핵심 재미와 콘텐츠 진행 구조를 정의한다. 페이지 잠금 UX, 위험 수치, 저장 Schema, 실제 미니게임·전투 구현, 이미지·아트 제작은 후속 Design Spec과 승인 전 시작하지 않는다.
