## 1. 목적

현재 프로젝트에는 다음 플레이 자산이 각각 존재한다.

- CORE-MVP-001: 저승역 조사·기록·현장 검증·회수
- ANNUAL-MVP-001: 4주×7일 일정과 출동 위험
- ANNUAL-MVP-002: 동료·장비·연구·지원·저장 복귀
- URBAN-LEGEND-EVP-001: 후보 배제와 지지·반박·미해결 가설 보드
- 저승역 노선 복원 미니게임
- 전조 대응형 안정화·잔향 회수 화면

각 자산은 존재하지만 외부 플레이어가 하나의 세션에서 이해할 통합 경험 계약은 부족하다.

이 문서는 다음 질문을 검증 가능한 흐름으로 만든다.

> 플레이어가 권나래를 준비시키고, 기록을 조사해 괴이 규칙을 가설화하고, 그 규칙을 현장에서 적용한 결과가 피해자·괴이 매뉴얼·다음 준비에 남는다는 작품의 약속을 이해하는가?

## 2. 핵심 플레이어 약속

> **내가 준비한 방식이 조사와 위험 관리의 선택 폭을 바꾸고, 내가 연결한 기록이 괴이 규칙의 가설이 되며, 그 규칙을 적용한 결과가 공식 기록 또는 위험 사례로 남는다.**

반드시 연결할 다섯 단계:

```text
준비 선택
→ 현장 접근·안전·정보 표현 차이
→ 기록과 근거 관계 구성
→ 규칙 적용형 미니게임·회수 대응
→ 위험 사례·매뉴얼·연구·다음 준비 환류
```

이번 Validation Cut이 증명하지 않는 것:

- 1년 전체 콘텐츠 규모
- 선택적 로맨스 완성도
- 다수 사건의 반복성
- 모바일 조작성
- Steam 출시 품질
- 최종 밸런스
- 장시간 캠페인 유지율

## 3. 검증 순서

### 3.1 Validation Cut — 우선 검증

목표 시간: 35~50분

```text
저승역 콜드 오픈
→ 기록국 브리핑
→ 제한된 준비 결정 1회
→ 저승역 핵심 조사
→ 사건 수준 가설 보드
→ 노선 복원 핵심 단계
→ 회수 패턴 2개 이상
→ 결과·매뉴얼 환류
```

검증 질문:

- 첫 10분 안에 플레이어 역할을 이해하는가
- 준비 선택이 사건에 영향을 줬다고 느끼는가
- 관측 근거로 후보 두 개를 제거하는가
- 남은 불확실성을 설명하는가
- 미니게임과 회수 판단의 책임 차이를 이해하는가
- 행동 성공과 추론 검증을 구분하는가
- 결과가 다음 준비로 이어지는 이유를 설명하는가

제외:

- 4주 전체 일정 반복
- 관계 체인 전체
- 모든 회수 패턴 강제
- 연구·장비 전체 탐색 UI
- ANNUAL-MVP-003/004

### 3.2 Showcase Cut — Validation 통과 뒤

목표 시간: 70~90분

```text
콜드 오픈
→ 기록국 브리핑
→ 대표 4주 준비
→ 출동 결정
→ 저승역 전체 조사
→ 가설 보드
→ 노선 복원
→ 회수 encounter
→ 피해자·매뉴얼·연구·관계 환류
```

선택형 일상·관계 장면을 포함하면 최대 약 100분을 허용한다.

진입 조건:

- Validation 사람 테스트 완료
- 핵심 연결 판정 `KEEP` 또는 `AMPLIFY`
- P1 Finding에 `HOLD` 없음
- 준비→사건→결과 인과 설명 성공
- 사용자 별도 승인

## 4. 시작 상태와 종료 상태

### 시작 상태

- 권나래는 괴이 기록국 신입 요원이다.
- 플레이어는 저승역의 규칙과 안전 노선을 모른다.
- 기록관 아카는 사실·추정·미확인을 구분하지만 정답을 만들지 않는다.
- 저승역 이상 징후 일부만 관측됐다.
- 일반 공간형 괴이 참고 기록은 있으나 사건 전용 대응은 없다.

### 종료 상태

- 해결 등급: temporary / standard / complete 중 하나
- 피해자 구조·후유증 상태
- 공식 규칙 또는 위험 사례
- 괴이 매뉴얼 신규 항목
- 연구 질문 또는 장비 환류
- 동료 기여와 관계 반응
- 다음 준비에서 달라지는 요소 1개 이상
- 미해결 질문 1개 이상

목표 종료 감정:

> 정답을 받은 것이 아니라 기록을 연결해 규칙을 이해했고, 그 판단으로 사람을 구했거나 실패 원인을 남겼다. 다음에는 더 잘 준비할 수 있다.

## 6. 제한된 준비 결정

Validation Cut에서는 전체 ANNUAL 루프 대신 사건에 직접 영향을 주는 선택 1회를 제공한다.

선택 축:

1. 준비 분야: 관측 / 보호 / 봉쇄 / 대인
2. 동료 후보 중 1명
3. 장비 계열 중 1개

실제 선택 수는 한 화면에서 세 축을 전부 요구하지 않는다. 첫 테스트에서는 하나의 주요 선택과 하나의 보조 선택만 사용한다.

허용 영향:

| 준비 요소 | 허용 | 금지 |
|---|---|---|
| 관측·분석 | 추가 원문, 전조 태그 정확도 | 자동 가설 확정 |
| 현장 대응 | 위험·피해 완화, 재시도 안전성 | 오답을 정답 처리 |
| 대인 대응 | 피해자·동료 맥락 | 필수 단서 독점 |
| 동료 | 조건부 지원·다음 기회 | 자동 정답 선택 |
| 장비 | 기록·보호·봉쇄 보조 | 핵심 규칙 우회 |
| 연구 | 이미 관측한 현상 해석 | 신규 괴이 자동 분류 |

준비 결과 문법:

```text
무엇이 변했는가
→ 왜 변했는가
→ 현장에서 무엇이 달라지는가
```

## 7. 저승역 조사

### 조사 질문

> 같은 방송을 들은 사람들이 서로 다른 목적지를 기억하는 최초 원인은 무엇이며, 현실 경로를 고정하려면 무엇을 신뢰해야 하는가?

### 관측 사실 층

- 방송 원본의 목적지 공백
- 사람별 목적지 기억
- 기기별 목적지 불일치
- 공식 운행 기준
- 검은 승차권 각인
- 피해자 기록의 00:00 고정
- 최종 인과 구분용 시간순 기록

사실과 해석을 분리한다. 기록 카드에는 관측 문장, 출처, 획득 시점, 원문 복귀를 둔다.

### 조사 선택

- 공식 운행 기록 우선
- 방송 원본 우선
- 피해자 기록 확인
- 검은 승차권 관측
- 전광판·기기 기록 비교

모든 핵심 사실은 최초 플레이에서 관측 가능해야 한다. 선택 순서는 위험·맥락·추가 정보에 영향을 줄 수 있지만 필수 정답을 영구 누락시키지 않는다.

- 지지
- 반박

- 후보
- 미해결
- 근거 검토 가능
- 제거됨
- 최종 후보

정답·오답·숨은 required evidence·정답률은 노출하지 않는다.

## 9. 원인 가설과 안전 운용 규칙 분리

원인 질문:

> 개인별 목적지가 생기는 최초 원인은 무엇인가?

안전 운용 규칙:

> 개인화된 목적지 표기는 현실 경로 기준으로 신뢰할 수 없으며, 공식 노선 식별 정보와 방송 종료 식별음이 안전 경로를 고정한다.

두 질문을 분리하는 이유:

- 원인이 완전히 확정되지 않아도 안전 행동은 수행할 수 있다.
- 안전 행동 성공이 원인 정답을 자동 확정하면 안 된다.
- 공백 투사설과 승차권 지정설은 일부 안전 행동을 함께 지지할 수 있다.

## 10. 노선 복원 미니게임

책임:

- 안전 운용 규칙을 공간 조작에 적용한다.
- 공식 식별 정보로 현실 경로를 복원한다.
- 개인 목적지 표기를 경로 기준에서 배제한다.

입력:

- 공식 노선 식별 정보
- 방송 종료 식별음
- 개인화된 목적지 표기

성공 출력:

- 안전 경로 검증 기록
- 회수 단계의 위험·경로 안정도 보정
- 요원 반응

실패 출력:

- 잘못된 경로의 위험 사례
- 재검토할 기록
- 회수 부담 변화

성공이 의미하지 않는 것:

- 공백 투사설의 최초 원인 확정
- 검은 승차권 역할의 완전 규명
- 사건 전체 공식 규칙 자동 완성

접근성:

- 포인터와 키보드 완전 진행
- 경로 미리보기는 조작 횟수에 포함하지 않음
- 시간 제한은 기본 필수가 아님
- 확대·기록 확인 중 입력 차단 상태를 명확히 표시

## 11. 회수 encounter

회수는 사건 전체 가설을 다시 만드는 단계가 아니다.

책임:

- 새 전조를 이미 정리한 규칙·패턴·예외에 따라 분류
- 짧고 중립적인 행동 선택
- 안정화·봉쇄·잔향 회수
- 새 예외와 위험 사례 기록

대표 패턴 후보:

- 존재하지 않는 종착 안내
- 역무원의 시선 유도
- 검은 승차권의 승객 각인
- 선로 경계 붕괴

Validation Cut에서는 2개 이상을 사용한다. 어떤 2개를 고정할지는 회수 encounter 상세 설계에서 결정한다.

권장 단계:

```text
Phase 1 — 전조 관측
→ 패턴 분류
→ 대응 선택
→ 행동 결과
→ 필요 시 추가 근거
→ 안정화 기준 충족
→ 잔향 회수
```

Showcase 목표는 5~8턴이지만 Validation Cut은 2개 패턴의 책임 분리와 이해도만 우선 확인한다.

## 12. 행동 성공과 추론 검증

| 현장 행동 | 가설·근거 | 현장 결과 | 기록 결과 |
|---|---|---|---|
| 올바름 | 검증됨 | 안정화 진행 | 공식 규칙 후보 갱신 |
| 올바름 | 부족·불일치 | 안정화 진행 | 행동 성공 / 추론 미검증 |
| 잘못됨 | 논리 일관 | 피해·위험 증가 | 반례·위험 사례 추가 |
| 잘못됨 | 근거 부족 | 피해·위험 증가 | 오독 근거·추가 질문 기록 |

보호 원칙:

- 우연히 올바른 행동을 골라도 공식 규칙을 얻지 않는다.
- 원인 미검증 상태에서 complete를 자동 부여하지 않는다.
- 정확한 temporary / standard / complete 매핑은 기존 threshold·보상 계약 감사 뒤 확정한다.
- 첫 오대응은 즉사·강제 중상·영구 실패를 만들지 않는다.

## 13. 아카와 동료의 경계

### 기록관 아카

허용:

- 읽지 않은 기록 위치 안내
- 사실·추정·미확인 분류
- 연결한 근거의 원문 복귀
- 제출 뒤 제거 이유 요약
- 기록 손상·오류 상태 표시

금지:

- 지지·반박 관계 자동 선택
- 제거 후보 지정
- 최종 가설 추천
- 시간순 기록의 결론 대신 설명

### 동료 지원

허용:

- 피해 완화
- 재시도 안전성
- 이미 확보한 기록의 불일치 후보 강조
- 비교 가능한 기록 쌍 제안
- 다음 기회 생성

금지:

- 신규 핵심 단서 생성
- 미관측 사실 공개
- 제거 후보 표시
- 정답 행동 자동 선택

## 14. 결과와 환류

결과 화면은 다음 네 질문에 답한다.

```text
무엇이 일어났는가
왜 그런 결과가 났는가
무엇을 공식 기록 또는 위험 사례로 남겼는가
다음 준비에서 무엇이 달라지는가
```

최소 환류:

```text
공식 규칙 또는 위험 사례 1개
→ 연구 질문 1개
→ 연구·장비·지원 후보 1개
→ 다음 출동 미리보기에서 영향 표시
```

괴이 매뉴얼 항목:

- 공식 규칙
- 관측 패턴
- 위험 사례
- 권장 대응
- 미해결 질문
- 연결 연구·장비·동료 경험

## 15. 저장·복귀

현재 사실:

- 미니게임 진입 직전 체크포인트를 사용한다.
- 미니게임 내부 보드 진행은 저장하지 않는다.
- 같은 체크포인트는 같은 보드와 변수 조합으로 복구해야 한다.
- 회수 화면은 각 대응 뒤 자동 저장을 수행한다.

기획 검수 항목:

- 회수 자동 저장을 유지할지 encounter 진입·종료 체크포인트로 축소할지
- 재불러오기로 예측·지원·패턴 순서를 재추첨하지 않는 방법
- 저장 직후 UI와 실제 상태가 일치하는지

현재 저장 동작을 변경하지 않는다.

## 18. 사람 플레이테스트

테스터 과제:

1. 첫 모순을 발견한다.
2. 준비 선택 1회를 완료한다.
3. 저승역 기록을 조사한다.
4. 후보 두 개를 관측 근거로 제거한다.
5. 남은 두 후보의 차이를 설명한다.
6. 시간순 기록을 비교한다.
7. 노선 복원으로 안전 운용 규칙을 적용한다.
8. 회수 패턴 2개 이상에 대응한다.
9. 결과와 다음 준비의 인과를 설명한다.

관찰 지표:

- 첫 10분 역할 설명 성공
- 첫 제거 시간
- 근거 연결 수정 횟수
- 원문 복귀 사용
- 시스템 제안을 정답으로 오인한 횟수
- 원인과 운용 규칙 혼동
- 미니게임 성공을 원인 정답으로 오인하는지
- 회수 단계의 반복 피로
- 결과→다음 준비 인과 설명

판정:

- KEEP
- AMPLIFY
- CHANGE
- RETEST
- HOLD

## 19. 완료·중단 기준

Validation Cut 성공:

- 다수 참가자가 프로젝트 역할을 첫 10분 안에 설명한다.
- 두 후보 제거를 관측 근거로 설명한다.
- 남은 불확실성을 설명한다.
- 안전 운용 규칙과 최초 원인 가설을 구분한다.
- 행동 성공과 추론 검증을 구분한다.
- 결과가 다음 준비를 바꾸는 이유를 설명한다.

수정 필요:

- 정답 문장 길이로 행동을 고름
- 시스템 제안을 정답으로 오인
- 미니게임 뒤 가설 보드가 불필요하게 느껴짐
- 회수에서 동일 추론을 반복한다고 느낌
- 준비 선택이 사건에 영향을 주지 않았다고 느낌

중단:

- 비관측 규칙이 판정에 사용됨
- 동료·아카가 정답을 대신함
- 실패가 원인 정보 없이 자원만 소모함
- 핵심 경로 소프트락 발생
- 준비·가설·미니게임·회수의 책임을 분리할 수 없음
