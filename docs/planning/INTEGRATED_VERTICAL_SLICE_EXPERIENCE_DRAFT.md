## 0. 목적

괴이기록국에는 다음 플레이 자산이 각각 존재한다.

- `CORE-MVP-001`: 저승역 조사·기록·현장 검증·회수
- `ANNUAL-MVP-001`: 4주×7일 일정과 출동 위험
- `ANNUAL-MVP-002`: 동료·장비·연구·지원·저장 복귀
- `URBAN-LEGEND-EVP-001`: 후보 배제와 지지·반박·미해결 가설 보드 Pilot
- 저승역 노선 복원 미니게임
- 전조 대응형 회수 화면

그러나 이 자산을 외부 플레이어가 하나의 경험으로 이해하는 통합 계약은 아직 없다.

이 문서는 다음 질문을 검증 가능한 데모 흐름으로 바꾸는 기획 초안이다.

> 플레이어가 권나래를 준비시키고, 저승역의 기록을 조사하고, 스스로 괴이 규칙을 설명하고, 그 규칙을 현장에서 적용한 결과가 피해자·괴이 매뉴얼·다음 준비에 남는다는 작품의 약속을 이해하는가?

---

## 1. 핵심 플레이어 약속

> **내가 준비한 방식이 조사와 위험 관리의 선택 폭을 바꾸고, 내가 연결한 기록이 괴이 규칙의 가설이 되며, 내가 그 규칙을 현장에서 적용한 결과가 공식 기록 또는 위험 사례로 남는다.**

### 반드시 연결할 5단계

```text
일정·동료·장비 선택
→ 현장 접근·안전·정보 표현 차이
→ 기록과 근거 관계 구성
→ 규칙 적용형 미니게임·회수 대응
→ 위험 사례·매뉴얼·연구·다음 준비 환류
```

### 데모가 증명하지 않는 것

- 1년 전체 콘텐츠 규모
- 선택적 로맨스 완성도
- 다수 사건의 반복성
- 모바일 조작성
- Steam 출시 품질
- 최종 밸런스
- 장시간 캠페인 유지율

## 2. 검증 단위를 두 단계로 분리한다

적대적 검토 결과, 70~90분 전체안을 첫 테스트부터 사용하면 실패 원인을 분리하기 어렵다. 따라서 최종 공개 데모를 둘로 나누는 것이 아니라 **개발·검증 순서만 두 단계로 나눈다.**

## 2.1 Validation Cut — 먼저 검증할 35~50분

```text
저승역 콜드 오픈
→ 기록국 브리핑
→ 제한된 준비 결정 1회
→ 저승역 핵심 조사
→ 사건 수준 가설 보드
→ 노선 복원 핵심 단계
→ 회수 패턴 2개 이상
→ 결과·매뉴얼 환류
```

### 목적

- 첫 10분에 작품 목표를 이해하는가
- 준비 선택이 사건에 영향을 줬다고 느끼는가
- 기록으로 후보를 배제할 수 있는가
- 미니게임과 회수 판단이 같은 규칙의 서로 다른 적용으로 읽히는가
- 성공·실패 원인을 설명할 수 있는가

### 제외

- 4주 전체 일정
- 관계 체인
- 모든 회수 패턴 강제
- 긴 연구·장비 메뉴

## 2.2 Showcase Cut — Validation 통과 뒤 70~90분

```text
콜드 오픈
→ 기록국 브리핑
→ 대표 4주 준비
→ 출동 결정
→ 저승역 전체 조사
→ 가설 보드
→ 노선 복원
→ 회수 encounter
→ 피해자·매뉴얼·연구·관계 환류
```

선택형 일상·관계 장면을 포함하면 최대 약 100분을 허용한다.

## 2.3 대안

| 안 | 길이 | 장점 | 위험 | 판정 |
|---|---:|---|---|---|
| Validation Cut 우선 | 35~50분 | 실패 원인 분리, 빠른 재검증 | 연간 운영 깊이는 제한적 | `RECOMMENDED_FIRST` |
| Showcase Cut 직행 | 70~90분 | 전체 약속을 한 번에 체험 | 피로·범위·원인 진단 위험 | `AFTER_VALIDATION` |
| 사건 우선 압축 공개 데모 | 45~60분 | 괴담 도달이 빠름 | 연도제 육성이 부록처럼 보일 수 있음 | `ALTERNATIVE` |

## 3. 시작 상태와 종료 상태

### 시작 상태

- 권나래는 괴이 기록국의 신입 요원이다.
- 플레이어는 저승역의 규칙과 안전 노선을 알지 못한다.
- 기록관 아카는 사실·추정·미확인을 구분하지만 정답을 만들지 못한다.
- 저승역의 이상 징후 일부만 관측됐다.
- 일반 공간형 괴이 참고 기록은 있으나 사건 전용 대응은 없다.

### 종료 상태

- 해결 등급: `temporary / standard / complete`
- 피해자 구조·후유증 상태
- 공식 규칙 또는 위험 사례
- 괴이 매뉴얼 신규 항목
- 연구 절차 또는 장비 환류
- 동료 기여와 관계 반응
- 다음 준비에서 달라지는 요소 1개 이상
- 미해결 질문 1개 이상

### 목표 종료 감정

> “정답을 받은 것이 아니라 내가 기록을 연결해 규칙을 이해했고, 그 판단으로 사람을 구했거나 실패의 원인을 남겼다. 다음에는 더 잘 준비할 수 있다.”

## 6. 대표 4주 준비 계약

### 목적

4주 준비는 능력치 최대화 퍼즐이 아니라 **현재 사건에서 무엇을 더 확인하고 어떤 실패 비용을 줄일지 선택하는 단계**다.

### 선택 예산

- 주당 핵심 결정 2~3개
- 활성 사건·연구·관계 시계 최대 3개
- 반복 결과는 주간 요약으로 압축
- 선택형 일상 장면은 통합 데모 전체 1개

### 반드시 체험할 선택

1. 관측·분석·현장 대응·대인 대응 중 준비 분야 선택
2. 동료 선택 또는 편성 변경
3. 장비 계열 선택
4. 휴식과 추가 준비의 기회비용
5. 2·3·4주차 위험 0/15/30 변화 확인

### 사건 징후가 공개할 범주

- 공간·경계 이상
- 반복 방송·신호
- 피해자 기억 불일치
- 접촉 매개체 가능성

정확한 정답 대응·필수 단서 위치·안전 노선 답안은 공개하지 않는다.

### 준비 요소의 허용·금지 영향

| 요소 | 허용 | 금지 |
|---|---|---|
| 관측·분석 | 추가 원문, 전조 태그 정확도 | 자동 가설 확정 |
| 현장 대응 | 위험·피해 완화, 재시도 안전성 | 오답을 정답 처리 |
| 대인 대응 | 피해자·동료 맥락 | 필수 단서 독점 |
| 동료 | 조건부 지원·피해 완화·다음 기회 | 자동 정답 선택 |
| 장비 | 기록·보호·봉쇄 보조 | 핵심 규칙 우회 |
| 연구 | 이미 관측한 현상 해석 | 신규 괴이 자동 분류 |

### 주간 결과 문법

```text
무엇이 변했는가
왜 변했는가
다음 출동에서 무엇이 달라지는가
```

## 7. 출동 결정 계약

- 2주차: 위험 0, 조기 출동과 추가 준비의 교환
- 3주차: 위험 15, 준비와 현상 심화 사이의 선택
- 4주차: 위험 30, 결과 확인 뒤 긴급 강제 출동

출동 화면은 다음을 보여준다.

- 현재 징후 단계
- 다음 위험 증가 시점
- 준비 강점 2개 이하
- 확인되지 않은 위험 범주
- 동료의 짧은 의견
- 조기/지연의 예상 손실 범주

최적 출동 시점·숨은 정답 점수·확정 결과 예측은 표시하지 않는다.

## 8. 저승역 사실 기준선

### 현재 사건 규칙

- 방송 원본의 목적지 구간은 비어 있다.
- 청자는 목적지 공백을 개인 목적지로 채워 듣는다.
- 안내 종료 전 이동하면 위치가 초기화된다.
- 공식 운행 기록과 일치한 경로가 현실 승강장 기준이다.

### 현재 단서

1. 피해자의 마지막 문자 — 도착 예정 시각 `00:00`
2. 검은 승차권 관련 관측 및 안전 노선 검증 기록
3. 반복 안내방송 녹음
4. 서로 다른 목적지 표기
5. 역무원실 근무 기록

### 현재 회수 패턴

1. 존재하지 않는 종착 안내
2. 역무원의 시선 유도
3. 검은 승차권의 승객 각인
4. 선로 경계 붕괴

### 현재 미니게임

- ID: `minigame_frequency_sync`
- 표시명: 저승역 노선 복원
- 현행 타입: `route_restore`
- 3×3 조작 학습, 4×4 최종 검증
- 공식 기록과 방송 원본을 대조해 안전 노선을 복원

### 현재 결과 환류

- `temporary / standard / complete`
- 피해자 구조·후유증 차이
- 반복 방송·검은 승차권·종착지 기록
- 폐주파수 분석 절차
- 폐주파수 필터

## 9. 추론을 세 층으로 나누되 반복시키지 않는다

### 9.1 사건 수준 가설 보드

**질문:** 저승역 전체의 규칙과 현실로 돌아오는 기준은 무엇인가?

- 후보 4개
- 관측 근거로 2개 제거
- 남은 후보의 지지·반박·미해결 관계 구성
- 최종 규칙 후보와 예외 제출

### 9.2 미니게임

사건 보드에서 만든 규칙을 공간·순서 조작으로 실제 적용한다.

- 새 가설을 다시 만들지 않는다.
- 현재 규칙 후보와 관련 기록을 화면에 가져온다.
- 성공은 안전 노선 검증 기록을 만든다.

### 9.3 회수 패턴 판단

새 전조가 이미 만든 규칙·예외 중 어디에 해당하는지 빠르게 판별한다.

- 모든 턴에서 사건 보드를 다시 만들지 않는다.
- 기존에 검증한 규칙은 `매뉴얼 후보`로 불러온다.
- 새로운 예외·미해결 패턴에서만 근거 선택을 확장한다.

## 10. 사건 가설 보드 계약

### 현재 상태

단서·회수 패턴은 존재하지만 플레이어에게 보여줄 **가설 후보 4개와 제거 근거 체인**은 현재 확인 범위에서 별도 정본으로 고정되지 않았다.

정확한 후보 문구는 `MISSING_CANON`이며 후속 기획에서 작성한다.

### 후보 작성 규칙

1. 네 후보 모두 초기 관측으로는 그럴듯해야 한다.
2. 오답 후보마다 관측 가능한 반증이 1개 이상 있어야 한다.
3. 최종 후보는 서로 다른 출처의 지지 근거 2개 이상을 가진다.
4. 사후 규칙으로 오답을 제거하지 않는다.
5. 대상·조건·순서·예외 중 무엇이 다른지 읽을 수 있어야 한다.

### 제출 최소 조건 초안

- 제거 후보: 반박 근거 각 1개 이상
- 최종 후보: 지지 근거 2개 이상
- 경쟁 후보 또는 예외: 반박/미해결 검토 1개 이상

### 보드 책임

- 관측 사실과 해석 분리
- `지지 / 반박 / 미해결` 관계
- 연결 이유 표시
- 원문·관측 장면 복귀
- 제거 근거 회수
- 결과 뒤 강한 근거·오독 근거·미해결 질문 기록

## 11. 노선 복원 미니게임 계약

### 적용 규칙

- 개인이 들은 목적지를 사실로 취급하지 않는다.
- 공식 운행 기록과 식별 정보를 현실 경로 기준으로 사용한다.
- 안내 종료 전 성급하게 이동하지 않는다.

### 성공

- 현실 승강장으로 이어지는 노선 복원
- 안전 노선 검증 기록 획득
- 회수 encounter 정보 또는 안전 보조

### 실패

- 위험 사례 등록
- 노선 왜곡 또는 회수 부담 증가
- 조사 화면으로 돌아가 기록 재대조
- 정답 자동 공개 없음

### 접근성

- 키보드·포인터 완전 진행
- 드래그 필수 금지
- 색 외 연결 상태 표시
- 시간 제한 사용 시 연장·일시정지·비활성 대안
- 기록 오버레이가 열리면 보드 입력 차단

### 정본 충돌 Finding

현재 에피소드 JSON과 런타임 코드가 미니게임 제목·설명·규칙·수치를 중복 소유하고, JSON에는 리듬형 legacy 필드가 남아 있다.

기획 승인 뒤 구현 계획에서 다음을 처리한다.

```text
사건별 규칙·수치의 단일 데이터 원본 지정
→ 런타임 override 책임 축소
→ legacy 필드 소비 여부 감사
→ ACTIVE / COMPATIBILITY / REMOVE 판정
```

지금은 파일을 수정하지 않는다.

## 12. 회수 encounter 계약

### 목표

관측한 패턴에 올바르게 대응해 안정화 기준을 채우고 피해자와 검은 승차권 잔향을 회수한다. 괴이 HP를 소진하거나 처치하지 않는다.

### 3단계 구조

```text
Phase 1 — 현실 기준 고정
Phase 2 — 개인 목적지·시선·승차권 유인 차단
Phase 3 — 선로 경계 복원과 잔향 회수
```

목표 길이 `5~8턴 DRAFT_TARGET`.

### 패턴 기준

| 패턴 | 전조 | 연결 근거 | 대응 의미 |
|---|---|---|---|
| 존재하지 않는 종착 안내 | 반복 방송과 사라지는 전광판 글자 | 방송 녹음 + 목적지 표기 | 안내 신호 차단 |
| 역무원의 시선 유도 | 피해자 동선과 다른 시선 | 마지막 문자 + 근무 기록 | 시간 기록으로 동선 고정 |
| 검은 승차권 각인 | 이름 형태로 번지는 천공 자국 | 승차권 관측 + 마지막 문자 | 접촉 차단 |
| 선로 경계 붕괴 | 안전선 단절과 선로 중첩 | 표지 + 근무 기록 | 현실 경계 복원 |

### 가설·근거·대응 3층

현재 정답 선택지는 근거와 행동을 한 문장에 합쳐 정답을 누설할 위험이 있다. 다음 구조를 사용한다.

```text
가설: 전조를 설명하는 규칙
근거: 플레이어가 선택한 기록
대응: 짧고 중립적인 행동
```

행동 버튼에는 정답 근거를 직접 써주지 않는다.

### 이중 결과

```text
행동 성공
→ 현장 안정화·피해 관리

추론 검증
→ 공식 규칙·괴이 매뉴얼·완전 해결·연구 품질
```

- 올바른 행동을 우연히 선택하면 즉시 생존할 수 있다.
- 근거가 검증되지 않으면 공식 규칙 확정이나 완전 해결을 얻지 못한다.
- 올바른 추론인데 조작 실패가 나면 위험 사례와 연구 근거는 남길 수 있다.

### 단서 효과 분리

- **의미 효과:** 전조 태그·규칙 관계·예외 공개
- **안전 효과:** 피해 완화·재시도·포획 창 보조

단서 합산 수치만으로 완전 해결을 자동 보장하지 않는다.

### 이해도별 표시

| 이해도 | 전조 정보 |
|---|---|
| 미확인 | 미관측 핵심 전조, 범용 보호·관찰 가능 |
| 단서 확보 | 대상 또는 범위 1개 확인 |
| 유력 | 대상·범위·시점 중 2~3개 확인 |
| 이해 | 행동명·조건을 포함한 전체 정보 확인 |

거짓 행동명이나 틀린 대상·범위를 표시하지 않는다.

### 자동 예측 경계

현재 회수 화면에는 확률 기반 자동 예측이 존재한다. 정확한 소비 규칙은 후속 감사가 필요하다.

기획 경계:

- 대상·범위·시점 태그 보조만 허용
- 올바른 대응 행동명 직접 제공 금지
- 실패 시 거짓 정보 금지
- 같은 저장 상태에서 재추첨 금지

### 동료·대표 요원 경계

프로젝트 코어 권장안:

- 권나래가 직접 판단·행동한다.
- 대표 요원 전환은 지원 우선순위 또는 피해 보호 대상 선택으로만 해석한다.
- 다른 동료를 직접 조작하는 구조로 확대하지 않는다.

이 항목은 `USER_DECISION_REQUIRED`다.

### 실패 전진

- 첫 오대응: 회복 가능한 피해·위험 상승과 반응 단서
- 누적 오대응: `temporary` 또는 불완전 해결 가능성 증가
- 후퇴: 피해를 줄이고 미해결·위험 사례로 종료
- 결과: 실패 원인·배운 규칙·다음 확인 항목 기록

## 14. 결과·매뉴얼·연구 환류

### 결과 화면 4행

```text
무엇이 일어났는가
왜 그런 결과가 나왔는가
무엇을 공식 규칙 또는 위험 사례로 기록했는가
다음 출동에서 무엇이 달라지는가
```

### 해결 등급

| 등급 | 의미 |
|---|---|
| temporary | 피해자 구조, 후유증·미해결 규칙 잔존 |
| standard | 피해자 구조, 주요 조건 기록, 연구 절차 확보 |
| complete | 안정 구조, 괴이 핵 회수, 추가 기록 보존 |

별 개수보다 사람·기록·미해결 상태를 먼저 보여준다.

### 최소 환류

```text
공식 규칙 또는 위험 사례
→ 폐주파수 분석 절차
→ 폐주파수 필터
→ 다음 준비 화면에서 연결 경로 표시
```

### 매뉴얼 항목

- 사건 요약
- 공식 규칙
- 관측 패턴
- 권장 대응
- 위험 사례
- 미해결 질문
- 연구·장비 연결
- 참여 동료와 기여 기록

## 15. 저장·복구

### 확인된 현재 사실

현재 회수 화면은 각 대응 뒤 `GameState.save_game()`을 호출한다.

상태 표기:

```text
recovery_response_autosave: IMPLEMENTED_CURRENT
```

### 사용자 결정 필요

- A. 대응 뒤 자동 저장 유지
- B. encounter 진입/종료 체크포인트만 사용

권장안은 A를 우선 검토한다. 긴 판단 세션의 손실을 줄일 수 있기 때문이다.

어느 안이든 다음을 금지한다.

- 재불러오기로 패턴·자동 예측·지원 판정 재추첨
- 실패 직전 상태를 반복 로드해 결과 선택
- 저장 상태에 따라 핵심 단서 소실

### 미니게임

- 진행 중 저장하지 않음
- 진입 직전 체크포인트
- 같은 보드·변수 조합으로 처음부터 재진입

## 19. 플레이테스트

### 참가자

- 추리/VN 경험이 적은 신규 플레이어 3명 이상
- 추리·미스터리 경험자 3명 이상
- 개발 문서를 읽지 않은 참가자 우선

### Validation Cut 과제

1. 첫 10분 뒤 게임 목표 설명
2. 준비 결정과 예상 영향 설명
3. 관측 사실과 추정 구분
4. 후보 두 개를 근거로 제거
5. 노선 복원에 적용한 규칙 설명
6. 회수 패턴 대응의 근거 설명
7. 결과 뒤 다음 준비 변화 설명

### 행동 지표

- 첫 의미 보상 도달 시간
- 다음 행동을 찾지 못한 정지 시간
- 원문 재확인 횟수
- 가설 관계 수정 횟수
- 제거 근거 설명률
- 미니게임 규칙 설명률
- 회수 오대응 원인 이해
- 저장·복귀 성공
- 아카·동료를 정답 제공자로 오인했는가

### KEEP / AMPLIFY 후보

- 작품 목표를 `기록·규칙 추리·현장 적용`으로 설명한다.
- 후보 제거와 대응을 관측 근거로 설명한다.
- 준비 선택이 정보·안전·위험에 미친 영향을 설명한다.
- 회수 encounter가 공격 전투가 아니라고 이해한다.
- 실패 뒤 무엇을 배웠는지 말할 수 있다.

### CHANGE / RETEST

- 일정 최적화가 주 게임이라고 인식한다.
- 아카·동료·자동 예측을 정답으로 오인한다.
- 가설 보드·미니게임·회수가 같은 내용을 반복한다고 느낀다.
- 올바른 행동을 골라도 왜 맞는지 설명하지 못한다.
- 연구·매뉴얼 환류를 이해하지 못한다.

### HOLD

- 비관측 규칙이나 거짓 전조가 판정에 사용된다.
- 필수 단서가 선택형 관계·동료·스탯에만 잠긴다.
- 첫 오대응이 비가역 실패·소프트락을 만든다.
- 저장·복귀로 판정을 재추첨할 수 있다.
