# 저승역 완전 사건 설계 — Section 06

## `[목적지 합창]`과 공통 무음 구간 파훼

책임 Decision:

`D-2026-08-04-AFTERLIFE-STATION-DESTINATION-CHORUS-SILENCE-COUNTER`

상태:

`APPROVED_PRODUCT_DECISION / GRILLME_BATCH_4_6_OF_10 / PENDING_BATCH_MERGE`

## 1. 패턴 정체성

`[목적지 합창]`은 승차권이나 좌표가 아니라 **서로 다른 개인 경험에서 공통으로 남는 원본 공백**을 찾는 패턴이다.

- 요원 A: 철거된 옛집 역명을 들음
- 요원 B: 고향의 환승역을 들음
- 피해자 잔상: 자신이 돌아가고 싶은 역을 들음
- 방송 원본: 목적지 부분은 모두 같은 공통 무음 구간

플레이어는 목적지 이름 중 하나를 고르는 대신, 서로 다른 기록이 공유하는 무음 타임스탬프를 찾아야 한다.

## 2. 가변 전조

패턴은 `N ≥ 2`, `N-1개의 전조`를 따른다.

### 1턴 전조

플레이어의 평상 행동 전에 여러 대상의 머리 위와 전투 로그에 서로 다른 목적지 자막이 나타난다. 방송 파형에는 목적지 구간이 비어 있다.

### 2턴부터 N-1턴

플레이어의 행동이 먼저 해결된 뒤 대상별 목적지 자막이 바뀌거나 겹친다. 그러나 모든 녹음에서 공통 무음 구간과 타임스탬프는 유지된다.

### 최종 턴

```text
대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행
```

`패턴 준비 완료`나 `다음 턴 발현` 같은 직접 경고는 표시하지 않는다.

## 3. 정확한 대응

플레이어는 복수 기록을 비교해 공통 무음 구간을 지정하고, 그 구간에 `공식 역 식별음 삽입`을 선택한다.

```text
공통 무음 구간 확인
→ 공식 역 식별음 공백에 삽입
→ 개인 목적지 투영 붕괴
→ 목적지 합창 중단
→ [파훼]
→ 기억 매듭 노출
→ 괴이 [취약]
```

공식 역 식별음은 소모품이 아니라 현실 위치 기준을 제공하는 도구다. 구출 단계에서 사용했더라도 전투에서 다시 참조할 수 있다.

## 4. 다른 대응의 결과

### 하나의 목적지를 선택

- 해당 개인 투영이 현실처럼 강화됨
- 선택된 대상에게 집중 피해와 연결 심화
- 기억 매듭은 노출되지 않음

### 방어

- 정신·위치 교란 피해 감소
- `[취약]`은 발생하지 않는다

### 잘못된 타이밍에 식별음 삽입

- 행동이나 자원만 소비
- 파훼 효과 없음
- 다음 전조 기록은 계속 축적

### 허상 공격

- 허상이 분산되지만 원본 공백은 남음
- 반격 발생
- 기억 매듭 미노출

모든 결과는 숨겨진 확률 없이 동일 입력에 동일 결과를 반환한다.

## 5. 승차권·지속 흔적 패턴과의 차이

- `[무정차 환송]`: 공식 승차권으로 투영 노선을 무효화
- `[회귀 승강장]`: 복수 주기의 지속 흔적으로 실제 잔향 좌표 고정
- `[목적지 합창]`: 복수 대상의 서로 다른 목적지에서 공통 무음 구간을 찾아 공식 식별음을 삽입

승차권을 파훼 수단으로 사용하지 않는다. 지속 흔적 좌표를 고정하는 패턴이 아니다.

## 6. 공정성·접근성

- 공통 무음 구간을 자동 강조하지 않는다.
- 정답 타이밍을 자동 선택하지 않는다.
- 자막에 대상·목적지·기록 시각을 함께 표시한다.
- 파형에는 구간 번호·타임스탬프·파형 구간 라벨을 제공한다.
- 공식 식별음은 음성 외에 텍스트명·파형 모양·진동 패턴으로 구분한다.
- 음향만으로 판별하지 않는다.
- 접근성 기능은 후보 구간을 추천·순위화하지 않는다.
