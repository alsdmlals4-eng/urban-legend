## 1. 제품 약속과 대상 플레이어

### 제품 약속

> 플레이어가 1년 동안 육성하고 준비한 권나래가 조사로 괴이의 규칙을 밝혀내고, 그 이해를 조작형 검증과 턴제 회수 전투에서 직접 증명하며, 성공과 실패를 연구·장비·동료 협업·다음 연도 기록으로 축적한다.

| 질문 | 답 |
|---|---|
| 플레이어는 누구인가 | 괴이 기록국 신입 요원 권나래의 일정과 판단을 맡는 플레이어 |
| 일상에서 무엇을 하는가 | 주간 일정·중요 반일 선택으로 성장·피로·연구·관계·기관 협력을 조정한다 |
| 조사에서 무엇을 하는가 | 관측 정보와 매뉴얼을 비교하고 규칙 가설에 지지·반박·미해결 근거를 연결한다 |
| 미니게임에서 무엇을 하는가 | 조사한 규칙을 경로·순서·타이밍·대상 선택으로 직접 검증한다 |
| 전투에서 무엇을 하는가 | 전조를 읽고 권나래의 대응을 선택해 안정화·봉쇄·포획 조건을 연다 |
| 무엇을 남기는가 | 공식 규칙·관측 패턴·위험 사례·연구 결과·관계·기관 상태·연도 결산 |
| 무엇을 하지 않는가 | 자동 정답, 거짓 예측, 핵심 추리 난수화, 조사와 무관한 화력전, 권나래 교체 |

### 대상 플레이어

- 오컬트·괴담 서사와 인물 관계를 장기적으로 즐기는 플레이어
- 순수 비주얼 노벨보다 직접 판단하고 준비하는 플레이를 원하는 플레이어
- 프린세스 메이커식 주인공 육성과 일정 최적화를 선호하는 플레이어
- 정답 찍기보다 관측·비교·설명하는 규칙 추리를 선호하는 플레이어
- 실시간 액션보다 낮은 입력 부담의 턴제 판단을 선호하는 PC 플레이어

초기 수직절편은 대규모 경영·복잡한 경제·하드코어 전투 최적화를 검증하지 않는다.

## 2. 장르와 이중 코어

### 장르

> **주인공 육성 시뮬레이션 + 텍스트 노벨 + 규칙 추리 + 조작형 미니게임 + 턴제 회수 전투**

텍스트 노벨은 전체 서사·화면 문법이다. 조작형 미니게임과 회수 전투를 삭제하지 않고, 핵심 사건의 검증과 클라이맥스로 유지한다.

### 육성 코어

```text
주간 일정 편성
→ 권나래 역량·가치 성향·전문성 성장
→ 피로·상태 관리
→ 관계·기관 협력 형성
→ 연구·장비·동료 준비
```

### 사건 코어

```text
사건 징후
→ 텍스트 노벨형 조사
→ 규칙 가설 작성
→ 조작형 규칙 검증 미니게임
→ 턴제 회수 전투
→ 성공·실패·위험 사례 기록
```

### 이중 코어 순환

```text
육성·준비
→ 사건 조사·검증·회수
→ 기록·연구·관계·기관 평가
→ 장비·스킬·전문성 확장
→ 다음 육성 기간
```

## 3. 권나래 성장 모델

권나래는 과거·기본 성격·말투·핵심 욕구가 고정된 작가 캐릭터다. 플레이어는 어떤 사람이든 만들지 않고, 반복 선택으로 어떤 요원이 되는지를 결정한다.

### 기초 역량

| 성장 요소 | 허용 영향 | 금지 영향 |
|---|---|---|
| 관찰 | 추가 조사 지점·전조 정보·미니게임 보조 | 정답 표시 |
| 분석 | 근거 비교·가설 폭·연구 효율 | 자동 가설 확정 |
| 현장 대응 | 허용 오차·피해 완화·재시도 안전성 | 오답 성공 처리 |
| 대인 대응 | 증언·협력·기관 선택지 | 필수 단서 독점 |
| 가치 성향 | 대사·해결 방식·결산 | 선악 점수 단일화 |
| 전문성 | 질문·행동·모듈·스킬 해금 | 신규 괴이 자동 분류 |

### 가치 성향

- 괴이 구제
- 민간인 보호
- 기관 명령 준수
- 진실 공개

가치 성향은 선악 수치가 아니다. 대사·사건 해결 방식·동료 반응·기관 평가·연도 결산의 서술을 바꾼다.

### 전문성

전문성은 현상 계열, 조사 기법, 회수 대응법, 기관 직무, 괴이별 심화 연구로 구성한다. 숫자 증가보다 새로운 질문·행동·장비·스킬 해금에 집중한다.

## 4. 1년 4분기 캠페인

첫 완성 캠페인은 봄·여름·가을·겨울의 4분기다.

```text
봄 — 입국·기초 적응·첫 핵심 사건
→ 여름 — 전문화·관계 심화·두 번째 핵심 사건
→ 가을 — 가치 충돌·기관 압박·세 번째 핵심 사건
→ 겨울 — 누적 선택 회수·연도 핵심 사건·연도 결산
```

각 분기는 다음을 포함한다.

- 핵심 사건 1개
- 제한된 중형·소형 사건
- 기관 업무·교육
- 괴이 연구·장비 정비
- 동료 관계 이벤트
- 분기 정산

### 핵심 사건 진입

1. 분기 초·중반에 징후를 공개한다.
2. 플레이어는 일정으로 준비한다.
3. 마감 전 자율 출동할 수 있다.
4. 지연할수록 현상 심화·민간 피해·난도가 상승한다.
5. 마감까지 출동하지 않으면 긴급 출동한다.

핵심 선택은 `더 성장한 뒤 출동할 것인가, 상황 악화 전에 현재 준비로 출동할 것인가`다.

## 5. 주간 일정과 중요 반일 선택

### 주간 계획

한 주의 반복 활동을 한 번에 편성한다.

- 훈련
- 기관 업무
- 괴이 연구
- 장비 정비
- 휴식·치료
- 동료 교류

반복 결과는 압축해 보여주고 중요한 변화만 텍스트 노벨 장면으로 전환한다.

### 중요 반일 선택

- 사건 징후 조사
- 돌발 출동
- 관계 이벤트
- 기관 요청
- 상태 태그 관련 장면
- 핵심 사건 진입 결정

핵심 사건에 진입하면 일반 일정은 중단하고 사건 전용 흐름으로 전환한다.

## 6. 피로·상태·기관 지원·잔향 자료

### 피로

상시 관리 수치는 피로 하나로 제한한다.

- 높을수록 일정 효율 감소
- 미니게임 허용 오차 축소
- 회수 전투 부상 위험 증가
- 대사·관계 반응 변화
- 행동 자체를 완전히 금지하지 않음

### 상태 태그

예: 경상, 중상, 불안, 집착, 과신. 휴식·치료·관계 이벤트·사건 극복으로 해소하거나 변형한다. 회복 부족으로 진행이 막히는 소프트락을 금지한다.

### 자원

| 자원 | 용도 |
|---|---|
| 일정 슬롯 | 훈련·업무·연구·휴식·교류 |
| 기관 지원도 | 장비·치료·허가·교육·출동 지원 |
| 잔향 자료 | 연구·매뉴얼 확정·모듈·보조 스킬 |

개인 돈·생활비·반복 상점 거래는 별도 핵심 시스템으로 만들지 않는다.

## 7. 사건 등급과 핵심 사건 흐름

| 등급 | 구성 | 목적 |
|---|---|---|
| 핵심 사건 | 전체 조사 → 대표 미니게임 → 완전한 회수 전투 | 분기 메인 서사와 성장 검증 |
| 중형 일반 사건 | 축약 조사 → 짧은 미니게임 → 축약 회수 | 전문성·관계·장비 조합 시험 |
| 소형 일반 사건 | 텍스트 조사 → 단일 규칙 판정 | 자원·성향·위험 사례 변화 |
| 기관 업무·일상 | 텍스트 노벨 선택 | 육성·관계·세계관 전개 |

### 핵심 사건 전체 흐름

```text
징후 공개
→ 동료·장비·모듈·보조 스킬 준비
→ 텍스트 노벨형 현장 조사
→ 단서·증언·매뉴얼 비교
→ 경쟁 가설 구성
→ 조작형 미니게임으로 규칙 검증
→ 괴이 출현·상황 악화
→ 턴제 회수 전투
→ 안정화·잔향 회수
→ 사건 결과·연구·후일담
```

회수 전투는 사건 종료 뒤 별도 모드가 아니라 핵심 사건 내부의 클라이맥스다.

## 8. 텍스트 노벨형 조사

### 기본 화면

1. 현재 상황과 관측 가능한 전조
2. 대응 선택지 4개
3. 관련 괴이 매뉴얼 사례 2~3개 자동 제시
4. 규칙 가설 카드
5. 최소 상태: 권나래 체력·괴이 위험도·직전 반응

### 선택지와 근거

- 4개 선택지 중 관측 가능한 근거로 2개를 배제한다.
- 배제 오답은 농담이 아니라 현재 근거나 기존 위험 사례와 충돌한다.
- 남은 2개는 현재 정보에서 모두 합리적인 경쟁 가설이다.
- 시스템은 관련 자료를 찾지만 어느 선택지에 적용할지는 플레이어가 결정한다.
- 잘못된 기록 연결은 체력·위험도 비용 없이 거부한다.
- 자동 추천·정답 강조·미확보 정보 노출을 금지한다.

### 가설 카드

- 규칙 문장
- 지지 근거 1개 이상
- 반박 근거 0개 이상
- 미해결 질문 0개 이상
- 현장 검증 결과
- 기록 상태: 후보 / 공식 규칙 / 위험 사례

### 현장 이해도

`unknown → clue → likely → understood`

- 승격 조건은 결정론적이다.
- `understood`는 관측한 패턴을 확정 해석한다.
- 재출현 때 영구 매뉴얼은 남지만 현재 출현 이해도는 다시 쌓는다.

### 실패 갱신

오답 검증은 정답을 공개하지 않는다. 반응 단서·배제 근거·피해·위험 사례를 남기고 `기존 가설 1개 + 직전 반응으로 생긴 변형 가설 1개`로 부분 갱신한다.

## 9. 조작형 규칙 검증 미니게임

목적은 조사에서 세운 가설을 실제 조작에 적용해 검증하는 것이다.

### 공통 조작 문법

- 올바른 경로 선택
- 행동 순서 기억과 재현
- 특정 타이밍 회피·진입
- 금지 대상·구역 회피
- 소리·빛·시선·반복 주기 대응
- 제한 자원으로 안전 구역 유지

### 성장·장비 영향

- 실수 허용 횟수
- 판정 영역과 제한 시간
- 경로·주기 표시 보조
- 실패 후 재시도 안전성
- 피해·상태 악화 완화

높은 능력치도 잘못된 규칙을 성공으로 바꾸지 않는다. 기존 `route restore`, `rain dodge` 등은 `전조 관측 → 규칙 적용 → 즉시 결과` 문법을 만족할 때만 재사용한다.

## 10. 턴제 회수 전투

### 목표

괴이 HP를 소진하거나 처치하지 않는다.

```text
전조 확인
→ 권나래 행동 선택
→ 동료 보조 스킬 판정
→ 행동 결과와 괴이 반응
→ 안정화·봉쇄 조건 누적
→ 포획 창 개방
→ 잔향 회수
```

### 권나래 행동군

| 행동 | 역할 |
|---|---|
| 관찰 | 다음 전조·패턴·상태 추가 확인 |
| 보호 | 자신·동료·민간인 피해 완화 |
| 규칙 대응 | 확인한 금기·조건에 맞춘 전용 행동 |
| 장비 사용 | 연구 모듈과 현장 장비 기능 사용 |
| 봉쇄·회수 | 포획 표식과 안정화 진행 |
| 후퇴·긴급 대응 | 실패 비용을 줄이고 불완전 종료 |

### 논리와 확률

- 실제 패턴과 포획 조건은 판정 전에 고정한다.
- 거짓 전조를 제공하지 않는다.
- 중간 이해도에서 이미 관측한 패턴의 정보 공개만 확률 판정할 수 있다.
- 저장·불러오기로 같은 판정을 재추첨하지 않는다.

### 미관측 핵심 패턴

- 첫 발동은 행동명을 공개하지 않는다.
- 미관측 핵심 전조임은 표시한다.
- 범용 방어·엄폐·보호 중 최소 하나는 항상 유효하다.
- 첫 발동은 즉사·강제 중상·캠페인 소프트락·영구 분기 실패를 만들지 않는다.
- 실제 발동 뒤 패턴을 매뉴얼에 등록한다.

### 승리

올바른 대응으로 2~4개의 사건별 조건을 충족하면 포획 창이 열린다. 승리는 HP 0이 아니라 안정화·봉쇄·잔향 회수다.

## 11. 동료·고유 스킬·공용 보조 스킬

### 편성·조작

- 출동은 권나래 + 동료 최대 2명
- 플레이어는 권나래만 직접 명령
- 동료는 독립 턴이나 직접 명령을 갖지 않음
- 정답·필수 단서·최적 행동을 독점하지 않음

### 슬롯

- 동료별 고유 스킬 1개
- 기본 공용 슬롯 1개
- 협업 성장 뒤 공용 슬롯 1개 추가
- 관계 사건 완료 시 고유 스킬 강화 또는 파생 효과 해금

### 획득

- 기관 교육: 현장 대응, 기록 분석, 응급 의료, 봉쇄 기술, 대외 협력
- 괴이 연구: 음향, 경계·공간, 기억·인식, 시선·관측, 반복·순서 등

### 자동 발동 공정성

- 조건 충족 시 확률 판정
- 신뢰·협업·전문성·사건 경험으로 확률 조정
- 연속 불발 시 지원 준비도 누적
- 최대 준비도에서 다음 적합 조건 확정 발동
- 조건·현재 확률·준비도를 UI에 공개
- 같은 저장 상태의 재불러오기로 재추첨 금지
- 대표 고유 스킬은 관계 성장 후 전투당 1회 보장 가능
- 동료는 오답을 정답으로 교정하지 않고 피해 완화·다음 기회 생성·상태 회복·행동 보강만 수행

## 12. 괴이 연구와 기본 장비·모듈

### 연구 입력

- 관측한 현상·패턴
- 검증된 규칙·가설
- 성공한 대응 절차
- 실패로 축적된 위험 사례
- 잔향 자료
- 연구 일정과 기관 지원

정보가 부족한 연구는 완료되지 않으며 부족한 항목을 다음 조사 목표로 표시한다.

### 연구 계층

1. 공용 현상 연구: 음향, 경계, 기억, 시선, 반복, 온도, 모방·언어
2. 괴이별 심화 연구: 공식 규칙, 미관측 패턴, 전용 대응, 전용 모듈

공용 연구는 신규 괴이의 정답을 제공하지 않는다.

### 기본 장비

| 장비 계열 | 주요 역할 |
|---|---|
| 관측 장비 | 전조·현상·단서 기록 |
| 현장 보호 장비 | 피해·상태·민간 위험 완화 |
| 규칙 대응 장비 | 확인된 규칙의 특수 행동 |
| 봉쇄·회수 장비 | 안정화·포획 표식·잔향 보존 |
| 조사 도구 | 미니게임과 현장 검증 지원 |

강화는 모듈 슬롯·안정성·사용 제한·부작용·범용 기능을 개선한다. 공격력 반복 상승은 중심이 아니다.

### 모듈

- 공용 계열 모듈: 여러 관련 괴이에 제한적으로 유효
- 괴이 전용 변형: 정확한 규칙과 연구 기록이 있을 때 강한 기능
- 출동 전에 제한 슬롯에 장착
- 사건 중 자유 교체 불가
- 필수 모듈이 없어도 범용 방어·후퇴 경로 보장

## 13. 기관·관계·선택적 로맨스

### 기관

- 동료는 괴이 기록국 소속 또는 공식 협력 인력이다.
- 각 동료는 경찰·소방·의료·학술·기술기관 등 이전 경력과 협력망을 가진다.
- 외부 기관은 직접 경영하지 않고 교육·허가·장비·치료·사건 정보의 공급망으로 사용한다.

### 관계 축

| 축 | 의미 |
|---|---|
| 업무 신뢰 | 현장 판단, 책임 분담, 협업 안정성 |
| 개인적 유대 | 친밀감, 이해, 갈등 회복, 사적 후일담 |

관계는 선물 반복보다 공동 일정·사건 편성·위기 판단·가치 충돌·실패 책임·부상 장면으로 변화한다.

일부 인물만 선택적 로맨스가 가능하다. 업무 신뢰 없이 진입할 수 없고, 비연애 관계도 완결된 우정·멘토·라이벌 결산을 가진다.

## 14. 실패 전진

핵심 사건 회수 실패도 정식 결과다.

- 괴이 도주
- 불완전 안정화
- 잔향 일부 회수
- 민간 피해
- 권나래 부상·심리 상태
- 기관 평가 변화
- 동료 관계 변화
- 위험 사례 추가
- 추적·보완 사건 개방

플레이어는 체크포인트 재시도 또는 실패 수용 진행을 선택할 수 있다. 캠페인 전체 게임오버는 최종 국면의 제한된 조건에만 사용한다.

## 15. 분기 정산과 연도 결산

### 분기 정산

- 권나래 역량·전문성·피로·상태
- 기관 평가와 협력 관계
- 동료 신뢰·협업 숙련
- 사건 성공·실패·민간 피해
- 매뉴얼 완성도와 연구 성과
- 다음 분기 위험·관계·사건 조건

정산은 수치표만이 아니라 보고서와 인물 반응을 포함한 텍스트 노벨 장면으로 보여준다.

### 연도 결산

한 해의 종료는 최종 엔딩이 아니라 해당 연도의 주요 갈등, 현재 진로 방향, 현재 신념, 관계·기관·괴이 상태를 짧게 정리하는 **연도 결산**이다. 후속 연도가 추가되면 계승 데이터로 다음 해 도입부와 사건 조건을 변경한다.

연도 결산의 세 층:

1. 현재 진로 방향: 확정 직업이 아닌 잠정 역할·평가
2. 현재 신념: 반복 선택에서 두드러진 책임 우선순위
3. 관계·세계 상태: 동료·기관·회수·도주·미해결 괴이·장기 미스터리

## 16. 다음 연도 계승과 성장 인플레이션 방지

### 직접 계승

- 기초 역량·가치 성향·전문성
- 기본 장비 강화·연구 모듈
- 괴이 매뉴얼
- 동료 신뢰·협업·공용 스킬
- 기관 평가·협력 관계
- 회수·도주·미해결 괴이 상태
- 핵심 경험 태그

### 재설정·완화

- 일반 피로
- 일시적 경상
- 현재 출현 현장 이해도
- 분기 기관 지원도
- 임시 장비·사건 허가

### 인플레이션 방지

- 기초 역량은 일정 수준 뒤 성장 속도 감소
- 이후 성장은 전문화·선택지·운용 방식 확장 중심
- 새 연도는 높은 숫자보다 복합 현상·책임·조건을 제시
- 기존 장비는 폐기보다 모듈·파생 강화로 확장
- 과거 지식은 유리한 출발점이나 신규 변형의 정답은 아님

## 17. UI·접근성

### 화면 문법

- 일상·육성·관계·조사·결산은 텍스트 노벨을 기본으로 한다.
- 사건에서는 현재 단계에 필요한 정보만 전면에 둔다.
- UX-PD-001 2A의 준비 화면 점진 공개 기준을 회귀 보호한다.
- 상세 수치·장비·관계 태그는 필요할 때 여는 서랍·탭으로 둔다.

### 접근성

- 긴 한국어 자동 줄바꿈
- 1280×720·1920×1080 가독성
- 색상·음향만으로 전조·위험 전달 금지
- 시간 제한이 있으면 일시정지·연장·비활성 대안 제공
- 단계 전환 뒤 첫 유효 컨트롤로 포커스 복구
- UI·컷인·표정은 상태를 표현하지만 진행을 대신 소유하지 않음

## 18. 저장·호환·난수 재현성

현재 본편 저장은 `mvp-039`이며 `mvp-038` 이관을 지원한다.

- ANNUAL-MVP-001은 독립 PoC 저장만 사용한다.
- 기존 `GameState`, 사건 데이터, 기존 조사·회수 장면을 직접 통합하지 않는다.
- 실제 연도 캠페인 통합 전에 새 저장 버전·ID·기본값·이관·롤백을 별도 승인한다.
- 난수 seed 또는 판정 결과를 저장해 재불러오기로 전조·동료 지원을 재추첨하지 않는다.
- 주간 계획 확정 전, 주간 결과 뒤, 사건 진입 직전, 사건 결과 뒤의 안전 저장 지점을 우선 검증한다.
- 사건 중간 저장은 별도 PoC 없이는 도입하지 않는다.

## 20. 검증 게이트와 구현 트랙

### 완료·보존 자산

CORE-MVP-001은 사건 1개의 `조사 → 가설 → 현장 검증 → 전조 → 회수 → 매뉴얼` 인과를 독립 실행하는 `POC_BUILD_READY` 자산이다. 자동 검증은 통과했지만 플레이 증거가 없어 `POC_PASSED`는 선언하지 않는다.

### 현재 트랙

`ANNUAL-MVP-001`은 3주 육성·출동 준비가 기존 CORE-MVP-001 사건의 정보·위험·피해 관리에 영향을 주고, 사건 결과가 연구·스킬·분기 결산으로 되돌아오는지를 격리 경로에서 검증한다.

### 검증 질문

> 육성·준비에서 내린 선택이 사건의 정보·위험·피해 관리에 체감 가능한 차이를 만들고, 사건 결과가 연구·스킬·분기 결산으로 되돌아오는가?

### 판정

- 자동 계약·회귀 통과: `BUILD_READY`
- 사람 눈 UI·텍스트 QA 통과: `QA_READY`
- 플레이 인과 체감 통과: `KEEP / AMPLIFY`
- 일부 연결 실패: `CHANGE / RETEST`
- 코어 침해·불공정·소프트락: `HOLD`

플레이 증거 없이 `POC_PASSED`, 연도제 루프 통과, 제작 확대를 선언하지 않는다.
