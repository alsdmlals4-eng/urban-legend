# ANNUAL-MVP-001 7일 주간·가변 일정 일수 설계

> 상태: `APPROVED_DESIGN_BASELINE`
> 사용자 승인: 2026-07-25
> 추적 Issue: #75

## 목표

기존 `주당 3개 활동` 계약을 실제 달력 감각에 가까운 `1주 7일` 계약으로 교체하고, 일정마다 서로 다른 일수 비용을 부여해 주간 편성의 조합·기회비용·휴식 결정을 강화한다.

## 시간 계약

- 1주 = 7일
- 1개월 = 4주 = 28일
- 일정은 1~3일을 소비한다.
- 일정은 주차 경계를 넘지 못한다.
- 현재 주의 남은 일수보다 비용이 큰 일정은 선택할 수 없다.
- 같은 일정을 반복 선택할 수 있다.
- 정확히 7일을 사용하면 즉시 주간 결과로 진행한다.

## 활동별 일수

| 활동 ID | 표시명 | 일수 |
|---|---|---:|
| `annual001_activity_observation_drill` | 관측 훈련 | 2일 |
| `annual001_activity_analysis_desk` | 기록 분석 | 2일 |
| `annual001_activity_field_training` | 현장 대응 훈련 | 3일 |
| `annual001_activity_interview_duty` | 증언 면담 업무 | 2일 |
| `annual001_activity_signal_research` | 신호 현상 연구 | 3일 |
| `annual001_activity_companion_drill` | 오현 협업 훈련 | 2일 |
| `annual001_activity_rest` | 휴식 | 1일 |

기존 활동 ID와 authored delta는 유지한다.

## 남은 일수 확정 흐름

1. 플레이어가 7일 미만의 계획에서 `주간 일정 확정`을 누른다.
2. 상태를 변경하지 않고 다음 경고를 표시한다.
   - `사용하지 않은 일정이 N일 남아 있습니다. 지금 확정하면 남은 N일은 자동 휴식 처리됩니다.`
3. UI는 같은 편성을 유지하며 플레이어가 일정을 추가하거나 취소할 수 있게 한다.
4. 편성을 바꾸지 않고 다시 확정하면 남은 일수를 자동 휴식으로 처리한다.
5. 활동 추가·제거·불러오기·주차 전환이 발생하면 재확정 상태를 해제한다.

## 직접 휴식과 자동 휴식

### 직접 선택한 휴식

- 활동 ID `annual001_activity_rest`를 사용한다.
- 1일을 소비한다.
- 기존 authored fatigue delta `-25`를 적용한다.
- `status_recovery_eligible=true` 계약을 가진다.
- 일반 활동이므로 향후 직접 휴식 전용 장면·상태 회복 확장에 참여할 수 있다.

### 자동 휴식

- 남은 일수 1일당 피로 5를 회복한다.
- 합산 결과는 `annual001_activity_auto_rest`로 주간 결과에 기록한다.
- 역량·기관 지원·연구 진척·동료 신뢰를 변경하지 않는다.
- 상태 회복, 관계 이벤트, 특수 회복, 추가 보상을 발생시키지 않는다.
- 자동 휴식은 편의 처리이며 직접 휴식보다 항상 약하다.

## 출동 계약 보존

- 2주차 자율 출동 위험 0
- 3주차 자율 출동 위험 15
- 4주차 7일 결과 확인 후 미출동이면 긴급 강제 출동 위험 30
- 출동 시점·CORE 사건·연구·결산 연결은 변경하지 않는다.

## 저장·호환

- 데이터 계약은 `annual-mvp-001-v3`으로 올린다.
- PoC 저장은 `annual-mvp-001-save-v1`을 유지한다.
- 계획 선택과 경고 대기 상태는 UI 임시 상태로 두고 저장 payload에 추가하지 않는다.
- 이미 커밋된 주간 결과는 `used_days`, `auto_rest_days`, `activity_results`를 포함한다.
- 본편 `mvp-039`, `mvp-038` 이관과 `GameState`는 변경하지 않는다.

## UI 계약

- 각 활동 버튼에 `· N일`을 표시한다.
- 선택 요약에 `사용 X/7일 · 남은 Y일`을 표시한다.
- 남은 일수보다 비용이 큰 버튼은 비활성화한다.
- 경고 뒤 편성을 유지하고 `확인`을 다시 누를 수 있다.
- 주간 결과에는 직접 활동과 자동 휴식 일수를 구분해 표시한다.

## 검증

- 데이터 계약과 활동별 일수
- 7일 초과 불변성
- 7일 미만 첫 확정의 무상태 변경 경고
- 두 번째 확정의 자동 휴식 적용
- 자동 휴식이 피로 외 수치를 변경하지 않음
- 직접 휴식이 자동 휴식보다 강함
- 주차 경계 초과 일정 선택 차단
- 2·3·4주차 출동 위험과 강제 출동 회귀
- 저장 버전 및 CORE 보호 경로 회귀
