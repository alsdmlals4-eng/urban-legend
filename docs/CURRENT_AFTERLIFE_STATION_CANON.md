## 핵심 규칙

- 방송 목적지 공백은 듣는 사람의 귀환 기억으로 채워진다.
- 안내 종료 전 자신이 들은 목적지를 향해 경계를 넘으면 시간·기록은 유지되고 위치만 초기화된다.
- 피해자의 현실 귀환 경로와 일치하는 승차권을 회수하고 지정 역에서 함께 하차한다.
- 회수는 조사 기록을 다시 사용한다.
  - 1장 → `[목적지 합창]`
  - 2장 → `[회귀 승강장]`
  - 3장 → `[무정차 환송]`
- 세 패턴의 전조·대응·첫 세션 teaching order는 `docs/M01_RECOVERY_SCENE_PACKET.md`가 소유한다.
- 매뉴얼·접근성 기능은 정답 대응·좌표·타이밍을 자동 표시하지 않는다.

## 현재 결과 계약

`LEGACY_SINGLE_GRADE_SUPERSEDED`

과거 Decision 9의 S-rank/단일 등급 부분은 2026-08-21 월간 제품 정본의 `COMPOSITE_RESULT` 계약으로 대체됐다. Decision 9의 **후속 재조사·기록 재현·구출 후 승인 철수 같은 고유 의미는 계속 보존**하지만, 한 글자 등급이 사건 결과 전체를 소유하지 않는다.

현재 결과는 최소 다음 축을 독립적으로 보존한다.

- 피해자 상태 / 구조 결과
- 확인된 규칙과 근거
- 회수·안정화 상태
- 위험 사례·비용
- 잔향 / 미회수 상태
- 미해결 질문
- 후속 연구·관계·정보 공유 변화

구출 성공 뒤 회수 중단/실패는 피해자 구출을 소급 삭제하지 않는다. 반대로 구출만 성공했다고 괴이 회수까지 성공으로 승격하지 않는다.
