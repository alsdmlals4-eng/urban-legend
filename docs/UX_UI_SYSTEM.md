## 1. 플레이어 경험 약속

플레이어는 괴이를 처치하는 대신 기록·증언·환경 단서를 비교해 규칙과 피해 경로를 추론하고, 검증한 지식을 회수 판단으로 연결해야 한다.

```text
현장·기록·증언 조사
→ 정보의 출처·신뢰 상태 구분
→ 가설 작성과 모순 확인
→ 규칙 검증 행동 선택
→ 위험·비용·예상 결과 확인
→ 회수/철수/추가 조사 결과 복기
```

핵심 경험은 **불완전한 정보에서 규칙을 찾아내는 긴장**, **가설이 맞아떨어지는 지적 보상**, **기록이 다음 조사에 남는 축적감**이다.

## 2. 범위와 보호 대상

포함:

- 조사 가능 요소·기록·증언·단서의 정보 구조
- 확인 사실·추정·모순·미확인의 신뢰 상태
- 가설·규칙 검증·위험 행동·회수 결과
- 대사·기록·튜토리얼·최근 진행 재열람
- 키보드·마우스·게임패드 포커스와 긴 한국어

제외:

- 괴이 규칙·분기·단서·플래그·호감도·미니게임 결과 변경
- 새로운 설정·증언·사건 발명
- 제품 Scene·script·JSON·asset 수정
- HTML 기획 대시보드

UI는 기록과 권위 상태를 표시하고 조사·가설·검증·회수 요청만 전달한다.

## 3. 정보 신뢰 상태

| 상태 | 의미 | UI 표현 | 금지 |
|---|---|---|---|
| 확인 사실 | 둘 이상의 근거 또는 직접 검증 | 출처·검증 시점·관련 규칙 | 단순 강조색만 사용 |
| 단일 증언 | 출처가 있으나 미검증 | 화자·상황·신뢰 한계 | 사실로 자동 승격 |
| 추정/가설 | 플레이어가 연결한 설명 | 근거·반례·검증 행동 | 정답처럼 표시 |
| 모순 | 정보끼리 충돌 | 충돌 항목·추가 조사 경로 | 어느 쪽이 참인지 임의 판정 |
| 미확인 | 언급됐으나 조사하지 않음 | 조사 위치·조건 | 빈 상태와 혼동 |
| 폐기 | 반증되거나 적용 범위 밖 | 반증 근거·기록 보존 | 정보 자체 삭제 |

## 4. 화면 중심 질문

| 단계 | 중심 질문 | 첫 시선 | 핵심 행동 | 결과·복귀 |
|---|---|---|---|---|
| 현장 조사 | 무엇을 확인해야 하는가 | 현재 위험·조사 가능 요소 | 조사/이동 | 기록과 위험 변화 |
| 기록 검토 | 어떤 정보가 사실이고 충돌하는가 | 신뢰 상태·출처·모순 | 비교·연결 | 가설 작성으로 이동 |
| 가설 | 어떤 규칙이 피해를 설명하는가 | 근거·반례·미확인 | 가설 선택/수정 | 검증 행동 제안 |
| 검증 전 | 무엇을 잃고 무엇을 확인하는가 | 위험·비용·예상 증거 | 실행/취소 | 현장 결과로 이동 |
| 회수 판단 | 충분히 이해했는가 | 확인 규칙·남은 불확실성 | 회수/추가 조사/철수 | 결과·기록 갱신 |
| 복귀 | 이전에 무엇을 알아냈는가 | 최근 사건·현재 목표·미해결 모순 | 조사 재개 | 의미 위치 복귀 |

## 6. 공포와 명료성의 경계

- 공포는 규칙의 의미·불완전한 정보·결과에서 만들고 조작과 읽기 자체를 불명료하게 만들지 않는다.
- 의도적으로 가려진 정보는 `미확인` 또는 `손상된 기록`처럼 상태와 이유를 표시한다.
- 중요한 위험 규칙은 화면 흔들림·소리 하나에만 의존하지 않는다.
- 서술적 세계관 문구와 실제 실행 조건을 구분한다.
- 선택 결과를 완전히 예고하지 않더라도 플레이어가 알고 있던 위험과 불확실성은 공정하게 표시한다.

## 7. Godot 구현 경계

```text
에피소드·플래그·단서·괴이 규칙 권위 상태
→ 조사/기록/가설 View Data
→ Control/Container/Theme 표시
→ 조사·가설·검증·회수 요청 Signal
→ 도메인 처리
→ 사건·위험·기록 Event
→ 현장 피드백·기록·복기 UI
```

금지:

- UI가 단서 획득·플래그·호감도·분기 조건을 재계산
- 대사 UI가 사건 결과를 직접 저장
- 연출 완료를 괴이 규칙 처리 시점으로 사용
- UX 개선 명목으로 새 분기·단서·설정 발명

## 8. 접근성·폴백

- 신뢰 상태·위험·모순·선택 가능 여부를 색만으로 구분하지 않는다.
- 음향을 꺼도 이상 현상·위험 규칙·대사 정보가 자막·아이콘·로그로 남는다.
- 모션 감소에서도 위협과 결과 인과가 유지된다.
- 긴 한국어 대사·기록은 읽기 폭·줄바꿈·재열람·진행 속도를 지원한다.
- 게임패드·키보드·포인터로 조사→기록→가설→회수를 완주한다.
- 이미지 누락 시 인물/기관/장비 이름과 상태로 기능을 유지한다.
