## 결정

괴이 매뉴얼 후보 가설은 단계형 검증을 사용하지만, **세션 중에는 정답 여부를 공개하지 않는다**.

```text
작성 중
→ 저장 불가능한 구조 오류만 차단
→ 정답·오답 비공개

조사 체크포인트
→ 구조·근거·상충·실행 준비도 피드백
→ 정답 키워드·오답 위치·정답 근접도 비공개

구출·회수 진입 전
→ 빈칸·구조 오류·이미 관찰된 위험만 경고
→ 최종 진입 확인
→ 매뉴얼 읽기 전용

구출·회수 실행 중
→ 관찰 가능한 현상과 새 단서 [기록]
→ 자동 정오 판정·자동 수정 금지

사건 결과 확정
→ 세션 종료 보고서
→ 슬롯별 정답 비교
```

## 1. 작성 중 안전 피드백

다음만 차단한다.

- 저장할 수 없는 손상 데이터
- 필수 관계가 누락돼 문장 자체를 직렬화할 수 없는 상태
- 동일 참조가 데이터 구조를 무한 순환시키는 오류
- 사건 데이터에 존재하지 않는 ID

다음은 플레이어 가설로 허용한다.

- 사실과 다른 인과관계
- 근거가 약한 후보
- 상충 증거가 있는 후보
- 임의 후보 배치
- 동일 키워드 재사용
- 정상 후보와 `[변조]` 후보의 오인

구조 오류와 게임 세계의 오답을 분리한다.

## 2. 조사 체크포인트 피드백

세션 중 검증은 다음 범주만 사용한다.

### 검증 불가

연결된 단서 [기록]이 없거나 구조가 평가 가능한 상태가 아니다.

### 근거 부족

연결 기록이 적거나 출처 신뢰 상태가 낮다. 정답과의 거리 점수가 아니다.

### 증거 상충

지지 기록과 반박 기록이 함께 있다. 어느 키워드가 틀렸는지는 표시하지 않는다.

### 실행 준비

모든 빈칸이 채워지고 실행 가능한 문장 구조다. 정답 보증이 아니다.

동일한 키워드·관계·기록 연결을 다시 제출하면 같은 캐시 결과를 반환한다. 새 기록이나 실질적 의미 변경이 있을 때만 다시 평가한다. 검증 횟수는 재화 소모·랭크 감점으로 사용하지 않는다.

## 3. Decision 8 교정

Decision 8에 따라 기존 `확인 가능`과 화면상의 `확인 규칙` 승격 표현을 다음처럼 교정한다.

- 세션 중에는 `확인 규칙` 상태를 표시하지 않는다.
- 높은 내부 신뢰도는 저장할 수 있으나 플레이어에게 정답 판정으로 노출하지 않는다.
- 피드백은 `구조·근거·상충·실행 준비도`에 한정한다.
- 정답 여부는 세션 종료 보고서의 슬롯별 정답 비교에서만 공개한다.
- 구출·회수 성공도 사용한 모든 슬롯을 자동 확인하지 않는다.
- S 랭크 판정에 필요한 공식 확인은 사건 결과 보고서에서 계산한다.

## 4. 진입 전 준비도

표시 가능:

- 빈칸 수
- 문장 저장 가능 여부
- 연결된 기록 수
- 관찰된 상충 존재 여부
- 피해자 위험도
- 최종 진입 확인

표시 금지:

- 정답·오답
- 정답 후보 추천
- 정답 적합도
- 정답 근접도
- 성공 확률
- `확인 규칙` 배지
- 틀린 슬롯 위치

최종장 모든 빈칸과 문장 구조가 완성되면 진행할 수 있다. 근거가 약하거나 `[변조]`를 오인한 상태도 허용한다.

## 5. 실행 중 피드백

- 잘못된 대상·순서·타이밍은 피해자 반응과 환경 변화로 드러난다.
- 결과 로그는 관찰 사실을 기록한다.
- 시스템은 “이 카드가 틀렸다”고 해설하지 않는다.
- 실패는 새로운 관찰 증거와 위험 사례가 된다.
- 매뉴얼을 자동 수정하지 않는다.
- 동일 상태 반복은 같은 결과를 반환한다.
- 조사 페이즈로 후퇴하면 새 기록을 사용해 수정할 수 있다.

## 6. 사건 결과 보고서

사건 결과가 확정된 뒤에만 높은 해상도의 정답 피드백을 제공한다.

- 플레이어의 최종 제출본
- 공식 규칙
- 슬롯별 정확·부분 일치·오답·미해결
- 잘못된 인과·대상·순서
- 사용한 `[변조]`의 원본과 변경 변수
- 획득했지만 사용하지 않은 중요 기록
- 위험 사례와 구출·회수 결과
- 일반 클리어와 S 랭크 정밀 기록의 차이

다음 사건의 정답이나 미획득 증거는 공개하지 않는다.

## 7. 접근성

동일 정보는 텍스트, 아이콘과 형태, 색상 외 구분, 키보드·컨트롤러 포커스, 스크린리더 설명, 필요 시 음향으로 등가 제공한다.

접근성 기능은 정답 해상도·정답 공개 시점·랭크를 바꾸지 않는다. 매뉴얼 열람과 기록 재생에 위험 비용을 부과하지 않는다.

## 8. 적대적 검토

- 체크포인트가 정답 탐색기로 변하지 않는가?
- `근거 부족`과 `증거 상충`이 정답 근접도처럼 보이지 않는가?
- 실행 준비를 정답 보증으로 표현하지 않는가?
- 구출·회수 결과를 정오 아이콘으로 바꾸지 않는가?
- 매뉴얼을 자동 수정하지 않는가?
- 저장·로드·메뉴 이탈로 결과 보고서를 조기 해금하지 않는가?
- 검증 횟수나 접근성 사용을 감점하지 않는가?
