## 1. 승인 결정

괴이기록국의 조사 페이즈와 일반 플레이는 자유 이동형 탐색 HUD가 아니라 **텍스트 노벨 중심 화면**을 기본 제품 표면으로 사용한다.

`서울 2033`은 텍스트 중심 진행 감각을 설명하기 위한 사용자 지정 레퍼런스이며, 해당 작품의 UI·문구·콘텐츠를 복제하지 않는다.

## 2. 기본 화면 구성

일반 플레이의 기본 프레임은 다음 요소로 구성한다.

- 현재 장소를 전달하는 배경 일러스트 또는 환경 이미지
- 상황·관찰·위험을 전달하는 서술문
- 대화 중인 인물의 초상 또는 반신 일러스트
- 화자명과 대사 영역
- 2~4개의 선택지 또는 조사 행동
- 조건·자원·기록 변화의 짧은 인라인 표시
- 이전 기록·괴이 매뉴얼·현재 목표 바로가기

화면의 중심은 지도 이동이나 다수의 HUD 패널이 아니라 **읽기 → 판단 → 선택 → 결과 텍스트**다.

## 3. 조사 표현 규칙

조사는 다음 방식으로 진행한다.

```text
장소·상황 서술
→ 관찰 또는 대화 선택
→ 조건·비용 확인
→ 결과 서술과 반응 대사
→ 단서·기록·상태 갱신
→ 다음 선택지 또는 전문 화면 전환
```

- 조사 지점은 텍스트 선택지와 상황 카드로 표현한다.
- 동료 반응은 대사와 짧은 초상 변화로 제공한다.
- 단서 획득은 결과 텍스트와 기록 알림으로 명확히 표시한다.
- 실패·부분 성공도 별도 결과 문장과 상태 변화로 설명한다.
- 자유 이동형 현장 탐색은 기본값으로 간주하지 않는다.

## 4. 전문 조작 화면 전환

다음처럼 별도 조작이 필요한 순간만 전문 화면으로 전환한다.

- 사건 전체 원인 정리: 가설 보드
- 시간순 기록 비교: 증거 비교 패널
- 안전 운용 규칙 시험: 노선 복원·미니게임
- 현장 회수 판단: 패턴 분류·근거·중립 행동 화면
- 출동 전 편성: 준비·자원 관리 화면
- 사건 종료: 결과·보고서 화면

전문 화면을 마치면 텍스트 노벨 흐름 또는 명시된 다음 화면으로 돌아간다.

## 5. 화면 보드 수정 계약

향후 `상황별 인게임 화면 명세 보드`에서는 다음을 지킨다.

- `SCREEN-02 핵심 플레이 화면`의 기본형은 텍스트 노벨 조사 화면이다.
- 현장 배경 위 자유 이동 캐릭터와 상시 HUD를 기본 화면처럼 표시하지 않는다.
- 조사 시퀀스는 배경·서술·초상·선택지·결과 텍스트의 변화로 보여준다.
- 가설 보드·회수·미니게임은 일반 화면이 아니라 전문 전환 화면으로 분리한다.
- 생성 이미지가 이 계약과 다르면 `PLACEHOLDER / REVISION_REQUIRED`로 표시한다.

## 6. 비주얼 방향 연결

- 현대 오컬트 조사기관의 다크 세미리얼 일러스트 톤
- 장소 배경은 현대 한국 도시·역사·골목·기관 내부의 현실감을 우선
- 인물은 역할별 포인트 컬러를 가진 반신·초상 중심
- UI는 기록국 문서·단말기 느낌을 유지하되 본문 가독성을 우선
- 발광 문양과 초현상 효과는 선택·위험·기록 갱신 순간에 제한적으로 사용

## 7. 금지

- 일반 조사를 액션 RPG식 자유 이동 화면으로 고정
- 조사보다 미니맵·스킬바·상시 전투 HUD를 크게 표시
- 텍스트 선택만 존재하면서 화면 변화가 없는 정적 문서 UI
- 전문 화면을 일반 플레이 화면과 한 화면에 과밀하게 합침
- 동료·장비·아카가 정답 선택지를 직접 표시

## 8. 데이터·구현 경계

이번 승인은 화면 표현과 UX 책임의 기획 기준선이다.

아직 승인하지 않은 항목:

- 실제 Scene·Node 구조
- 대사창의 정확한 크기·좌표·폰트 수치
- 선택지 개수의 모든 사건 공통 강제
- JSON·Resource Schema 변경
- 기존 자유 이동 코드 삭제
- Codex Goal·제품 구현
