## 1. 결정

괴이 사건의 조사·보고·피해자 구출·회수 전투는 서로 다른 정답 사본을 가지지 않는다. 모든 단계는 플레이어가 작성한 괴이 매뉴얼의 **단일 권위 상태**를 읽고, 단계에 맞는 밀도로만 표현한다.

```text
단일 괴이 매뉴얼 권위 상태
→ 조사·보고: 전체 괴이 매뉴얼 작업공간
→ 피해자 구출·회수 전투: 현행 규칙 스트립
→ 전체 매뉴얼 재열람
→ 사건 결과에 따른 공식 규칙·위험 사례 기록
```

### 조사·보고 단계

- 플레이어는 **전체 괴이 매뉴얼 작업공간**에서 후보 규칙을 편집한다.
- 발생 조건, 피해 연결, 금지 행동, 안전 행동, 지지 근거, 반박 근거, 미해결 질문, 현재 확신도를 함께 확인한다.
- 후보·확인·위험 사례·미해결 상태를 구분한다.
- 화면은 플레이어가 모은 정보와 작성한 가설만 표현하며 객관적 정답을 대신 작성하지 않는다.

### 피해자 구출·회수 전투 단계

- 활성 플레이 중 **현행 규칙 스트립**을 지속적으로 제공한다.
- 스트립은 별도 데이터나 별도 판정 권위를 갖지 않고 단일 괴이 매뉴얼 권위 상태에서 파생된다.
- 현재 선택·대상·전조와 **행동 관련**성이 높은 발생 조건, 금지 행동, 안전 행동을 우선 노출한다.
- 상세 근거와 반례는 필요할 때 확장하며, 화면 전체를 상시 점유하지 않는다.
- 플레이어의 가설과 관측 결과 사이에 새 모순 또는 규칙 위반이 생기면 원인과 영향을 **즉시 표시**한다.
- 즉시 표시는 관측된 충돌을 알릴 뿐, 숨은 진실이나 정답 규칙을 자동 판정하지 않는다.
- 전체 매뉴얼은 **단축키 또는 버튼**으로 다시 열 수 있다.

### 플랫폼 방향

- PC 기준선은 **PC 사이드 패널**과 확장 가능한 규칙 스트립이다.
- 향후 모바일은 같은 정보 구조를 **모바일 접이식 카드**로 변환한다.
- 모바일 구현은 PC 사람 검증 뒤로 연기하며 이번 승인으로 모바일 제작을 허가하지 않는다.

## 2. 정답 보호 규칙

- **정답 자동 공개 금지**: 스트립은 플레이어가 작성한 현재 가설, 확신도, 근거 상태와 관측된 모순만 표시한다.
- 능력치·태그·동료·장비·기록관 아카가 올바른 규칙을 대신 선택하지 않는다.
- 숨은 진실과의 불일치를 내부적으로 알고 있더라도 관측되지 않은 정답을 UI 문구로 누설하지 않는다.
- 후보 규칙이 틀렸더라도 완성된 가설로 구출·회수에 진입할 수 있으며, 결과와 위험 사례를 통해 책임을 지게 한다.
- 스트립과 전체 매뉴얼의 상태가 다르면 스트립이 아니라 단일 권위 상태를 기준으로 복구한다.

## 3. 접근성 계약

- 확신·모순·위험·금지·안전 상태는 **색상만으로 구분 금지**이며 라벨, 형태, 아이콘, 문구를 함께 사용한다.
- 키보드와 게임패드로 스트립 항목 이동, 확장, 전체 매뉴얼 열기, 원래 행동으로 복귀할 수 있어야 한다.
- 텍스트 확대에서도 핵심 행동과 규칙 상태가 가려지지 않아야 한다.
- 모션 감소에서는 흔들림·점멸 대신 정적 강조와 텍스트 알림으로 동일한 모순·위반 정보를 전달한다.
- 포커스는 스트립과 전체 매뉴얼 사이에서 갇히지 않고 이전 의미 위치로 복귀한다.

## 4. 적대적 보호 규칙

- 스트립을 전체 매뉴얼의 독립 정본으로 만들지 않는다.
- 스트립을 정답 오라클이나 자동 공략 목록으로 만들지 않는다.
- 모든 규칙을 항상 펼쳐 화면 과밀을 만들지 않는다.
- 전투 전조, 피해자 상태, 행동 대상과 비용을 가리지 않는다.
- 공포 연출을 이유로 실제 규칙 라벨과 경고를 읽을 수 없게 만들지 않는다.
- 모순 알림이 관측되지 않은 정답을 역산 가능하게 누설하지 않는다.
- 구출 성공이 회수 전투 자동 승리 또는 삭제로 이어지지 않는다.
