## 1. 결정 — 전조 → 패턴 시스템

회수 페이즈의 한 패턴 주기는 다음 **비대칭 정보 구조**를 사용한다.

```text
1턴: 전조 1 → 선택 → 평상 진행
2턴: 선택 → 전조 2 → 평상 진행
3턴: 선택 → 전조 3 → 평상 진행
4턴: 대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행
```

이 순서는 편의상 재배열하지 않는다. 특히 2턴과 3턴은 새 전조를 먼저 보고 선택하는 구조가 아니다.

## 2. 용어와 책임

### 평상 선택

1~3턴의 `선택`은 회수 페이즈의 평상 선택이다. 보호·관찰·공격·장비·봉쇄 준비·후퇴 준비 등 현재 허용된 평상 행동 중 하나를 고른다.

- 평상 선택은 해당 턴의 현장 상태와 결과 범위를 바꿀 수 있다.
- 평상 선택만으로 대기 중인 패턴을 조기 해결하지 않는다.
- 평상 행동 반복만으로 자동 승리 금지다.

### 평상 진행

`평상 진행`은 선택한 행동, 지속 효과, 보호 의무, 괴이의 일반 반응, 안정도·봉쇄·피해·자원 상태를 처리하는 구간이다.

- 패턴 전용 정답 판정은 평상 진행에서 산출하지 않는다.
- 4턴 결과 산출 뒤에도 평상 진행을 마친 후 다음 패턴 주기로 넘어간다.

### 전용 대응 선택

4턴의 `대응 선택`은 1~3턴의 평상 선택과 다른 전용 판단창이다.

- 세 전조를 모두 누적한 뒤에만 열린다.
- 현행 규칙 스트립과 괴이 매뉴얼 근거를 사용한다.
- 4턴에는 전용 대응 뒤 추가 평상 선택을 끼워 넣지 않는다.
- 대응 선택이 끝나면 고정된 패턴이 발현되고 결과를 산출한다.

## 3. 턴별 정보 계약

### 1턴

`전조 1 → 선택 → 평상 진행`

- 패턴 주기를 시작하고 `pattern_id`를 고정한다.
- 전조 1은 플레이어가 현재 주의해야 할 현상의 첫 관측을 제공한다.
- 플레이어는 전조 1과 기존 조사 근거를 바탕으로 평상 선택을 한다.

### 2턴

`선택 → 전조 2 → 평상 진행`

- 플레이어는 전조 1까지만 알고 평상 선택을 확정한다.
- **2턴과 3턴의 선택은 새 전조 공개 전에 확정**한다.
- 전조 2는 이미 확정된 2턴 선택을 소급 변경하지 않는다.
- 전조 2는 3턴 이후 판단을 위한 새 근거다.

### 3턴

`선택 → 전조 3 → 평상 진행`

- 플레이어는 전조 1·2를 바탕으로 평상 선택을 확정한다.
- 전조 3 역시 이미 확정된 선택을 소급 변경하지 않는다.
- 전조 3은 4턴 대응을 위한 마지막 근거다.

### 4턴

`대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행`

- 세 전조를 모두 누적한 상태에서 전용 대응 선택을 연다.
- 패턴 발현은 선택 결과로 새로 생성되지 않는다. 1턴에 고정된 객관적 패턴이 발현한다.
- 대응의 정오, 1~3턴 평상 행동의 준비 상태, 구출 결과에서 넘어온 보호 의무를 함께 반영해 결과를 산출한다.
- 결과와 평상 진행을 마친 뒤 다음 패턴 주기를 새 1턴부터 시작한다.

## 4. 전조 설계 원칙

**전조는 근거이지 정답 공개가 아니다.**

- 각 전조는 개별적으로 의미가 있어야 한다.
- 세 전조를 함께 읽으면 어떤 규칙과 대응을 검토해야 하는지 추론 가능해야 한다.
- 전조 1에서 정답을 사실상 확정하게 만들지 않는다.
- 전조 3이 정답 문구를 직접 제시하지 않는다.
- 예고되지 않은 결정적 규칙을 패턴 발현 순간 추가하지 않는다.
- 색상이나 음향만으로 전조를 구분하지 않는다.
- 전조 1·2·3은 공개 순서대로 로그에 유지한다.
- 현행 규칙 스트립과 전체 매뉴얼 열람은 행동 비용 없음이다.

전조 공개는 숨은 진실을 확정하는 것이 아니라 관측된 현상과 플레이어 가설을 대조할 근거를 추가한다.

## 5. 평상 행동과 패턴 정답의 관계

1~3턴 평상 행동은 패턴의 객관적 정답을 바꾸지 않는다.

- 보호는 피해자·요원·매개체의 피해 범위를 줄일 수 있다.
- 관찰은 전조 표현의 명료도나 기록 근거를 보강할 수 있다.
- 공격·제압은 현현체를 약화하거나 봉쇄 창구를 만들 수 있다.
- 장비는 결과 보정·보호·기록을 준비할 수 있다.
- 봉쇄 준비는 올바른 대응 후 결과 품질을 높일 수 있다.
- 후퇴 준비는 승인 철수의 손실 범위를 줄일 수 있다.

그러나 이 행동들은 패턴 정답을 바꾸지 않는다. 대응의 올바름은 괴이 규칙과 세 전조의 의미로 결정된다.

## 6. 결과 산출 범위

4턴 결과는 최소한 다음을 구분한다.

- 대응 정오
- 전조 근거 사용 여부
- 1~3턴 평상 행동으로 준비한 보호·관찰·봉쇄 상태
- 구출 결과 패킷의 보호 의무와 회수 초기 조건
- 요원·피해자·현장·매개체의 피해 또는 보존
- 안정화·봉쇄·잔향 회수 창구 변화
- 위험 사례와 다음 패턴 주기 조건

정확한 수치·공식·턴당 비용은 이번 Decision에서 승인하지 않는다.

## 8. 중단·철수 계약

- 4턴 전에 승인 철수나 긴급 봉쇄로 주기를 중단할 수 있다.
- 이 경우 공개된 전조와 평상 행동은 기록하지만 발현하지 않은 패턴의 정오 결과를 조작해 만들지 않는다.
- 상태는 `중단된 주기`로 남긴다.
- 대상·매개체·현장 상태가 객관적으로 사라져 패턴이 무효가 되면 명시적인 취소 결과를 기록한다.
- 진행 중 패턴을 다른 패턴으로 조용히 교체하지 않는다.

## 9. 접근성 계약

- 전조는 텍스트·아이콘·형태와 선택적 음향/모션으로 중복 전달한다.
- 모션 감소에서는 정적 패턴 발현을 제공한다.
- 전조 로그는 키보드·포인터·게임패드로 순서대로 탐색 가능해야 한다.
- 텍스트 확대에서도 전조 1·2·3의 순서와 현재 턴이 유지되어야 한다.
- 입력·시간·표현 등가 기능은 랭크 감점 대상이 아니다.

## 10. 현행 구조와의 관계

현재 구현은 패턴 하나를 선택한 뒤 단일 `telegraph`를 즉시 보여주고 곧바로 대응·결과 산출을 수행한다. 이는 본 Decision의 4턴 주기와 호환되지 않는 `LEGACY_RUNTIME_CONFLICT`다.

현재 Canon v2 회수 데이터는 패턴·전조·대응 의미를 제공하므로 내용 기반은 재사용할 수 있지만, 단일 `telegraph`를 저작된 세 전조 순서로 확장해야 한다.

기존 runtime과 단일 전조 데이터는 삭제하지 않고 이관 입력과 회귀 기준으로 보존한다. 존재 자체를 최신 4턴 구조 구현 완료로 표시하지 않는다.
