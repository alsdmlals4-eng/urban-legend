## 1. 결정

괴이기록국의 핵심 사건 화면은 다음 세 단계로 구분한다.

```text
텍스트 노벨 조사
→ 피해자 구출 미니게임
→ 턴제 회수 전투
```

### 조사 화면

- 기본 흐름은 `상황 설명 → 선택지`다.
- 선택지는 일반 선택, 특정 능력 요구, 태그 요구, 판정 요구, 지원 조건 요구 상태를 명확히 표시한다.
- 조사 선택 결과로 키워드를 획득한다.
- 획득 키워드는 규칙 문장을 구성하고 검증하는 데 사용한다.
- 플레이어 노출 패널명은 `추리문 진행`이 아니라 공식 용어인 **괴이 매뉴얼**로 통일한다.
- 괴이 매뉴얼 안에서 후보 규칙·확인된 규칙·위험 사례·미해결 항목을 구분한다.

### 피해자 구출 미니게임

- 미니게임의 공통 목적은 조사에서 파악한 규칙을 적용해 피해자를 구출하는 것이다.
- 각 핵심 괴담은 서로 다른 간단한 구출 조작을 사용한다.
- 구출 결과는 회수 전투의 피해자 상태·추가 보호 목표·괴이 고착·위험 사례에 환류한다.

### 회수 전투 화면

- 전투의 메인 상단·중앙 공간에는 대상 괴이만 지속적으로 표시한다.
- 플레이어 캐릭터 전신은 전장에 상시 배치하지 않는다.
- 아군은 하단의 초상·상태·스킬 UI로 표현한다.
- 캐릭터는 스킬 사용 시에만 하단에서 짧은 컷인 연출로 등장한다.
- 기본 행동군은 `보호·관찰·대응·공격·장비·봉쇄`다.
- 공격은 현현체·매개체 약화와 대응·봉쇄 기회 생성에 사용하며, 기본 승리 조건은 괴이 HP 0 처치가 아니라 안정화와 회수다.

## 2. 화면 흐름 기준선

```text
상황 설명
→ 조건이 표시된 조사 선택지
→ 키워드 획득
→ 괴이 매뉴얼 후보 규칙 갱신
→ 피해자 구출 미니게임
→ 괴이 단독 중심 회수 전투
→ 안정화·봉쇄·잔향 회수
→ 공식 규칙·위험 사례 기록
```

## 3. UX 가변 범위

이번 승인은 화면의 정보 위계와 표현 방향에 대한 기준선이다. 다음은 후속 UX 설계와 사람 검증에서 수정할 수 있다.

- 패널의 정확한 위치·크기·비율
- 한 화면에 노출하는 선택지 수
- 괴이 매뉴얼의 탭·접기·오버레이 방식
- 캐릭터 컷인의 크기·방향·지속 시간
- 전투 로그·규칙 패널·피해자 상태의 위치
- 키보드·마우스 입력과 단축키
- 해상도별 반응형 배치
- 애니메이션·사운드·화면 전환 속도

## 4. 적대적 보호 규칙

- 조사 화면을 복잡한 대시보드로 만들어 상황 설명과 선택지를 밀어내지 않는다.
- 능력·태그·판정 요구를 숨기지 않으며, 잠금 이유와 필요한 조건을 선택 전에 보여 준다.
- 판정이 핵심 규칙의 진위를 무작위로 바꾸지 않는다. 판정은 정보량·비용·위험·우회 경로를 조정한다.
- `괴이 매뉴얼`이라는 명칭 때문에 미확정 가설을 공식 규칙처럼 표시하지 않는다.
- 구출 미니게임 성공이 회수 전투를 삭제하거나 자동 승리로 바뀌지 않는다.
- 전투에서 괴이 단독 구도를 사용하더라도 아군 상태·행동 순서·대상·다음 행동 전조를 읽기 어렵게 만들지 않는다.
- 컷인 연출이 괴이의 전조·대상·피해 결과를 가리거나 전투 흐름을 과도하게 지연하지 않는다.
- 공격만 반복해 사건을 해결할 수 없고, 관찰·대응·보호·봉쇄가 실제 승리 조건에 기여해야 한다.

- Production 확대
