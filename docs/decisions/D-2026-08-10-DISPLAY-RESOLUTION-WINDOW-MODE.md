# D-2026-08-10-DISPLAY-RESOLUTION-WINDOW-MODE

## Decision

괴이기록국 PC 설정 화면에 해상도와 표시 모드를 추가한다.

승인 기본값:

- 해상도: `1280×720`, `1600×900`, `1920×1080`
- 표시 모드: `창 모드`, `전체화면`
- 설정은 런타임에서 적용되고 사용자별 설정으로 저장된다.
- 현재 `project.godot`의 1280×720 viewport와 `canvas_items + expand` 기준은 유지한다.

## Ownership

디스플레이 설정은 접근성 효과 강도 저장과 분리된 전용 설정 소유자가 담당한다. 기존 `AccessibilitySettings`는 화면 흔들림·섬광·공포 왜곡만 계속 소유한다.

## UX

`설정 / 접근성` 패널에서 다음을 한 영역에 제공한다.

1. 표시 모드 선택
2. 해상도 선택
3. 적용 결과가 즉시 반영됨
4. 재실행 후에도 마지막 선택 유지

지원 목록 밖의 저장값이나 현재 모니터에서 적용할 수 없는 값은 안전한 기본값 `1280×720 / 창 모드`로 복구한다.

## Scope

포함:

- PC 표시 모드와 해상도 선택
- 사용자 설정 저장/로드
- 설정 UI
- 1280×720, 1600×900, 1920×1080 회귀 검증

제외:

- 렌더 스케일, FPS 제한, VSync, HDR, 다중 모니터 선택
- 모바일/Android 표시 설정
- 기존 접근성 효과 의미 변경

## Evidence

- 2026-08-10 Windows Human QA 중 사용자가 게임 창 크기 변경을 설정에서 직접 지원해 달라고 요청했다.
- 현재 `project.godot`은 1280×720 viewport와 `canvas_items + expand`를 사용한다.
- 현재 `설정 / 접근성` 패널은 화면 흔들림·섬광·공포 왜곡만 제공한다.

## Implementation gate

Persistent Godot authoring은 프로젝트 계약에 따라 HiGodot 권위를 사용한다. 구현 전 TDD 계획과 회귀 기준을 확정한다.
