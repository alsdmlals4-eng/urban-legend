## 1. 메인 콘텐츠 권위

괴이기록국의 메인 콘텐츠는 다음 사건 플레이 루프다.

```text
괴이 사건 진입
→ 조사
→ 기록 비교·가설
→ 위험 검증
→ 회수
→ 안정화·사건 종결
→ 결과·기록·환류
```

간결 표현:

> 메인 콘텐츠 = 괴이 사건에 진입해 `조사`와 `회수`를 수행하는 것.

`조사`에는 관측, 기록 비교, 가설 구성, 위험 검증이 포함된다. `회수`에는 전조 해석, 대응, 안정화·봉쇄·포획 창 개방, 잔향 회수가 포함된다.

## 2. 일정·육성의 역할

일정, 동료, 장비, 연구, 관계, 기관 지원은 메인 콘텐츠를 대체하지 않는다.

이들은 다음을 담당하는 지원·준비·환류 계층이다.

- 사건 진입 전에 위험과 선택 폭을 조정
- 조사 가능한 질문·경로·보호 범위를 확장
- 회수에서 허용되는 대응·복구·지원 조건을 조정
- 사건 결과를 다음 사건 준비에 반영
- 권나래의 장기 성장과 관계 변화를 표현

따라서 다음 표현은 금지한다.

- 일정 편성이 게임의 메인 콘텐츠라고 설명
- 자동 일정 결과만으로 핵심 사건을 해결
- 사건 플레이보다 일정 소비 시간이 더 큰 기본 구조
- 일정·능력치가 조사 정답이나 회수 정답을 대신함

## 3. 계층 구조

```text
메인 콘텐츠
- 괴이 사건
  - 조사
  - 추론·검증
  - 회수
  - 결과 기록

지원 계층
- 일정·육성
- 동료·관계
- 장비·연구
- 기관·보급
- 저장·복귀
```

지원 계층은 메인 콘텐츠를 더 깊고 다양하게 만들기 위해 존재한다. 지원 계층 자체가 비대해져 사건 코어를 가리면 범위 오류로 판정한다.

## 4. 분기 캠페인 적용

각 분기의 핵심 괴담 1개는 반드시 완전한 `조사 → 회수 → 안정화·종결` 경험을 제공한다.

분기 사이의 일정·육성은 다음 핵심 사건을 준비하고 이전 사건의 결과를 환류하는 연결부다. 일정만 진행하고 핵심 괴담을 자동 처리하는 분기는 허용하지 않는다.

## 5. 미니게임과의 관계

분기별 전용 미니게임은 조사 또는 회수 안에 배치한다.

- 조사 미니게임: 규칙 가설의 남은 불확실성을 검증
- 회수 미니게임: 조사에서 확인한 규칙을 현장 행동으로 적용

미니게임은 사건 흐름과 별개인 부가 아케이드가 아니다.

## 6. 기존 코어와의 관계

이 결정은 기존 프로젝트 코어의 다음 인과를 재확인한다.

```text
관측 → 가설 → 위험 검증 → 전조 → 대응 → 포획 → 매뉴얼
```

연도제·일정 시스템은 이 인과의 앞뒤에 연결되는 지원 구조이며, 이를 대체하거나 상위 권위로 덮어쓰지 않는다.
