## 1. 승인 결정

괴이기록국의 캐릭터와 주요 화면은 **다크 현대 오컬트 + 세미리얼 애니 일러스트**를 기본 그림체로 사용한다.

핵심 특징:

- 성인형의 슬림하고 긴 인체 비율
- 현대 전술복·제복·코트와 퇴마·마법 장비의 결합
- 짙은 남색·검정·회색 기반과 역할별 포인트 색
- 절제된 발광 문양·기록 노이즈·초현상 흔적
- 기록국 문서·관제 단말기·현장 태블릿 감각의 UI
- 일반 조사에서는 배경·서술·반신·선택지를 우선하고 전신은 소개·편성·핵심 연출에 제한

책임 원본:

- `docs/visual/VISUAL_ART_DIRECTION.md`

## 2. 레퍼런스 경계

사용자 제공 이미지는 스타일의 밀도·비율·현대 오컬트 결합·역할별 색 구분을 설명하는 참고 자료다.

- 이미지 자체를 제품 에셋으로 사용하지 않는다.
- 인물·의상·장비·문양·레이아웃을 그대로 복제하지 않는다.
- 실제 에셋은 프로젝트 고유 요소로 새로 설계하고 권리·유사성 검수를 거친다.
