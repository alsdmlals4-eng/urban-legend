## 결정

접근성 기능은 사용 여부가 아니라 **플레이어가 평가 대상인 판단을 직접 수행하는지**를 기준으로 랭크와 업적에 반영한다.

화면·음향·입력·시간을 다른 방식으로 제공하면서 관찰·추리·보호·대응·기록의 판단을 보존하는 **접근성 등가 기능**은 일반 클리어, C/B/A/S 랭크와 업적에 완전히 중립이다.

정답 키워드 공개, 미니게임 자동 완료, 전투 대응 자동 선택처럼 판단 또는 해법 자체를 시스템이 대신하는 기능은 일반 클리어와 핵심 서사를 차단하지 않는다. 다만 자동 해결이 대신한 해당 숙련 관문은 플레이어가 직접 충족한 것으로 처리하지 않으며, 가능한 경우 동일한 판단 능력을 검증하는 접근성 등가 과제로 대체한다.

## 기능 분류

### 1. 표현·정보 접근 기능

예시:

- 화면 낭독
- 자막과 비언어 소리 표시
- 글자·아이콘 확대
- 고대비·색각 옵션
- 진동·섬광 조절
- 키 재배치

처리:

```text
일반 클리어 영향 없음
종합 랭크 영향 없음
S 랭크 영향 없음
업적 영향 없음
```

### 2. 입력·시간 등가 기능

예시:

- 연타를 길게 누르기로 전환
- 버튼 유지와 토글 전환
- 입력 시간 확대
- 게임 속도 조절
- 대상 선택 보조
- 미니게임 입력 단순화

플레이어가 규칙을 이해하고 대상과 대응을 직접 선택한다면 모든 랭크와 업적에 중립이다. 괴이기록국의 숙련은 입력 속도가 아니라 관찰·추리·보호·대응·기록으로 평가한다.

### 3. 판단·해법 자동 해결 기능

예시:

- 정답 키워드 자동 공개
- 올바른 조사 선택지 자동 강조
- 피해자 구출 미니게임 완전 자동 완료
- 전투 대응 자동 선택
- 봉쇄 절차 자동 실행

처리:

- 일반 클리어와 캠페인 진행 가능
- 이야기·수집·관계 업적 획득 가능
- 자동 해결과 관계없는 평가축은 정상 평가
- 자동 해결이 대신한 숙련 관문은 직접 충족으로 처리하지 않음
- 접근성 등가 과제를 완료하면 해당 관문과 S 랭크를 충족할 수 있음

## 접근성 등가 과제

접근성 등가 과제는 원래 입력 방식이 아니라 같은 판단 능력을 검증해야 한다.

예시:

```text
빠른 타이밍 입력
→ 제한 시간 없는 순서 선택형 대체
→ 같은 괴이 규칙 이해를 검증
→ S 랭크 가능
```

```text
복잡한 연타 구출 조작
→ 단계별 대상·행동 선택형 대체
→ 피해자 보호 판단을 직접 수행
→ S 랭크 가능
```

```text
정답 키워드 자동 공개
→ 추론을 시스템이 대신함
→ 조사 정확도 정밀 관문 미충족
→ 다른 평가축과 일반 클리어는 정상 처리
```

## 필수 제작 원칙

> S 랭크에 필요한 모든 핵심 행동에는 출시 전에 접근 가능한 등가 수행 방식이 최소 하나 존재해야 한다.

동일한 판단을 검증하는 등가 수행 방식을 만들 수 없는 운동·감각 과제는 S 랭크 필수 조건에서 제거한다.

## 보호 규칙

1. 화면 낭독·자막·고대비·색각·키 재배치 등은 모든 랭크와 업적에 중립이다.
2. 시간 확대·게임 속도 조절·연타 대체도 판단을 보존하면 중립이다.
3. 접근성 프리셋 사용 자체를 결과 보고서에서 경고하거나 감점하지 않는다.
4. 장애 여부 증명이나 의료 정보 입력을 요구하지 않는다.
5. 자동 해결도 일반 클리어와 핵심 서사를 차단하지 않는다.
6. 자동 해결이 대신하지 않은 평가축은 정상 평가한다.
7. 자동 해결이 대신한 숙련 관문에는 가능한 경우 등가 과제를 제공한다.
8. 등가 과제를 완료하면 S 랭크와 관련 업적을 획득할 수 있다.
9. 등가 수행 방식을 만들 수 없는 운동·감각 과제는 S 필수 조건에서 제외한다.
10. 각 기능을 사용하기 전에 랭크·업적 영향 여부를 명확히 표시한다.
11. 접근성 기능을 사용하지 않는 플레이에 별도 우월 칭호나 보상을 부여하지 않는다.
12. 무보조·시간 단축 같은 도전은 종합 랭크가 아닌 별도 선택 업적으로만 운용할 수 있다.
13. 자동 해결은 접근성 기능과 난이도 완화를 이유로 조롱하거나 낮은 등급명을 붙이지 않는다.
14. 기능별 등가성과 실제 사용성은 장애 당사자·접근성 컨설턴트를 포함한 사람 검증 전까지 `NOT_VALIDATED`다.
15. 구현·사람 검증·POC 통과는 별도 승인 전까지 선언하지 않는다.

## 적대적 검토

### 방지하는 실패

- 화면 낭독·색각 모드·키 재배치를 부정행위처럼 취급하는 배제
- 입력 속도를 추리·판단 숙련으로 오인하는 랭크 설계
- 자동 정답 공개와 표현 접근 기능을 같은 범주로 처리하는 오류
- 접근성 옵션 사용을 결과 화면에 낙인처럼 표시하는 문제
- S 랭크 필수 조건에 대체 불가능한 운동·감각 과제를 두는 문제
- 자동 해결 하나 때문에 관계없는 평가축까지 전부 무효화하는 과잉 처벌

### 남은 미확정

- 기능별 접근성 등가 과제의 구체 설계
- 자동 해결 기능의 정확한 목록과 UI 분류
- 축별 최소·상위·최고 관문의 상세 조건
- 사건별 정상 종결 실패·치명적 결과·랭크 상한 표
- 최고 랭크·업적·숙련 보상 범위
- 판정 모델
- 저장·클라우드 충돌 복구와 세부 UX
- 장애 당사자·접근성 컨설턴트 검증 계획
