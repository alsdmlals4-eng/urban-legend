## 1. 결정

각 분기 핵심 사건은 하나의 종결 상태와 `지식·관계/기관·현장` 세 축의 결과 패킷을 남긴다.

```text
사건 종결
→ 분기 결과 패킷 생성
→ 다음 분기에 필요한 결과 최소 2축 활성화
→ 겨울에는 3축 모두 활성화
→ 연도 결산 기록 생성
→ 대표 결과를 2년차로 계승
```

모든 세부 결과는 사건 보고서와 괴이 매뉴얼에 보존한다. 다음 분기의 실제 플레이에 직접 작용하는 주 결과는 축마다 최대 1개로 제한해 상태 폭발을 통제한다.

## 2. 사건 종결 상태

| 상태 | 의미 |
|---|---|
| 정밀 안정화 | 피해 최소화·핵심 규칙 검증·안정적인 잔향 회수 |
| 안정화 | 현재 사건 종결·일부 비용이나 후유증 존재 |
| 불완전 안정화 | 사건은 봉쇄했으나 피해·재출현·미해결 규칙이 남음 |
| 기관 강제 봉쇄 | 플레이어 출동 실패 뒤 기관 개입으로 진행은 보존되지만 큰 장기 비용이 남음 |

`기관 강제 봉쇄`는 성공으로 위장하지 않는다. 피해·기관 압박·관계 변화·재출현 조건·추가 보호 목표를 다음 분기로 넘긴다.

## 3. 결과 패킷 세 축

### 지식

- 확인된 공식 규칙
- 위험 사례
- 미해결 질문
- 재출현 대응 절차
- 연구 가능한 현상

### 관계·기관

- 동료 신뢰와 갈등
- 피해자·유족·민간과의 관계
- 기록국 내부 평가
- 외부 세력의 협력 또는 불신
- 책임 부담 주체

### 현장

- 피해자 상태
- 회수된 잔향과 안정도
- 놓친 피해 경로
- 재출현 조건
- 남은 현장 오염·보호 대상

## 4. 활성 후속 결과 계약

활성 결과는 단순 능력치 보너스로만 처리하지 않는다. 다음 분기에서 최소 하나의 실제 조건으로 나타나야 한다.

- 새로운 선택지 또는 접근법
- 기존 선택지의 비용 변화
- 추가 조사 기회
- 사용 가능한 동료·기관 지원
- 반드시 보호해야 하는 대상
- 위험도 상승 조건
- 전투 중 추가 대응 행동
- 피해자 구출 미니게임 시작 상태
- 사건 종료 뒤 책임 선택

과거 성공은 현재 괴담의 정답을 자동 공개하지 않는다. 과거 실패는 필수 진행이나 유일한 정답을 영구 잠그지 않는다.

## 5. 분기별 환류

### 봄 → 여름

저승역의 결과에서 최소 두 축을 사용한다.

- 공식 기록과 개인 기억의 불일치 경험
- 조기 이동 위험 사례
- 동료 신뢰와 기록 절차 준수
- 피해자 보호 우선 여부
- 잔향과 재출현 조건

여름에는 반사와 실제 행동을 구분하는 조사 접근, 보호·격리 지원, 추가 위험 경고, 구출 시작 상태 등으로 반영한다.

### 여름 → 가을

빨간 우산의 결과에서 최소 두 축을 사용한다.

- 호위·격리 역할 배치 결과
- 동료에게 전이된 마른 흔적
- 피해자와 현장 요원 사이의 우선순위
- 우산 잔향 회수 여부
- 기억 후유증과 재출현 위험

가을에는 음성 피해자 반환과 추가 피해 차단의 비용, 동료 기술 제한, 외부 기관 압박, 민간 보호와 증거 보존의 충돌로 반영한다.

### 가을 → 겨울

겨울은 지식·관계/기관·현장 세 축을 모두 사용한다.

- 공식 규칙·위험 사례·미해결 질문·잘못 작성했던 후보 규칙
- 기록을 신뢰하는 인물과 기관 불신
- 독립 원본을 제공할 외부 협력
- 회수 잔향의 안정도와 남은 재출현 조건
- 후유증 피해자와 미완료 보호 책임

겨울에는 조사 기록 종류, 독립 원본 접근, 구출 대상 수와 상태, 회수 전투 보호 목표, 괴이가 점유할 권위 매체, 봉쇄 뒤 책임 처리 선택이 달라진다. 과거 기록은 비교 근거이며 현재 사건의 자동 정답이 아니다.

## 6. 실패 전진과 철수

### 즉시 복구 가능한 실패

- 첫 오판
- 피해자 구출 부분 실패
- 잘못된 전투 대응
- 일부 피해 증가

### 불완전 종결

- 피해자 후유증
- 잔향 일부 미회수
- 재출현 조건 잔존
- 관계 갈등
- 위험 사례 추가

### 기관 강제 봉쇄

```text
플레이어 출동 실패
→ 기관 긴급 봉쇄
→ 분기 핵심 사건 불완전 종결
→ 큰 후유증과 책임을 다음 분기로 이동
```

기관은 플레이어 대신 완벽하게 해결하지 않는다. 개입은 캠페인 진행을 보존하지만 더 큰 장기 비용을 남긴다.

## 7. 연도 결산

연말 평가는 단일 점수·선악 등급·S~D 랭크로 처리하지 않는다.

다음 네 관점을 결산한다.

1. 조사 방식 — 공식 기록·개인 기억·위험 검증·미해결 보존
2. 피해자 보호 — 구조 인원·후유증·보호 우선순위·회복하지 못한 피해
3. 관계·기관 — 동료 신뢰·기관 평가·외부 관계·명령과 현장 판단의 충돌
4. 괴이 기록 — 공식 규칙·위험 사례·미해결 질문·회수 잔향·재출현 가능 사건

연말에는 다음 조합으로 복합 요원 기록을 생성한다.

```text
조사 성향
+ 보호 원칙
+ 기관 내 위치
+ 남은 책임
```

연도 결산은 플레이어의 행동을 설명하며 도덕적 정답이나 단일 최고 등급을 선언하지 않는다.

## 8. 2년차 계승

모든 사건 보고서와 괴이 매뉴얼은 보존한다. 2년차 초반에 직접 활성화하는 대표 결과는 다음으로 제한한다.

```text
지식 대표 결과 1개
관계·기관 대표 결과 1개
현장 대표 결과 1개
1년차 요원 성향 기록
```

나머지 결과는 삭제하지 않고 기록 보관소·후일담·후속 사건에서 필요할 때 불러온다.

다음 항목은 2년차에 반드시 보존한다.

- 공식 규칙
- 위험 사례
- 미해결 질문
- 회수하지 못한 잔향
- 피해자 후유증
- 동료·기관 관계
- 플레이어가 선택한 책임

겨울 성공은 이를 초기화하지 않는다.

- 활성 결과는 다음 분기에서 실제 조건·선택·비용으로 사용한다.
- 과거 성공이 현재 사건 정답을 공개하지 않는다.
- 과거 실패가 필수 진행을 잠그지 않는다.
- 기관 강제 봉쇄가 플레이어 실패를 완전 해결하지 않는다.
