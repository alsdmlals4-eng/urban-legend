## 1. 결정

하루 일정은 `주요 활동 1개 + 기본 휴식` 구조를 유지한다.

다만 기본 휴식과 의도적으로 선택하는 전일 회복·치료는 서로 다른 책임을 가진다.

```text
기본 휴식
= 매일 자동 적용되는 소량 피로 회복

전일 회복·치료
= 필요할 때 주요 활동으로 선택하는 큰 회복
```

## 2. 기본 휴식

기본 휴식은 플레이어가 매일 별도 선택하지 않는다.

- 모든 정상 진행일에 자동 적용한다.
- 주요 활동과 다일 활동 진행일에도 적용한다.
- 작은 피로 회복만 담당한다.
- 관계·성향·전문성·연구·장비·기관 지원을 증가시키지 않는다.
- 부상·중상·불안 등 상태 태그를 단독으로 치료하지 않는다.
- 핵심 단서·가설·사건 조건·특수 이벤트를 생성하지 않는다.
- 일정 UI에서는 소형 고정 표시 또는 예상 변화 합계에 포함한다.

기본 휴식은 두 번째 활동 슬롯이나 별도 일상 활동 카탈로그가 아니다.

## 3. 전일 회복·치료

전일 회복·치료는 하루의 주요 활동을 소비한다.

- 큰 피로 회복을 제공한다.
- 조건을 충족하면 경상·불안 등 허용된 상태 태그의 치료를 진행한다.
- 중상·특수 후유증은 기관 치료·연구·사건 후속 조건을 별도로 요구할 수 있다.
- 고정 사건·강제 출동·이미 시작된 다일 활동과 충돌하면 선택할 수 없다.
- 관계·연구·훈련의 대체 보상을 제공하지 않는다.
- 회복 수치는 기본 휴식이 함께 적용되는 것을 전제로 설계한다.

UI는 `전일 회복 효과 + 해당 날짜 기본 휴식`의 총 예상 변화를 확정 전에 보여준다.

## 4. 기존 계약의 해석

### ANNUAL PoC

- 빈 날짜·남은 일수의 자동 휴식은 `기본 휴식`의 역사적 구현으로 본다.
- 직접 선택하는 1일 휴식은 `전일 회복·치료`의 선행 구현으로 본다.
- 기존 수치와 주간 일괄 확정 방식은 `CURRENT_IMPLEMENTATION_LEGACY`이며 제품 일일 일정의 최종 수치가 아니다.

### 기존 preparation_scene

반일 `대기·회복`은 현재 제품 흐름의 레거시 계약이다.

- Validation 축약 준비에서는 일정 선택으로 노출하지 않는다.
- 향후 SCREEN-05 일일 일정의 전일 회복·치료로 책임을 이관한다.

## 5. 금지 사항
