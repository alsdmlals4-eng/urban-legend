# D-2026-08-03-INCIDENT-CHECKPOINT-RETRY-AND-CANON-CONFIRMATION

## 결정

사건 결과가 캠페인 정본으로 확정되기 전에는 **구간 체크포인트 + 제한적 즉시 복구 + 결과 보고서의 명시적 확정 Gate**를 사용한다.

선택 결과나 전투 행동을 확인한 뒤 한 단계씩 자유롭게 되감는 기능은 기본 제공하지 않는다. 대신 단순 조작 실수와 반복 피로를 줄이기 위해 조사 소단락, 피해자 구출 시작, 회수 전투 시작을 주요 체크포인트로 사용한다.

## 조사

- 조사 선택을 확정하기 전에는 취소하거나 다른 선택지를 확인할 수 있다.
- 결과 문장이 출력되고 키워드·시간·피로·위험 등 사건 상태가 반영되면 해당 선택은 확정된다.
- 확정된 선택을 결과 확인 뒤 한 단계만 되돌리는 기능은 기본 제공하지 않는다.
- 조사 장면 또는 소단락 시작 체크포인트에서 다시 시작할 수 있다.
- 이미 본 대사와 설명은 빠른 넘김을 지원한다.

## 피해자 구출 미니게임

- 첫 실패는 즉시 재시도할 수 있다.
- 재시도 시 핵심 조작과 실패 원인을 다시 안내한다.
- 반복 실패 시 일반 클리어를 막지 않는 접근성 대체 또는 완화 옵션을 제공한다.
- 미니게임 재시도는 이미 확정된 조사 결과까지 되돌리지 않는다.
- 접근성 대체 사용 여부와 최고 랭크 처리 기준은 후속 Spec에서 별도로 정의한다.

## 회수 전투

- 회수 전투 시작 체크포인트를 제공한다.
- 전투 패배 시 전투 시작부터 즉시 재시도할 수 있다.
- 턴 단위 자유 되감기는 기본 제공하지 않는다.
- 대상·장비 소비·봉쇄 시도 등 중대한 행동은 실행 전 확인과 결과 예측 정보를 제공해 오입력을 줄인다.
- 전투 재시도는 조사와 피해자 구출 결과를 자동으로 되돌리지 않는다.

## 사건 정본 확정 Gate

```text
회수 전투 종료
→ 사건 결과 보고서 확인
→ 결과 확정 또는 출동 재개 선택
→ 결과 확정 시 캠페인 정본 저장
```

### 결과 확정

- 현재 사건 종결 상태, 네 평가축, 종합 랭크, 피해자 상태, 관계·기관 변화, 결과 패킷을 캠페인 정본으로 저장한다.
- 결과 확정 뒤에는 일반 재도전인 기록 재현 또는 별도 캠페인 되감기 규칙을 적용한다.

### 출동 재개

- 캠페인 정본이 생성되기 전에 마지막 주요 체크포인트로 복귀한다.
- 사건당 1회만 사용할 수 있다.
- 복귀 시 폐기되는 진행과 유지되는 준비 상태를 사전에 표시한다.
- 모든 선택 결과를 순차적으로 시험하는 자유 되감기 수단으로 사용할 수 없다.

## 자동 저장

자동 저장은 최소 다음 지점에 생성한다.

- 조사 소단락 또는 주요 장면 시작
- 조사 선택 결과 반영 뒤
- 피해자 구출 시작
- 회수 전투 시작
- 사건 결과 보고서 진입 직전
- 캠페인 결과 확정 직후

자동 저장 슬롯 수, 수동 저장 범위, 백업 정책은 구현 Spec에서 확정한다.

## 보호 규칙

1. 선택 결과 반영 뒤 선택 단위 즉시 취소는 허용하지 않는다.
2. 조사 소단락·피해자 구출 시작·회수 전투 시작에 주요 체크포인트를 둔다.
3. 이미 본 텍스트는 빠르게 넘길 수 있다.
4. 피해자 구출 미니게임 첫 실패는 즉시 재시도할 수 있다.
5. 전투 패배는 전투 시작부터 재시도할 수 있다.
6. 턴 단위 자유 되감기는 기본 제공하지 않는다.
7. 중요 행동은 실행 전 확인·대상·예상 결과를 명확히 표시한다.
8. 사건 결과 보고서에서 `결과 확정`을 선택해야 캠페인 정본이 생성된다.
9. 결과 확정 전 `출동 재개`는 사건당 1회 마지막 주요 체크포인트 복귀로 제한한다.
10. 결과 확정 뒤에는 기록 재현 또는 캠페인 되감기 계약을 따른다.
11. 접근성 완화 기능을 사용해도 일반 클리어와 캠페인 진행은 가능하다.
12. 접근성 옵션이 최고 랭크·업적에 미치는 영향은 숨기지 않고 후속 Spec에서 명시한다.
13. 체크포인트 재시작이 능력·태그 요구나 사건 규칙을 우회하는 수단이 되지 않게 한다.
14. 확정 전 복귀와 확정 후 캠페인 되감기를 같은 용어·버튼으로 혼동시키지 않는다.

## 적대적 검토

### 방지하는 실패

- 모든 선택 결과를 본 뒤 되돌려 정답만 남기는 최적 플레이
- 조사 불확실성·판정 실패·위험 사례의 의미 상실
- 긴 텍스트와 미니게임을 사소한 오입력 때문에 전부 반복
- 전투 대상 오선택이나 UI 오입력을 서사적 책임으로 오인
- 결과 화면을 봤다는 이유만으로 원하지 않은 캠페인 정본이 자동 저장됨
- 무제한 출동 재개로 최고 랭크를 사실상 한 출동에서 강제 파밍
- 확정 전 복구와 확정 후 서사 되감기의 데이터 혼합

### 남은 미확정

- 캠페인 되감기 해금 시점·횟수·비용
- 출동 재개가 돌아가는 `마지막 주요 체크포인트`의 사건별 정의
- 접근성 완화 사용 시 최고 랭크·업적 처리
- 수동 저장과 자동 저장 슬롯 정책
- 축별 상세 관문과 사건별 랭크 상한
- 결과 확정·출동 재개 화면의 세부 UX
