## 1. 결정

네 사건은 공통 메인 흐름과 공통 UI·행동군을 유지하되, 조사부터 회수 전투까지 하나의 대표 위협 문법을 일관되게 사용한다.

```text
텍스트 노벨 조사
→ 키워드 획득
→ 괴이 매뉴얼 구성
→ 피해자 구출 미니게임
→ 턴제 회수 전투
→ 안정화·봉쇄·잔향 회수
```

| 분기 | 핵심 괴담 | 대표 위협 문법 |
|---|---|---|
| 봄 | 저승역 | 순서와 이동 시점 |
| 여름 | 비 오는 골목의 빨간 우산 | 대상과 역할의 전이 |
| 가을 | 폐주파수 방송국 | 응답과 송수신 구간 |
| 겨울 | 기록되지 않은 병동 | 기록 권위와 존재 대체 |

## 2. 공통 조사·괴이 매뉴얼 계약

조사는 `상황 설명 → 조건 표시 선택지 → 결과 문장 → 키워드 획득`으로 진행한다.

괴이 매뉴얼은 다음 문장군을 구성한다.

1. 발생 조건
2. 피해 연결 방식
3. 금지 행동
4. 피해자 구출 절차
5. 회수 전투 대응

키워드는 `후보·확인·위험 사례·미해결` 상태를 구분한다. 능력·태그·판정은 진실을 무작위로 바꾸지 않으며, 실패 시 조사 시간·위험도·우회 단서·부분 키워드·검증 비용·동료 지원 기회가 달라진다.

## 3. 사건별 계약

### 봄 — 저승역 / 순서

- 조사: 목적지 공백·개인 목적지·공식 노선 번호·종료 식별음·조기 이동·위치 초기화를 분리한다.
- 구출: 공식 기준으로 안전 경로를 복원한 뒤 안내 종료 후 이동시킨다.
- 전투: 괴이 행동 순서와 종료 시점을 관찰하고, 피해자의 강제 이동을 보호하며, 공식 번호 고정과 종료 식별음 뒤 봉쇄를 수행한다.
- 공격은 스피커 잔향·검은 승차권·현현체 약화에 사용한다.

### 여름 — 비 오는 골목의 빨간 우산 / 전이

- 조사: 세 번째 빗소리·선행 반사·젖은 손자국·마른 발자국·귀가 기억·전이 대상을 분리한다.
- 구출: 반사 차단·우산 격리·피해자 호위·마른 흔적 감시 역할을 배치한다.
- 전투: 반사상이 예고하는 대상과 이동하는 표식을 관찰하며 보호·격리·대응한다.
- 공격은 우산 현현체와 손자국 연결을 약화하며, 세 번째 박자 오공격은 공격자를 새 전이 대상으로 만들 수 있다.

### 가을 — 폐주파수 방송국 / 응답

- 조사: 빈 호출문·음성 응답·이름 복사·조립된 사연·원본 음성·송수신 동시 무음을 분리한다.
- 구출: 고정할 무음 구간·반환할 원본 음성·차단할 채널과 보호 범위를 선택한다.
- 즉시 전체 차단과 기존 피해자 목소리 반환은 완전 양립하지 않을 수 있으며, 결과와 대가를 선택 전에 표시한다.
- 전투: 채널 상태를 관찰하고 음성 응답을 금지하며, 비언어 신호·무음 고정·가짜 명령 거부를 사용한다.
- 음성형 스킬 여부는 사용 전에 명확히 표시한다.

### 겨울 — 기록되지 않은 병동 / 기록 권위

- 조사: 반복 누락·기록에 없는 병상·충돌 신원·독립 원본·대체 보호 관계·보존해야 할 공백을 구분한다.
- 과거 세 사건 기록은 비교 근거와 위험 사례이며 현재 규칙의 자동 정답이 아니다.
- 구출: 확인 사실·충돌 기록·보존할 공백·타인을 밀어내는 위험 복구를 분류하고 복구 순서를 정한다.
- 전투: 괴이가 점유한 문서·단말·환자 팔찌·안내 표지를 관찰하고, 독립 사본으로 존재를 보호하며, 자동 동기화 중단·충돌 기록 유지·대체 관계 해제를 수행한다.
- 기록 자체를 무차별 파괴하지 않고 현현체와 침식 연결만 공격한다.

## 4. 공통 회수 전투 승리 계약

```text
피해자 구출 또는 보호 상태 확보
+ 대표 규칙 관찰
+ 사건 고유 대응 성공
+ 현현체·매개체 약화
+ 봉쇄 조건 달성
= 안정화·잔향 회수
```

공격 반복만으로 기본 승리할 수 없지만, 공격은 행동 중단·연결 약화·대응 틈 생성·봉쇄 창 유지에 실질적으로 기여한다.

## 5. 실패 전진

- 정밀 성공: 피해 최소·추가 기록·안정된 잔향
- 일반 성공: 사건 종결·일부 후유증
- 부분 성공: 피해자 후유증·위험 사례·기관 부담
- 철수: 재출현 조건·관계 변화·다음 조사 이점
- 반복 오판: 더 어려운 보호 목표와 명확한 반증

팀 전멸이나 핵심 피해자의 회복 불가능 상태에서는 출동 실패가 가능하다. 단, 획득한 위험 사례와 일부 관측 기록은 보존한다.

## 6. 적대적 보호 규칙

- 사건별 시스템을 완전히 별도 장르로 분리하지 않는다.
- 같은 텍스트·퍼즐·전투에 명칭과 스킨만 교체하지 않는다.
- 능력·태그·판정 결과로 사건의 객관적 진실을 뒤집지 않는다.
- 저승역과 빨간 우산을 동일 경로 퍼즐로 만들지 않는다.
- 폐주파수 방송국을 무음 타이밍 맞추기만으로 끝내지 않는다.
- 기록되지 않은 병동을 서류 정리 화면만으로 구성하지 않는다.
- 구출 미니게임 성공이 회수 전투를 자동 승리 처리하지 않는다.
- 관찰·대응 없이 공격만 반복해 봉쇄할 수 없게 한다.
- 과거 기록이 겨울 사건 정답을 자동 제공하지 않는다.

## 7. 승인하지 않은 것

- 각 사건의 전체 조사 장면·선택지·키워드 목록
- 괴이 매뉴얼 최종 문구와 UX
- 미니게임 최종 UI·입력·시간·난이도
- 회수 전투 수치·행동 비용·스킬·장비 밸런스
- 기록되지 않은 병동의 피해자·세부 장면·아트
- 구현 계획·코드·아트 제작
- 사람 플레이 검증 통과 선언
- POC 통과·Production 확대
