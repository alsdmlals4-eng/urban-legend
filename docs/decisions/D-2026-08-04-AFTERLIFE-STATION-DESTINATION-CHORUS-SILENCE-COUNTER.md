## 결정

저승역의 세 번째 대표 회수 패턴은 `[목적지 합창]`으로 확정한다.

```text
요원과 괴이 허상마다 서로 다른 목적지를 들음
+ 모든 원본 기록에서 같은 공통 무음 구간이 남음
+ 최종 턴에 공식 역 식별음을 그 공백에 삽입
= 개인 목적지 투영 붕괴
→ [파훼]·기억 매듭 노출·괴이 [취약]
```

이 패턴은 승차권을 파훼 수단으로 사용하지 않는다. 지속 흔적 좌표를 고정하는 패턴이 아니다. Decision 1의 `목적지 공백에 개인의 귀환 기억이 투영된다`는 규칙을 전투 판단으로 사용한다.

## 전투 계약

- 패턴 길이는 `N ≥ 2`, 발현 전 `N-1개의 전조`를 따른다.
- 여러 대상의 목적지 자막·증언은 서로 다르지만 원본 방송의 무음 타임스탬프는 일치한다.
- 최종 턴은 `대응 선택 → 패턴 발현 → 결과 산출 → 평상 진행` 순서다.
- 정확한 대응은 공식 역 식별음을 공통 무음 구간에 삽입하는 것이다.
- 하나의 개인 목적지를 정답으로 고르는 것은 오답이다.

## 대체 대응

- 하나의 목적지를 선택: 해당 투영이 강화되어 대상 집중 피해
- 방어: 정신·위치 교란 피해 감소, `[취약]` 없음
- 잘못된 타이밍에 식별음 삽입: 행동·자원 소비, 파훼 없음
- 괴이 허상 공격: 허상 분산 후 반격, 기억 매듭 미노출

모든 결과는 숨겨진 확률 없이 결정적으로 산출한다.

## 공정성·접근성

- 공통 무음 구간을 자동 강조하지 않는다.
- 정답 타이밍을 자동 선택하지 않는다.
- 자막·타임스탬프·파형 구간 라벨로 비교 가능하게 한다.
- 음향만으로 판별하지 않는다.
