## 1. 결정 목적

직전 비주얼 화면 보드에서 잘못 표현된 항목을 수정하고, 후속 SCREEN 명세와 이미지 제작의 우선 규칙으로 고정한다.

이 결정은 `D-2026-07-31-VALIDATION-SCREEN-AUTHORITY`와 `D-2026-07-31-EXTENDED-MANAGEMENT-SCREENS`의 화면 책임은 유지하되, SCREEN-01과 SCREEN-05의 표현·입력 규칙을 보정한다.

## 2. SCREEN-01 메인 화면 — 캐릭터 비노출

메인 화면에는 캐릭터를 표시하지 않는다.

### 허용 요소

- 괴이기록국 건물·관제실·도시 야경·비 내리는 역 등 프로젝트 고유 장소
- 게임 로고와 메뉴
- 현재 사건·저장 상태·업데이트 공지의 짧은 정보
- 빈 복도, 꺼진 관제 장비, 비정상 신호 등 간접적인 괴이 흔적
- 기록국 문서·단말기형 UI

### 금지 요소

- 주인공 또는 동료의 전신·반신·초상
- 캐릭터 단체 포즈
- 캐릭터 실루엣을 전면 키비주얼처럼 배치
- 메인 메뉴에서 인물 선택이나 파티 편성을 암시하는 구성

### 첫인상 목표

캐릭터가 아니라 다음 요소로 장르를 전달한다.

```text
현대 서울의 익숙한 장소
+ 비어 있는 기관·역 공간
+ 기록·관제 UI
+ 설명되지 않은 괴이 흔적
```

메인 화면은 인물 소개 화면이 아니라, 플레이어가 괴이기록국의 세계로 들어가는 조용하고 불길한 진입점이다.

## 3. SCREEN-05 일정 화면 — 하루 단위 편성

일정은 주간 활동 묶음을 한 번에 고르는 방식이 아니라 **하루씩 직접 편성**한다.

### 기본 조작 흐름

```text
날짜 선택
→ 주요 활동 1개 선택
→ 일상 활동 1개 선택
→ 비용·피로·예상 변화 통합 확인
→ 하루 일정 확정
→ 다음 날짜 선택
```

### 화면 구조

- 4주 × 7일 달력은 전체 기간과 마감을 보여주는 개요로 사용한다.
- 실제 입력과 확인의 기본 단위는 `1일`이다.
- 선택한 날짜의 상세 패널에서 주요 활동과 일상 활동을 각각 편성한다.
- 주간 자동 편성이나 주간 활동 묶음 선택을 기본값으로 두지 않는다.
- 복사·템플릿 기능을 사용하더라도 플레이어가 날짜별 결과를 확인하고 수정할 수 있어야 한다.

## 4. 하루 슬롯 구조 — 주요 활동 1개 + 일상 활동 1개

각 날짜는 서로 책임이 다른 두 슬롯을 가진다.

### 4.1 주요 활동 슬롯

하루에 주요 활동은 1개만 편성한다.

주요 활동은 다음과 같이 하루의 핵심 시간과 기회비용을 사용하는 행동이다.

- 훈련
- 기관 업무
- 괴이 연구
- 장비 정비
- 휴식·치료
- 동료 관계 이벤트
- 사건 조사·출동

주요 활동은 능력 성장, 연구 진행, 기관 평가, 피로 회복, 사건 진입 등 큰 상태 변화를 담당한다.

### 4.2 일상 활동 슬롯

하루에 일상 활동은 1개 편성한다.

일상 활동은 주요 활동과 병행 가능한 짧은 생활·관계·습관 행동이다. 일상 활동의 정확한 목록과 수치는 후속 기획에서 확정하지만, 다음 경계를 지킨다.

- 주요 활동 슬롯이나 날짜를 추가로 소비하지 않는다.
- 다일 연구·훈련의 진행 일수를 대체하거나 단축하지 않는다.
- 핵심 단서, 정답 가설, 미관측 패턴을 생성하지 않는다.
- 주요 활동과 같은 수준의 성장·연구·관계 보상을 제공하지 않는다.
- 피로·부상·상태 비용을 무효화하지 않는다.
- 플레이어가 선택한 주요 활동의 의미와 기회비용을 뒤집지 않는다.

일상 활동은 작은 피로 조정, 관계 접점, 성향 표현, 생활 기록, 짧은 준비 보정처럼 낮은 강도의 변화를 담당한다.

### 4.3 다일 주요 활동과 일상 활동

2~3일 주요 활동이 연속 날짜를 자동 점유해도, 각 날짜의 일상 활동 슬롯은 별도로 유지한다.

예시:

```text
5월 8일 — 주요: 신호 현상 연구 1/3 / 일상: 선택 가능
5월 9일 — 주요: 신호 현상 연구 2/3 / 일상: 선택 가능
5월 10일 — 주요: 신호 현상 연구 3/3 / 일상: 선택 가능
```

- 다일 블록은 주요 활동 슬롯만 점유한다.
- 일상 활동은 날짜별로 독립 선택한다.
- 다일 블록을 이동·취소해도 이미 선택한 일상 활동을 함께 삭제하지 않는다. 충돌이 생기면 해당 날짜만 재확인한다.
- 돌발 출동·중상·강제 휴식처럼 일상 활동까지 제한할 수 있는 예외는 후속 규칙에서 별도로 정한다.

### 4.4 화면 표현

달력 셀과 상세 패널에서 두 슬롯의 위계를 분명히 구분한다.

- 주요 활동: 셀의 중심을 차지하는 큰 일정 블록
- 일상 활동: 셀 하단의 작은 보조 행·아이콘·짧은 라벨
- 다일 주요 활동: `1/3`, `2/3`, `3/3` 연결 블록
- 일상 활동: 각 날짜별 독립 표시
- 확정 전 미리보기: 주요·일상 활동의 효과를 합쳐 보여주되 두 출처를 분리 표기

일상 활동이 두 번째 주요 일정처럼 보이지 않도록 크기와 강조 수준을 낮춘다.

## 5. 2~3일 주요 활동 — 연속 날짜 자동 점유

2일 또는 3일이 필요한 연구·훈련·기관 업무를 시작 날짜에 배치하면 필요한 **연속 날짜를 자동으로 점유**한다.

### 확정 전 미리보기

활동을 선택하면 확정 전에 다음을 보여준다.

- 시작 날짜
- 필요한 총 일수
- 자동 점유될 날짜 범위
- 완료 예정일
- 해당 기간에 발생하는 피로·자원·연구 변화 범주
- 사건 마감 또는 고정 일정과의 충돌 여부

달력에서는 점유 예정 셀을 하나의 연결된 일정 블록으로 강조한다.

### 확정 후 상태

예시:

```text
5월 8일 — 신호 현상 연구 1/3 · 시작
5월 9일 — 신호 현상 연구 2/3 · 진행
5월 10일 — 신호 현상 연구 3/3 · 완료
```

- 첫 날짜가 일정 블록의 기준점이다.
- 이후 날짜는 `진행 중` 상태로 자동 점유되며 다른 주요 활동을 동시에 배치할 수 없다.
- 일정 블록의 이동·취소는 일부 날짜가 아니라 전체 블록 단위로 처리한다.
- 연속 날짜 중 하나라도 사용할 수 없으면 확정 버튼을 비활성화하고 충돌 날짜와 이유를 표시한다.

### 주차 경계

기존 일정 계약을 유지해 다일 활동은 주차 경계를 넘지 않는다.

- 남은 주간 일수가 부족하면 해당 시작일에서 선택할 수 없다.
- 다음 주에 다시 시작할 수 있는 가장 빠른 날짜를 안내한다.
- 주차 경계를 넘기기 위해 활동을 자동 분할하지 않는다.

### 반복 조작 완화

- 플레이어가 같은 주요 활동을 매일 다시 선택하지 않는다.
- 달력 셀에는 `1/3`, `2/3`, `3/3`처럼 진행 위치를 표시한다.
- 상세 패널에서는 전체 점유 범위와 예상 결과를 한 번에 확인한다.
- 복사 기능은 전체 다일 블록을 복사하며, 일부 진행일만 복사하지 않는다.

## 6. 아직 확정하지 않은 일정 세부사항

다음 항목은 후속 일정 화면 설계에서 한 항목씩 사용자 확인 후 확정한다.

- 일상 활동의 세부 목록·효과 상한·반복 제한·기본 선택값
- 이미 확정한 미래 일정을 언제까지 수정할 수 있는지
- 돌발 출동이 다일 활동과 일상 활동을 어떻게 중단·대체하는지
- 다일 주요 활동의 효과를 매일 분할 적용할지, 마지막 날 완료 시 정산할지
- 사건·중상·강제 휴식일에 일상 활동 슬롯을 유지할지 비활성화할지

## 7. 직전 이미지 판정

1. 메인 화면에 캐릭터가 노출됨
