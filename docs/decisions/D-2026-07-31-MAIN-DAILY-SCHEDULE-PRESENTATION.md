## 1. SCREEN-01 메인 화면

메인 화면에는 주인공·동료·캐릭터 실루엣을 포함한 인물을 표시하지 않는다.

장르는 다음 요소로 전달한다.

```text
현대 서울의 익숙한 장소
+ 비어 있는 기록국·역 공간
+ 기록·관제 장비
+ 설명되지 않은 괴이 흔적
```

허용 요소:

- 괴이기록국 건물·관제실·도시 야경·비 내리는 역사
- 게임 로고와 메뉴
- 현재 사건·저장 상태의 짧은 정보
- 비정상 신호·꺼진 장비·빈 복도 같은 간접 연출

금지 요소:

- 캐릭터 전신·반신·초상·단체 포즈
- 캐릭터 실루엣을 전면 키비주얼로 사용하는 구성

## 2. SCREEN-05 일정 화면

일정은 주간 묶음이 아니라 하루씩 편성한다.

```text
날짜 선택
→ 주요 활동 1개 선택
→ 기간·비용·피로·예상 변화 확인
→ 하루 일정 확정
→ 다음 날짜
```

- 4주 × 7일 달력은 전체 기간과 사건 마감을 보여주는 개요다.
- 실제 입력과 확인의 기본 단위는 `1일`이다.
- 하루에 선택하는 의미 있는 일정은 `주요 활동 1개`다.
- 오전·오후 분할과 별도 일상 활동 카탈로그는 만들지 않는다.

## 3. 주요 활동

주요 활동만 하루의 선택과 기회비용을 담당한다.

예시:

- 훈련
- 기관 업무
- 괴이 연구
- 장비 정비
- 치료
- 관계 이벤트
- 사건 조사·출동

## 4. 휴식 처리

기존의 `일상 활동 1개`는 세부 시스템으로 확장하지 않고 **`휴식`으로 통합**한다.

- 식사·산책·독서·취미·개인 정비·기록 습관 등의 별도 목록을 만들지 않는다.
- 일정 UI에서 플레이어가 두 번째 활동을 매일 고르게 하지 않는다.
- 주요 활동 외의 일상 시간은 `휴식`으로 고정 표시하거나 자동 적용한다.
- 휴식은 작은 피로 회복만 담당한다.
- 관계·성향·연구·장비·핵심 단서·정답 가설을 생성하지 않는다.
- 휴식을 별도 성장·육성·반복 최적화 시스템으로 확장하지 않는다.

따라서 최종 일일 구조는 다음과 같다.

```text
주요 활동 1개
+ 기본 휴식 처리
```

## 5. 2~3일 주요 활동

연구·훈련·기관 업무처럼 2~3일이 필요한 주요 활동은 시작 날짜에서 선택하면 필요한 연속 날짜를 자동 점유한다.

- 달력에 `1/3 → 2/3 → 3/3` 연결 블록으로 표시한다.
- 다일 활동은 주요 활동 자리만 점유한다.
- 각 진행일의 기본 휴식 처리는 유지한다.
- 이동·취소·복사는 전체 블록 단위로 처리한다.
- 고정 일정과 충돌하거나 같은 주의 남은 날짜가 부족하면 확정할 수 없다.
- 다일 활동은 주차 경계를 넘지 않고 자동 분할하지 않는다.

## 6. 직전 이미지 판정

직전 생성한 7종 화면 보드는 다음 이유로 `SUPERSEDED_PLACEHOLDER`다.

1. 메인 화면에 캐릭터가 노출됨
2. 일정 화면이 주간 묶음 편성처럼 표현됨
3. 일상 활동을 별도 선택·육성 시스템처럼 과도하게 표현함

그림체와 7종 화면 구분만 참고하고 SCREEN-01·05의 레이아웃 근거로 사용하지 않는다.
