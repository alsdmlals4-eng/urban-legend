## 1. 결정 질문

회수 단계에서 사건 원인 추론을 반복하지 않으면서, 새 전조를 분류하고 조사 근거에 맞는 현장 행동을 선택하게 하려면 문구와 정보 위계를 어떻게 구성할 것인가?

## 2. 접근 비교

### A. 설명형 행동 버튼

예: `방송 주기와 전광판 표기를 대조해 안내 신호를 차단한다`

- 이해는 쉽지만 근거·판단·정답 행동을 한 문장에 묶어 정답을 누설한다.
- 판정: `REJECT`

### B. 패턴 분류 + 중립 현장 행동

- 전조 분류 → 관련 기록 연결 → 현장 조작 선택
- 행동 결과와 추론 검증을 별도로 기록
- 판정: `RECOMMENDED`

### C. 현장 행동만 선택

- 입력은 단순하지만 조사 지식 소비가 약하고 버튼 추측으로 진행할 수 있다.
- 판정: `HOLD_FOR_ACCESSIBILITY_FALLBACK`

## 3. 공통 흐름

```text
전조 관측
→ 패턴 분류 후보 선택
→ 관련 기록 확인·연결
→ 중립 현장 행동 선택
→ 현장 결과
→ 추론 검증 결과
→ 위험 사례 또는 다음 패턴
```

사건 수준 원인 가설 네 개를 매 패턴에서 다시 제시하지 않는다.

## 4. 패턴 1 — 존재하지 않는 종착 안내

### 전조

> 스피커가 같은 승강장 이름을 세 번 반복한다. 반복될 때마다 전광판의 글자가 한 칸씩 사라진다.

### 분류 후보

1. `개인화된 경로 유도`
2. `새 노선 개통`
3. `표시 장치 단독 오류`

권장 분류: `개인화된 경로 유도`

공식 운행 기록 또는 노선 복원 검증 기록을 연결해야 추론 검증이 가능하다.

### 중립 행동

1. `스피커 회로를 분리한다.`
2. `전광판이 가리키는 쪽으로 이동한다.`
3. `방송에 현재 역명을 답한다.`

권장 행동: `스피커 회로를 분리한다.`

버튼에는 방송 주기, 전광판 대조, 안전 노선 같은 근거를 넣지 않는다.

### 결과

- 올바른 행동 + 올바른 분류·근거: `RULE_APPLIED_AND_VERIFIED`
- 올바른 행동 + 근거 부족: `ACTION_SUCCESS / REASONING_UNVERIFIED`
- 잘못된 이동: 개인화된 목적지를 실제 경로로 취급한 위험 사례
- 방송 응답: 위치·이름 정보가 괴이 신호에 반영되는 위험 사례

## 5. 패턴 2 — 검은 승차권의 승객 각인

### 전조

> 검은 승차권의 천공 자국이 번지며 가장 가까운 요원의 이름과 비슷한 획을 만든다.

### 분류 후보

1. `접촉 대상을 승객으로 등록`
2. `인쇄된 목적지를 출력`
3. `봉인 절차를 요청`

권장 분류: `접촉 대상을 승객으로 등록`

이 분류는 승차권이 사건의 최초 원인임을 의미하지 않는다. 승인된 시간순 증거와 함께 `최초 원인`과 `현장 매개 역할`을 분리한다.

### 중립 행동

1. `투명 격리함으로 옮긴다.`
2. `개찰기에 통과시킨다.`
3. `보호 봉투에 넣어 요원이 소지한다.`

권장 행동: `투명 격리함으로 옮긴다.`

`접촉 차단`, `승객 등록 방지` 같은 정답 논리는 버튼에 쓰지 않는다.

### 결과

- 올바른 행동 + 역할 구분 성공: `PATTERN_ROLE_VERIFIED`
- 올바른 행동 + 승차권을 최초 원인으로 오판: `ACTION_SUCCESS / CAUSAL_REASONING_CONTRADICTED`
- 개찰: 목적지 표식이 조작자에게 옮겨가는 위험 사례
- 직접 소지: 신규 승객 각인. 즉시 영구 이탈·강제 중상은 금지

- 현재 전조 원문
- 대상·시점·조건 중 관측된 태그
- 안정화·위험 상태

### 중앙 2단계

- 첫 Validation에서는 능력치 이름·성공 확률을 숨겨 정답 신호를 차단

### 하단

- 선택 분류·연결 근거·실행 행동
- 현장 결과·추론 검증 상태
- 남은 미해결 질문

금지:

- 정답 행동 강조색
- 행동 길이·상세도 차이로 정답 암시
- 동료 예측을 정답 표시로 사용
- 사건 원인 가설 네 개 반복 표시
- 행동 성공을 공식 원인 검증으로 자동 승격
