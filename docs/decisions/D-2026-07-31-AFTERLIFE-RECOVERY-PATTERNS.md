## 1. 결정 질문

회수 단계에서 사건 원인 가설을 반복하지 않고, 새 전조를 분류한 뒤 조사 기록에 맞는 현장 행동을 선택하게 하려면 어떤 정보 위계와 문구를 사용해야 하는가?

## 2. 권장 구조

```text
전조 관측
→ 패턴 분류 3개 중 선택
→ 관련 기록 연결
→ 현장 행동 3개 중 선택
→ 현장 결과
→ 추론 검증
→ 위험 사례 또는 다음 패턴
```

- 사건 수준 원인 가설 네 개를 다시 제시하지 않는다.
- 행동 성공과 원인·역할 검증을 별도 상태로 기록한다.
- 행동 버튼에 근거·정답 논리·예상 성공 결과를 쓰지 않는다.
- 첫 Validation에서는 능력치 이름·성공률·동료 예측을 정답 신호로 노출하지 않는다.

## 3. 패턴 1 — 존재하지 않는 종착 안내

### 전조

> 스피커가 같은 승강장 이름을 세 번 반복한다. 반복될 때마다 전광판의 글자가 한 칸씩 사라진다.

### 분류 후보

1. `개인화된 경로 유도`
2. `새 노선 신호`
3. `표시 장치 오류`

권장 분류: `개인화된 경로 유도`

### 연결 가능한 기록

- 방송 원본의 목적지 공백
- 같은 시각에 서로 다르게 기록된 목적지
- 공식 운행·노선 복원 기록

분류 선택만으로 검증하지 않는다. 관련 기록을 최소 1개 연결해야 추론 검증 상태를 판정한다.

### 현장 행동

1. `승강장 스피커 전원을 내린다.`
2. `전광판이 가리키는 방향으로 이동한다.`
3. `안내 방송에 현재 역명을 응답한다.`

권장 행동: `승강장 스피커 전원을 내린다.`

### 결과 상태

- 올바른 행동 + 올바른 분류·기록: `RULE_APPLIED_AND_VERIFIED`
- 올바른 행동 + 근거 부족: `ACTION_SUCCESS / REASONING_UNVERIFIED`
- 표시 방향 이동: 개인화된 목적지를 실제 경로로 취급한 위험 사례
- 역명 응답: 위치·이름 정보가 괴이 신호에 반영되는 위험 사례

## 4. 패턴 2 — 검은 승차권의 승객 각인

### 전조

> 검은 승차권의 천공 자국이 번지며 가장 가까운 요원의 이름과 비슷한 획을 만든다.

### 분류 후보

1. `접촉자를 승객으로 등록`
2. `목적지 정보를 출력`
3. `봉인 절차를 요구`

권장 분류: `접촉자를 승객으로 등록`

이 분류는 승차권이 사건의 최초 원인이라는 뜻이 아니다. 승인된 시간순 증거와 함께 다음을 분리한다.

```text
사건의 최초 원인
≠
현장에서 승객 각인을 전달하는 매개
```

### 연결 가능한 기록

- 개인 목적지 청취 `23:57:42`
- 검은 승차권 최초 접촉 `23:59:08`
- 천공·식별 번호 관측 기록

### 현장 행동

1. `승차권을 투명 보관함에 넣는다.`
2. `승차권을 개찰기에 통과시킨다.`
3. `승차권을 봉투에 넣어 대표 요원이 보관한다.`

권장 행동: `승차권을 투명 보관함에 넣는다.`

### 결과 상태

- 올바른 행동 + 역할 구분 성공: `PATTERN_ROLE_VERIFIED`
- 올바른 행동 + 승차권을 최초 원인으로 오판: `ACTION_SUCCESS / CAUSAL_REASONING_CONTRADICTED`
- 개찰: 표식이 조작자에게 옮겨가는 위험 사례
- 직접 보관: 대표 요원이 신규 승객으로 각인되는 위험 사례

오대응은 즉시 영구 이탈·강제 중상으로 처리하지 않는다. 피해·위험 증가와 한 번의 복구 기회를 우선 사용한다.

## 6. 금지

- 정답 행동 강조색
- 정답만 길고 구체적인 문구
- 행동 버튼에 `대조`, `검증`, `접촉 차단`, `승객 등록 방지` 같은 해설 포함
- 동료가 정답 분류·행동을 추천
- 사건 원인 가설 네 개 반복 표시
- 현장 성공을 최초 원인 검증으로 자동 승격
- 수집률이나 스탯만으로 회수 단계 통과

허용:

- 한 번의 재대응 기회
- 입력 허용 오차 조정

금지:

- 정답 분류·행동 자동 선택
- 미관측 패턴명 공개
- 최초 원인 확정
- 잘못된 행동을 성공으로 변경
- 신규 핵심 기록 생성

## 10. 적대적 검토 쟁점

1. `스피커 전원을 내린다`와 `투명 보관함`이 문구만으로 정답처럼 보일 수 있음
2. 분류와 기록 연결이 같은 판단을 두 번 요구할 수 있음
3. 패턴 2에서 최초 원인과 현장 매개 역할을 혼동할 수 있음
4. 행동 성공 후 추론 반박 상태가 실패처럼 느껴질 수 있음
5. 오대응 복구가 너무 관대하면 현장 긴장이 약해질 수 있음

사람 검증에서는 행동 라벨만 본 집단과 기록을 읽은 집단의 정답률을 분리해 측정한다.
