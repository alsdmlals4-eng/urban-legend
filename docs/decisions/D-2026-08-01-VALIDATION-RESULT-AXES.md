## 1. 결정 질문

저승역 결과를 하나의 숨은 합산 점수로 처리하지 않으면서, 현장 성공·피해자 구조·원인 검증·괴이 핵 회수를 플레이어가 구분해 이해하도록 어떻게 기록할 것인가?

## 2. 승인 원칙

1. 결과 계산의 권위는 네 개의 원시 축이 가진다.
2. 요약 등급은 원시 축을 읽기 쉽게 압축한 표시값이다.
3. 행동 성공과 추론 검증은 다른 축이다.
4. 단서 수집률·동료 지원 횟수·스탯·장비만으로 등급을 올리지 않는다.
5. 연구·보급 환류는 다음 사건의 질문과 준비 폭을 넓히되 정답을 제공하지 않는다.

## 3. 결과 원시 축

### AXIS-01 현장 안정화

| 상태 | 의미 |
|---|---|
| `FAILED` | 현장 반복과 위험을 통제하지 못함 |
| `TEMPORARY` | 즉시 피해는 막았지만 재발 조건이 남음 |
| `STABILIZED` | 현재 출현을 안전 범위로 안정화함 |

### AXIS-02 피해자 구조

| 상태 | 의미 |
|---|---|
| `FAILED` | 구조 경로를 확보하지 못함 |
| `RESCUED_WITH_AFTEREFFECT` | 구조했지만 후유증·기억 손상이 남음 |
| `SAFE_RESCUE` | 중대한 후유증 없이 구조함 |

### AXIS-03 규칙 검증

| 상태 | 의미 |
|---|---|
| `UNRESOLVED` | 원인과 안전 규칙을 설명하지 못함 |
| `OPERATING_RULE_VERIFIED` | 현장에서 쓸 수 있는 안전 운용 규칙을 검증함 |
| `CAUSAL_MODEL_VERIFIED` | 최초 원인과 현장 매개 역할까지 구분해 검증함 |
| `CONTRADICTED` | 제출한 설명이 시간순 기록이나 핵심 관측과 충돌함 |

### AXIS-04 괴이 핵·잔향 회수

| 상태 | 의미 |
|---|---|
| `NONE` | 회수하지 못함 |
| `PARTIAL_RESONANCE` | 잔향 일부만 확보함 |
| `CORE_SECURED` | 괴이 핵을 안전하게 격리·회수함 |

## 4. 요약 등급

요약 등급은 다음 네 단계만 사용한다.

1. `미해결`
2. `임시 안정화`
3. `제한적 해결`
4. `완전 해결`

Legacy 호환 ID:

| 목표 표시 | Legacy 호환 ID |
|---|---|
| 미해결 | `unavailable` |
| 임시 안정화 | `temporary` |
| 제한적 해결 | `standard` |
| 완전 해결 | `complete` |

호환 ID는 마이그레이션 편의를 위한 것이며 계산 권위가 아니다.

## 5. 요약 등급 판정 규칙

### 미해결

다음 중 하나면 `미해결`이다.

- 현장 안정화 `FAILED`
- 최소 안전 노선 미확보
- 결과 화면까지 정상 도달하지 못함

피해자·규칙·회수 축은 실패 당시 상태 그대로 별도 기록한다.

### 임시 안정화

최소 조건:

- 현장 안정화 `TEMPORARY` 또는 `STABILIZED`
- 즉시 피해 확산 차단

다음 중 하나가 있으면 등급 상한은 `임시 안정화`다.

- 규칙 검증 `UNRESOLVED`
- 규칙 검증 `CONTRADICTED`
- 피해자 구조 `FAILED`

즉, 우연히 올바른 행동을 선택했지만 원인을 설명하지 못한 경우 현장 안정화는 인정하되 요약 등급은 임시 안정화보다 높아지지 않는다.

### 제한적 해결

다음 조건을 모두 만족해야 한다.

- 현장 안정화 `STABILIZED`
- 피해자 구조 `RESCUED_WITH_AFTEREFFECT` 이상
- 규칙 검증 `OPERATING_RULE_VERIFIED` 이상

회수 축은 `NONE`이어도 제한적 해결이 가능하지만 결과와 보상은 축소한다.

### 완전 해결

다음 조건을 모두 만족해야 한다.

- 현장 안정화 `STABILIZED`
- 피해자 구조 `SAFE_RESCUE`
- 규칙 검증 `CAUSAL_MODEL_VERIFIED`
- 괴이 핵·잔향 회수 `CORE_SECURED`
- 회수 패턴 1·2에서 행동과 추론을 모두 검증
- 중대한 시간순 모순 없음

선택형 보조 기록 일부를 놓친 것만으로 완전 해결을 막지 않는다.

## 6. 행동 결과와 추론 결과 결합

| 행동 결과 | 추론 결과 | 결과 해석 |
|---|---|---|
| 성공 | 검증됨 | 안전 규칙 또는 원인 모델 승격 가능 |
| 성공 | 근거 부족 | 현장 안정화만 인정, 규칙은 미검증 |
| 성공 | 반박됨 | 현장 안정화만 인정, 잘못된 인과 설명 기록 |
| 실패 | 검증됨 | 지식은 보존하되 현장·구조·회수 손실 반영 |
| 실패 | 반박됨 | 위험 사례 기록, 복구 가능 여부 별도 판정 |

## 7. SCREEN-04 정보 위계

### 1단 — 네 결과 축

화면 첫 영역에서 네 축을 같은 크기의 카드 또는 행으로 보여준다.

```text
현장 안정화 | 피해자 구조 | 규칙 검증 | 핵·잔향 회수
```

각 축은 상태명과 한 문장 이유를 함께 표시한다.

### 2단 — 왜 그런 결과가 났는가

- 성공한 현장 행동
- 실패·오대응
- 검증된 기록
- 반박된 주장
- 미해결 질문

### 3단 — 무엇을 기록했는가

- 공식 규칙
- 안전 운용 규칙
- 후보 규칙
- 위험 사례

### 4단 — 다음에 무엇이 달라지는가

- 연구 질문 1개
- 보급 후보 1개
- 다음 날짜 영향 1개

긴 사건 보고서·저장 진단·전체 해금 목록은 접힌 상세 영역으로 둔다.

## 8. Validation 최소 환류

### 연구 질문

`개인화된 신호와 공식 식별 신호를 어떻게 분리할 것인가`

- 출처: 시간순 증거와 안전 노선 복원
- 역할: 후속 주파수·공간형 현상에서 이미 확보한 기록의 비교 보조
- 금지: 다음 사건 원인·정답 가설·미관측 패턴 공개

### 보급 후보

`폐주파수 필터`

- 역할: 잡음 속 공식 식별 신호의 가독성 보조
- 허용: 기록 비교 편의·입력 허용 오차 보정
- 금지: 신규 핵심 기록 생성·정답 분류·자동 해결

### 다음 날짜 영향

- 사건 보고서 등록
- 연구 질문·보급 후보가 후속 화면에 `후보`로 추가됨
- 전체 연구·보급 화면을 Validation 종료 직후 강제로 열지 않음

## 9. 피해자·관계 결과

피해자 구조는 네 원시 축 중 하나다.

동료 관계 변화는 결과 축과 별도 기록한다.

허용 예시:

- 위험을 먼저 감수함
- 피해를 완화함
- 기록 비교를 도움
- 플레이어 판단에 동의·반대함

관계 변화는 해결 등급·다음 사건 정답·필수 기록을 직접 결정하지 않는다.

## 10. 보호 규칙

- 단서 수집률 100%만으로 완전 해결 금지
- 올바른 행동만 우연히 선택한 경우 규칙 검증 부여 금지
- 최초 원인 미검증 상태에서 완전 해결 금지
- 동료 지원 성공 횟수로 등급 직접 상승 금지
- 장비 보유 여부로 필수 구조·핵심 추리 잠금 금지
- 일부 선택형 기록 누락만으로 기본 구조 경로 차단 금지
- 하나의 숨은 총점만 저장해 원시 축을 역산하는 방식 금지

## 12. 기존 구현과의 관계

현재 `result_scene`의 단일 회수·안정화 등급, 단서 수집률, 보상·해금 목록, 반일 준비 복귀는 `CURRENT_IMPLEMENTATION_LEGACY`다.

재사용:

- 피해자 결과
- 노선 검증 기록
- 괴이 매뉴얼
- 사건 보고서
- 판단 근거
- 연구·장비 해금 데이터
- 저장된 완료 보고서

승인 목표:

- 네 결과 축을 첫 정보로 승격
- 긴 상세 정보는 접힌 영역으로 이동
- `현재 반일 결과 확인` 제거
- Validation은 SCREEN-04에서 완료 처리 후 메인으로 복귀
- 전체 제품은 SCREEN-05 다음 날짜로 연결

별도 8번째 완료 화면은 만들지 않는다.

## 13. 사람·비주얼 검증 잔여 위험

1. 네 축이 많아 첫 결과가 복잡해질 수 있음
2. 현장 성공인데 임시 안정화 상한이면 보상이 약하게 느껴질 수 있음
3. 완전 해결 조건이 체크리스트처럼 보일 수 있음
4. 회수 실패가 전체 해결을 과도하게 낮출 수 있음
5. 연구·보급 후보가 사실상 필수 정답 보상처럼 보일 수 있음

대응:

- 각 축은 상태명 + 한 문장 이유만 우선 표시
- 상한 이유를 `원인 미검증`처럼 직접 설명
- 숨은 체크리스트를 플레이 중 사전 공개하지 않음
- 제한적 해결은 회수 실패를 허용
- 환류 후보는 비교 편의만 제공

## 14. 승인 범위

1. 요약 등급 네 단계 명칭
2. 규칙 미검증·반박 시 `임시 안정화` 상한
3. 제한적 해결에서 잔향 회수 실패 허용
4. 완전 해결에 네 축 최고 상태 요구

7. 별도 완료 화면 없이 메인으로 복귀
