## 결정

괴이 매뉴얼의 완성도를 하나의 이진 상태로 판정하지 않는다. 플레이어가 불완전한 지식으로 위험을 감수해 현장에 진입할 수 있는 단계, 실제 구출·회수에 성공한 일반 클리어 단계, 사건 규칙과 근거망을 완전하게 정리한 S 랭크 정밀 기록 단계를 분리한다.

```text
조사와 가설 작성
→ 현장 진입 가능
→ 피해자 구출·잔향 회수 실행
→ 일반 클리어
→ 추가 조사·반증·기록 정리
→ S 랭크 정밀 매뉴얼
```

이 구조는 캠페인 진행을 단서 누락 하나로 막지 않으면서도, 우연한 실행 성공만으로 사건의 모든 규칙이 자동 확정되는 것을 방지한다.

## 1. 현장 진입 가능

현장 진입 가능은 성공 보증이나 일반 클리어가 아니다. 플레이어가 현재 위험을 이해하고 실행할 최소 안전 정보를 확보했음을 뜻한다.

필수 조건:

- `금지 행동`, `구출 절차`, `회수 전투 대응`의 실행 핵심 3슬롯이 최소 `실행 가능 후보` 상태다.
- 위 3슬롯 중 치명적 피해를 일으킬 수 있는 필수 항목이 비어 있지 않다.
- 확보된 정상 증거와 정면으로 충돌하는 `치명적 상충`이 남아 있지 않다.
- 발생 조건과 피해자 연결은 `근거 부족` 또는 `근거 확보` 상태여도 진입할 수 있다.
- 진입 화면은 미해결·근거 부족·위험을 경고하지만 정답 키워드와 성공 확률은 공개하지 않는다.

진입을 막는 조건:

- 구출 또는 회수 대응의 핵심 행동 자체가 비어 있음
- 현재 후보가 확인된 정상 증거와 치명적으로 상충함
- 실행 시 즉시 피해자를 확정적으로 잃는 것으로 확인된 위험 사례를 그대로 반복함
- 저장 또는 의미 구조가 성립하지 않아 실행 규칙으로 읽을 수 없음

## 2. 일반 클리어

일반 클리어는 플레이어가 매뉴얼을 실제 현장에서 사용해 피해자를 구출하고 잔향을 회수한 사건 해결 상태다.

필수 조건:

1. 피해자 구출에 실제 성공한다.
2. 잔향 회수 또는 사건별 승인된 동등 종결에 실제 성공한다.
3. `금지 행동`, `구출 절차`, `회수 전투 대응`의 실행 핵심 3슬롯이 실행 결과로 지지되거나 확인된다.
4. `발생 조건`, `피해자 연결`은 최소 `근거 확보` 이상이다.
5. 치명적 상충이 남아 있지 않다.

허용되는 잔여 상태:

- 비치명적 미해결
- 틀렸지만 후속 반증으로 폐기된 초기 가설
- 실행 중 발생한 위험 사례
- S 랭크에 필요한 추가 출처·예외·정밀 조건의 미확인
- 사건의 핵심 실행과 무관한 선택적 미스터리

필수 보호 규칙:

- 실행 성공만으로 모든 슬롯을 자동 `확인 규칙`으로 승격하지 않는다.
- 결과가 한 가설을 지지해도 원본 출처와 독립 근거가 부족하면 `근거 확보`에 머물 수 있다.
- 실패와 부분 성공은 새 증거·위험 사례로 남지만 정답 매뉴얼을 자동 작성하지 않는다.
- 일반 클리어 뒤에도 추가 조사와 기록 정리가 가능해야 한다.

## 3. S 랭크 정밀 매뉴얼

S 랭크는 캠페인 진행의 필수 조건이 아니라 사건 기록을 완전하게 정리한 숙련 성과다.

필수 조건:

- 다섯 의미 슬롯 모두 `확인 규칙` 상태다.
- 각 슬롯에 추적 가능한 원본 출처와 근거 연결이 있다.
- 핵심 오답 가설이 후속 근거로 반증·폐기 또는 위험 사례로 분류됐다.
- 사용된 `[변조]` 후보가 원본 정상 키워드와 변경 변수 기준으로 판별·분류됐다.
- 치명적 상충과 필수 미해결이 없다.
- 사건 제작자가 `핵심 증거`로 지정한 단서가 누락되지 않았다.
- 플레이어가 피할 수 있었던 중대한 위험 사례가 남아 있지 않다.
- 사건별 정밀 조건·예외·전조·구출 순서·취약 조건이 근거와 함께 기록됐다.

S 랭크를 막지 않는 항목:

- 사건 제작자가 `선택적 미스터리`로 지정한 세계관 의문
- 다음 사건이나 장기 캠페인에서만 해소되는 미해결 기록
- 접근성 기능 사용
- 검증 요청 횟수
- 키보드·컨트롤러·스크린리더 등 입력·표현 방식
- 기록 재현 도전 프리셋의 사용 여부

## 5. 사건 제작 계약

사건 작가는 각 슬롯과 증거에 다음을 지정한다.

- 현장 진입에 필요한 최소 상태
- 일반 클리어에 필요한 상태
- S 랭크 정밀 기록에 필요한 상태
- 안전 필수 여부와 치명적 상충 조건
- 실행 결과가 지지할 수 있는 범위
- 독립 출처가 추가로 필요한지 여부
- 선택적 미스터리인지 필수 미해결인지 여부
- 일반 클리어 뒤 재조사·복기·기록 보완 경로

모든 사건이 동일한 슬롯 중요도를 가질 필요는 없지만, 구출과 회수의 실행 핵심을 우연한 성공만으로 우회할 수는 없다.

## 6. 적대적 검토

### 모든 슬롯 완전 확인을 일반 클리어에 요구하는 문제

단서 하나를 놓쳤을 때 캠페인 진행이 막히고, S 랭크와 일반 클리어가 사실상 같은 조건이 된다. 실행 안전성과 정밀 기록을 분리한다.

### 실행 성공만으로 일반 클리어를 주는 문제

반복 시도와 우연한 성공이 조사와 매뉴얼을 대체할 수 있다. 실행 성공 외에 실행 핵심 3슬롯의 결과 지지와 발생·연결 슬롯의 최소 근거를 요구한다.

### 성공 결과가 모든 규칙을 확정하는 문제

한 번의 성공은 특정 행동이 유효했음을 보여 주지만 발생 원인·피해자 연결·예외 전체를 증명하지 않는다. 실행 결과는 증거로 추가하되 모든 슬롯 자동 승격을 금지한다.

### S 랭크가 과도한 수집 체크리스트가 되는 문제

S 랭크는 모든 텍스트와 세계관 비밀을 수집하는 조건이 아니다. 핵심 규칙·근거·반증·실행 안전성을 정밀하게 기록하는 조건이며 선택적 미스터리는 분리한다.

### 접근성·검증 요청이 불이익이 되는 문제

접근성 기능과 검증 요청은 같은 정보에 접근하는 방법이다. 사용 여부와 횟수를 랭크 감점으로 사용하지 않는다.

## 7. GPT·Codex 작업 역할 경계

이 항목은 제품 Decision 수를 추가하지 않는 프로젝트 운영 경계다.

- `GPT`에서는 핵심 재미, 콘텐츠 기획, 사건 구조, 서사·규칙 연결, 이미지·아트 방향과 생성 기획을 논의한다.
- GPT는 적대적 검토, 벤치마킹, 설계 정본, 이미지·아트 콘셉트 및 검수 기준을 담당한다.
- 실제 이미지 생성은 해당 Design과 아트 방향이 승인된 뒤 별도 요청에서 진행한다.
- 코드·Scene·Schema·저장 마이그레이션·게임 구현은 `구현 승인 후` Design Spec을 거쳐 `Codex` 단계에서 수행한다.
- GPT 단계에서 구현 완료·POC 완료·Production 진입을 선언하지 않는다.

## 8. 적용 경계

현재 확정하는 것은 제품 설계, 사건 제작 계약, GPT/Codex 역할 분리다.

아직 확정하지 않는 항목:

- 정확한 상태 enum과 판정 산식
- 사건별 안전 필수 슬롯의 최종 구성
- S 랭크 점수·보상·UI 문구
- 재조사 가능 시점과 비용
- 선택적 미스터리의 저장 표현
- 결과 화면과 사건 보고서 UI
- 실제 사건 데이터·코드·저장 마이그레이션
- 이미지·애니메이션·HX 제작

상세 Schema·UI·저장·사건 구현은 별도 Design Spec과 승인 전 시작하지 않는다.
