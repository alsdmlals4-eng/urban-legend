## 결정

괴이 매뉴얼의 **구조적 페이지 완료**, 실제 현장에서의 **일반 클리어**, 근거망을 정리한 **S 랭크 정밀 매뉴얼**을 분리한다.

```text
빈칸이 많은 괴이 매뉴얼
→ 조사·후보 획득·페이지 순차 작성
→ 최종장 모든 빈칸 완료
→ 현장 진입 가능
→ 피해자 구출 미니게임
→ 회수 페이즈
→ 일반 클리어
→ 기록 복기·정밀화
→ S 랭크 정밀 매뉴얼
```

후속 Decision 7에 따라 `현장 진입 가능`은 일부 빈칸이 남은 상태가 아니다. **모든 페이지와 모든 빈칸은 완료되어야 하며**, 불완전할 수 있는 것은 키워드의 진실성·근거 확실성·`[변조]` 판별 상태다.

## 1. 현장 진입 가능

현장 진입 가능은 조사 페이즈 종료 Gate를 통과해 구출·회수에 사용할 수 있는 `실행 가능 상태`다. 성공 보증이나 정답 확인은 아니다.

필수 조건:

- 1장부터 최종장까지 모든 페이지 진행 완료
- 모든 빈칸 완료
- `금지 행동`, `구출 절차`, `회수 전투 대응`의 실행 핵심 3슬롯이 구조적으로 읽히는 문장
- 저장 가능한 의미 구조
- 시스템이 이미 판명한 `치명적 상충`이 없음

허용되는 불확실성:

- 발생 조건·피해자 연결의 근거 부족
- 정상 후보로 오인한 `[변조]` 후보
- 아직 확인되지 않은 가설
- 비치명적 상충
- 선택적 미스터리

진입 화면은 위험과 근거 부족을 알릴 수 있지만 정답 키워드·성공 확률·미획득 후보를 공개하지 않는다.

## 2. 일반 클리어

일반 클리어는 플레이어가 완성한 매뉴얼을 현장에서 사용해 피해자를 구출하고 잔향을 회수한 사건 해결 상태다.

필수 조건:

1. 피해자 구출에 실제 성공한다.
2. 잔향 회수 또는 사건별 승인된 동등 종결에 실제 성공한다.
3. `금지 행동`, `구출 절차`, `회수 전투 대응`의 실행 핵심 3슬롯이 결과로 지지되거나 확인된다.
4. `발생 조건`, `피해자 연결`은 최소 `근거 확보` 이상이다.
5. 치명적 상충이 남아 있지 않다.

허용되는 잔여 상태:

- 비치명적 미해결
- 반증된 초기 가설
- 실행 중 발생한 위험 사례
- S 랭크용 정밀 조건 미확인
- 선택적 미스터리

보호 규칙:

- `실행 성공만으로 모든 슬롯을 자동` 확인 규칙으로 승격하지 않는다.
- 결과는 증거가 되지만 발생 원인·피해자 연결·예외 전체를 자동 증명하지 않는다.
- 일반 클리어 뒤에도 기록 복기와 정밀화가 가능해야 한다.

## 3. S 랭크 정밀 매뉴얼

S 랭크 정밀 매뉴얼은 캠페인 진행 필수 조건이 아니라 사건 규칙과 근거망을 재현 가능하게 정리한 숙련 목표다.

필수 조건:

- 다섯 의미 슬롯 모두 확인 규칙
- 각 슬롯의 추적 가능한 원본 출처와 근거 연결
- 핵심 오답 가설의 반증·폐기 또는 위험 사례 분류
- 사용된 `[변조]` 후보의 원본 정상 키워드·변경 변수 분류
- 치명적 상충과 필수 미해결 없음
- 핵심 증거 누락 없음
- 예방 가능한 중대한 위험 사례 없음
- 사건별 정밀 조건·예외·전조·구출 순서·취약 조건 기록

S 랭크를 막지 않는 항목:

- 사건 제작자가 `선택적 미스터리`로 지정한 세계관 의문
- 장기 캠페인에서만 해소되는 기록
- `접근성 기능` 사용
- `검증 요청 횟수`
- 입력 장치·표현 방식

## 5. 사건 제작 계약

사건 작가는 다음을 정의한다.

- 시작 시 보이는 매뉴얼 페이지와 빈칸
- 페이지 진행 순서와 최종장 Gate
- 각 슬롯의 일반 클리어·정밀 기록 최소 상태
- 안전 필수 여부와 치명적 상충 조건
- 실행 결과가 지지할 수 있는 범위
- 선택적 미스터리와 필수 미해결의 구분
- 일반 클리어 뒤 복기·정밀화 경로

모든 사건이 같은 슬롯 중요도를 가질 필요는 없지만, 구출과 회수의 핵심을 우연한 성공만으로 우회할 수는 없다.

## 6. 적대적 검토

### 빈칸이 남은 채 현장 진입하는 문제

괴이 매뉴얼 작성이 핵심 재미가 아니라 선택적 힌트로 약화된다. 후속 Decision 7에 따라 모든 페이지·모든 빈칸 완료를 조사 종료 Gate로 고정한다.

### 페이지 완료와 정답 확인을 동일시하는 문제

완전한 증거 확보를 요구하면 실행 검증과 위험 감수의 의미가 사라진다. 구조적 완료와 진실성 확정을 분리한다.

### 실행 성공만으로 일반 클리어하는 문제

반복 시도와 우연한 성공이 조사를 대체할 수 있다. 실제 구출·회수 외에 실행 핵심 3슬롯의 결과 지지와 발생·연결의 최소 근거를 요구한다.

### 성공 결과가 모든 규칙을 확정하는 문제

한 번의 성공은 특정 행동의 유효성만 지지할 수 있다. 실행 결과는 증거로 추가하되 전 슬롯 자동 승격을 금지한다.

### S 랭크가 수집 체크리스트가 되는 문제

핵심 규칙·근거·반증·실행 안전성을 평가하며 선택적 미스터리와 무관한 수집품은 분리한다.

### 접근성·검증 요청이 불이익이 되는 문제

접근성 기능과 검증 요청은 정보 접근 방식이므로 랭크 감점으로 쓰지 않는다.

## 7. GPT·Codex 작업 역할 경계

- `GPT`에서는 핵심 재미, 콘텐츠 기획, 사건 구조, 서사·규칙 연결, 이미지·아트 방향과 생성 기획을 논의한다.
- GPT는 적대적 검토, 벤치마킹, 설계 정본, 이미지·아트 콘셉트와 검수 기준을 담당한다.
- 실제 이미지 생성은 Design과 아트 방향 승인 뒤 별도 요청에서 진행한다.
- 코드·Scene·Schema·저장 마이그레이션·게임 구현은 `구현 승인 후` Design Spec을 거쳐 `Codex` 단계에서 수행한다.
- GPT 단계에서 구현 완료·POC 완료·Production 진입을 선언하지 않는다.
