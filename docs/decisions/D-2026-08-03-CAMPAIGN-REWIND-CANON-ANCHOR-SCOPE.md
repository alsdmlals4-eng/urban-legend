## 결정

캠페인 되감기는 지속 결과를 남기는 사건마다 하나씩 지정한 **정본 앵커**로만 돌아간다. 정본 앵커는 해당 사건의 출동 준비를 확정하기 직전 상태다.

플레이어는 정본 앵커 당시 보유했던 자원 범위 안에서 출동 동료·장비·소비품·기관 지원을 다시 구성할 수 있다. 현재 시점에 획득한 성장·장비·관계·자원을 과거 사건에 소급 반입하지 않는다.

조사·피해자 구출·회수 전투 중간 지점으로 직접 캠페인 되감기하지 않는다. 사건의 캠페인 정본을 바꾸려면 조사부터 구출·회수 전투·결과 확정까지 사건 전체를 다시 진행한다.

## 정본 앵커 위치

```text
사건 수락과 기본 정보 공개
→ 출동 팀·장비·지원 선택
→ 출동 준비 확정 직전
────────────────── 정본 앵커
→ 사건 진입
→ 조사
→ 피해자 구출
→ 회수 전투
→ 결과 보고서와 정본 확정
```

정본 앵커는 사건 이전의 캠페인 상태를 보존하고, 사건 이후의 진행은 새 분기에서 폐기한다.

## 과거 상태 복원

정본 앵커에서 복원하는 항목:

- 당시 사용할 수 있던 동료와 관계 상태
- 당시 보유했던 장비·소비품·기관 지원
- 당시 능력·태그·성장 상태
- 사건 이전까지 확정된 피해자·기관·분기 결과
- 당시 일정과 진행 시점

새로 재구성할 수 있는 항목:

- 출동 동료 편성
- 장비와 소비품 배치
- 기관 지원 선택
- 당시 선택 가능했던 능력·태그 조합

소급 반입할 수 없는 항목:

- 이후 분기에서 획득한 능력과 태그
- 이후 사건에서 얻은 장비와 소비품
- 이후 형성된 동료·기관 관계
- 이후 확인한 사건 정답을 시스템이 자동 제공하는 기능

플레이어가 현재 성장 상태로 최고 랭크·업적을 노리는 목적은 캠페인 되감기가 아니라 `기록 재현`이 담당한다.

## 반복 피로 완화

캠페인 정본은 사건 전체를 다시 만들어야 하지만 다음 기능으로 반복 피로를 줄인다.

- 이미 본 비상호작용 대사와 연출 빠른 넘김
- 읽은 텍스트 자동 진행
- 조사 소단락 체크포인트
- 피해자 구출 첫 실패 즉시 재시도
- 회수 전투 패배 시 전투 시작 재시도
- 결과 확정 전 사건당 1회 출동 재개

빠른 넘김은 선택·키워드·피해·자원 결과를 자동으로 최적화하거나 건너뛰지 않는다.

## 정본 앵커 적용 범위

정본 앵커는 다음 중 하나 이상을 지속적으로 변경하는 콘텐츠에만 둔다.

- 피해자 상태와 후유증
- 동료·기관·외부 세력 관계
- 분기 결과 패킷
- 연도 결산의 책임
- 이후 사건 조건
- 핵심 괴이 매뉴얼 기록

짧은 일상 대화, 장식성 상호작용, 정본 결과를 쓰지 않는 보조 장면에는 별도 정본 앵커를 만들지 않는다.

## 보호 규칙

1. 캠페인 되감기 대상은 사건의 출동 준비 확정 직전 정본 앵커다.
2. 조사·구출·전투 내부 선택이나 턴으로 직접 캠페인 되감기하지 않는다.
3. 사건 이전 캠페인 상태는 유지한다.
4. 사건 이후 캠페인 진행은 새 분기에서 폐기하고 다시 진행한다.
5. 당시 보유 자원 범위에서 출동 준비를 재구성할 수 있다.
6. 현재 시점의 성장·장비·관계를 과거 정본에 소급 반입하지 않는다.
7. 현재 성장 상태를 이용하는 최고 랭크 재도전은 기록 재현으로 처리한다.
8. 사건 전체의 조사→구출→회수 전투 인과관계를 다시 검증한다.
9. 이미 본 텍스트와 비상호작용 연출은 빠르게 넘길 수 있다.
10. 정본 결과를 쓰지 않는 짧은 콘텐츠에는 정본 앵커를 만들지 않는다.
11. 되감기 전에 유지·폐기·공유되는 데이터를 구분해 표시한다.
12. 사건별 정본 앵커와 복원 상태는 사건 Spec에 명시한다.
13. 중간 단계 스냅숏을 조합해 유리한 상태만 남기는 혼합 정본을 만들지 않는다.
14. 구현·사람 검증·POC 통과는 별도 승인 전까지 선언하지 않는다.

## 적대적 검토

### 방지하는 실패

- 조사에서 놓친 단서와 완전한 구출·전투 상태를 임의로 조합하는 혼합 정본
- 이후 성장과 장비를 과거 사건에 반입해 캠페인 인과를 무너뜨리는 문제
- 선택 지점마다 저장 스냅숏을 만들어 QA 경우의 수가 폭발하는 문제
- 구출·전투만 재실행해 조사 규칙 이해를 우회하는 문제
- 캠페인 되감기와 기록 재현의 역할이 다시 겹치는 문제
- 사소한 일상 장면마다 분기 앵커가 늘어 저장·UI가 복잡해지는 문제

### 남은 미확정

- 접근성 완화 사용 시 최고 랭크·업적 처리
- 축별 최소·상위·최고 관문의 상세 조건
- 사건별 정상 종결 실패·치명적 결과·랭크 상한 표
- 사건별 정본 앵커가 복원할 구체 데이터 목록
- 자동 저장 슬롯·수동 저장·클라우드 충돌 복구 정책
- 최고 랭크·업적·숙련 보상 범위
- 판정 모델
- 결과·출동 준비·정본/숙련 기록·분기 슬롯 화면의 세부 UX
