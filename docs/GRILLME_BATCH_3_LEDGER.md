## 승인 Decision

### 1 / 10 — `D-2026-08-03-INVESTIGATION-MANUAL-STRUCTURED-KEYWORD-ASSEMBLY`

- 괴이 매뉴얼을 발생 조건·피해자 연결·금지 행동·구출 절차·회수 전투 대응의 5개 의미 슬롯으로 구성
- 조사에서 획득한 사건 키워드와 공통 관계자를 배치해 규칙 구성
- TRPG 《둘이서 수사》식 번호 키워드 문장은 증거를 읽을 수 있는 추론으로 정리하는 중간 계층으로 채택
- 추론문이 하나 이상의 의미 슬롯을 지지·반박하도록 연결
- 자유 메모는 제공하되 시스템 판정·LLM 파싱·자동 번역 입력으로 사용하지 않음
- 문장 표면형과 언어 중립 의미 구조 분리
- 미획득 키워드 비노출, 출처 보존, 그럴듯한 오답 후보 허용
- 일반 클리어는 최소 실행 가능 매뉴얼, S 랭크는 더 높은 확인·반증·기록 완성도를 요구 가능
- 구출·회수 전투를 자동 해결하지 않고 플레이어의 대상·순서·타이밍 판단을 유지

### 2 / 10 — `D-2026-08-03-INVESTIGATION-HYPOTHESIS-STAGED-VALIDATION-AND-FEEDBACK`

- 기본 캠페인은 단계형 가설 검증 사용
- 작성 중에는 의미상 불가능한 조합만 즉시 차단하고 정답·오답은 숨김
- 조사 소단락 또는 안전 체크포인트에서 플레이어가 검증 요청
- 피드백은 `검증 불가 / 근거 부족 / 증거 상충 / 실행 가능 후보 / 확인 가능`의 근거 상태로 제공
- 틀린 키워드 위치·정답 단어·정답 근접도는 공개하지 않음
- 동일 제출은 캐시 결과를 반환하고 새 증거 또는 실질적 의미 변경 때만 재평가
- 구출·회수 전투 전에는 준비도만 경고하고 최소 실행 가능 매뉴얼이면 진행 허용
- 실행 결과는 새 증거가 되지만 매뉴얼 자동 수정 금지
- 사건 결과 보고서에서 잘못된 관계·누락 근거·위험 사례를 상세 복기
- 구출·전투 또는 사건 종료까지 검증을 미루는 방식은 기록 재현 전용 선택 변칙으로 격리
- 지연 검증 변칙은 첫 플레이·S 랭크·핵심 업적·캠페인 전력·필수 서사에 강제하지 않음
- 접근성 기능은 같은 피드백 의미를 다른 감각·입력 방식으로 제공

## 적대적 검토 — Decision 1

판정: `FIT_WITH_GUARDRAILS`

1. **정답 누설** — 문장 틀을 최종 판정기로 쓰지 않고 5개 의미 슬롯과 분리한다.
2. **브루트포스** — 미획득 키워드 비노출·출처 보존·단계 검증을 사용한다.
3. **현지화 결합** — 언어별 문장이 아니라 의미 구조를 저장한다.
4. **카드 관리 피로** — 수량·그룹·검색·접근성은 후속 UX Decision과 사람 검증 대상으로 남긴다.
5. **핵심 행동 자동화** — 매뉴얼은 구출·전투 정보를 제공하지만 직접 행동을 대체하지 않는다.
6. **상충 증거** — 후보·확인·위험·미해결 상태는 유지하되 강등·반증 규칙은 후속 Decision으로 분리한다.

## 적대적 검토 — Decision 2

판정: `FIT_WITH_GUARDRAILS`

1. **즉시 정오 판정** — 카드 전수 대입을 최적 전략으로 만들므로 구조 오류만 즉시 차단한다.
2. **무피드백 좌절** — 안전 체크포인트에서 근거 상태를 제공하되 정답 위치는 숨긴다.
3. **근접도 오해** — `근거 부족`과 `증거 상충`을 정답 거리 점수로 사용하지 않는다.
4. **반복 제출** — 동일 의미 구조는 캐시 결과를 반환하고 더 세밀한 힌트를 누적하지 않는다.
5. **캠페인 진행 차단** — 최소 실행 가능 매뉴얼이면 위험을 감수하고 진행할 수 있다.
6. **자동 해결** — 실행 결과는 증거가 되지만 매뉴얼을 자동 수정하지 않는다.
7. **고난도 강제** — 지연 검증은 기록 재현 선택 변칙이며 S 랭크·첫 플레이 의무가 아니다.
8. **접근성 불이익** — 피드백 표현 방식만 등가화하고 정보 해상도는 동일하게 유지한다.
