- 저장·복귀·무부작용 계약 충족

### `CHANGE`

- 흐름·기록·회수·결과 이해가 일부 목표 미달
- 수정 범위가 국소적이고 코어는 유지

### `RETEST`

- 수정 뒤 같은 과제 재검증 필요

### `HOLD`

- 소프트락·저장 손실·정답 자동 제공·숨긴 기능 부작용
- 원인/매개 구분 실패가 화면 문구가 아니라 사건 정보 공정성 문제일 가능성
