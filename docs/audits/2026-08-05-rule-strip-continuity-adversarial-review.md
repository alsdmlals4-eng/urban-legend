## 1. 검토 질문

승인된 규칙 스트립이 괴이기록국의 핵심 재미인 `관찰 → 가설 → 적용 → 반증/증명 → 기록`을 강화하는가, 아니면 정답 안내 UI·화면 과밀·단계 분절을 새로 만드는가?

## 3. 핵심 재미 적합성

### 강화되는 점

- 조사에서 만든 가설이 구출·회수의 실제 행동 옆에 유지된다.
- 기억력보다 규칙 비교와 적용 판단에 집중할 수 있다.
- 새 모순을 즉시 기록해 가설이 세계에 의해 시험되는 경험을 강화한다.
- 실패가 단순 오답 판정이 아니라 어떤 가설을 적용했고 무엇이 충돌했는지 추적 가능한 위험 사례가 된다.

### 약화될 수 있는 점

- 관련 규칙 자동 선별이 지나치게 정확하면 플레이어가 무엇을 참조할지 판단하는 과정이 사라진다.
- 경고 문구가 행동 전에 결과를 확정적으로 예고하면 불확실성의 긴장이 사라진다.
- 스트립을 따라 누르기만 하면 되는 체크리스트로 만들면 규칙 추리가 절차 수행 게임으로 축소된다.

### 결론

승인안은 핵심 재미와 맞지만 다음 세 조건이 필수다.

1. 스트립은 단일 괴이 매뉴얼 권위 상태에서 파생한다.
2. 정답이 아니라 플레이어의 현재 작전 가설을 보여 준다.
3. 관측된 모순은 알려 주되 숨은 정답을 판정하지 않는다.

## 4. 접근성 공격 검토

- **색상만으로 구분 금지**: 확신·위험·모순·금지는 라벨과 형태를 병행한다.
- 키보드와 게임패드에서 스트립과 행동 UI 사이를 왕복할 수 있어야 한다.
- 텍스트 확대 시 핵심 전조·대상·행동 버튼이 가려지면 실패다.
- 모션 감소 시 흔들림·점멸 대신 정적 강조와 문구가 필요하다.
- 화면 읽기 순서가 스트립 전체를 매 턴 강제 낭독해 행동을 지연하지 않도록 의미 단위 탐색 구조가 필요하다.

현재 이 항목들은 설계 계약만 존재하며 `HUMAN_QA_NOT_RUN`이다.
