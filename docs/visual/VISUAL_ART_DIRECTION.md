# 괴이기록국 비주얼 아트 방향

> 상태: `APPROVED_PLANNING_BASELINE`
> Decision ID: `D-2026-07-31-VISUAL-ART-DIRECTION`
> 승인일: 2026-07-31
> 사용자 근거: 대화에서 직접 제공한 캐릭터·능력 시트 이미지와 “우리 그림체는 이 느낌” 지시
> 구현 권한: `NONE`
> 실제 제품 에셋 승인: `NOT_GRANTED`

## 1. 핵심 시각 문장

**현대 한국의 초상현상을 조사하는 정부기관 요원들을, 다크 현대 오컬트와 세미리얼 애니 일러스트가 결합된 성인형 비율로 표현한다.**

플레이어가 받아야 하는 첫인상은 일반 판타지 모험이 아니라 다음 세 요소의 결합이다.

1. 현실적인 현대 도시와 공공기관
2. 기록·분석·현장 대응을 수행하는 전문 요원
3. 현실 표면 아래 번지는 절제된 괴이와 마법 흔적

## 2. 캐릭터 표현

### 승인 기준

- 세미리얼 애니 일러스트
- 성인형의 슬림하고 비교적 긴 인체 비율
- 미형이되 지나치게 유아적이거나 SD화하지 않은 얼굴
- 현대 전술복, 제복, 코트, 현장 장비를 기본 실루엣으로 사용
- 동양 퇴마·서양 마법·비마법 현장 요원의 차이를 장비와 포인트 색으로 구분
- 직업과 현장 역할이 전신 실루엣만으로 구분되어야 함
- 반신·초상에서도 표정, 장비, 역할색이 유지되어야 함

### 표현 우선순위

1. 역할과 전문성
2. 세계관 소속과 현장 기능
3. 인물의 성격과 감정
4. 장식적 매력

### 금지

- SD·치비 비율을 기본 캐릭터 표현으로 사용
- 일반 중세 판타지 갑옷과 로브를 현대 맥락 없이 사용
- 과도한 노출과 성적 장식으로 역할 가독성을 약화
- 특정 상용 게임·애니 캐릭터의 얼굴, 의상, 무기, 포즈를 직접 복제

## 3. 배경 표현

- 현대 한국의 역사, 지하철, 골목, 사무실, 기록 보관실, 관제실을 현실적으로 표현
- 장소의 생활감과 공공시설 구조를 먼저 보여주고 괴이 흔적은 후순위로 배치
- 화면 전체를 판타지 공간으로 바꾸기보다 현실 공간 일부가 오염되거나 규칙을 벗어난 인상을 사용
- 공간의 위험은 조명 불균형, 반복 표지, 비정상 시간, 기록 노이즈, 소실된 글자처럼 표현

## 4. 컬러와 발광

### 기본 팔레트

- 짙은 남색
- 검정
- 먹색과 차가운 회색
- 저채도 청록

### 역할 포인트

- 현장 조사·기록: 청록·푸른색
- 동양 퇴마·위험 대응: 적색·주홍
- 서양 마법·분석: 보라
- 방호·안정화: 황금·주황
- 기억·잔향·특수 관측: 옅은 청색·백색

포인트 색은 캐릭터 전체를 덮지 않고 장비, 문양, UI 상태, 효과 순간에 제한적으로 사용한다.

### 발광 규칙

- 평상시에는 저강도
- 단서 획득, 위험 예고, 규칙 위반, 가설 연결, 회수 성공 순간에만 강화
- 발광이 본문, 얼굴, 선택지, 기록 원문을 가리지 않아야 함

## 5. UI 시각 언어

- 기록국 내부 문서, 사건 파일, 관제 단말기, 현장 태블릿의 혼합
- 얇은 선과 어두운 반투명 패널
- 본문과 선택지는 장식보다 가독성을 우선
- 카드와 패널은 실제 행정·기록 분류의 질서를 느끼게 하되 현실 기관 UI를 그대로 복제하지 않음
- 상태는 색만으로 구분하지 않고 아이콘, 문구, 형태를 함께 사용
- 일반 플레이 텍스트 노벨 화면과 가설 보드·회수·준비·결과 전문 화면의 시각 계층을 공유

## 6. 그림체와 텍스트 노벨 결합

조사·일반 플레이에서는 다음 비중을 기본으로 한다.

- 장소 배경: 상황과 공포의 맥락
- 캐릭터 초상·반신: 대화와 동료 반응
- 서술·대사: 핵심 플레이 정보
- 선택지: 판단과 비용
- 초현상 효과: 위험·기록 변화 피드백

캐릭터 전신 일러스트를 모든 대화 화면에 상시 배치하지 않는다. 전신은 요원 소개, 편성, 결과 컷, 핵심 연출에서 사용하고 일반 조사에서는 반신·초상을 우선한다.

## 7. 이미지 레퍼런스 경계

사용자 제공 이미지는 다음 용도로만 사용한다.

- 그림체의 밀도와 인체 비율
- 현대 전술·오컬트 의상 결합
- 역할별 색과 능력 연출 분리
- 캐릭터 시트와 UI 카드의 조합 감각

금지:

- 제공 이미지 자체를 제품에 포함
- 이미지 속 인물, 장비, 문양, 레이아웃을 그대로 복제
- 원작 또는 제작자를 확인하지 않은 상태에서 상업 에셋으로 사용

실제 제작 이미지는 고유 캐릭터·의상·기관 문양·괴이 효과로 새로 설계하고 권리·유사성 검수를 거친다.

## 8. 현재·미정 구분

### CURRENT / APPROVED

- 다크 현대 오컬트
- 세미리얼 애니 일러스트
- 성인형 슬림 비율
- 현대 기관 요원과 역할별 포인트 색
- 기록국 문서·단말기형 UI
- 절제된 발광과 현실 공간의 부분 오염

### INFERRED

- 일반 조사 화면은 반신·초상을 중심으로 하고 전신은 특별 화면에 제한
- 캐릭터별 역할색은 UI 상태색과 연결하되 정답 신호로 사용하지 않음

### 미정

- 정확한 색상 코드
- 폰트 패밀리와 크기 체계
- 캐릭터 전신·반신·표정의 최종 제작 규격
- 배경 렌더링의 붓터치와 사진적 질감 비율
- 애니메이션 프레임과 Live2D 사용 여부
- 최종 키아트와 상점 이미지 규격

## 9. 검수 체크

- 괴이기록국 요원으로 보이는가
- 현대 한국 배경과 충돌하지 않는가
- 역할이 실루엣과 포인트 색으로 구분되는가
- 세미리얼 성인형 비율을 유지하는가
- 발광과 장식이 텍스트 가독성을 침범하지 않는가
- 일반 판타지·사이버펑크·특정 IP 모사로 흐르지 않는가
- CURRENT와 신규 제안이 구분되는가
- 원출처·권리·유사성 확인 전 제품 에셋으로 승인하지 않았는가
